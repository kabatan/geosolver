# Evidence Register

EVID-01 through EVID-11 were extracted before the clean rewrite and remain
research priors, not accepted truth. New evidence produced in this repository
is explicitly marked as reproduced and links to its replay artifacts.

| ID | Prior observation | Initial implication |
|---|---|---|
| EVID-01 | With 32 local solves, residual-ranked starts found far fewer true roots than Sobol; topographical starts found more. | Reject residual-only ranking; retest soft topology. |
| EVID-02 | A 12-root synthetic family favored topographical starts over Sobol at equal launch counts. | Create a counterexample-controlled discovery experiment. |
| EVID-03 | Hard APOSMM-like suppression lost close roots; independent starts recovered them. | No hard heuristic discard; preserve independent insurance. |
| EVID-04 | Target+branch archive retained far more answers than an x-only capped archive. | Prioritize reversible multi-view archive research. |
| EVID-05 | Only 229 of 4,224 high-precision refinements were accepted. | Duplicate refinement suppression is a major cost target. |
| EVID-06 | Residual scaling roughly halved evaluations. | Study scaling first in fixed-start local experiments. |
| EVID-07 | Naive homotopy/lifting did not improve results; barriers produced boundary false values. | These remain failure-targeted experiments, not defaults. |
| EVID-08 | Strict-boundary near-zero convergence persisted across exploration policies. | Guard validation is independent from discovery. |
| EVID-09 | A direct typed kernel matched a reference to about 1e-15 and indicated large speed potential. | Compiler economics precede global-policy selection. |
| EVID-10 | Primitive registries/backends were fragmented and branch names leaked across layers. | Plugin conformance and Core/Geometry separation are gates. |
| EVID-11 | Dynamic safe evaluation was materially slower and semantically brittle. | No eval/dynamic expression execution in production kernels. |
| EVID-12 | The preregistered dimension/rank/condition LM/TR route improved development P_local_gold by 0.65 points with no truth regression, but its fully charged warm wall was 3.03 times the simple TR control. | Reject ROUTE-LMTR-A1 at the development freeze gate; do not materialize locked inputs. |
| EVID-13 | **Reproduced:** EXP-JAC-001 found zero dense/colored mismatches and 43.81% sparse oracle-work reduction, but 14.78% dense warm overhead and 25.48% maximum cold-coloring fraction failed the registered gates. | Keep coloring dormant and production dense; see `research/results/EXP-JAC-001/summary.json`. |
