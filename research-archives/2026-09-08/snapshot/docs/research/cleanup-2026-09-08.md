## 復元

削除した8本の旧起動コードを読むには、例えば次を使います。旧計画の全ファイルhashを照合する場合は、整理前commitの別checkoutを使用してください。

```bash
git show 0d384cac3:benchmarks/algebra_large/catalogue/reference-schedule-v16/resume.py
```

過去のraw runを読むrunnerを使用する前に、該当campaignを復元します。以下は最終候補 `final-v4` の例です。アーカイブは `<campaign>/runs/...` の相対パスを保持しています。

```bash
tar -xzf benchmarks/local-evaluation/solver-improvement-20260907/archived-runs/final-v4.tar.gz \
  -C benchmarks/local-evaluation/solver-improvement-20260907
cd benchmarks/local-evaluation/solver-improvement-20260907/final-v4
sha256sum -c SHA256SUMS
```

各archiveの隣には `<campaign>.files.json` として元ファイルごとのSHA256も保存しています。archiveのhashは本記録のJSONから確認できます。
