# GPT-5.6 Sol Pro：固定円上点から直線を作る構成の点検

2026-09-11 JST、サイドブラウザの同一会話「数学的反例導出点検」。モデル表示5.6 Pro、回答内もGPT-5.6 Sol Pro。readonlyプラグインと基準commit e703e2d99を指定。ソース実行・変更は依頼していない。回答の思考時間表示11分52秒。これは必須のGPT-6監査4回には数えない。

## 指摘と扱い

1. 共通接線の接点で、二つの円周点の一次移動は接線方向。その二点から作る**正規化された**直線の一次変動はゼロ。生の斉次直線係数には尺度方向の変化が残るので、raw coefficientの微分をそのまま使わない。単位接線に対する符号付き接触座標のJacobianは対角、絶対値4,3,4,3。
2. 面積の二次形式は階数2。円Bの角度e,gには二次感度、円Aの角度d,fだけを変えると二次・三次項が消える。公開残差rhoに対して面積の一次項は `-12 sqrt(2) (rho_LB+rho_RB)`。全方向q=2下界は反証される。
3. 半径4,3、中心間距離3は二円が交わるため、共通内接線は存在しない。余分な正確な接線枝より、D=E（円同士の交点）、左右同一直線、平行線、角度周期の退化が問題になる。正解の接点はCから底辺までの線分上で円Bが1/2、円Aが2/3の位置にある。
4. 両円を横断する一つの物理直線に4通り、左右一対に最大16通りの角度持上げ。16個を独立配置や16倍の計算予算として扱わない。物理配置をclusterとし、各シートの経路を残す。実持上げ不能、guardで除かれるシートも棄却理由付きで記録。
5. 左右線の向き反転はsigned残差の行符号を変えるだけで、理想的LMでは不変である。角度と弧長の尺度、公開差と安定二次式とsigned一次式、incidenceの丸め、退化marginも分離する。
6. Guts17と同じ抽象的な接触機構だが、固定直線上点→円と固定円上点→直線という異なる構成DAG。第三の独立した新機構とは数えない。

## 独立確認

`benchmarks/solver_analysis/check_line_area_jets.py` はGeoSolverをimportせず、直線交点の行列式から面積を構成してSymPyの厳密微分・Taylor展開を行った。結果は `../unknown-intake/cemc-line-area-jet-proof-v1.json`。

面積の物理直線パラメータ微分を確認し、さらにd,f単独方向の四次係数が正の `81 sqrt(2)/4`、e,g方向の二次係数が `-18 sqrt(2)` と分かった。したがって単に「q>=4かもしれない」ではなく、軸方向では厳密にq=4。同一問題の二次方向と四次方向では目標誤差の符号も異なる。これは入力からの数学的予測として記録し、未知solverの出力は未使用。
