## 1. 修正したもの

### 数値採点

`qwen/answer_check.py` に、入れ子の分数・根号を構造として読むCPU用採点器を実装した。例えば `\dfrac{5\sqrt{7}}{2}` は正しく `5*sqrt(7)/2` と読む。学習報酬と診断の両方でこの採点器を共用する。

- exactな数式の同値で採点し、任意の最後の数字や中間式を正解として拾わない。
- 最後のboxedが不正なら、前の都合のよいboxedへ戻らない。
- 思考タグが閉じていない回答、未知の構文、変数、非有限値は未解析とする。
- 不正な正解ラベルはエラーにする。未知のLaTeX命令を削除して別の値に変換しない。
- 正解に極めて近い小数を、exactな正解とみなす旧許容誤差は廃止した。

「未解析」は数学的に誤りと証明されたという意味ではない。今回の監督は数値完全一致であり、対応していない表記は未解析として記録する。

### 数値例の生成

`authoring/variant_templates.json` に主学習37配置の文章と数値スロットを固定し、`gen_variants.py` は数値だけを差し替える方式へ変更した。全文照合により構成・条件・問いの欠落や、解法のヒントの混入を拒否する。

修正対象にはH07のEの定義、H14の円の定義、DA09の内心Iと枝条件、DB15の問いの欠落、H13/HX01への補助関係の追加がある。DA09の等しい二辺など、連動する数値も明示的に管理する。

元の座標構成を再生し、shape変種は独立した短い関係式とも照合した。相似変種は検証済み元配置の正の倍率と量の次数で処理する。処理時間切れを理由に相似例へ黙って置き換える動作は廃止した。新規生成で相似例を許す場合は `--allow-similarity` が必要。

さらに元の代表例にも不等辺条件の不備を発見し、条件を弱めずに修正した。

| 配置 | 修正 |
|---|---|
| H07 | AB=8、ON=8√10/5、MF=3、面積9へ再設定。文章の構成は維持 |
| H08 | AP=6、AC=3√34/2、tan∠BAQ=3/5、面積27/2へ再設定 |
| DA05 | 与条件BC=12、MD=4、答え5は維持。不等辺になる実在例へ交換 |
| HX01 v1/v2、H07 d1 | 承認済みの不等辺条件を満たす別の数値例を生成 |

H07/H08の研究者用解法、計算欄、存在例、学習用出力、レビュー画面も更新した。DA05の旧存在例が二等辺だったことは、問題そのものが不適切であることとは異なる。同じ与条件を満たす不等辺の実在例を再構成できたため、数値問題は変えていない。

修正後は148学習問・37評価問。旧版から本文122件、ラベル9件が変わった。本文変更には表記の復元も含み、122件すべてが誤問題だったという意味ではない。同じ配置・同じ数値の重複は0件。

shapeという分類も、全変種が互いに非相似であることまで保証するラベルではない。今回は修復と透明化を行い、独立な配置数や数値的多様性が増えたとは主張しない。この構成比のまま研究用本学習を再開する判断は保留する。

## 2. 過去の数値回答の再採点

**新しい問題に古い回答を当てはめてはいない。** 旧問題に対する保存済み回答を旧ラベルで読み直し、問題自体に不備があるものは別に扱った。

| 集計 | base | trained | 差 |
|---|---:|---:|---:|
| 旧採点（参考） | 38/148 = 25.7% | 42/148 = 28.4% | +2.7pt |
| 採点器だけ修正した全回答 | 45/148 = 30.4% | 49/148 = 33.1% | +2.7pt |
| 問題・条件・ヒントに懸念のある7配置を除外 | 35/120 = 29.2% | 38/120 = 31.7% | +2.5pt |

新たに正解となったものは両モデル7件ずつ。除外した配置はH07/H08/H13/H14/HX01/DA09/DB15。H08は元の相似例の実在証拠が不等辺条件を満たさないため、適格な評価例と認定していない。DA05は同じ条件を満たす別の実在例を確認できたため除外しない。

H07の旧dev本文はE=AP∩BQ、すなわちE=Nなので、記載どおりなら面積32/15。baseの2回答、trainedの3回答がこれに一致している。これは誤ったラベル16/3への採点と別欄に記録し、修正版H07の成績として流用しない。

配置単位で20,000回resamplingした探索的bootstrapの95%区間は、全回答の差で **−5.4〜+10.8pt**、除外後で **−7.5〜+12.5pt**。同系列配置間の依存も残り、除外後集合は事後的な品質確認である。この区間を正式な新規テストや効果の上限とは扱わない。

修正後も、明確な数値性能の改善を示す結果にはならない。ましてこの数値差だけでは、未提示の幾何的性質・証明への転移は示せない。

## 3. 証明80回答の再評価

モデル名・sample番号を隠し、80回答を固定順序にshuffleして全件を読んだ。全80件の判定と根拠を書き、hashを固定した後にモデル名を戻した。採点対象は最終回答であり、思考中の未採用の議論を後から補って正解にはしていない。

ただし、同じレビュー担当が以前の監査で一部答案を見ている。**完全に独立した人間による盲検ではなく、今回の読み直し時にモデル名を伏せた探索的評価**である。

基準は、一般の配置について核心を論証したものだけを完全正解とする。座標解法も同じく正解。「Humpty/Dumptyだから」だけでは不可。普通の交点計算・式への代入は、具体的な一般式が正しく提示されていれば通常の計算省略として許す。局所的な誤記を直せば完成するものは別分類にした。

| 問題 | base 完全正解 | trained 完全正解 | 補足 |
|---|---:|---:|---|
| EV02 | 3/4 | 2/4 | trainedに局所計算・表記誤り2件 |
| DU01 | 0/4 | 0/4 | AKと補助構成を結ぶ核心が未証明 |
| OB01 | 2/4 | 2/4 | 一般座標の円の方程式・根軸による証明 |
| AP01 | 0/4 | 0/4 | Fの共円性に至る核心が未証明 |
| N01 | 1/4 | 0/4 | baseに円の方程式による証明 |
| N02 | 1/4 | 0/4 | 両モデルに局所修正で完成するもの各1件 |
| **ヒントなし計** | **7/24** | **4/24** | 6題。24個の独立な数学的題材ではない |
| EV02_hint | 0/4 | 3/4 | 改善は座標解法。1件は指定補助点も座標で利用 |
| DU01_hint | 1/4 | 0/4 | baseの一般座標による証明 |
| OB01_hint | 0/4 | 0/4 | H/P/Mへの言及は両モデル4/4だが核心未証明 |
| AP01_hint | 0/4 | 0/4 | 指定されたALの中点とFを結べていない |
| **ヒントあり計** | **1/16** | **3/16** | 4題に対する別プロンプト条件 |

ヒントなし・ありは同一課題に依存するので、一緒にして独立な10題として検定しない。完全正解はすべて座標解法だった。trainedのEV02_hintに、有効な補助点を座標で使う例はあるが、これだけでHumptyの性質を学習で獲得したとはいえない。

N02 base sample0は、冒頭の座標設定を以後の計算と統一すれば完成するため「局所誤り」。OB01_hint trained sample1は、根軸の式が正しい形でも記号の定義と円の式の導出が欠けるため「核心不足」。DU01_hint base sample3は、一般の外心と接線交点からの傾きを提示しているため通常の代数省略として正解。この3件は境界例として明示した。

baseのEV02 sample2には、正しい証明の後に最終式を763回繰り返す出力がある。数学的正しさとは別に品質上の問題として記録した。これを学習による劣化とするものではない。

**正誤とも小標本なので、全体の改善・悪化や「害がない」を断定しない。** 新しい幾何的能力の獲得を支持する証拠は今回も不足している。
