# 今回の「別問題」の範囲

主評価の12構図IDは、完結OPDの8構図にもコード・数値SFTの7構図にも含まれない。
同じ構図の数値変更や証明への形式変更を主評価として数えない。
各構図について元の数値条件1つを2推論seedで解く。従って12構図・24答案であり、
24独立問題、2つの独立学習、未知の定理12種類の発見とは呼ばない。

全体としてHumpty／Dumptyとその周辺の幾何であり、関連領域内の転移を測る。
下表は既存catalogueの構成と幾何解法に基づく解釈用の整理で、距離の定量指標ではない。
これらの解法を学習教師や評価promptに追加するものではない。

| 評価構図 | 学習構図との関係と、新たに必要な処理 |
|---|---|
| H02 | Humpty点の共通弦に由来する、動く円の中心の軌跡・射影。H01の垂足やH13の中心距離と関連するが構成と求値が異なる。 |
| H03 | 二等分線から定義した3つの点を垂足と同定し、直径HGの円とEuler線を結ぶ。 |
| H08 | 二接円の交点の鏡映と等角関係から面積を求める。H07/H15と構成要素が関連する。 |
| DA03 | Dumpty配置で現れる接線を同定し、方べきへ結ぶ。H04の方べき計算とは接線の構成が異なる。 |
| DA06 | Dumpty配置の直角性と鏡映でOEをODへ結ぶ。 |
| DA15 | 垂直二等分線と中線から作る点の共円性を用いる。 |
| H12 | 2つのHumpty配置を持つ四角形から垂直性を導き、距離の差を求める。 |
| DA07 | HumptyとDumptyの両方を含む2組の円から平行性・相似を導く。 |
| DA11 | 中点での接円を相似でDumpty配置へ結び、第三の円の半径を求める。 |
| DB01 | 積条件で決まる円の接触を示し、共通外接線の長さを求める。 |
| DB08 | 角指定の横断線から隠れた接線を同定し、方べきへ結ぶ。 |
| DB16 | symmedian方向から2つの外心の中点を同定し、中線長を求める。 |

`related_construction` と `different_construction_or_composition` は探索的な整理であり、
後者を定理族全体の分布外評価とは解釈しない。同じ方べきや中点公式を最後に使っても、
その公式を使える関係を与条件から導くことは、最終数値の正答とは別に監査する。
例えば「隠れた接線」があるとだけ主張して平方根を取った答案は、数値が一致しても、
その関係の根拠がない限り十分な導出とは扱わない。

題材自体は既存研究用catalogueから選んでおり、過去の別実験で参照されたものを含む。
今回の追加学習から除外したことは確認できるが、基盤モデルの事前学習からの除外や、
研究者が一度も見ていない新規テスト集合であることは保証しない。

この比較で改善が出れば、直接教えていない別配置の数値求値を改善する小規模な材料となる。
人間に未知の領域への応用、一般法則を新たに獲得したという機序、未知定理の発見は
この結果だけからは結論しない。陰性の場合もsolver＋機械学習一般の不可能性とはしない。
