# GMBの「成功」の定義と許容誤差の切り分け（既存の記録の再集計、計算の再実行なし）

対象は、GMB の記録4つです。
- 既定設定（eps=1e-3）：`gmb-imo39-seed0-cpu4-20261022`（seed 0）と `gmb-imo39-seeds1-2-cpu4-20261022`（seed 1・2）。独立検査器の結果は `gmb-geosolver-campaign-20261022/assessment`。
- 厳格条件（eps=1e-8、regularize_points=0、n_iterations=100000）：`gmb-strict-seed0-cpu4-20261022` と `gmb-strict-seeds1-2-cpu4-20261022`。独立検査器の結果は `gmb-strict-comparison-campaign-20261022/assessment`。

「既定設定の gmb-comparison-20261022」という名前の記録はこのPCにありませんでした。既定設定は、上の `gmb-imo39-*` と、それを検査した `gmb-geosolver-campaign-20261022` を使いました。

各 seed に36問（表現非対応3問を除く）、合計108試行です（表の trials は非対応3問を含む）。独立検査器の対象は、各記録の生の出力（reused_official）です。補正版の入力2問の新規6試行は含みません。

## 言葉の定義

- (a1) GMBがモデルを返した：`outcome = model_returned`（期限内に正常終了し、1個以上の配置を返した）。
- (a2) GMBの自己検査を通った：返したモデルのうち、GMB自身の評価値がすべて eps×10 以下（`all_goals_passed = True`）。論文の「モデルを作れた」に近い定義です。自己検査の許容は、既定で 0.01、厳格で 1e-7。
- (b) 独立検査器（80桁）を通った：許容誤差 1e-3 / 1e-6 / 1e-9 のそれぞれ。

※ 「モデルを返した」95（既定）・47（厳格）のうち、各3試行（IMO_2015_P3 の seed 0・1・2）は、比較では入力を原文に合わせた版に差し替えたため、元の生の出力は独立検査器の対象外です。この3試行は GMB の自己検査では「通った」扱いです。上の (b) の数は、この3試行を含みません（通った扱いにしていません）。

不等式・条件の違いだけが原因の試行は、1件（厳格の IMO_2018_P1 seed 1）だけです。枝の違い（交点の witness など）だけが原因の試行は1件もありませんでした（検査器の失敗理由に `invalid_intersection_witness` は現れますが、等式の失敗と同じ試行です）。

## 読み取れること

1. **許容誤差の違いが主な原因です。** 通らなかった試行は、77件中76件が等式の残差で、残り1件が鋭角の条件の違反です。枝の違いが原因の試行はありません。
   - 既定では、誤差が 1e-3〜1e-2 の試行が35件あります。これは GMB の自己検査の許容（eps×10 = 0.01）の内側です。GMBは「成功」と判定し、独立検査器は 1e-6 で落としています。
   - 厳格では、誤差の大きい13件が 1e-6〜1e-4 に集まっています。GMB の自己検査の許容（1e-7）は通っていますが、独立検査器の1e-6 には届きません。GMBの内部計算が検査器より粗い可能性がありますが、内部の計算精度は確認していません。
2. **成功の定義の違いも効いています。** 既定で、(a1)=95、(a2)=74、(b 1e-6)=30 と段階的に減ります。論文の 93.52% に近いのは、(a1)（モデルを返した、88.0%）や (a2) の定義で、独立検査器で 1e-6 を課した値（約28%）とは、約2.5倍の差があります。
3. 許容誤差を 1e-3 にゆるめても、35.2% にとどまります。誤差の大半が 1e-3〜1e-2 にあるためです。
4. 論文の 93.52% の分母（問題数、試行、時間制限の有無）は、このPCの資料からは確認できません。したがって、論文の値との差を、定義と許容誤差にどう配分するかまでは、ここでは言えません。

## 注意

- 同じ入力（GMB公式の36問）、seed 0〜2、各1回（180秒、CPU4固定）です。
- 独立検査器の判定は、数値検査であり、定理の証明ではありません。
- 列の詳細は `per-trial.csv`（試行ごと）と `summary.json` を参照してください。
