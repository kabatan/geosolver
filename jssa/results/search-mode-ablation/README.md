## 読み取れること（1 seed の記述的比較）

- 正解数は scipy_multistart が最も多く、既定より11問多いです（既定だけが解いた問題が3問、scipyだけが解いた問題が14問）。
- 一方、時間は約5倍です（両方が解いた305問の時間の中央値は 3.69秒 対 13.90秒）。評価回数は約60倍で、評価失敗の合計も約9倍です。
- disco_mads と mads の差は、正解数で1問、時間でほぼ同じです。ただし各1 seed で、既定だけが解いた問題が8問、madsだけが解いた問題が9問あり、差は seed のばらつきの範囲内と考えるべきです。DiscoMADS（不連続を考慮する設定）の有利さは、この計測では示せていません。
- したがって、この結果から言えるのは「NOMADは速い（時間が約1/5）」であり、「NOMADは正解数で勝つ」とは言えません。
