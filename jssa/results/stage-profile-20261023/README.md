# 段階別プロファイル（既存の本計測の記録から、再実行なし）

- 対象: 本計測 `jssa-main-j6-20261022`（凍結版 60db4b6、323問×seed 0〜2＝969実行、1問1コア180秒、6並列）。
- 方法: 各実行の記録（`solver_result.diagnostics`）に入っている `phase_timings`（段階ごとの時間）、`pipeline_summary`（候補数の流れ、採用された候補のID）、`counters` を集めただけ。solverは動かしていない。スクリプトは `stage_profile.py`、出力は `stage-profile-output.txt`、実行ごとの表は `stage-profile-main-j6.csv`。
- 段階の時間は互いに重ならない（例：AIME 2015 I-7 seed 0 は各段階の和 138.8 秒、実時間 140.4 秒）。

## 分かったこと

| 項目 | 結果 |
|---|---|
| 全969実行の時間の内訳 | 探索 18.9%、高精度化（LM）50.9%、厳密値同定・検証 29.1%、救済 0.8%、初期サンプリング 0.3% |
| 30秒を超えた140実行で最も時間を使った段階 | 高精度化 91、探索 26、同定・検証 23 |
| 段階ごとの時間（探索を行い正解した実行） | 中央値：探索 0.87秒、高精度化 1.23秒、同定 2.03秒。90%点：探索 2.5秒、高精度化 20.8秒、同定 13.2秒 |
| 答えになった候補の出どころ（正解959実行） | 第1回探索のNOMAD 471、代数的前処理 292、作図の直接評価（d=0） 93、SciPy探索 74、救済探索のNOMAD 21、その他 8 |
| 第2回の探索（hybrid）が選ばれた実行 | 32 |
| 解析的ヤコビアン | 要求した704実行のうち572実行で、全要求が「非対応」（数値差分を使用） |

## 事例

- AIME 2015 I-7（3 seedで128〜179秒）：探索は1.3〜27秒。時間の大半は、高精度化（74〜96秒）と同定・検証（47〜54秒）だった。seed 0 では、56候補を高精度化して収束したのは2候補。残り54候補は検証で偽候補として棄却された。答えの候補は救済探索（seed 0・2）と、SciPy探索（seed 1）から来た。解析的ヤコビアンは全要求が非対応だった。
- HMMT 2019年2月 幾何10番（1.3〜1.7秒）：作図の直接評価だけで、探索も高精度化もない。

## 注意

- これは「どの経路で答えが出たか」の観察で、各機構が必要だったかどうか（因果）は示さない。
- 第2回の探索は、第1回で解けなかった実行でだけ動くため、出どころの数を機構の優劣として比べてはいけない。
- 6並列で測った時間なので、別の計測と秒数を直接比べるときは条件の違いに注意する。
