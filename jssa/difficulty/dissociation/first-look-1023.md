# 二重の解離：最初の確認（10/23、再実行なし）

データ：当たる確率 p（probe323-seed1、200出発点、探索変数のある292問）、DSLから数えた量（feat.csv）、Easy2Hard の人間難度（p のある109問：AIME 43問、HMMT 66問）。「探索の難しさ」は −log p で表す。値は順位の偏相関で、[ ] は問題を単位にしたブートストラップの95%区間。

| 関係 | 全292問 | AIME | HMMT |
|---|---|---|---|
| −log p と作図の数（d をそろえる） | 0.06 [−0.06, 0.18] | | |
| −log p と作図の数（そのまま） | 0.01 | −0.02 [−0.31, 0.25] | 0.08 [−0.17, 0.32] |
| −log p と d（そのまま） | 0.54 | | |
| 人間難度と作図の数（−log p をそろえる） | | **0.43 [0.15, 0.64]** | **0.30 [0.05, 0.52]** |
| 人間難度と −log p（作図の数をそろえる） | | 0.27 [−0.04, 0.55] | 0.14 [−0.10, 0.36] |

## 読み取れること
- solverの探索の難しさ（当たる確率）は、作図で決まらない自由度 d で決まる。図の大きさ（作図の数）とは無関係である。
- 人間の難度は、図の大きさで増える。solverの探索の難しさとは、図の大きさをそろえると、はっきりした関係が残らない。
- solverの時間全体（log C）には、d をそろえても作図の数が少し効く（AIME 0.48、HMMT 0.22）。経路は探索ではなく、探索の後の精密化と同定だと予想する。精密化と同定は時間の75%を占める。これは次に確かめる。

## 注意
作図の数は、AIが書いたDSLから数えた「図の大きさ」の代わりの量である。人間の難度は問題番号と強く連動する（ρ 0.87／0.94）。
