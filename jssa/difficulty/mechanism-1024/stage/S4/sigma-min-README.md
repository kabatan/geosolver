# 最小特異値の追加計測

記述的な計測のみ。対象はS4の `per-problem.csv` で `status=ok` の8問。
S4が保存した参照座標をそのまま再利用し、参照解の再作成・精密化はしない。
S3の結果ファイルは開かない。

- 凍結版の読込後の全残差を使う。接条件以外の元条件、読込時の追加行、距離0の座標差、半径の補助式を含む。後者2種類はT0・T1・T2とも既定の「あり」とする。
- 接条件だけをS4の式に置き換える。T1は直線円の符号付き距離の2乗−半径の2乗、円円の近い方の符号付き距離差（同値なら外接側、枝は参照点で固定）。Distance形式も同じ直線円の式。T2は凍結版の構文判定が返す接点式を使い、返さない条件はT1のまま。
- 凍結版の精密化用関数が元残差へ戻る場合も、指定されたT1/T2式を明示的に評価する。関数との照合値と復帰回数を詳細JSONに残す。
- 元条件由来の行はS1の保存済み固定除数を継承する。距離0を分けた2行も同じ親の除数を使う。S1にない追加行は、同じ保存初期候補の正確な二進float座標を700桁で評価し、`max(1, 有限な|左辺|, 有限な|右辺|)` を候補全体で取る。評価不能なら1。参照解から除数を作らず、T1・T2で共用する。行対応・除数を詳細JSONに保存する。
- 微分・特異値分解は200桁演算。探索変数を独立に動かし、構成を再評価する。変数の再尺度化や他の等式への射影はしない。中央差分の幅はS4と同じ `h_j=10^-70 max(1,|u_j|)`、照合幅は `10^-60 max(1,|u_j|)`。
- CSVの行数は全残差行数。非ゼロ行数は各幅の中央差分行に厳密な非ゼロ値が1つ以上ある行数（閾値なし）。ゼロ行だけを分解前に除く。非ゼロ行数m、変数数nに対し、m≥nならn個の最小、m<nなら不足するn−m個のゼロを補った最小を記録する。全特異値は常にn個、昇順。これは探索変数側の `J*J` の平方根に相当する定義で、計算は直接SVDを使う。数値的に小さい値をゼロに丸めたり、追加の階数判定をしたりしない。
- 「2つの幅での一致」は対応する全特異値について `|a-b|/max(|a|,|b|) ≤ 10^-40`（両方0なら一致）、かつ非ゼロ行数が同じ場合。両幅の全特異値、最大絶対差・最大相対差も保存する。200桁は演算精度であり、差分や保存値の200桁の正確性を意味しない。
- T0は測らず、各問題のCSV行に「T0：折れ目で微分できない」とだけ記録する。

`sigma_min.py prepare` が入力・コードのSHA-256を `sigma-min-hashes.json` に記録し、`sigma_min.py measure` が照合してから計測する。並列1、1コア、内部1スレッド。CSVと `sigma-min-details.json` に両幅の測定値、全ヤコビ行列、残差行の対応、凍結版T2全残差との照合、SVD再構成誤差を保存する。
