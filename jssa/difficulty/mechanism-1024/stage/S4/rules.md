# S4 (1)：判定前の固定規則

事前登録11の(1)のみ。K1〜K3の文言・閾値を変更しない。S3ではpreregistration-11.mdだけを読む。S3の結果・実行コードは読まない。

- 対象・順序はS1の12問。元DSLの各IsTangent=0、およびDistance(中心,直線)=半径の等式を条件単位とする。条件番号は元DSLのconditionsの0始まり。式と構文上の接点判定も保存する。
- 参照図の選択は数値判定前に固定する。S1保存記録でBASE、NO_RESIDUAL_REWRITEの順に、最初のfinal_pass=Trueの候補を一つ選ぶ。最良目標値による選択や図の交換はしない。通過候補がない場合は「参照解を作れず」。S1の検証は返却座標を保存していないので、当該候補だけを同じ凍結版verify_final_candidateで再検証し、verified=Trueのvaluesを回収する。通過しなければ欠測。
- 参照解の作成に限り、S2と同じ凍結版_run_findroot_closureを一度使う。620 dps、smooth_zero_constraints=True、target_residual=1e-580、solver_tolerance=1e-1160、max_steps=1240、180秒。探索・別候補・再試行なし。凍結版srcを変更しない。参照解作成以外の精密化、T1/T2を比較する精密化実験は行わない。
- 620有効桁で保存した座標を再読込し、620 dpsで元の全残差ノルム<=1e-580、hard_feasible=True、有限の目標値を確認する。S1と同じ独立参照式を凍結版_eval_exact_to_mpfで700 dpsで評価する（high_precision_modeの外）。最も近い参照値との絶対誤差<=1e-200、相対誤差<=1e-200をともに要求する。作業精度>=300 dpsであり、実測一致も記録する。座標自体の620桁すべての正確性や解の存在の厳密証明は主張しない。門を通らない場合は「参照解を作れず」とし、低精度・未検証図・厳密式からの別図で代用しない。
- 微分は探索変数uそのものについて行う。他の等式が定める多様体への射影や接空間への制限は行わない。構成を通じた依存はすべて再評価する。T1の直線円は正規化された直線係数でdelta=a*cx+b*cy+cとし、delta^2-r^2。円円はd-(r1+r2)、d-|r1-r2|の絶対値の小さい側（同値なら外接側）。選択枝を参照点で固定する。Distance形式もdelta^2-r^2。
- T2式は凍結版tangency_contacts.pyのcontact_tangency_source / distance_contact_sourcesが返す式そのもの。判定に渡す構成と等式は凍結版load_problem_bundle後のもの。推測で接点を補わない。返却なしならg2・g2判定は空欄。T1は接点を一切使わない。
- 計測は200 dpsの中央有限差分。各jについてh=1e-70*max(1,|u_j|)、(s(u+h e_j)-s(u-h e_j))/(2h)。固定の照合幅1e-60でも同じ計算を行い、型判定の一致と差を保存する。両幅で型が違う、非有限、式評価不能の場合は当該判定「不定」。200桁は演算精度であり有限差分の200桁正確性を意味しない。中央差分の打切り誤差・丸めに対し閾値から十分離れた判定を行う。
- 尺度S_jは凍結版final_verifier._variable_scalesと同じmax(1,|u_j|,|推定上限-推定下限|)。g=ユークリッド勾配ノルム / max(1,S_1,...,S_n)。全変数と尺度・勾配成分を保存する。0変数なら勾配0。閾値はg<1e-50が重根型、g>1e-10が単根型、その間（境界を含む）は不定。
- 型R：T1が重根型かつ同じ条件のT2が単根型である条件を一つ以上持つ。型S：対象条件が一つ以上あり全てT1で単根型。その他は型U。参照解を作れない場合はU（欠測）と明記し、重根の実測と混同しない。固定構成だけからなる恒等的な条件も除外しない。
- K1はS1に対する事後の確認。大改善5問はS1のp1_met=Trueの5問、差20桁以内の5問は元のP2指定5問（p1_group=False）。S1の「高精度」は固定済みP1と同じ目標値絶対誤差<=1e-100とする。S1はT0/T1分離前なのでNO_RESIDUAL_REWRITEの値をT0側の証拠として使い、T1値は推定しない。既知の反例があればK1「外れ」、反例なしで必要な欠測があれば「判定不能」。K2・K3は「未判定（S3後）」。
