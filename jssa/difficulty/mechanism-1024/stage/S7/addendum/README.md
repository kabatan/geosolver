## 計算前に固定する判定規則

この節と protocol.json は片側差分の結果を計算・閲覧する前に固定し、pre-run-hashes.json に SHA-256 を保存する。閾値は結果を見て変更しない。

- 対象：段階(1) classification.csv の raw=特異 または base=特異の全問題。片側差分は raw=特異の全問題。W3の指定5問も対象に含む。
- 段階(1)と同一の保存参照座標、固定除数、rawのT1分岐を使う。新しいsolve・精密化は行わない。
- mpmath 200桁、h_j=10^-k max(1,|x_j|)、k=70,60。
- J+[:,j]=(r(x+h_j e_j)-r(x))/h_j、J-[:,j]=(r(x)-r(x-h_j e_j))/h_j、J中央=(J++J-)/2。
- 最小特異値は段階(1)と同じ spectrum：厳密ゼロ行を除き、列数に足りない特異値を0で補う。σ<1e-60 は特異、σ>1e-10 は非特異、それ以外は不定（等号は不定）。SVD再構成相対誤差<1e-170。
- 行列の片側差 g=||J+-J-||F/max(1,||J+||F,||J-||F)。各幅で、σ+ または σ- が >1e-10、または g>1e-20 なら「微分不能」。後者により m<n や別の零空間があっても cusp を見落とさない。
- 上記に該当せず、σ+ と σ- がともに <1e-60 かつ g<=1e-20 なら「特異」。残りは「不定」。両幅の分類が一致するときのみその分類を採用し、不一致は「不定」。幅別の値と理由は全件保存する。
- この「微分不能」は指定の座標方向・二幅での操作的診断。座標方向検査だけで一般のFréchet微分可能性を証明するものではない。
- W3：base中央行列から、元のbundle条件ごとの書き換えを1つずつraw中央行に戻す（補助式は1行ずつ削除）。同じ固定除数でσを計算し、非特異から特異へ変わる行群を特定する。両幅で行い、条件と変数、raw行の片側差も示す。これは図上の局所ヤコビ行列の検査であり、精密化の因果効果を測るものではない。
- 書き換えは凍結版の実際の分岐から判定する：距離0の座標差、接点（line-circle / circle-circle）、signed tangency（line-circle / circle-circle）、距離=半径の接点、正半径の補助式。全体fallbackの場合はbase適用0。rawに適用したT1は別列に記録する。
- 単独/複数の主集計はbaseに適用された種類数（0、1、2以上）で分ける。raw T1を含む種類数も別に示す。複数種類がある問題から接点以外の効果を主張しない。
