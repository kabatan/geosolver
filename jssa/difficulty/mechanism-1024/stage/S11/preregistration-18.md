# 事前登録18：出発点の数と、1回あたりの当たりやすさ p から、図を見つけられるかを予測する（S11）

固定：この文書の commit・push の時刻。S11 の実行前。

## きっかけ
S8（事前登録15、再実行後 5ff4304a）で、素朴版 N（NOMAD・第2探索・散らす選び方・書き換え・尺度・代数・解析ヤコビを全部外したもの）が、スーパーPCの53問中51問を解いた。N に残っている探索は、SciPy の多点出発（Halton の出発点 320 個から LM。範囲つきの TRF 24 個など）である。一方、1つの出発点から1回だけ局所探索すると、正しい図に当たる割合 p は低い問題が多い（minima/basins-323.csv、一様な出発点 200 個、LM の評価上限は凍結版と同じ 80）。本人の体感「工夫のない数値最適化では幾何は解きにくい」と、N の強さとの間をつなぐ説明が要る。

## 理論
出発点 k 個が互いに独立で、それぞれ確率 p で正しい図に当たるなら、少なくとも1つ当たる確率は P_k = 1 − (1 − p)^k。p = 0.05 でも、k = 320 なら P はほぼ 1 になる。つまり「1回では当たりにくいが、0ではない」問題は、出発点の数で越えられる。p がほぼ 0 の問題は、それでは越えられず、別の経路（TRF、1変数の走査、代数、有限枝の探索）が要る。

## 構成
N_k：N と同じで、Halton の出発点の数だけを k = 1, 4, 16, 64, 320 に替える（320 が N）。範囲つき TRF の出発点数などの、ほかの出発点の扱いは実行前に sol が調べ、下の「追記」に書いて固定する。

## 対象と条件
機構72問（p は全問にある。p = 0 が8問、0 < p < 0.1 が14問、p ≥ 0.5 が約30問）。seed 801〜803、180秒、1コア。「解けた」と費用は S8 と同じ定義。各実行で、答えを出した候補の出所（Halton の LM、TRF、走査、代数など）を記録する。

## 予測
- Q1：0 < p < 1 の問題で、予測 P_k と、実際に解けた割合（3 seed）との順位相関が、5つの k をまとめて 0.5 以上。
- Q2：k = 1 で解けた問題の割合は、p ≥ 0.5 の群で 0.6 以上、p < 0.1 の群で 0.3 以下。
- Q3：p = 0 の8問のうち、k = 320 で解けた問題では、答えの出所の半分以上が Halton の LM 以外。
- Q4：p ≥ 0.5 の問題では、k を増やしても解けた数は増えず、費用の中央値は k = 320 の方が k = 16 より大きい（出発点を増やしすぎる代価）。

## 読み方
- Q1・Q2 が当たれば、「1回の当たりやすさ p と出発点の数で、図を見つけられるかがほぼ決まる」と書ける。本人の体感（1回では当たらない）と、N の強さ（多くの出発点で当たる）の両方を説明できる。
- Q3 が当たれば、p がほぼ 0 の問題を越えているのは別の経路だと書ける。
- 出発点は Halton 列で独立ではない。p は一様な出発点で測っている。ずれはそのまま報告する。
