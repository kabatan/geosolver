# 事前登録19：枝の切り替わりと作図の消失が、残差の地形にどれだけ段差を作り、当たりやすさを下げるか（S12）

固定：この文書の commit・push の時刻。下の計測量 J・U は、まだ誰も計算していない。

## きっかけ
本人（10/24 18:56 JST）：幾何 solver の難しさとして挙げた点、特に複数の枝が出る部分はどうなっているか。
コード（60db4b6）：交点が複数ある作図は、入力の選び方（exclude／near／far／n）で枝を決める（intersections_selection.py）。作図が成り立たない点は評価不能（NOMAD は隠れ制約、SciPy は大きな定数残差）。選び方の余裕が0の点は不許容（_hard_feasibility_core.py の selection trace）。
記録：1回の局所探索の失敗で「別の枝の図に収束」はほぼ0件（minima）。ただし、枝の切り替わりや作図の消失が残差の地形に作る段差は測っていない。

## 計測（結果の記録は見ない。凍結版の評価器だけを使う）
対象：探索変数のある開発群292問。solver が推定する探索箱で、seed 1901 から一様に選んだ2点を結ぶ線分を200本とり、各線分上の等間隔64点で、作図と残差を倍精度で評価する。
- U：評価不能（例外・非有限・非OK）だった点の割合。
- J：線分上の隣り合う2点で、どれかの交点の選ばれた候補の番号（並べ替えた候補の何番目か）が変わるか、作図の成否が変わった回数を、線分1本あたりで平均したもの。
- J_sel：J のうち、両方の点で作図が成り立ち、選ばれた候補の番号だけが変わった回数（純粋な枝の切り替わり）。
- 交点の選び方がない問題は J_sel = 0 とする。

## 予測
- V1：J > 0 の問題が292問の30%以上ある（枝や作図の消失による段差は珍しくない）。
- V2：1回の局所探索の当たりやすさ p（minima/basins-323.csv）と J の順位相関は、探索変数の数と出発点の許容率 φ（start-feasibility の記録）をそろえた偏相関で −0.15 以下。
- V3：J_sel > 0 の問題では、J_sel = 0 の問題より、失敗終点のうち「打切り（stuck）」の割合が高い（basins-323.csv の frac_stuck、問題ごとの中央値で比較）。
  理由：枝が切り替わる線を局所探索の一歩がまたぐと、残差が跳び、差分ヤコビ行列が誤った向きを示して止まる。
- V4（記述）：derivative-free（Q32）の28問で、NOMAD と LM の当たり数の差と J の関係を示す。問題数が少なく当たりが2問に偏るので、判定はしない。

## 読み方
- V1〜V3 が当たれば、「枝と作図の消失が地形に段差を作り、局所探索の当たりやすさを下げる」と書け、solver の扱い（入力での枝の固定、評価不能点の除外、余裕0の不許容、微分を使わない探索、多点出発）がどの段差に対応するかを示せる。
- 外れれば、枝は入力で固定されているため、探索の主な壁ではない、と書く。
