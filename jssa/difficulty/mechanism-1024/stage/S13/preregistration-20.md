# 事前登録20：不等式を満たす出発点を作る工夫を外すと、満たす出発点が少ない問題ほど悪くなるか（S13）

固定：この文書の commit・push の時刻。スイッチの準備前、実行前。

## きっかけ
本人（10/24 18:58 JST）：交点の選択や順序の指定で不等式が出る。そのせいで、最適解にたどり着かない、有効な図があまり見つからない、ということが起きる。
記録（start-feasibility-1023）：一様な出発点の34%が不等式を満たさない。満たす出発点からの当たりは70%、満たさない出発点からは33%。満たす出発点だけにすると p が0.39から0.55へ上がり、上がり幅は (1−φ)(p_F−p_I) で予測できた（順位相関0.90）。
solver の工夫（inventory）：M039 不等式を満たす点を優先して出発点を選ぶ。M041 一様な点に満たすものが無いとき、線形の不等式の内点を線形計画で求める。M042 その内点から hit-and-run で内側に点を広げる。これらだけを外した比較は無い（walls-catalogue の W01）。

## 構成
- F0：凍結版。
- FA：M041 と M042 を外す（NO_AFFINE_GUARD_SAMPLER）。
- FB：M039 の「満たす点を優先」を外し、score の順だけで選ぶ（NO_GUARD_PRIORITY）。近接除去は残す。
スイッチは sol が作り、スイッチなしで F0 と出力が一致することを確かめる。実問題で FA・FB の分岐が実際に動くかも、短い試走で確かめて追記する。

## 対象
start-feasibility-1023/per-problem.csv の φ（= n_feas / starts）で分ける。
- 群Z：φ = 0 の28問すべて。
- 群L：0 < φ < 0.2 の問題から、SHA256("S13|" + id) の昇順で20問。
- 群H：φ > 0.8 の問題から、同じ規則で20問。
計68問。seed 2001〜2003、180秒、1コア。「解けた」と費用は 7b と同じ定義。

## 予測（効果 = その構成の費用の平均 − F0 の費用の平均）
- P1：FA の効果は、群Z が群H より大きい。群Z では、FA で解けた問題の数が F0 より少ない。
- P2：FB の効果は、群L が群H より大きい。
- P3：群H では、FA・FB とも、解けた問題の数は F0 と同じ。
- 完成した solver では NOMAD などが点を作るので、効果が消える可能性がある（S10 部分B ではそうだった）。その場合もそのまま報告する。

## 読み方
P1・P2 が当たれば、「不等式で有効な図が見つかりにくい壁を、solver は満たす出発点を作ることで越えている」と書ける。外れれば、完成した solver ではほかの段がこの壁を補っている、と書く。
