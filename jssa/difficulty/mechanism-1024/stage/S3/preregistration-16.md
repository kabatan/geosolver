## 目的

solver は、探索に微分を使わない NOMAD を、精密化に LM 法（減衰つきガウス・ニュートン）と信頼領域、ニュートン法を組み合わせて使う。開発の履歴は残っていないので、選んだ理由を「替えるとどの問題で、なぜ壊れるか」から再構成する。それぞれの選択を、測れる問題の性質と結び付けて予測し、確かめる。

## 部分A：精密化のアルゴリズム（同じ候補から精密化だけを比べる）

- 対象：S1 と S3 の12問と、72問（S4.6）のうち探索変数があり候補が作られる全問題。seed 0 の主探索直後の候補を保存し（S1 と同じ手順）、各構成で精密化だけを行う（各90秒）。最終検証は凍結版。
- 構成（正確な実装と環境変数は「実行前に固定するもの」で決める）：
  - R0 既定（LM と信頼領域、その後ニュートン法）
  - R1 減衰なし（純粋なガウス・ニュートン。LM の減衰を0に固定）
  - R2 減衰を固定（FIXED_LM_DAMPING。適応的な減衰の調整を止める）
  - R3 LM を飛ばしてニュートン法だけ
- 指標：精密化直後の最良候補の目標値の正しい桁数、収束した候補の数、時間。
- 問題の性質（S7 の計測を使う）：正しい図での最小特異値 σ_base、候補の初期の残差の大きさ。

予測：
- A1：σ_base が特異（< 10⁻⁶⁰）の問題では、R1 と R3 は R0 より桁数が40桁以上低い問題が半数以上。σ_base が非特異の問題では、R1・R3 と R0 の差が20桁以内の問題が70%以上。
- A2：初期残差が大きい（候補の残差の中央値が全問題の中央値より大きい）問題では、R3 が R0 より収束候補数が少ない問題が70%以上。
- A3：R2 と R0 の差は、ほとんどの問題（80%以上）で20桁以内。

事前登録15 の N と N+1（NOMAD を戻しただけ）、C1 の結果を使う。新しい実行はしない。

- 問題の性質（実行前に入力から計算して push する）：探索変数の数、不等式（ガード）の数、不等式の割合、「壁」型の罰則が働く条件の数（S5.6 の定義）、既存の記録にある局所探索の当たりやすさ p（S4.1、S5.1）。

- B3：探索変数の数だけでは、NOMAD の効果のある・なしを分けられない（中央値の差が1以下）。
