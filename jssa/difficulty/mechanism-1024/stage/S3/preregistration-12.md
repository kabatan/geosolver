# 事前登録12：正しい図での特異さから、接点を使う書き換えの効き方を未見の問題で予測する（S5）

固定日時：この文書の commit・push の時刻。下の(1)の分類を push するまで、(2)の精密化の比較は実行しない。

## 目的

S4.12 で、正しい図での全残差のヤコビ行列の最小特異値（σ）と S3 の結果が8問で対応した。ただしこれは S1 の結果を見た後に考えた計測だった。そこで、S1・S3 に使っていない問題で、σ から先に予測し、その後に S3 と同じ比較で確かめる。

## 対象（機械的に決める）

S1・S3 の12問以外で、入力に IsTangent か Distance(中心, 直線) = 半径を含む全ての問題。探す場所は benchmarks/dsl（開発群）、jssa/difficulty/unseen-2、unseen-1983、new2026、holdout-1023 の DSL。同じ問題の重複は1つにする。一覧（targets.json）を(1)の前に push する。追加・除外はしない。開発群の残りは S1 で「候補が作られない」とされた問題を含むが、(2)で候補が作られなければその旨を記録する。

## (1) 予測の固定（精密化の比較の前）

各問題で、凍結版が最終検証を通した図から参照解を作る（S4 と同じ手順、620桁、目標値が参照値と300桁以上一致）。作れない問題は「参照解なし」と記録し、予測しない。参照解で、S4.12 と同じ方法（全残差、固定除数で正規化、200桁の中央差分、2つの幅）で T1 と T2 の最小特異値 σ1、σ2 を求める。

分類（σ < 10⁻⁶⁰ を特異、σ > 10⁻¹⁰ を非特異、その間は不定）：
- 型P：σ1 特異、σ2 非特異。予測：T2 が T1 より40桁以上良い。
- 型N：σ1、σ2 とも非特異。予測：T1 と T2 が20桁以内。
- 型B：σ1、σ2 とも特異。予測：T2 の桁数は300桁未満（S3 の AIME 2002 II-14 のように止まる）。
- 不定・参照解なし：予測しない。

## (2) 比較（S3 と同じ）

seed 0 の主探索の直後の候補を保存し、T0／T1／T2 で精密化（各90秒、他は S3 と同じ）。主指標は精密化直後の最良候補の目標値の正しい桁数。

## 予測と判定

- U1：型P の問題の80%以上で、T2 が T1 より40桁以上良い。
- U2：型N の問題の80%以上で、T1 と T2 が20桁以内。
- U3：型B の問題の80%以上で、T2 の桁数が300未満。
- 各型に2問未満しかなければ、その予測は判定不能とし、個別の結果だけ示す。
- 候補が作られない問題、参照値を評価できない問題は欠測として別に数える。

外れた予測もそのまま報告する。問題数は少ないので一般化はしない。
