# 機構分析（事前登録7）の問題の組：72問

実行前に固定する（結果を見て入れ替えない）。選び方は select.py、結果は problem-set.json。

- 母集団：開発群323問。凍結版 60db4b6 の本計測（seed 0〜2、jssa/results/mechanism-attribution/attribution.csv）の記録だけを使って層を作った。
- 複数値（8問）：参照の答えが2つ以上ある問題の全件（posthoc-20/multivalue-problems.csv）。
- 遅い・不安定（48問）：複数値以外で、3 seed の時間の中央値が10秒以上、または不正解の seed がある、または第2探索か救済の探索が起動した seed がある問題（116問）から、sha256("mech1024:"+問題ID) の小さい順に48問。
- 速い（16問）：残り（遅い・不安定でも複数値でもない）のうち、3 seed とも代数的前処理が答えを出した問題（89問）から8問、どの seed でも代数的前処理と直接評価（変数0）が答えを出していない問題（75問）から8問。どちらも同じハッシュ順。
- 注意：開発群の問題なので、開発外の評価ではない。差が出やすい問題を多めに選んでいるので、この組での改善を全問題の平均として報告しない。
