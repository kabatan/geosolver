# 事前登録7b：機構分析（第2弾：新しいスイッチ2つ）

固定日時：commit・push の時刻。共通の条件（72問の組、採点、記録、「問題が解けた」の定義、集計の単位）は事前登録7と同じ。

## 構成と実行
- BASE、NO_RESIDUAL_REWRITE、NO_DIVERSE_SELECTION の3構成。BASE も同じPC（スーパーPC）で走らせ直し、事前登録7（WinPC）の BASE とは混ぜない。
- seed 401〜403、180秒、1コア、16並列前後（固定して記録）。構成の順は問題と seed で回す。
- NO_RESIDUAL_REWRITE：精密化での残差の書き換え群（接する条件、距離0、半径の補助式）を止める。解析的な微分の採用判定も連動。最終検証は凍結版のまま。
- NO_DIVERSE_SELECTION：候補を選ぶ段を、残差の小さい順の上位20個に替える。それ以降は共通。
- 「書き換えが適用される問題」＝ BASE の3 seed のいずれかで書き換えの呼び出しが1回以上記録された問題。実行後に BASE の記録から機械的に決める。

## 予測
- R1：書き換えが適用される問題のうち、NO_RESIDUAL_REWRITE で「解けた」でなくなる問題、または両方正解の時間比の中央値が1.5倍以上になる問題が、合わせて半数以上。
- R2：書き換えが適用されない問題では、「解けた」の差は1問以内で、両方正解の時間比の中央値（問題ごとの中央値の中央値）は0.9〜1.1倍。
- D1：複数値8問で、NO_DIVERSE_SELECTION は BASE より、集合が完全に一致した実行が3回以上少ない。
- D2：複数値以外の64問では、NO_DIVERSE_SELECTION と BASE の「解けた」の差は2問以内。
- D3：複数値以外の64問で、両方正解の時間比（NO_DIVERSE_SELECTION／BASE）の問題ごとの中央値は1.0倍以下。

外れの判定：数値の条件を満たさなければ外れ。結果は良し悪しにかかわらず補足に載せる。
