# 事前登録：退化した厳密解と、solver・人間の難しさ（10/23、sol-1/sol-2 の実行前）

測る量（探索の終点を使わない。jssa/strategy/codex-tasks-1023.md の sol-1, sol-2）：
- G：2点が重なり、かつ元の等式をすべて満たす解（退化した厳密解）が見つかった組が1つ以上ある。
- D：その解の集合の次元の最大値（見つからなければ −1）。
- G3, D3：3点が一直線になる場合の同じ量（sol-2）。

既にある量：p（minima/basins-323.csv、200出発点で当たる確率）、f_ghost（ghost-1023/endpoints_v1.csv、外れの終点のうち2点が重なる割合、coinc < 1e-4）、human（ghost-1023/human_feat.csv、Easy2Hard の人間の難易度、131問）、n_vars。

予測：
- H1（機構の確認）：G のある問題は f_ghost が高い。f_ghost の中央値の差（G あり − なし）が 0.3 以上。
- H2（主予測、p）：変数の数をそろえても、G のある問題は p が低い。n_vars = 1, 2, 3, 4, 5以上 の5層のうち4層以上で p の中央値が G あり < G なし、かつ層別の並べ替え検定（層内で G のラベルを入れ替え、1万回）で片側 p < 0.05。
- H3（人間とのずれ）：human と G（0/1）の順位相関の絶対値が 0.15 未満。human と D でも同様。
- H4（直感に反する予測）：条件のうち「接続・一致の条件」（Collinear、OnCircle/共円、平行、垂直、等しい長さ・等しい角）の割合が高い問題ほど G を持つ。割合の上位半分と下位半分で G の割合の差が 0.2 以上。人間にとって「きれいな図」の問題ほど、solver には退化した解の引き込みが強い、という予測。

棄却：H2 が外れたら、「退化した厳密解の有無が p を決める」は支持しない（f_ghost との関係だけを報告する）。H1 が外れたら、終点の重なりは厳密解ではなく別の機構（式の特異点での停滞など）と考える。
