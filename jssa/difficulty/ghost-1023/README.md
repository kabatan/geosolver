# 外れた探索はどんな図で止まるか（予備調査、10/23）

データ：局所解の数え上げの生データ（minima/raw-323、1問200出発点、seed 0、乱数出発、凍結版の LM 法）。当たる確率が0.95未満の201問、終点 37,281個。solver は再実行していない。手順は `ghost_scan.py`。

各終点で、DSL の全点の座標を変数から計算し、次の2つを測った。
- coinc = 最小の2点間距離 ÷ 図の直径（0に近い＝2点が重なる）。当たりの図すべてで重なる組は除く（答えの一部なので）。
- scale = 図の直径 ÷ 当たりの図の直径の中央値（1から遠い＝図が膨らむか縮む）。

判定：coinc < 1e-4 なら「重なり」、そうでなく scale > 100 または < 0.01 なら「尺度の崩れ」、それ以外は「一般の図」。

| 終点の分類 | 個数 | 重なり | 尺度の崩れ | 一般の図 |
|---|---:|---:|---:|---:|
| 当たり | 14,359 | 0.0% | 0.2% | 99.8% |
| 箱の外 | 6,580 | 48% | 8% | 44% |
| 打ち切り | 14,186 | 33% | 1% | 66% |
| その他（誤答・枝違いなど） | 2,156 | 54% | 0% | 46% |

- coinc の分布は二つの山に分かれる。外れの約35%は 1e-6 以下（多くは 1e-12 以下、ほぼ完全に重なる）、残りは当たりと同じ 1e-3〜1e-1。当たりで 1e-4 未満は14,359個中2個。
- 問題ごとの「外れのうち退化した図の割合」（外れ5個以上の199問）：中央値0.36。0.8以上が28%の問題、0.2未満が43%の問題。問題によって、外れの正体が「退化した図」か「一般の図での打ち切り・局所解」かに分かれる。
- 変数の数による差は小さい（変数1：32%、2〜5：41〜46%）。
- 例：AIME 2018 I-15 の外れはすべて2点の重なり（A0 と対角線の交点 XA など、1e-7〜1e-10）。AIME 2020 II-15 の外れは、図が数百〜10万倍に膨らみ、垂線の足 X が B に重なる。

限界：三角形がつぶれる（3点が一直線）退化はまだ数えていない（集計中、v2）。終点は LM 法が止まった点で、真の極小かは確かめていない。
