# 事前登録3：誤差の単調変換が効くのは、形の誤った出発点だけか（10/23 16:40、実行前）

astra-B の単調変換 R → (1 + r²/a²) R（誤差の順位と局所極小の場所を保つ）は、2問で当たる回数を大きく上げ、救われた出発点はすべて出発時に hard feasibility を破っていた。これが一般に成り立つかを、astra-B が使っていない40問で確かめる。

対象：transform-targets.csv（seed 0 で 0.05 ≤ p ≤ 0.95 の問題から、乱数 20261023 で機械的に選んだ）。
- 群L：0.05 ≤ φ < 0.8 の20問。
- 群H：φ = 1（出発点がすべて形の条件を満たす）の20問。

手順：astra-B の experiment.py と同じ変換・同じ a の決め方（問題ごとに別の16出発点の r の中央値）・同じ LM 設定（上限320）。出発点は各問64個、乱数 [3, 問題番号の順位]、base と sharpen で共通。採点は元の等式・guard・hard feasibility・箱・答え。

予測：
- T1：群Lで、sharpen − base の当たる割合の差の中央値 ≥ 0.10。
- T2：群Hで、差の中央値の絶対値 ≤ 0.03。
- T3：全40問で救われた出発点のうち、出発時に hard feasibility を破っていたものが80%以上。
- 棄却：T1 か T2 が外れたら、「単調変換の効果は形の誤った出発点を通じて生じる」とは言わない。
