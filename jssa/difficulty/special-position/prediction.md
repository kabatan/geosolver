## 3. 指標の定義

### 特別さ

**主指標G：図の偶然の一致。** Q22aの `hidden_equal_length_1e-07`、`hidden_collinear_1e-07`、`hidden_concyclic_1e-07` を使う。hiddenは「Q22aの構文規則では説明済みと判定されなかった」の意味に限る。数学的に独立な事実、人間が気づく事実とは断定しない。

測定点数をq、各種類の件数をcとし、候補数Mを等長 `C(C(q,2),2)`、共線 `C(q,3)`、共円 `C(q,4)` とする。`d=c/max(1,M)`、`G=mean(log(1+1000d))`（3種類の等重み、自然対数）。M=0ならc=0であることを要求する。点数の多い図ほど組合せが増える影響を抑える。件数cそのものも併記する。Q22aで有効な図がない場合はG欠測であり、0にはしない。

Q22aの `status=ok`、`accepted_figures>=1`、件数・測定点数が有限の非負整数、各 `c<=M` を必要条件にする。既存の最大3配置で共通して成立するというQ22aの定義を維持する。保存された `max_error` の閾値は主解析1e-7、感度分析1e-8と1e-6。raw列（明示された一致も含む）への置換も感度分析とし、良い方を主指標に選び直さない。

**補助指標：直角と接線。** 直角列はないため、stage2でのみQ22aの保存 `points` を使う。頂点Bと順序なしの端点対{A,C}について、異なる3点、両辺の二乗長>1e-12、`abs((A-B)·(C-B))/(|A-B||C-B|)<=1e-7` を数える。候補数は `q*C(q-1,2)`。Q22a座標は図の直径で正規化済み。保存された最初の配置だけの検査であり、hidden分類や全枝での成立とは呼ばない。接線は既存の `raw_tangent_*` と `hidden_tangent_*` を使い、候補数 `C(q,2)*n_circles+C(n_circles,2)` で割る。双方とも閾値1e-8・1e-6を併記し、主解析の救済には使わない。きれいな数値、完全な鏡映対称性は今回直接測らない。

### 特異性

`first_hit[ref].svals` と `n_residuals` を使う。元コードの等式残差に対する中心差分（h=1e-6）の保存値であり、罰則付き残差ではない。σmin・σmaxの生値を残し、`r=σmin/σmax`、`S=-log10(max(r,1e-12))` を主指標とする。大きいSほど条件が悪い。全特異値0ならS=12とし、別フラグを立てる。各問の保存された参照解ごとに算出後、Sの中央値を使う。枝の数、範囲、未観測の参照解数も残す。最も悪い枝だけを選ばない。

主解析は **変数数n>=2、等式行数m>=n** に限る。特異値の長さはmin(m,n)、全要素が有限・非負を必要条件とする。`n=1` では比が通常1になるため、生のσminを別枠で示す。`m<n` の構造的な自由度、`n=0`、未観測は分け、いずれも「特別な位置による退化」と数えない。補助的に `n-#{σ>1e-8*σmax}` を記録するが、恒常的な冗長性と特定位置でのランク低下はこの資料だけでは区別できない。

生の `-log10(max(σmin,1e-300))`、枝の最小・最大S、全零Jを除いた場合、全参照解が保存されている場合、seed 1のSを感度分析にする。残差・変数ごとの単位変更にはrも不変ではない。保存されていないJの行・列正規化は行えず、尺度の問題は残る。

### solverの結果と人間の難しさ

- **p（主解析）**：seed 0の `cls=hit` 数hを `starts_requested` のNで割る。誤答、誤枝、停滞、箱外、例外、時間切れ、記録されなかった予定出発点をすべて非成功として分母に含める。これは「予定予算での成功割合」であり、完了した試行だけの確率と区別する。
- `p_completed=h/len(records)` も算出し、basinsの `p` と照合する（絶対差1e-12以下、`n_starts` も一致）。既存pを使う解析を必須の感度分析にする。`starts_done`、recordのkの一意性、h<=len(records)<=Nを検査する。不整合は解析保留。ファイル全体が欠ける場合、h=0と作らず欠測として323問の表に残す。
- solver難度はD=1-p（大きいほど難しい）。主結果はp、補助結果は全記録の `nfev` と `sec` の中央値。hitだけの平均を主結果にしない。費用の欠測や未完了試行は別に数え、全予定出発点の90%以上で費用が記録されていなければ費用の関連は判定不可。秒数には機械・負荷の差が残る。
- **精密化**：高精度化段階だけの秒数または反復数を必要とする。現行の保存仕様にはない。`nfev`・`sec` は局所探索、Q22aの `seconds` は特徴抽出時間であり、精密化時間に代用しない。この入力範囲では精密化の予言は検証不能と記す。新しい計測で補わない。
- **人間**：`human_feat.csv` の `human` を使い、大きいほど難しいという既存の定義でHとする。大会内の平均順位に直して比較する。空欄を易しい値で埋めない。ID・値の出典や向きに疑義が残る場合、人間との方向比較は判定不可とし、結果に合わせて符号を変えない。

## 4. 数値つきの予言

ρは次節の交絡調整後の順位相関。方向比較P3・P4には、G・S・p・Hと交絡がすべてある**同一問題集合**を使う。P1・P2は各々の必要列がある最大の集合を使い、その違いを明記する。

| 予言 | 固定する効果の大きさ・向き |
| --- | --- |
| P1：特別さ→特異性 | ρ(G,S)>=+0.20 |
| P2：特異性→solver難度 | ρ(S,D)>=+0.20。S上位3分の1と下位3分の1の調整後p差は **-0.10以下**（10ポイント以上低下） |
| P3：特別さ→solver難度 | 同一集合でρ(G,D)>=+0.20。Gの上下3分の1の調整後p差も **-0.10以下** |
| P4：特別さ→人間難度は逆向き | 同一集合でρ(G,H)<=-0.20、かつ `ρ(G,D)-ρ(G,H)>=0.40` |
| P5：精密化も遅い（未検証） | S上位群の精密化費用が下位群の **1.5倍以上**。必要な段階記録がなく、今回は支持・反証とも判定しない |

別の補助予言として、S上位群の局所探索nfevの幾何平均（各問の中央値+1）が下位群の1.5倍以上になると予想する。精密化のP5とは独立に記す。接線・直角・生のσminの関係は補助報告に限る。

**支持・反証を分ける。** P1〜P4は点推定が全ての数値基準を満たし、主ρの方向検定が多重比較調整後5%未満なら支持候補。p差とρ差は95%区間も必ず示す。例えば正方向ρの95%区間上端が0.20未満、p差の区間下端が-0.10より大きい、人間ρの区間下端が-0.20より大きい、ρ差の区間上端が0.40未満なら、その**数値つき予言は反証**。方向自体の反転も別記する。点推定だけ閾値未達、または区間が広く閾値をまたぐ場合は未支持・未決着であり、成功と数えない。補助予言の比の区間上端<1.5も同様。

## 5. 解析手順（stage2の許可後だけ）

1. lockを検証し、全323問の台帳を作る。上の整合性・欠測・枝・次元区分を記録してから、固定定義で指標を作る。Q22aの `experiment.py` やprobeを再実行・importしない。
2. 交絡Xを固定する：切片、変数数のカテゴリ、大会、年、等式数、不等式数、点数、円数、作図の深さ、DSL長、角条件の有無、接線条件の有無、参照解数。構造列はhuman_featを優先、そこにないものだけQ22aを使い、両方あれば一致を要求する。深さはDSLの名前参照の最長経路（葉を1、Q22aの `structure` と同じ規則）を静的に計算し、既存Q22a値があれば照合する。循環参照は欠測。参照解数はrawのreferences、大会・年はIDと既存列を照合する。足りない交絡を効果を見て外さない。pや成功数を交絡に入れない。
3. 連続変数は解析集合内で平均順位に変換（同順位は平均）。大会内順位化したH以外は全体の順位を使う。Xの連続列も平均順位化し、カテゴリはダミー化する。定数列だけ落とし、SVD疑似逆行列（相対閾値1e-10）で対象2列をそれぞれXから残差化し、そのPearson相関をρとする。残差分散0なら判定不可。使用数>=80、`N-rank(X)>=40` を最低条件とする。
4. p差は、各説明変数をXで調整した順位残差の33 1/3・66 2/3パーセンタイル（線形補間）で上下群を作り、下位群0・上位群1として、元のpを群指標と同じXでOLS回帰した群係数を使う。境界以下を下位、境界以上を上位とし、中間群はこの差の比較だけ外す。両境界が同値なら判定不可。両群各20問以上と群係数の識別可能性を要求する。補助nfev比は同じS群を使い、`log(各問のnfev中央値+1)` を回帰した群係数の指数とする。これは交絡を揃えた関連の差であり、介入効果ではない。
5. 不確実性は問題単位のブートストラップ5,000回（大会ごとに元と同数を復元抽出、乱数seed=424200）。順位・調整・群分けも再計算し、95%百分位区間を示す。P3・P4とρ差は同じ再標本を使う。無効な再標本が5%超なら区間判定不可。方向検定は順位化した応答をXで回帰し、その残差を大会×変数数の層内で置換して当てはめ値に加え、再びXで残差化するFreedman–Lane法9,999回（seed=424201、片側、+1補正）。置換中はXと説明変数の順位を固定し、作った応答を再順位化しない。応答はP1がS、P2・P3がD、P4がH。層内で動かせる問題が40未満なら検定不可。P1〜P4の4検定をHolm法で調整する。依存のある出発点を独立な問題として水増ししない。
6. 再現確認はseed 0で作ったG・Sを固定してseed 1のpに替える。同一IDの積集合でseed 0も再計算し、集団変更とseed変更を分ける。幾何閾値1e-8・1e-6、raw件数、p_completed、特異性の定義による感度分析を全て出す。大会別、1年ずつ除外した結果も出す。効果を見て閾値・群・主指標を変更しない。
7. 正解が見つかったときだけSやGがあるという選択偏りを明記する。欠測の特別さを通常の図・特異な図と決めつけない。補助的に、交絡と結果がある欠測行のSを全員0／全員12、Gを全員0／全員log(1001)と置く4通りを提示する（観測値は不変、n>=2かつm>=nを確認できた範囲）。これは仮定別の感度分析であり、厳密な最悪境界でも欠測解消でもない。主推定は観測範囲だけに限定する。

## 6. 不可・縮小とする条件

- 母集団が323問でない、入力・solverのハッシュが違う、IDや出発点数に不整合、必要な交絡がない場合は該当する解析を保留。欠測数と失敗数を減らして成功率を上げない。
- P1〜P4の一つでも反証、未支持、または判定不可なら、仮説全体の確認とは呼ばない。人間の方向が逆にならなければ「人間と逆」は撤回する。Sだけの関係なら「数値的な条件の悪さとの関連」に縮める。
- 広がりを主張する最低条件は、同一集合でG・S・pの鎖を調べられる問題が100/323以上、大会が2種類以上で各20問以上。人間の逆向きの主張も同一集合80問以上が必要。それ以下なら部分集団の観察に限る。非対象・欠測も含む323問の内訳を必ず示す。
- 安定の条件は、seed 1でもP2・P3のρ>=0.15、同一IDでのp差<=-0.05、閾値1e-8・1e-6でもP1〜P4の方向維持、大会別（各20問以上）で逆転なし、判定可能な年除外の80%以上で方向維持。必要な再現データがなければ「安定」は未確認。欠測を含む仮定で逆転すれば323問全体への外挿は不可。
- 特異値と件数の相関だけでは、一般の位置からのランク低下、判別式上での枝の合流、対称性による分岐、因果関係を証明できない。特別な配置であることとヤコビアンの退化は同義ではない。Q40・Q41への材料にはなるが、この解析だけで深い理論が必要、新規原理、solver固有、Aの中心を担えるとは結論しない。

## 7. 結果の出し方

stage2の `answer.md` 冒頭は短く、(1)直感に反するか、(2)深い理論が必要か、(3)323問のうち何問で再現し安定か、(4)solverならではか、続けて「人間が導けるか／他手法でも得られるか／Aの中心を担えるか」を判定する。不可なら短く書く。続ける場合も、予言別の推定値・区間・対象数、欠測と失敗、反証と未検証を分けて示す。別solver・人間の解法を測っていない点、精密化を検証できない点を隠さない。

stage1で読んだのは指定節、保存仕様を確認するコード、ヘッダ・キーである。周辺コードの探索では既存調査の件数を含むコメント等も目に入ったが、Q42の値の表・相関結果を閲覧して閾値を選んではいない。既存データの再解析であり、未使用データによる独立検証とは呼ばない。
