# 局所解（谷）の数え上げ まとめ

実行: kabatan/geosolver の claude/project-thread-9bdbbg（solver本体は60db4b6のまま）。`probe_basins.py` に終点の座標と開始点の保存を追加（それ以外は同じ）。323問と benchmarks/extra-variables の60入力（k=0〜3）で、1問200開始点、seed 0、乱数開始（作図位置からの開始なし）。
- 探索変数のある292問と60入力すべてで完走。残り31問は変数なし。
- 1問ごとの値は `basins-323.csv` / `basins-extra60.csv`（p、谷の数、各谷の大きさ、箱外・打切りの割合）。生データは `raw-*`、再検査は `recheck/`。集計表は `tables.md`。
- 数え方: 終点を探索箱の幅で正規化し、距離1e-3以内を同じ谷とみなした（`count_basins.py`）。残差の値でも別に数えた（谷底が曲線だと位置はばらけるため）。

## 分かったこと

1. **外れた探索は少数の誤った谷に落ちているのではない。** 外れが10%超の問題で、誤った終点の位置クラスタ数の中央値は 変数1:1、変数2:7、変数3〜4:30、変数5〜6:58。一番大きい誤った谷が外れ全体に占める割合の中央値は 1.00 → 0.37 → 0.05 → 0.05。変数が増えると外れは多数の小さな落ち先に散る。「誤った谷が1つあって吸われる」のは変数1の問題だけ。
2. **外れ終点の中身。** 外れの大半は「打切り（stuck）」か「箱外」。wrong_answer と wrong_branch はほぼ0。箱外の割合は変数が増えると増える（1変数11%、2変数29%、7変数以上61%）。k=0→3でも箱外は44%→53%。
3. **打切りの多くは本物の局所解ではない。** 打切り終点を残差0でなくなった場所から単一開始solverで再開すると、6663点中 68% は動かない（谷底、真の局所極小に近い）が、9%（616点）は残差が0に達し、他にも残差が下がるものが残る。変数2の問題では17%、extra k=3 では22%が再開で解けた。つまり一部の「外れ」は谷の問題でなく、1回の探索の打切り（長く細い谷）。
4. **変数・k・pとの関係。** n_vars と p は ρ=-0.55（323問）、-0.50（60入力）。p と「2点以上の残差の谷の数」は -0.65 / -0.45：pが低い問題ほど、複数の外れ終点が同じ残差の値に落ちる谷（局所解）が多い。ただし「谷の数」自体は n_vars と ρ=0.49（323問）、0.24（60入力）で、変数の数だけでは決まらない。k を増やしても谷の数（2点以上）の中央値は 1→1→2→2 と少ししか増えず、pは 0.95→0.77→0.50→0.37 と大きく下がる。pの低下は「谷が増える」よりも「箱外に出る・打切りで止まる・外れ先が散る」で説明される。
5. **正解の谷が複数ある問題。** 323問のうち71問、60入力のうち22入力は正解側の位置クラスタが2つ以上（対称配置や複数の正解解。探索の失敗ではない）。

## 理論検証への含意（私の解釈・未検証）
- 「変数を消すと当たりやすい」は、谷が減るからというより、箱外への逃走と打切りが減るからという形で説明するほうが今回のデータに合う。
- 再開で解けた9%と動かなかった68%は、「p」を `谷に落ちる確率` と `1回の探索で到達する確率` に分けられる可能性を示す。

## 限界
- クラスタ判定は距離1e-3（箱幅比）と残差2%幅の2つの閾値に依存。厳密な極小性（勾配・ヘッセ行列）は未確認で、再検査は「単一開始solverを再開しても動かない」を代用した。
- 再検査は1問最大40点、stuckが3未満の問題は対象外。
- 200開始点では稀な谷（確率1%未満）は見えない。
