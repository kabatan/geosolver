# Q19 結果（事前登録5に従う採点。封印開封後）

採点: `prereg/score_q19.py`（既存 research_runner の `_answer_keys`／`read_run_outcome` をそのまま使用、解答は監査表の一次解答）。生データ（tar、runs/）は commit しない。集計は `q19-scored/assessment.jsonl`。
実装上の注意（開示）: 最初の採点で一次解答の先頭0（`026`）を数として読めず、正解を誤と数えた（31実行）。監査表に「先頭0は整数表記の差」と明記済みの表記差なので、`026→26` に直して再採点した。それ以外の規則は変えていない。

## 予測の判定（対象26問×5 seed＝130実行）
| 予測 | 事前の内容 | 結果 | 判定 |
|---|---|---|---|
| P1（主） | 実行ごと正答率 ≥ 0.85（点予測0.92） | **85/130 = 0.654** | **不成立** |
| P2 | 3 seed 以上正解の問題が 23問以上 | **17/26問** | **不成立** |
| P3 | 正解実行の初回正解までの時間の中央値 ≤ 15秒 | 代理指標（実行の経過時間）の中央値 12.1秒 | 厳密には測れない（候補ごとの時刻を記録していないため）。代理指標では成立 |
| P4 | AIME問題番号と問題ごと正答率の順位相関の絶対値 < 0.3 | ρ = −0.38（AIME 23問、p=0.07） | 不成立（番号が大きい問題ほど失敗が多い傾向。弱い〜中程度） |

本文では「未使用問題での成績は開発群（2026年20問の55/60）より下がった」と書く。未使用26問での実行ごとの正答率は約65%（26問と少なく、問題間のばらつきも大きいので幅広く見る）。

## 失敗の中身
- 失敗45実行は**すべて「答えなし」**。**誤答（別の値を返す）は0**。つまり 正解した85実行のどれもが唯一の正解のみを返し、誤答率は0/130（返した答えの精度100%）。
- 失敗の問題: 完全失敗（0/5）8問、部分失敗2問（AIME-1997-04 1/5、AIME-1991-14 4/5）。残り16問は5/5。
- 失敗実行の診断は全て `numeric_feasible=False`（制約を満たす数値配置が見つからず、したがって同定・検証に進めていない）。45件中 38件は180秒の時間切れ、6件は探索終了、1件は探索・精製段階。**同定（PSLQ等）で落ちたものは0**。
- 分類: 同定の失敗は0。残りは「探索」か「DSLの記述」のどちらかだが、これをこの採点だけで切り分けることはできない（DSL の書き起こしは監査で本文と照合したが、解が存在することの検証はしていない）。切り分けは別途、失敗10問を個別に調べる必要がある。
