# Q29d 機械的な書き直し規則（書き直し・solver実行前に固定）

これはQ19の失敗を見た後の事後修正実験である。凍結版・元DSLの85/130は変更しない。
対象は指定の9問、元ファイルは `../../dsl/<ID>.json`。元ファイルは上書きしない。

1. targetが出力形式の記号式で、条件 `G = m/n` または `G = a+sqrt(b)` が
   幾何量Gとその記号を結んでいる場合、targetをそのGの文字列に置換する。
   当該結合等式、出力だけに使う変数、その整数性・符号・既約性の証人条件だけを削除する。
2. `100*a+b` は、結合等式の左辺（元の第2最大辺長の**二乗**）をそのままtargetにする。
   max/min、二乗、幾何構成、点の枝、制約の順序や表記は変更しない。
3. `Angle(B,C,D)=n*pi/180`、target=nでは、targetを `Angle(B, C, D)` とし、
   nの結合等式・整数性・正値条件・変数nだけを削除する。度数への換算は採点側。
   元の8個の凸性条件が角の正値を保証する。新しい枝の条件は足さない。
4. `(1000*r) // 1` はtargetだけを `r` にする。変数・構成・全条件を保持する。
5. 削除対象外の変数・構成・条件・guard・枝は、JSON値と順序を完全に保持する。
   不等式の移動、等式の二乗化、座標消去、補助線追加、尺度変更、正解数値の注入をしない。
   各問のunified diffと、削除した条件の元インデックスを保存する。

## AIME-1983-12に対する必須の例外（規則5による恒等変換）

この問題のtargetは既に `Distance(A, B)` である。a,bは直径の十進2桁と逆転弦長、
p,qは問題文が要求するOHの有理性の証人であり、**出力形式の変数ではない**。
したがって全ファイルをバイト単位で保持する。diffは空（別の変更台帳にno-opと記す）。
これらを削ると条件を弱め、元問題と異なる連続族を解くことになる。
「9問全部が出力形式だけの問題」というQ29追記の分類は、この1問について訂正する。
指定9問×5seedの分母45は維持し、変更8問×5seed=40も副解析として示す。

## 開発群の実際の採点慣例

`benchmarks/cases.jsonl`の323問、`jssa/difficulty/new2026/cases.jsonl`の20問を参照。
例えばAIME-2025-II-06はtargetがArea、参照値が288/5（公式整数293への変換前）。
AIME-2025-II-12も距離和をtargetにして根号式を参照値としている。
Q19の `score_q19.py` / `research_runner.py` 自体にはm+nの汎用変換関数はなく、
既存の仕組みは `describe_exact` → `_answer_keys` の厳密値集合比較である。
Q29dも同じ比較を幾何量の参照値に適用し、出力形式の変換を別の決定的関数で併記する。
変換前の厳密値集合と変換後の公式解答の両方が一致し、実行契約に違反しない実行だけを正答とする。
候補のつまみ食い、丸めでの正答認定、seedのやり直しによる置換はしない。
