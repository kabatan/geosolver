# Q2 オフライン暫定規則

この規則は候補DSL作成前に記録した。指定の new2026/authoring-rules.md と
dsl-audit/cards.md は、このcheckout・取得済みの別ブランチ2本・指定/mntパスに
存在しなかった。既存 new2026 のDSL、README、公開DSL仕様、
benchmarks/gmb_comparison/AUTHORING.md の数学的変換の考え方から推定した規則であり、
指定ファイルを読めたとは主張しない。

1. 原文にある点・図形・関係・数値だけを条件にする。答え・解説・solverの成否・
   人間の難度をDSL作成にも採否にも使用しない。
2. 平行移動・回転・鏡映で座標を固定してよい。絶対長のない、相似不変の問いだけ
   尺度を固定してよい。どの自由度を除いたか、カードに根拠を書く。
3. 原文の定義的な作図は構成で表す。正多角形の頂点は中心角の定義から座標化してよい。
   解答の途中で初めて得られる長さ・角・因数分解等を条件に追加しない。
4. 内部・同側・弧の選択・鋭角・非退化を明記する。交点の根番号を恣意的に選ばない。
5. 目標は原問を保持する。Rに比例する長さはR=1で係数を問うことを明記する。
   床関数は目標の // 1 にのみ書く。最適化、期待値、無限過程、配置の個数を
   有限個の等式とguardに直すために解法が必要な問題は除外する。
6. 数値解を使う検算、構成や残差の数値評価、局所探索、solver、PSLQは実施しない。
   JSONモデル検査、式のASTパース、関数・引数・名前の静的検査だけを行う。
7. 原文、入力、採否・理由をhashで固定する。答えは別ファイルに分離する。
   二次資料の答えを「公式照合済」としない。未入手の公式答えはnullとする。
8. 原文がないIDは、原文/入力hashをnullとして保留にする。原文や公式答えを記憶から
   補わない。件数不足や原資料不足を隠さず、検証済み集合と呼ばない。
9. 後日修正が必要なときは理由と新旧hashを別版で保存する。本版のhashを
   solver結果を見て上書きしない。

## 固定する選定規則

- 第一の対象はAIME 1983〜1999、各年1〜15の全255スロット。原文未入手は保留。
- オフラインの補完母集団は、このrepoに保存済みの
  jssa/strategy/astra-consult-14/E/e2h-rows.jsonl のHMMT February全行。
  他大会・HMMT November・2000年以降のAIMEはこの補完母集団に入れない。
- 年、コーパスの番号、部門名、split、row_idxの昇順で全件を台帳に載せる。
  同年同番号の異なる部門を混同しない。
- 既存323問・2026年20問とIDが同じものを除き、平面幾何の単一の求値として
  上記規則内で直接DSLに書けるものをすべて採用する。難度・変数の個数・予想成功率で
  間引かない。30問に達した場合だけその先を定員超過とする（今回は未達）。
- コーパスの収集自体には既存研究の選択が入っている。本版の選定はその
  入手可能性に条件づけられた全件監査であり、大会全体の無作為標本ではない。
- HMMTの番号はコーパスのindexによる暫定番号で、公式冊子との一致は未確認。
  公式番号確認前に本検証用IDとみなさない。row_idx・原文hashでも同定する。

本規則の固定はローカルファイルによる。ユーザーの指示によりcommit・pushはしない。
