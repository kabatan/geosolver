# 実装上の具体化・検算修正

事前登録の本文・閾値・主解析母集団は変更していない。最初の集計は `audit-pass1-summary.json` に残した。

- 高精度モード内の float(mpf) は凍結コードが禁止している。最初の実装で候補のシリアライズにこれを使い、332件（全資料）の branch_error に記録された。50桁計算を変えず、float変換だけをモードの外へ移し、全件を再評価した。最初の「d=0」は確定値として採用しない。
- 構成点が1個しか取得できない図で、直径0を全体の収縮と数えていた。2点未満では直径は未定義とし、陽性の独立証拠がなければ unknown とする。該当の aime-2002-2-15 は主解析から除外しない。
- 固定した尺度プローブは、最初に単調減少の条件が破れた時点で残りの評価を省略する。同じ陽性判定を、余分な評価なしに得るためであり、終点を動かす探索ではない。
- 感度解析の(d)は主解析で高精度確認した候補に限定する。(a)(b)と中止判定の感度は全件再計算する。これは感度解析を別枝探索にしないための限定。
- humanの作成スクリプトはこのチェックアウトで見つからなかった。指定CSVを使い、値の方向は既存原稿・既存のEasy2Hard結合監査に依拠する。個人の認知過程を測ったとはしない。

- 修正後の全件再評価は184問の完了ログを残してプロセス終了（exit 1、Python tracebackなし）。既存の圧縮入力を使って未完了108問を再評価した。入力再読込・新しい終点取得は行っていない。
