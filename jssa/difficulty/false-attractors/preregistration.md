## 計測（局所探索なし）

凍結 src の DSL/IR を読み、保存 x から構成点の座標・等式残差・guard/hard を再評価する。初期尺度 S0 は同問題の seed 0 の保存 start における有限な図の直径の中央値。得られない場合は探索箱の幅の二乗平均平方根、さらに不可なら不明。原点 O0 はそれら初期図の点の重心の座標別中央値。図の直径 D(x) を使う尺度不変量と、初期尺度 S0 を使う絶対的な収縮・発散を分ける。全座標が評価できない図は部分評価と明示する。

正しい図に必須の一致・共線を退化と誤認しないため、seed 0 の全保存 hit 図で一致（距離/D <= 1e-4）する点対、全 hit 図で共線（面積/D^2 <= 1e-6）となる三点を対象から除く。hit 図のない問題では、保存 start 全部で同じ条件を満たす点対／三点だけを除き、hit による除外不能と明記する。これは入力または正解図に常在する関係の除外であり、失敗終点を使って除外を選ばない。

(a) 退化：除外されない点対の距離/D <= 1e-6、除外されない三点の面積/D^2 <= 1e-8（点対距離が全て >= 1e-3 D の三点のみ）、または D/S0 <= 1e-6 のいずれか。面積は絶対値の通常の三角形面積（外積の半分）。名前を持つ円の半径が取得できれば |r|/D <= 1e-6 も測定し、取得不能を記録する。単なる意図された共線は数えない。広い指標と、点対／円半径／全体収縮のみの保守的指標を併記する。

(b) 無限遠への逃避：構成点の max ||P-O0|| / S0 >= 100、または以下の固定した尺度プローブで等式残差が単調減少。尺度プローブは x(t)=m+t(x-m), t=1,2,4,8、m=探索箱中心。全ての評価が有限、各段で残差ノルムが少なくとも相対1e-6減少、最後が最初の半分以下、最初の残差>1e-12、かつ図の半径が最後で最初の4倍以上のときに陽性。残差は同一問題・同一凍結式の生のL2ノルム。残差の尺度による割り算はしない。有限4点は無限遠極限の証明ではなく「逃避の兆候」。座標がもともと巨大な初期図は S0 に反映する。尺度プローブは各有限失敗終点で最大3点の評価だけで、最適化・解き直し・追加乱数点は使わない。

(c) 許容境界での停滞：有限・hard feasible の終点で、等式残差>1e-8、探索箱幅に対する +/- 各座標軸 1e-6 および固定乱数8方向の少なくとも一方向で hard feasibility が反転するもの。既存 G の b6 診断が対応するものは再利用。それ以外は同じ有限差分を評価する。乱数は default_rng([15023, 辞書順問題番号, 保存k])。保存トレースに「等式+guardは減るがhard増加により同じ試行点が拒否された」があれば強い機構証拠を別記する。境界近接だけで拒否の因果や局所最適性を断定しない。

(d) 別の本物の解の枝：等式残差<=1e-8、元の guard/hard/箱を通過、答えが全公式値から相対1e-6（尺度 max(1,|ref|)）超離れ、(a)(b)ではないもの。高精度50桁で保存点を再評価し残差<=1e-10と元の許容条件を確認できたものを「数値的別枝候補」、確認できないものを未確認として分ける。数値許容差による判定であり、実数解の存在証明が無ければ「本物と証明済み」とは書かない。wrong_answer ラベルだけで(d)に入れない。

(e) その他：測定可能な有限終点で(a)(b)(c)(d)のいずれも検出されないもの。局所最適性を証明していないため「その他の失敗終点」と呼ぶ。再評価不能は e へ押し込まず unknown とする。(a)(b)(c)は非排他的に集計し、交差表も出す。(a)+(b) は和でなく和集合を指す。

## 問題ごとの一つの主因

まず各失敗終点に b > a > c > d > e の優先順で一つの診断票を割り当てる（unknownは別票）。bを先にするのは、巨大な図の直径で割っただけで(a)が陽性になる交絡を避けるため。問題内の最多票を「主因」とし、同票は e > c > d > a > b > unknown の順（偽到達点に有利にしない）で選ぶ。失敗なしを独立表示する。これは終点の多数型であり因果同定ではない。少なくとも一つ(a)(b)を持つ問題割合と、失敗中(a)(b)率>=50%の問題割合も別記する。
