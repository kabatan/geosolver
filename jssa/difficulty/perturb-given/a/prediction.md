## 3. 5版の作り方

対象は`selected.json`の`perturbed_slot_ids`。通常は上の全候補を動かす。
同じ数値でも、別の指定長なら別パラメータとする。共通の半径の再使用は連動させる。
静的に連動が見つかった6問の扱いは`interventions.json`に固定した。

| 例外 | 動かすもの／固定する理由 |
|---|---|
| AIME-2010-I-13 | ANのみ。ONと面積式の126は直径252に対応するので固定。 |
| AIME-2010-II-14 | CPと角の比2。直角は既存の角A<pi/4という枝指定とともに固定。 |
| JMO-2017-PRE-08 | XDのみ。BF+CF=BC=11という連動を維持。 |
| JMO-2022-PRE-02 | ABとDC。共通半径3・高さ6・中心の高さ3を維持。 |
| HMMT-2026-FEB-GEO-05 | 二つの指定弦長。半径11・2、中心距離9の対応を維持。 |
| AIME-2005-II-08 | 半径4・10。中心間距離、内接・接線・枝条件で使う同じ半径も同時に更新。 |

この入力点検で選択問題は交換していない。操作の限定は実行前に固定する。
原文未収録の開発問題もあるため、全原文との独立照合を済ませたとは主張しない。

各パラメータの場所を`slot_id = conditions/i/side/start:end`で表す（0始まり、終端を含まない）。
`s_d = +1` if `int(sha256(UTF8("Q40|4040|direction|ID|d|slot_id")),16)` is even, else `-1`。
ここでIDは正規化ID、dは下表の0または1を十進文字列にしたもの。
定数式cの**値全体**を `c*(1+δ)` にする。例えば`sqrt(1001)`の中身1001を直接変えない。
倍数の係数だけを変える場合も係数全体に掛ける。JSONには丸めた小数でなく有理数の積を書く。

| 版名 | 相対変化δ | 用途 |
|---|---:|---|
| original | 0 | 元のDSL |
| e3_plus | s₀/1000 | 1e-3の1版目 |
| e3_minus | −s₀/1000 | 反対方向 |
| e2_plus | s₀/100 | 1e-2、同じ方向 |
| e2_minus | −s₀/100 | 反対方向 |
| e1_random | s₁/10 | 1e-1、別の符号列 |

5版は小2・中2・大1で固定する。符号だけがランダムで、相対幅はちょうど指定値。
答えは計算せず、元の答えを流用しない。変数、条件数、目標式、構成の順序は維持する。
連動更新以外は構成や不等式を変えない。全差分は`variants.jsonl`、240個のDSLは`dsl/`。
入力不整合・実数解の消失・域外化も起こり得る。版を作り直して救済しない。

## 5. 特異値と枝の近さ

Fは等式部分だけとし、guard・不等式の罰則行はヤコビアンに加えない。
`z_j=(x_j-lower_j)/(upper_j-lower_j)`で変数の尺度をそろえる。
行尺度dは元版・主seedの200始点での`max(1, median(abs(F_l)))`。有限値20個未満の行があれば
その問の尺度調整診断を欠測にする。**dは6版・3seedで共通**。検索には使わない。

各版・seedで最初の厳しい当たり（上の当たり条件かつ残差≤1e-10）を参照図とする。
再探索・精密化はしない。中央差分でJxと`Jz=diag(1/d) Jx diag(box_width)`を求める。
zでの刻みは1e-6と5e-7。両側の評価が有限で、JzのFrobenius相対差
`norm(J1-J2)/max(1e-12,norm(J2))<=0.05`、かつ`max(σ1,σ2,1e-12)/max(min(σ1,σ2),1e-12)<=2`
のときだけ尺度調整したσminを有効とする。不安定な場合は数値0に置き換えずNA。
生のJxの全特異値、尺度調整後の全特異値、σmin/σmaxも保存する。
σmax=0なら比は0とする。m<nなら足りない右特異値n−m個を0としてσminを定義する。
rank閾値は`max(1e-12,1e-8*σmax)`。正次元の自由度を孤立根の合流と混同しない。

枝の近さBは**見つかった根候補間の距離の代理指標**とする。
各版・seedの先頭20個の厳しい当たりを採り、3seedの60点をzの辞書順に並べる。
各点を、既存全点とのRMS距離`||z-z'||2/sqrt(n)`が1e-4以下となる最初のクラスタに入れ、
なければ新クラスタとする。代表は各クラスタの辞書順先頭。Bは代表間距離の最小値。
全seedで20点ずつ得られ、全代表の差分が安定かつrank=nで、2クラスタ以上ある場合のみ有効。
それ以外は「単一根しか観測されない／標本不足／連続族疑い」と理由付きNA。
1根しか見えないことを「枝が遠い」やB=無限大とはしない。クラスタ幅1e-5、1e-3でも再集計する。
この方法は近すぎる根の分離、全枝の網羅、連続追跡による合流の証明をしない。
座標パラメータの違いを幾何学的に別の図と即断しない。

## 6. 数値つき予言・反証条件

`Δ_i,s = mean(p_i,v,s, v=5変更版) - p_i,original,s`。
5版を等重みにし、小・中・大の重みは2/5・2/5・1/5で固定する。
`D_s=mean_i Δ_i,s`、改善は`Δ>=0.05`、悪化は`Δ<=-0.05`とする。
以下は測定値ではなく、強めに置いた事前予言。足りなければ閾値を下げない。

| 予言 | 点予測 | 支持とする条件／満たさない場合 |
|---|---|---|
| P1：主seedで改善が多い | D=+0.08、改善28/40、悪化6/40 | D≥+0.05、問題単位95%区間の下端>0、改善≥26/40をすべて満たす。それ以外は主予言を支持しない。D≤0なら方向も反証。 |
| P2：群とseedを越える | 全3seedで改善する問24/40 | 全3seedでΔ≥0.05の問≥20/40、各群≥8/20。各seedでD≥+0.04、unseenのD≥+0.03も必要。失敗なら広い再現とはしない。 |
| P3：特異性の緩和を伴う | 下記の該当14/40 | 中水準でσminが2倍以上になり、P2の安定改善もある問≥10/40、各群≥3。未達なら特異値による機構説明を支持しない。 |
| P4：観測できた枝が離れる | 下記の該当6/40 | 中水準でBが2倍以上になり、P2の安定改善もある問≥4/40、各群≥1。未達・欠測過多なら枝の合流という説明は未支持。 |

P3の定義：各版の有効σminの3seed中央値をS_v（3seed揃う場合のみ）とし、
`G_i = (log10(S_e2_plus+1e-12)+log10(S_e2_minus+1e-12))/2 - log10(S_original+1e-12)`。
`G_i>=log10(2)`を2倍と呼ぶ。元版・中2版が揃う問が24/40未満なら機構判定は不可。
正次元系などでσminが常に0の問は改善件数に入れないが、分母40から除かない。
P4は`B_e2_plus>=2*B_original`かつ`B_e2_minus>=2*B_original`とする。
クラスタ幅1e-5、1e-3の両方でこの不等式が成立する問だけを支持件数に数える。
NAは支持に数えず、0でも無限大でも補完しない。

副解析：各水準別のΔ、元版pの天井・床、変数数2〜3／4以上、LM/Powell、群別を全件示す。
元版σmin/σmaxとΔのSpearman相関、群とn_varsの順位を回帰で除いた偏順位相関も記述する。
20問未満しか揃わない、または順位が定数なら相関はNA。ここから新しい有意な部分群を選ばない。
P1が支持されてもP3/P4が支持されなければ、「数値摂動の効果」までに主張を縮める。

8. 入力の連動漏れ・元の図の条件を壊す編集・不正な依存関係が後で分かった場合は、当該行と理由を報告する。
   固定計画のpでは失敗のまま。主実験を修正DSLの結果へ差し替えない。
   本来の操作と違う編集が1問でもあれば「その40問で仮説を確認した」という全体結論は不可。
9. 結果段階の`answer.md`冒頭は`answer.template.md`の4基準と3つの追加判定を必ず埋める。

## 8. 段階1の保存物と停止

静的確認はJSON/AST、選択規則の再生成、数値変更の差分、hash、凍結srcのbytes一致のみ。
solverのimport、DSLのsolverコンパイル、残差・座標の評価、局所探索、成功率の推定はしない。
数値変更後に図が存在することは未検証。`static-checks.json`を実行結果と扱わない。

`prediction.lock.json`に本書、共通選択規則、操作、全入力・DSL、準備コード、静的確認の
SHA256とUTC時刻を記録する。ロック自身のhashは含めず、srcと外部入力のhashは
ロック対象の`source-manifest.json`を介して固定する。`build`はロック後の再生成を拒否する。
`check`は読み取り専用。実行用エントリポイントは用意しない。
将来許可された追加コード・receipt・結果は`stage2/`、報告だけは`answer.md`に置く。
これらは将来の別manifestで固定し、段階1の固定ファイルとロックを更新しない。

ここで停止する。実行receipt・結果・answer.mdはまだ作らない。
