# 事前に固定した予測：出発点を正しい解に近づけると、自由点の系の不利は消えるか（10/23 03:20 JST、実行前）

## 背景（実行前に分かっていたこと）
- 事前予測 P2（列の膨らみで Y の低下を予測）は、新しい43問で支持されなかった（holdout-1023/）。
- AIME 2014 II-14 を減衰なしの Gauss-Newton（gn_common.py）で追跡すると、Y の u の更新方向は E と同じだった（作図の行が u の行と三角形に分かれるため、Newton の u 方向は y に依存しない）。違ったのは一歩の長さで、Y は 1/8192、E は 1/128 から始まり、E は7回で収束、Y は上限まで進まなかった。遠くから大きく動く一歩で、作図の行（非線形）の残差が増えるため、一歩が切り詰められる。
- 仮説：自由点の系の不利は「遠くからの長い一歩で、作図の式が線形近似から外れる」ことで生じる。作図で点を消した系（E、Z）は点を毎回正確に作り直すので、この制限がない。したがって不利は出発点と解の距離とともに増え、解の近くでは消える。

## 対象
Y が E より 0.2 以上落ちた10問（結果を見て選んだ。ここが検証の対象）。
- 15問の組（k=3）：AIME-2010-II-15, AIME-2014-II-14, AIME-2025-II-05, JMO-2013-PRE-03
- 新しい43問の組（k=2）：AIME-2018-I-15, AIME-2021-II-14, HMMT-2009-FEB-GEO-04, HMMT-2013-FEB-GEO-07, HMMT-2019-FEB-GEO-08, JMO-2025-PRE-09

## 手順
probe_common.py --near r（r = 0.02, 0.1, 0.3, 1.0）。E がランダムな出発点から当たった最初の終点を u* とし、u0 = u* + r × 箱の幅 × U(−1/2, 1/2)。各 r で出発点30個。LM法は本番と同じ設定。

## 予測
- N1：r = 0.02 では、10問中8問以上で p_Y ≥ p_E − 0.10。
- N2：問題ごとの差 p_E − p_Y の中央値は、r とともに増える（0.02 ≤ 0.1 ≤ 0.3 ≤ 1.0）。
- 対抗予測（変数の数や、解の近くの地形が原因）：r = 0.02 でも差が残る。

## 棄却条件
N1 が10問中3問以上で外れたら、仮説を支持しない。
