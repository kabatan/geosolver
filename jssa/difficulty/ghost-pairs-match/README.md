# sol-6: G の点対と保存済み終点の照合

## 結果を見る前に固定した定義（2026-10-23 07:39 UTC）

この節は分類・集計を実行する前に作成した。後から結果に合わせて変更しない。
新しい局所探索、LM、乱数出発点の生成は行わず、既存の終点の座標だけを評価する。

- 母集団は `minima/basins-323.csv` と `minima/raw-323/*.json` の問題。
  G 判定の対象は sol-1 と同じ n_vars >= 1。`ghost-exact/per-pair.csv` に
  found=1 が1組以上あれば G あり。found=1 がなく sol-1 の per-problem.csv に
  完了記録があれば G なし（「存在しない」の証明ではない）。対象外の n_vars=0、
  G 判定の欠測は別に数え、G なしに混ぜない。
- 層は n_vars=1, 2, 3, 4, 5以上。高成功率の問題も除かない。
- 分母 N は各群・層の **保存済み records の全件数**。200回未満でも問題を除かず、
  保存済み分をすべて含める。200に水増しせず、未実施・未記録数
  starts_requested - len(records) と問題数を別記する。n_vars=0 は探索不要であり、
  予定200回を未実施の探索に数えない。record のない問題も問題数に含める。
  主表は出発点を等重みとして n/N を示す（問題を等重みとはしない）。
- 成功は保存済み `cls == "hit"` のみ。既知の非成功ラベル
  `left_box, error, stuck, wrong_answer, wrong_branch` は失敗と分かっているが、
  幾何が欠測なら失敗の2種類に振り分けず「失敗・幾何判定不能」に置く。
  cls が無い・未知なら分類不能。coinc 欠測も独立に全記録で数える。
  hit は cls から成功と分かるのでそのまま成功とし、coinc 欠測の有無も併記する。
- 点候補・座標評価は `ghost_scan.point_names` と
  `probe_basins.construction_coordinates`, `answer_float` を使う。
  座標式が構築できない候補は ghost_scan と同じく点集合から除き、除外名・理由を記録。
  保存 x の変数順と座標 evaluator の変数順を名前で対応させる。
- 各図で有限に評価できた点の距離の最大値を diameter とする。
  点対の尺度は距離/diameter（ghost_scan と同じ）。diameter=0 で実測できた点対は
  ghost_scan の規則どおり coinc=0 とする。有限点2個未満、利用可能な点対なし、
  x 欠測・不正、非有限距離は欠測（利用可能な点対なしを0とはしない）。
- 全 hit 図（有限点2個以上）のすべてで距離 < 1e-6 * max(1, 原点距離の最大値)
  となる点対は ghost_scan と同じく除く。hit が無い場合は除外しない。
  この規則で残った全点対の最小尺度を coinc_any とする。
- G ありでは **found=1 の全点対** の最小尺度 coinc_G < 1e-4 なら
  「G点対が重なる失敗」。argmin の1組の一致だけを見るのではない。
  G なしでは除外後のどれかの点対の coinc_any < 1e-4 なら「任意点対が重なる失敗」。
  閾値は厳密な <。判定対象のいずれかが閾値未満なら存在が確認できる。
  閾値未満がなく、判定対象の点対が一部でも評価不能なら陰性とはせず幾何判定不能。
  全対象点対を評価でき閾値未満がない場合だけ「それ以外の失敗」。
  G ありで found=1 の点対が除外集合に入るなど入力矛盾があれば処理を止める。
- 主表は両群とも「成功 / 重なる失敗 / その他の失敗 / 失敗・幾何判定不能 /
  cls不明」を分ける。G なしについて依頼の二分表示も併記し、
  「重なる失敗」と「それ以外（成功+その他の失敗）」、判定不能は別列とする。
  欠測を二分のどちらかに代入しない。
- 補助指標は「重なる失敗 / 全既知失敗」と「重なる失敗 / 幾何判定可能な失敗」。
  後者は完全ケースの参考値であり、分母から落とした欠測数を必ず表示する。
  検定・閾値調整・因果推論は行わない。

## 実行結果

全323問を照合し、n_vars>=1 の292問・保存済み55,097出発点を分類した。
Gあり65問、Gなし227問、G判定欠測0問。変数なし31問は別枠（保存記録0件）。
200回未満の問題は38問（Gあり10、Gなし28）。予定58,400回に対し未実施・未記録は
3,303回（Gあり933、Gなし2,370）で、いずれも終点の分類に水増ししていない。

Gありでは成功5,078件、G点対が重なる失敗3,062件、それ以外の失敗3,927件。
全失敗6,989件の43.81%でG点対の重なりが確認された。変数数1・2・3・4・5以上で
この割合は67.04%・53.18%・32.69%・17.21%・57.83%であり、単調ではない。
「失敗は必ずG点対に重なる」という結果ではない。

Gなしでは成功26,773件、任意点対が重なる失敗4,792件、その他の失敗9,348件、
失敗・幾何判定不能2,117件。重なる失敗は全既知失敗16,257件の29.48%、
判定可能失敗14,140件だけを分母にすると33.89%。
判定不能の内訳は対象点対の座標が一部評価不能1,927件、除外後の対象点対なし190件。
前者は利用可能点対の最小値が有限でも、未評価の点対を陰性に補完しなかった記録である。
coinc_any自体が欠測なのは200件（aime-2002-2-15、うちhit 10件・既知失敗190件）。
hit 10件は保存済みclsで成功と分かるので成功欄にあり、幾何欠測も独立に数えた。
全問題で座標式の構築例外は0件、保存xの欠測・不正0件、cls不明0件。
ただし図で一部の座標が非有限となった記録は7,643件（Gあり1,400、Gなし6,243）ある。

Gありでも、任意点対の重なりはあるがG点対の重なりはない失敗が1,253件あった。
またG点対が重なる失敗のうち293件では、全点対の最小距離を与える点対はG点対ではない。
最小距離の1組だけを照合すると見落とすため、固定した全G点対の照合が必要だった。

### 限界

- Gなしは20出発点の数値探索で found=1 がなかったという意味。厳密な不存在判定ではない。Gは等式系だけであり元の不等式・答えの正しさは保証しない。
- 終点だけの照合なので、そこへ近づいた軌道や引力域、因果関係は分からない。重なる失敗が G の発見解そのものと同じ座標・残差・枝にあることも意味しない。
- diameter による相対尺度なので、図の膨張により絶対距離が小さくなくても重なりと判定されうる。ghost_scan と同じ有限点集合で diameter を測るため、一部座標の欠測は尺度にも影響する。
- hitで常に重なる組の除外は保存済みhitに依存する。hitなしでは除外せず、少数hitによる除外の不安定さもある。座標構築できないスカラー候補等は点集合に入らない。
- ghost_scan の高成功率フィルタは適用しない。また比較可能な点対が全くない場合は元コードの便宜的な0を使わず欠測とする。対象点対の一部が欠ける陰性候補も欠測として保存する。
- 時間制限で出発点数が異なるため、主表は200回未満の問題を少なく重み付けする。未記録終点の帰結は不明で、完全ケース割合も選択偏りを持ちうる。
- Gあり/なしで陽性の対象点対が違い、n_vars層内の点数・式・問題構造も揃えていない。群間差は記述であり介入効果ではない。
