# Q43a 実験方法

- 対象は開発323問とnew2026の20問。1〜8変数で、相似変換に対する同値性を機械検査できる命令だけの問題を候補とした。候補は174問・14問。`SHA256("431024|群名|問題ID")` の昇順で各12問、計24問を選んだ。選択はsolverを動かす前に固定した。除外理由を含む全候補は `selection-universe.csv`、入力・答えは `inputs.json` に保存した。失敗による問題の入れ替えはしない。
- new2026はsolverの開発に使わなかった群だが、既に他の研究実験には使われている。今回の再実行を「新しい未使用問題による確認」とは呼ばない。
- 幾何座標を `p' = s R (p − a) + t` とする。`s=10^k, k=-6,…,6`、回転90度・180度・約36.87度（cos=4/5, sin=3/5）、平行移動(1,-2)、(1000,-2000)、(1000000,-2000000)、最後の直接定義点／直接定義点の平均を原点にする2通り。さらに、図を変えずPoint式だけを書き直す対照を加えた。計22条件。
- 長さ・面積などの測定値を元の単位に換算するので、正解の集合は全条件で同じ。探索の自由パラメータの数値は変えていない。したがって、これは**幾何計算の座標系の実験**であり、探索変数自体を回転・拡大した実験ではない。自動探索箱は凍結版に任せるため変化しうる。
- 円の交点の「上側」など、座標系を変えると選ぶ枝の意味も変わる入力は対象外。属性への直接アクセス、未対応の命令も選択前の文法規則で除外した。候補群を代表する無作為抽出であり、全343問の代表標本ではない。
- 凍結版は `60db4b679b04167175c51c479c87c22fa663fda0`。srcの差分なし、実際のimport先とsource_hashを実行ごとに検査する。期待値は `sha256:d8fd9bb8392ad2984276bab3386e033669246ee79586317917c322d31b4541f5`。環境確認は `manifest.json`、各実行の確認は外部の生記録にある。
- `runtime.worker.execute` を直接呼び、凍結版の探索・精密化・厳密同定を通す。広い走査は15秒（内部で2秒を予約するので探索等は約13秒）、seed 431101・431102、24×22×2=1,056実行。これは公開APIの通常予算180秒より短い**診断実験**である。差が目立つ条件は同じ24問を180秒・別seedで追加比較する。短時間の結果を通常の公式成績に読み替えない。
- 3レーン、各実行はCPU1個に固定、数値ライブラリも1スレッド。条件・問題・seedを固定ハッシュ順に混ぜて実行する。共有機の壁時計時間とプロセスCPU時間を両方保存する。外側のwatchdogは予算+20秒。timeout・例外・答えなしをすべて分母に残す。
- 正答は、返った厳密答えの集合と元の正解集合のcanonical keyの完全一致。部分回収や余分な答えは不正解。時間は成功例だけの中央値に加え、失敗を予算いっぱいとして数えた平均費用を示す。共有機なので小さな時間差は主張しない。
- 採用された座標を元のDSLに代入し、元の等式・形の条件・答えを再評価する。図の比較は名前を対応させた点間距離を使い、座標系だけの差を除く。丸めた署名は集計用であり、解の個数を厳密に数えるものではない。
- 生ログ・候補座標・詳細な図は `/tmp/q43a-coordinates-20261024/` に保存し、リポジトリにはコード、選択表、検算、実行ごとの小さな要約、集計と代表図を置く。既存のsrc・既存結果は編集しない。

再現には `/home/kabatan/work/solver/.venv/bin/python -B experiment.py prepare`、`audit`、`launch short` の順で実行する。既存出力がある場合はprepareが停止し、launchは完了済み実行を再実行しない。`analyze.py summarize short` で全予定実行を分母に集計する。`diagnostics.py equivalence` は依存する作図を明示的に評価した補強検算、`diagnostics.py figures short` は図の再評価である。描画だけはmatplotlibのあるsystem Pythonで `plot_results.py short` を使う。
