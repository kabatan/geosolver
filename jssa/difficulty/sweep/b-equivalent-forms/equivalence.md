# 同値性の範囲

元の条件を満たす図の集合と、追加変数を捨てた変換後の図の集合を比べる。
数学的同値性は、数値残差や探索手順の同一性を意味しない。

| 変換 | 同値である理由・条件 |
|---|---|
| 非負の両辺を2乗 | a,b≥0 なら a=b ⇔ a²=b²。非負はDistance/Radiusなどの構文か元guardから確認。符号不明の式には適用しない。 |
| 点間距離²を内積 | \|B−A\|²=(B−A)・(B−A)。点以外のDistanceは2乗のまま。 |
| 角をcos | Angle(A,B,C)は[0,π]の無向角。この範囲でcosは単射。右辺も同じ範囲を構文で確認。 |
| 角をtan | tan((θ−π/2)/2)はθ∈[0,π]で単射、引数は[−π/4,π/4]なので極もない。単なるtan(θ)への置換ではない。 |
| 角を内積 | cosθ=(BA・BC)/(\|BA\|\|BC\|)。元Angleで禁止される零長の辺を明示guardに移す。 |
| 直線円接線を距離 | 円の中心O、半径r>0について IsTangent=0 ⇔ Distance(O,L)=r。円と直線の構成を残す。 |
| 同接線を判別式 | L=P+tV、W=P−Oなら、\|V\|²t²+2(V・W)t+\|W\|²−r²=0の判別式が0。元LineによりV≠0。係数表現ax+by+c=0は r²(a²+b²)−(aOx+bOy+c)²=0。 |
| 等式の重複 | 同じ真偽条件を何回要求しても解集合は不変。最小二乗の重み・計算量は同じとは限らない。 |
| 未参照の定数点32個 | 元の条件にも答えにも参照されない点(100+j,200+j)を追加。 |
| 独立ダミー1/8/32組 | 各t>0かつ\|(t,0)−(0,0)\|=1なので一意にt=1。全ての元の図が延長できる。元の変数への射影は同じ。 |

円円接線・弧は変換していない。複雑な角和・倍角など、範囲を構文だけで保証できない式も残した。
form_cosとform_vectorは、該当する長さ・角・接線をまとめて変える。効果が出ても、
追加の切り分けなしに「cosだけが原因」「判別式だけが原因」とは言わない。

入力240個は全て凍結版の公開DSL検証とloweringを通過した。
出力後には元DSLへの100桁代入を行い、保存された図の代表の残差・guard・答えを点検する。
この点検は再探索・新たな厳密証明ではない。図の同一判定は元変数の相対許容1e-7であり、
連続的な図族の異なる点も別候補になる。候補数を幾何的な枝の総数とは解釈しない。
