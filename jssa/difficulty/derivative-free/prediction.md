## 条件（全28問×16出発×11条件＝4,928枠）

| 記号 | 探索と変更 |
|---|---|
| N | PyNomad/DiscoMADS、凍結NomadConfigとNomadBlackboxAdapterの有限罰則、元座標、元残差 |
| L | SciPy LM、凍結の拡張残差、元座標。max_nfev=80は共通実評価上限へ置換 |
| Nfine | Nのinitial frameを箱幅の0.001に設定（既定0.1の1/100）。initial meshはNOMADが誘導。以後の拡大縮小は維持 |
| Nlp | Nの有限目的値をLMの拡張残差二乗和に置換 |
| Lnp | Lの拡張残差を `[F,0,1000*1[hard不許容]]` に置換（有限領域でNと同じ二乗和） |
| Nu / Lu | N / Lを箱の単位座標 u=(x-lower)/(upper-lower) で実行。物理始点・箱・残差は同じ |
| Nrs / Lrs | Nu / Luに残差行の尺度s_i=max(1,median_probe |F_i|)を追加。罰則行は変えない |
| Ls | Luの拡張残差をガウス平滑化するLM continuation。σ=0.1,0.03,0.01,0、累積評価枠=240,480,720,1200 |
| Lrestart | Luをσ=0のまま同じ4段・同じ累積評価枠で再開する対照 |

Lsは各正σで固定8組の正規乱数±Z（16評価）による平均残差とStein推定Jacobian `mean[r(u+σZ) Z^T]/σ` を使う。これはガウス畳み込みの有限標本近似で、厳密積分ではない。σ=0で元残差に戻し、最終判定にも元の条件を用いる。真のガウス平滑化と違い有限近似にノイズがあるので、陰性結果は全ての平滑化方式を否定しない。

LMにはm<nを避けるため必要な場合だけ零残差行を追加し、Powellへ切り替えない。1問の旧probeとは手法が違う。NOMADは与えた箱の内側、LMは元実装同様に箱外へ出られるが採点では失敗にする。この探索領域の扱い・評価不能点の扱いは残存差であり、罰則交換だけで全制約処理を同一化したとは言わない。NOMADの本来の箱25%拡張・多点開始・候補精密化・代数的前処理・救済は使わない。

## 固定した判定線

率は問題を等重みとし、hard21問と対照7問を分ける。各問16点が揃うため群内の全試行率と同じ。seed別、問題別、同一出発点の救済/喪失も報告。問題単位のbootstrap区間は記述的区間とし、有意性による仮説選択はしない。

1. **G0（問いの前提）**：hardの主指標で Δ=p(N)-p(L)>=0.10、両seedともΔ>0。未達なら「同条件でNOMAD単体の優位を再現していない」とする。完成solverの63/63を単体NOMADへ帰属させない。
2. **H1（強い尺度空間説）**：G0成立に加え、p(Nfine)<=p(N)-0.10、p(Ls)>=p(Lu)+0.10、p(Ls)>=p(Lrestart)+0.05。格子縮小による低下と平滑化による向上が各4問以上、両seedで平均効果が同符号。全て必要。格子効果だけなら大きな歩幅の効果に留め、mollificationとは認定しない。
3. **H2（罰則差が主要因）**：G0成立に加え、abs[p(Nlp)-p(L)]<=Δ/2 かつ abs[p(N)-p(Lnp)]<=Δ/2、さらにp(Lnp)-p(L)>=0.05、両seedでこの改善が正。NOMADを悪化させるだけの差消失を救済の説明にしない。literalな「hard EBとLM罰則の差」は実装監査だけで既に否定。
4. **H3（尺度・座標が主要因）**：G0成立に加え、単位座標か単位座標＋残差尺度の少なくとも一方で、N-Lの絶対差がΔ/2以下、対応するLの改善>=0.10、両seedで改善が正。LuとLrsも直接比較して座標と残差重みを区別。正のuniform-scale quotient/chartや表現の非線形変更を検査したことにはしない。

G0が成立しない場合でも全介入の効果量は報告し、H1/H2/H3を「機構が存在しない」とは断定しない。少数試行のスクリーニングであり、0/16の片側95%上限は約0.171。21問の全開始を同一pの独立試行として検定しない。いずれも一般理論から導いた普遍閾値ではなく、解釈を後付けで変えないための固定線。

## 理論と新規性についての事前制約

MADSのClarke停留性は局所Lipschitz性・方向の密化・極限等の条件の下での結果で、有限予算の根発見や大域成功率を保証しない。定数段差の境界に通常のClarke微分を直接適用しない。粗い格子上の点評価はガウス畳み込みではない。平滑化した残差の二乗と、二乗目的値を平滑化したものは異なる。

人は微分前に罰則の不一致、平滑化・尺度変更・大きい試行歩幅を考案できる。改善だけなら既知の数値最適化の説明が十分で、深い新理論やsolver固有の発見とは呼ばない。Aの中心として採用するには今回の既知21問を越える予言と広がりが別途必要。
