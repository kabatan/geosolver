11問の集計：**目標値が1つに決まる8問、認証多項式に複数の正の実根が残る2問、未確認0問**。別に、指定の構文規則では符号が決まらず「認証だけで1つに決まる」と言えない1問がある（8＋2＋1＝11）。8問についても「許容な図があれば」という条件付きである。

認証が保証するのは、**許容な図があれば、その目標値は認証した多項式の根になる**こと。実図の存在、答えの一意性、すべての根が実図に対応することは、認証自体の保証に含まれない。追加の根を元の不等式・主値で排除できても、「認証多項式と非負性だけ」の判定には加算しない。

対象は[事前登録9の結果](../per-problem.csv)の認証4問と、[9bの結果](../../eval9b/unseen/per-problem.csv)の認証7問だけ。事前登録不要の記述的整理であり、新たな認証評価ではない。pは保存済みsolverの多項式、qは符号・定数倍を変えずにp(T)p(−T)としたもの。

追加の根について確認できた範囲は次のとおり。

- **AIME-2005-I-07：追加正根 a=√141−9 ≈ 2.874342087。** 保存済みの代数化された等式・非零条件だけでは排除できない。`b=−a`などを代入すると全等式が0となり、全非零因子も非零になる。ただし元の`b>0`と`Distance(A,B)=a`を合わせると`b=a`。元の`Distance(C,D)=12`には`b²−18b−60=0`が必要だが、aでは`−36a≠0`となる。従って**元の条件では排除できる**。凸性まで調べる必要はない。
- **HMMT-2021-FEB-GUTS-14：追加正根 a=3＋√73 ≈ 11.544003745。** 保存済みの等式・非零条件をすべて満たす実代入例があり、それらだけでは排除できない。その例は`b>0, cy>0`も満たす。しかし辺AC=6、BC=8、AB=aなら、C角の余弦は`(100−a²)/96=(3−√73)/16<0`。C角の主値はπ/2より大きく、2倍するとπを超える。A角の主値は0とπの間なので、元の条件`Angle(B,A,C)=2*Angle(B,C,A)`に反する。従って**角の主値を含む元の条件では排除できる**。
- **AIME-2019-I-12：追加実根 9−√221 ≈ −5.866068747。** 正根は1個だが、符号未確定形なので負根も記録した。保存済みの等式・非零条件には負根の実代入例がある。一方、構築`Z=Point(x,11)`より`Z.x=x`なので、**元の`x>0`では排除できる**。この追加確認を使えば候補値は絞れるが、指定された構文規則による一意性の8問には含めない。

これらは元のDSLについての確認であり、自然言語の原問題との同値性を改めて検証したものではない。残り8問には他の正根がないため、追加根の排除確認は対象なし。追加根に関する「未確認」はないが、11問の実図の存在を一括して証明したわけではない。
