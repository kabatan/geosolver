# 事前登録：出発点の図の形と当たる確率（10/23、seed 1 の分割集計と seed 2 の実行の前）

seed 0 の集計（README.md、per-problem.csv）は見た後である。以下は、まだ計算していない seed 1 の出発点の分割と、まだ実行していない seed 2 の2条件についての予測。

対象：seed 0 で φ < 1（出発点の一部が不等式を破る）の150問。predictions.csv に問題ごとの予測値を固定した。

## 検証1：別の seed での再現（seed 1、既存の 200出発点の結果。出発点は同じ乱数で再生成する）
- R1：全体で、不等式を満たす出発点の当たる割合 − 破る出発点の当たる割合 ≥ 0.25（seed 0 では 0.37）。
- R2：φ と p の順位相関（292問）≥ 0.35、変数の数をそろえた偏相関 ≥ 0.25。

## 検証2：介入（seed 2、新しく実行）
条件 plain：通常どおり箱から一様に出発点を選ぶ。条件 feasible：不等式を満たすまで出発点を引き直す（`probe_basins.py --feasible-starts`）。人間が「図を正しい形に描いてから考える」ことに当たる。それ以外は同じ（LM法、上限、120秒の予算）。
- I1：feasible − plain の当たる確率の差の平均 > 0、かつ符号検定で片側 p < 0.01。
- I2（量の予測）：問題ごとの差の予測値 Δ = (1 − φ)(p_feas − p_infeas)（seed 0 から計算、predictions.csv の pred_delta）と、実測の差の順位相関 ≥ 0.4。
- I3：feasible 条件の当たる確率は、seed 0 の p_feas（pred_p_feasible）と、問題の60%以上で ±0.10 以内。
- I4（限界の予測）：seed 0 で p < 0.3 の問題では、差の中央値は 0.10 未満（形を正しくしても大して当たらない）。

## 棄却
I1 が外れたら、「形の誤りが当たり外れの原因」とは言わない（相関の報告にとどめる）。I2 が外れたら、効果の大きさは φ と分割から予測できない、と書く。
