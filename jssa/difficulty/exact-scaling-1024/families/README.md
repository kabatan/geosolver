# 深さだけを変える3族

各族でk=1〜8を作った。kは名前付き作図DAGの最大深さと一致する。全て自由スカラーtを1つ置き、最後の座標との等式で固定する。したがって全kで答えは有限であり、指定された実数の枝では1個である。solverは実行していない。

`generate.py` がDSL、問題文、深さ証跡、Tの最小多項式と証明を生成する。各 `kN.json` がDSL、`kN.md` が日本語の問題文、`kN-minpoly.json` が証明と係数列。`kN.base/strong.sing` と `.log` は実際の次数計算の入出力で、`.base/strong.json` は資源制限と結果。

|族|作図の意味|選択された答えt|既存系次数|強化系次数|tの最小多項式次数|
|---|---|---|---|---|---|
|circle_line|円とy軸の交点を正の枝で重ねる|2 cos(π/2^(k+1))|2^k|2^k|2^k|
|angle_bisector|π/4の角をk回二等分しx=1と交わらせる|tan(π/2^(k+2))|2^k|2^k|2^k|
|midpoint_control|原点との中点をk回取る|2^(−k)|1|1|1|

この表の系の次数はk=1〜8でSingularの零次元イデアル次数として計算できた。Tへの消去式との照合は24組中23組で一致。angle_bisectorのk=8だけ、系の次元0・次数256を出力した後のT消去が30秒で止まった。そこで先へ進めず、最小多項式次数256は下の厳密な証明による値として区別した。次数不明を256で埋めたものではない。

## 円と直線の鎖

y0=0。a=2+y(i−1)として、中心((a−1)/2,0)、半径(a+1)/2の円をy軸と交わらせると `yi²=a`。`near=Point(0,3)` は正の交点を一意に選ぶ。実際、全ての代数的な枝で −2<yi<2 なので円の半径は正、交点は2個で重ならない。

`P0(T)=T`, `Pi(T)=P(i−1)(T²−2)`。Piは先頭係数1、その他の係数は偶数、定数項は4で割れない偶数なので、素数2のEisenstein判定で既約。次数は2^iである。最後のyから `y(i−1)=yi²−2` と逆にたどれるため、全配置の次数も2^k。非零因子はどの共役でも消えず、強化版の飽和では減らない。

例k=1は `T²−2`、k=2は `T⁴−4T²+2`。

## 角の二等分の鎖

O=(0,0)、A=(1,0)、B0=(1,1)。角AOB(i−1)の内角二等分線とx=1の交点がBi。`yi = y(i−1)/(1+sqrt(1+y(i−1)²))` なので選択された値は `tan(π/2^(i+2))`。

n=2^k、θ=π/(4n)、ζ=exp(2iθ)と置く。ζの多項式 `X^(2n)+1` はXをX+1に移すと素数2のEisenstein判定を満たし、次数2nで既約。`i=ζ^n`、`t=−i(ζ−1)/(ζ+1)`、`ζ=(1+it)/(1−it)`。tは実数だから `[Q(t,i):Q(t)]=2`、従って `[Q(t):Q]=n`。

`Re((1+iT)^n)−Im((1+iT)^n)` が次数nの消去多項式になり、上の体次数から既約。最後のyから `y(i−1)=2yi/(1−yi²)` と逆にたどれ、余分な自由配置はない。各段の共役は0, ±1, ±iにならず、分母・線の方向・角の辺の非零因子も消えない。従って全配置の次数も2^k。

例k=1は `T²+2T−1`、k=2は `T⁴+4T³−6T²−4T+1`。

## 中点の鎖

O=(0,0)、P0=(1,0)、Pi=Midpoint(O,P(i−1))。t=2^(−k)で、原始整数係数の最小多項式は `2^k*T−1`。全て一意に決まり、深さが増えても次数は1のまま。この族は一次の作図を重ねる対照であり、二次拡大が毎段増える族とは分けて読む。

## 計算範囲と記録

全系の次数は変更しない既存変換・強化変換による。CASは1系30秒、1問2系で最大60秒。今回の補強は逐次実行した。kごとの合計CAS時間が30秒を超えた場合、または資源/変換限界が出た場合は次のkへ進めず、上限を8とした。角のk=8は消去で上限、それ以外はk上限で停止した。

`degrees.csv` の秒数は制限の確認用で、msolveとsolverの時間比較ではない。数値値と残差は220桁での健全性確認に限り、次数・既約性・有限性の根拠は上の厳密な議論とSingular出力である。

初回のk=1検査は同じ多項式のZZ/QQという係数領域表記の違いで停止した。QQに正規化する比較へ修正し、保存済みの2系のCAS出力を再利用した。CASのやり直しはない。
