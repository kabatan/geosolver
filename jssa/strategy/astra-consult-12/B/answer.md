# astra-B 回答：同じ解・同じ局所極小でも、探索の難しさは変わる

2026-10-23。指定されたタスク文書、相談12のプロンプト、本文 v7、補足資料 v7 を読み、既存データの再解析と新しい局所探索実験を行った。

## 結論

**一つの原理の候補は得られた。ただし、人間と solver の難易度のずれを問題ごとに予測する統一則を確立した、とは言えない。** 推す原理は次である。

> solver の難しさには、条件が何を意味するかに加えて、条件を満たさない図から、その残差を局所的にどう読み取って進むかが効く。論理的に同値な問題でも、この数値的な進み方は同値にならない。

v7 の「表し方が効く」を、今回はかなり強い対照実験に絞った。**変数数、正しい図、退化した等式解、残差による候補の順位、目的関数の全ての局所極小の場所を保つ操作でも、成功率が大きく変わる**と予測し、実測で確かめた。正しい図での等式ヤコビアンの条件数も、微分が定義される限り、この操作では変わらない。

残差全体を非線形に増幅するだけで、独立な追加100出発点の成功は、AIME 2023 I-12 で **62→98回**、HMMT 2024年2月 幾何4番で **50→100回**になった。反復上限は同じ320、元の条件・枝・探索箱・公式答えで採点した。単なる10倍では61回、50回だった。これは「退化解を消した」「未知数を減らした」「正解付近の条件数を改善した」結果ではない。

一方、**改善する問題を予測するために最初に提案した指標は、有効性を示さなかった。** 「最初の線形近似が悪いほど難しい」という指標の、変数数・入力の長さを調整した成功率との相関は −0.041。交差検証も改善しなかった。人間の難度との比較からも、この指標による統一的な説明は得られなかった。

したがって現時点の中心の主張として採用できるのは、**難しさを、解集合や退化解の有無だけの属性に還元できない、という実験的な結論**である。退化した図の仮説とは両立する。同じ退化解が残っていても、そこへ引き込まれる強さを変えられるからである。「人間は退化した図を考えない」という認知上の説明そのものは、今回測っていない。

## 根拠1：何を変え、何を保ったか

局所探索が実際に使う残差ベクトルを R(u) とする。これは等式の残差 F(u) に、guard と hard feasibility のペナルティ行を加えたもの。本番コードをそのまま呼び出した。r = ||R||、L = ||R||²/2 と置き、次の3種類を比べた。

| 名前 | 探索に渡す残差 |
|---|---|
| base | R |
| sharpen（増幅） | (1 + r²/a²) R |
| flatten（圧縮） | [asinh(r/a)/(r/a)] R。r=0 では R |

a は問題ごとに別の16出発点で測った r の中央値で、全ての探索で固定した。正解・成功率を使って調整していない。出発点ごとに a を変えた実験でもない。

増幅後の目的関数は

```text
L_sharpen = L (1 + 2L/a²)²
dL_sharpen/dL = (1 + 2L/a²)(1 + 6L/a²) > 0
```

圧縮後も L の厳密な単調増加関数である。このため、数学的には以下が保たれる。

- 候補の良し悪しの順位と、各等高線。局所極小の場所・個数も保つ。
- 元の等式を全て満たす配置。退化した等式解もそのまま残る。
- 正解の判定条件。終点は変換前の等式・guard・hard feasibility・箱・答えで採点する。
- 滑らかな点では、連続時間の最急降下の方向。勾配は正のスカラー倍になる。ただし実装には不連続なペナルティもあり、この微分の議論を境界へ適用しない。

等式解 F=0 で、変換した等式行は g(R)F。そのヤコビアンは g(R)J_F なので、定義される限り、ランクと特異値の比は変わらない。R 全体が0ならヤコビアンそのものも同じになる。HMMT 2024 幾何4番では正解にも約1.62×10⁻⁵の補助ペナルティが残ったので、「全ての正解で R=0」とは仮定していない。

数値的にも、2問の成功点で変換前後の残差ヤコビアンを中心差分で比べた。増幅による相対差は AIME で7.24×10⁻¹⁰、HMMT では浮動小数点上0だった。元の等式ヤコビアンの条件数はそれぞれ19.06、4.28。記録は [audit.json](audit.json)。これは全ての解を数値的に調べたという意味ではなく、上の代数的な不変性の確認例である。

**保ったのは極小の場所・順位・等高線であり、高さや曲率まで同じという意味ではない。** LM法は残差を線形近似して有限の一歩を選ぶため、この変換に対して不変ではない。

## 根拠2：実行前に記録した予測と、12問の結果

1. 出発点での線形近似の誤差 Q が大きいほど成功率 p は低い。人間の難度との関係は、それより弱い。
2. 上の単調変換で、少なくとも1問の成功率が0.20以上変わる。
3. Q の大きい問題ほど増幅によって改善し、圧縮によって悪化する。

## 根拠4：何が起きていそうか――事後的な機構の検討

ここからは結果を見てからの分析であり、一次予測に数えない。

本番の探索実装は、hard feasibility に失敗した配置では、残差の最後の行に **10000** を加える。これとは別に、滑らかな guard 違反ペナルティもある。大きな固定成分は残差の大きさに入るが、その領域の内部では座標を微小に動かしても減らない。

2問の追加100出発点をこの固定ペナルティの有無で分けると、増幅で救われた86個は全て、それが出発時に付いていた点だった。

| 問題・出発時の固定ペナルティ | 点数 | base の成功 | 増幅の成功 |
|---|---:|---:|---:|
| AIME 2023 I-12：あり | 50 | 14 | 50 |
| 同：なし | 50 | 48 | 48 |
| HMMT 2024 GEO-04：あり | 50 | 0 | 50 |
| 同：なし | 50 | 50 | 50 |

「増幅したから一歩が小さくなってよかった」とは限らない。減衰のないガウス・ニュートン法については、次の計算ができる。

J が列フルランクとし、η = ||P_col(J) R||² / ||R||² とする。η は、残差のうち線形化した座標変更で動かせる成分の割合。t=r/a、k=(1+3t²)/(1+t²) と置くと、増幅後の一歩は

```text
delta_sharpen = alpha * delta_base
alpha = k / [1 + (k² - 1) eta]
```

になる。J_sharpen = [(1+t²)I + 2RRᵀ/a²]J を正規方程式へ代入し、ランク1の項を逆行列から取り出すと得られる。正方系だけでなく過剰決定系でも、この条件下で成り立つ。

η=1なら alpha=1/k なので一歩は短くなる。一方、η<1/(k+1)なら alpha>1。**線形化で動かせない残差が多いと、誤差を強く増幅する操作が、一歩を逆に長くする。** 大きな固定罰則は、この η を小さくする要因になりうる。

実際の出発点で、この式と変換後の線形最小二乗問題を直接解いた一歩を比較した。相対誤差の最大は5.41×10⁻⁹だった。固定ペナルティのあった出発点では、η と一歩の倍率の中央値は、AIME で0.136と1.44、HMMTで6.95×10⁻⁵と2.00だった。

これは数式の数値確認であり、**実際のLM法の一歩が常にこの倍率になるという主張ではない**。LM法の減衰・列の尺度・信頼領域・差分微分・停止規則がさらに入る。境界をまたぐ差分ではヤコビアン自体が不安定になる。実際、AIME の代表的な失敗点では、差分幅を10分の1にすると見かけの勾配が約10倍になった。滑らかな局所極小と断定できない。記録は [mechanism-summary.json](mechanism-summary.json)、[stalled-point-diagnostics.json](stalled-point-diagnostics.json)。

**固定罰則を外せば解決する、という追加予測も試したが成立しなかった。** [hard-penalty-plan.md](hard-penalty-plan.md) を記録後、同じ2問・同じ100出発点で、探索時の hard feasibility 行だけを0にした。等式と滑らかな guard ペナルティは残し、終点の hard feasibility の検査も維持した。

| 問題 | base | hard 行を探索から外す | 救った点 / 失った点 |
|---|---:|---:|---|
| AIME 2023 I-12 | 62/100 | 76/100 | 20 / 6 |
| HMMT 2024 GEO-04 | 50/100 | 49/100 | 0 / 1 |

「両問で0.15以上改善」の予想に対し、+0.14と−0.01だった。特にHMMTでは改善しなかった。固定罰則との関連は観察できたが、「それが唯一の原因」「削除すればよい」とは言えない。この操作は損失の単調変換でもなく、一次実験とは区別する。

## 根拠5：人間とのずれを予測できたか

最初の指標 Q は、最適化を最後まで走らせずに計算した。独立な16出発点で、中心差分 J と delta=−J⁺R を使い、

```text
q(u) = ||R(u+delta) - R(u) - J delta|| / max(||R(u)||, 10^-12)
Q = 出発点間の log(1+q) の中央値
```

とした。既存の seed 0 の成功率と結合し、変数数とDSL文字数を調整した偏順位相関を計算した。95%区間は問題を単位とした2,000回のブートストラップ。

| 測定 | 問題数 | 相関 | 95%区間 |
|---|---:|---:|---|
| Q と p、調整なし | 271 | −0.098 | −0.217〜+0.020 |
| Q と p、変数数・文字数を調整 | 271 | −0.041 | −0.165〜+0.084 |
| 同、既存 seed 1 の p を使用 | 271 | −0.029 | −0.154〜+0.096 |
| Q と既存の solver 費用 C、同じ調整 | 271 | +0.015 | −0.100〜+0.134 |
| Q と AIME の人間難度、同じ調整 | 40 | +0.070 | −0.270〜+0.427 |
| Q と HMMT の人間難度、同じ調整 | 61 | +0.266 | +0.047〜+0.463 |

人間難度は `ghost-1023/human_feat.csv` の human 列を使用。AIME/HMMTを混ぜた生の難度相関は出していない。人間難度と今回の特徴量がそろうのは101問で、v7の109問とは、Powellの除外等により母集団が違う。

**Q と p の符号だけは予測と同じだったが、予測に使える強さを示せなかった。** また「人間難度より solver の難しさに強く関係する」という優位も確認できない。同じ人間データのある部分集合では Q と p の偏相関は AIME −0.020、HMMT −0.034だった。HMMTの人間難度との正の関係は、複数の比較のうちの一つなので、新たな認知理論の証拠に昇格させない。

問題ごとの5分割交差検証を20回行った。目的変数は (成功数+0.5)/(試行数+1) のロジット。変数数のカテゴリと入力長を使う固定のリッジ回帰に Q を足すと、平均二乗誤差は **9.588→9.632**。人間難度・大会も入れた101問では **9.326→9.570**。いずれも改善しなかった。この交差検証は開発用問題内での比較で、未知の大会の検証ではない。

補助量の「減衰なしの一歩で残差が半分以下になる率」は、p と偏相関+0.305 [0.176, 0.423]だった。ただし補助量として得た結果であり、最初の Q の失敗をこれに差し替えない。人間データのある部分集合では、AIMEとHMMTで関係がそろわず、統一的な予測指標にはまだなっていない。

Q が小さければよい、と考えたのも単純すぎた。固定罰則が大きいと、分母の ||R|| が大きいまま、その行は局所的に変わらず、Q が小さく出うる。逆に Q が非常に大きかった AIME 2014 II-14 は40回全て成功した。LM法の信頼領域が、最初の減衰なしの一歩の悪さを吸収している可能性がある。後者は解釈であって、軌道全体から原因を特定した結果ではない。

## 研究の中心としてどこまで使えるか

反直感的な予測として確かめたのは、「誤差の順位も局所極小も変えずに、誤差を非線形に増幅すると当たりやすくなる問題がある」という点である。2問では新しい出発点でも再現した。ただし、本人に事前予想を取っていないので、「IMO金メダリスト本人にも予想できなかった」ことを実証したとは書けない。

この原理は、残差が大きい候補でも収束することや、作図を自由点に戻すと改善する例と整合する。残差の絶対値や未知数の数だけでは、残差空間での一歩を決められないからである。一方、高精度化の停滞、最終的な厳密同定の成否、全ての答えの回収まで、今回の実験で説明したわけではない。**本番パイプライン全体の時間・正解率は再測定していない。** 局所探索の p の改善を、そのまま本番の速度改善として扱わない。

数値最小二乗の難しさを残差空間の幾何、座標、境界から説明する考え方自体には先行研究がある。例えば Transtrum・Machta・Sethna は、モデル多様体の境界や座標の曲がりと最適化の難しさを扱っている。[Geometry of nonlinear least squares（2011）](https://arxiv.org/abs/1010.1449)。今回の原理を数値解析として新発見とは主張しない。今回の強みは、この幾何問題群で、保つ量を明確にした対照と新しい出発点での再現を示したこと、そして予測指標・方向予測・追加の原因仮説が外れた点まで残したことにある。

次の計算に進むなら、Qを再調整し続けるより、今回の増幅を探索にだけ入れ、元の残差で精密化・検証する本番の対照実験を、まだ介入していない問題で行うのが先である。問題の選択と、初期点の固定罰則率・ηでどこまで改善を予測するかを結果前に固定する。今回の2問から「その率が高ければ必ず改善」とは結論しない。

## 実験記録と再現

新しく実行した局所探索は **2,472回**。一次実験1,440回、上限を増やした再実行32回、別の100出発点での再現800回、hard行を外す追加実験200回。ほかに272問×16点の一歩の診断を行った。一次実験・再現では時間切れはなく、30秒上限で打ち切った結果に効果を依存させていない。

特徴量測定の問題別経過時間の合計は約69秒、一次介入約140秒、再現約90秒、hard行の追加実験約19秒。これらは同時に動く他タスクのある環境の経過時間で、速度比較には使っていない。統計集計・記述・追加診断の時間はこの合計に含めない。成果物全体は約7MBで、大きな単一ファイルは作っていない。

Python 3.12.11、NumPy 2.5.1、SciPy 1.18.0。指定された `/home/kabatan/work/solver/.venv/bin/python` を使用した。solver 本体と入力データのハッシュを実験前後で確認した。コード・結果は全てこの B フォルダに置いた。既存ソースの変更、依存の追加、commit・pushは行っていない。

```bash
/home/kabatan/work/solver/.venv/bin/python -B jssa/strategy/astra-consult-12/B/experiment.py intervene
/home/kabatan/work/solver/.venv/bin/python -B jssa/strategy/astra-consult-12/B/analyze.py
/home/kabatan/work/solver/.venv/bin/python -B jssa/strategy/astra-consult-12/B/followup.py
/home/kabatan/work/solver/.venv/bin/python -B jssa/strategy/astra-consult-12/B/mechanism.py
/home/kabatan/work/solver/.venv/bin/python -B jssa/strategy/astra-consult-12/B/hard_penalty_check.py
/home/kabatan/work/solver/.venv/bin/python -B jssa/strategy/astra-consult-12/B/audit.py
```

`features`・`intervene`・再現の本体は既存の問題別JSONがあれば再利用する。全てを計算し直す場合は、保存済み成果を退避した上で `features/`、`interventions/`、`replication/` の該当JSONを空にして実行する。集計コードは保存結果から再生成できる。
