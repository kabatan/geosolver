## 原理の候補

人間が利用するのは条件の論理的な内容と正しい図上の関係である。一方、この solver の探索は、条件を満たさない図においても残差を線形に予測して進む。その「解の外側での予測の信頼性」が有限予算の到達性を左右するのではないか。退化した図はその障害の一候補だが、必要条件ではない。

「p が難しさを決める」という言い換えを避けるため、最適化を走らせない1回の線形予測で測る量を用いる。

## 測定1：出発点の線形予測

- minima/basins-323.csv の n_vars >= 1 を対象とする。等式数 < 変数数の問題は本番の局所法が Powell なので、主解析から除外し件数を明記する。
- 独立の一様乱数出発点16個。問題IDをソートした番号 i を使い、default_rng([102312, i])。元の infer_problem_bounds を使用する。
- 本番の guard / hard feasibility のペナルティを含めた残差ベクトル R を使用。中心差分 h_j = 1e-5 max(1, |u_j|) の J を作る。delta = -pinv(J) R、SVD の相対閾値 1e-10。
- q = ||R(u+delta) - R(u) - J delta|| / max(||R(u)||, 1e-12)。主特徴量 Q は問題内の log(1+q) の中央値。補助量は、1歩で残差ノルムが半分以下になる率、および箱幅で正規化した一歩の長さ。
- 明らかな評価エラー（評価ステータスの失敗、非有限値）を区別して記録。試行先で失敗したものは q=1e12 とする。出発点で失敗ならその点は特徴量の集約から除く。
- P1：Q が大きいほど既存 seed 0 の p が小さい。変数数・DSL文字数を調整した偏順位相関が負になると予測。人間の難度とは、それより弱い関係になると予測する。
- 問題単位の区間と交差検証を使う。出発点を独立した「問題」として標本数を水増ししない。human のある部分集合と全体を分ける。

## 測定2：地形の順序を変えない介入

残差ノルムを r=||R||、a を測定1の有効な出発点での r の中央値（下限1e-6）とする。

- base: R。
- sharpen: (1 + r^2/a^2) R。
- flatten: [asinh(r/a)/(r/a)] R（r=0 では係数1）。

どちらも元の二乗残差の厳密な単調変換である。したがって数学的には残差の順位、局所極小の場所、元の残差が0になる点を保つ。R=0 ではヤコビアンも同じ。全ての正解で実装の補助ペナルティまで厳密に0かは別途確認する。

正方・正則の系を減衰なしで解く場合、sharpen の一歩は元の一歩の (1+t^2)/(1+3t^2) 倍（t=r/a、1/3〜1）。flatten では asinh(t)*sqrt(1+t^2)/t 倍（1以上）。実際の過剰決定系・減衰付きLMにこの向きと倍率をそのまま仮定しない。

- 対象は2変数、等式数>=2、測定1の有効点>=8の問題。Q 上位6問と下位6問（同値はID順）。既存の p、人間難度、退化率で選ばない。
- 各40個の共通出発点、default_rng([102313, i]) を使用。i は全対象をソートした番号。測定1とは別の出発点。
- scipy least_squares(method='lm')、ftol=xtol=gtol=1e-14、max_nfev=80。元の solver と同じ判定（元の残差<=1e-8、guard/hard feasible、元の探索箱内、公式の答えとの相対誤差<=1e-6）。変換した残差で正解を判定しない。
- max_nfev 到達の実行は、同じ出発点から上限320でも実行して、80での違いが打切りだけかを見る。1実行30秒を超えた場合は明示的に時間切れと記録する。実時間の比較は他タスクの負荷があるため主指標としない。
- P2（非自明な存在予測）：上限80で、少なくとも1問は base と変換の成功率が0.20以上違う。正解や局所極小の増減を伴わず難しさが変わるという予測。
- P3（より強い方向予測）：Q上位6問では sharpen-base の p の差の中央値が正、flatten-base は負。下位6問より sharpen の改善が大きい。外れれば、単純な「一歩が大きすぎる」説明と実用的な予測規則は未支持と報告する。
- P2 の上限320での持続は副次解析。新しい問題での再現と solver 全体の時間改善はこの実験の対象外。
