厳しめに言うと、今の「厳密法は $2^k$、数値 solver はほぼ $k$」という仮説は、そのままでは成立しません。この仮説を追加実験で補強するだけでは、上位賞の決め手にはならないと思います。

## 1．仮説のどこが正しく、どこが成立しないか
### 1.1 「作図の深さ」「配置の解数」「答えの次数」は別の量です

まず、次を分ける必要があります。


| 量 | 意味 |
| --- | --- |
| 作図の大きさ $L$ | 作図を計算するための演算の総数。共通する計算は共有する |
| 作図の深さ $k$ | 依存する作図が最も長く連なる段数 |
| 二次演算の数 $q$ | 平方根など、二つの代数的な枝を生み得る操作の数 |
| 実際の二次拡大の数 $r$ | それまでの数の範囲に含まれない平方根を、新たに加えた回数 |
| 配置の次数 $D$ | 零次元系なら、重複を含めた複素解の数 |
| 目標値の次数 $\delta_\tau$ | 求める数の最小多項式の次数 |


固定した基礎体から出発し、本当に新しい二次拡大が $r$ 回起きるなら、体の次数は $2^r$ になります。しかし、平方根を $q$ 回書いただけなら、言えるのは原則として「高々 $2^q$」です。

例えば、同じ $\sqrt3$ を何度使っても次数は増えません。有理演算だけの作図は、いくら深くても新しい二次拡大を生みません。逆に、多数の独立した平方根を並列に置けば、深さが小さくても全体の体次数は大きくなります。

さらに、今回のように自由変数 $u$ を残して作図 $h(u)$ を行い、最後に残った条件を解く場合、残余条件を解く難しさは、作図の平方根の段数だけでは決まりません。

正次元の問題にも注意が必要です。図が連続的に動く場合、配置の複素解数は有限ではありません。この場合の「代数多様体の次数」は定義できますが、「複素解の数」と同じではありません。

したがって、実験の説明変数を一つの「深さ $k$」にまとめるのは危険です。

### 1.2 次数が $2^k$ でも、厳密な表現は小さくできます

ここには、かなり決定的な反例があります。


$$x_0=0,\qquad
x_i^2=2+x_{i-1},\qquad x_i>0
\quad(i=1,\ldots,k).$$


選ばれる値は、


$$x_k=\sqrt{2+\sqrt{2+\cdots+\sqrt2}}$$


です。

この数の最小多項式の次数は、実際に $2^k$ です。確認するには $g(X)=X^2-2$ と置きます。すると


$$g^{\circ k}(x_k)=0$$


であり、$g^{\circ k}(X)$ は次数 $2^k$。最高次以外の係数はすべて偶数で、定数項は $-2$ または $2$ なので、アイゼンシュタインの判定法で既約です。

ところが、厳密な入れ子平方根の式は、$O(k)$ 個の演算で保持できます。

さらに、この例ではグレブナー基底さえ小さいままです。


$$f_1=x_1^2-2,\qquad
f_i=x_i^2-x_{i-1}-2$$


という入力の $k$ 本は、全次数を優先する単項式順序では、そのまま被約グレブナー基底になります。先頭単項式が $x_1^2,\ldots,x_k^2$ で互いに素だからです。

つまり、同時に次が成立します。

全配置の複素解数は $2^k$。
選択した正の枝の最終値も、最小多項式次数は $2^k$。
厳密な入れ子平方根の式は小さい。
順番に解ける三角系も小さい。
次数順序のグレブナー基底も、$k$ 本の二次式のまま。

これは人工族を主実験に使う提案ではありません。「次数増加の費用を厳密法は必ず払う」という理論主張を否定するための反例です。

指数的な大きさが問題になるのは、例えば全配置を列挙したり、最小多項式を展開した形で出力したりするときです。その出力を数値法にも要求すれば、数値法も出力の大きさから逃れられません。逆に、小さい入れ子式の出力を認めるなら、厳密法にもそれを認める必要があります。

### 1.3 厳密法の側には、実際に回避策があります

単なる理論上の可能性ではありません。


| 方法 | 何を省けるか | 限界 |
| --- | --- | --- |
| 式を計算グラフのまま保持する厳密計算 | 不要な展開、すべての中間値の最小多項式化 | 符号判定やゼロ判定が難しい式では、多くの精度が必要 |
| 拡大体の塔・三角系 | 各段の低次数関係を保った処理 | 後から加わる条件が全体を結びつけると、難しくなる |
| 実数条件を使った分解・枝の除外 | 不適切な枝や成分の一部 | 分解自体が高価な場合がある |
| 非零条件による飽和 | 退化成分 | 正負・凸性・区間条件をすべて表す操作ではない |
| 目標量への直接消去 | 配置全体の決定や列挙 | 中間計算が大きくなることや、不要な複素成分が残ることがある |
| 数値探索と厳密な認証の併用 | 候補を探す段階での全面的な記号計算 | 候補の認証と、全解の完全性は別 |


例えば CORE の Real/Expr は、四則演算と平方根からなる式を保持し、必要な精度で評価しながら、誤りのない比較を行う設計です。厳密計算は、すべてを展開して有理数係数の多項式にすることを意味しません。
cs.nyu.edu

実数の枝も、厳密法が扱えないわけではありません。Maple の RegularChains には、等式・非負条件・正条件・非零条件を扱う三角分解、処理を遅延させる分解、実連結成分ごとのサンプル点計算があります。もちろん、これらも万能の高速解法ではありません。
maplesoft.com
+1

msolve の論文は、主として零次元系の代数的な一変数表示と実根の分離を求める枠組みを説明しています。これは強力ですが、その計算仕様を、厳密法全体の必須仕様と見なしてはいけません。
arxiv.org

なお、不等式で枝を一つに選んでも、その枝の値の最小多項式の次数自体が下がるわけではありません。小さい表現を保てることと、あらゆる判定が安くなることも別です。この点では、厳密法について逆方向の過大評価もしない方がよいです。

### 1.4 数値 solver の「ほぼ線形」も、成立する範囲が狭いです

作図の大きさが $L$ なら、固定精度で作図を一回評価する費用は、おおむね $L$ に比例し得ます。

しかし、solver 全体の費用は、


$$T_{\mathrm{num}}
\approx
N_{\mathrm{eval}}\,C_{\mathrm{eval}}(L,p)
+
T_{\mathrm{線形代数}}
+
T_{\mathrm{式同定}}$$


です。

ここには、評価回数、再出発回数、探索変数数、必要精度 $p$、条件数、答えの次数・係数の大きさが入ります。正しい解に到達する確率が小さくなれば、再出発の費用が増えます。

今回の実装も、NOMAD と多点出発の LM を用いています。最初から正しい枝が分かっていて、その一本をたどるアルゴリズムではありません。 この説明は、実装とも一致していません。
report-draft-v11(3)

数値代数幾何にも一本の経路を認証しながら追う方法がありますが、その計算量は条件数を考慮した経路長などに依存します。「一本だから作図段数に線形」にはなりません。
arxiv.org

守れるのは、次のような条件付きの主張です。

枝が指定され、退化から十分離れ、必要精度・探索回数などが制御される場合、作図を展開せずに評価する費用は、作図の大きさにほぼ比例する。

ただし、これは厳密な式評価にも使える性質です。数値法だけの優位性ではありません。

### 2.2 「図が動いても値が一定」は重要ですが、数値法固有ではありません

AIME 2012 I-14、HMMT 2011 Guts 1、HMMT 2023 Guts 3 は、この研究の思想を説明するよい実例です。

ただし、そのうち目標量への消去が非常に短時間で成功した例は、

配置全体を求めなくても、求める量について計算すればよい。

という原理を支持します。数値法だけがそれをできる、という原理は支持しません。

さらに、一つの図を見つけて値を測ることと、どの許容図でも同じ値になると示すことは違います。原問題が一意の答えを持つと約束された計算課題なら、その約束を利用してよいですが、厳密側にも同じ約束を与える必要があります。

### 2.3 現在の「値の集合を求める」という主張は、まだ弱いです

複数値の対象は開発群の8問だけで、24実行中、完全一致17回、一部のみ4回、答えなし3回です。開発外34問には複数値の問題がありません。
posthoc-20-answer

したがって、

一つの正しい候補を得る能力
原問の答えと一致する集合を返す能力
すべての値を見つけたことを保証する能力

を分ける必要があります。

「実数枝を一本だけたどるから速い」を主張の中心にすると、「値の集合を求める」という仕様とは緊張関係が生じます。複数の値を求める場合、その一本以外を調べる費用と、調べ終えたと判断する根拠が必要になるからです。

## 3．実際の357問で行う、公平で反論に強い実験

人工問題を作って $k$ を伸ばすことを、主実験には勧めません。 既存の実問題を構造で分類し、原問を変えない比較と介入実験を行う方が、今回の目的に合っています。

### 3.1 最初に、双方が何を返せば成功かをそろえる

比較を二段に分けるのがよいです。

実用上の主比較

原問で要求される量について、参照解と一致する値・集合を返したか。全配置の列挙を厳密側に要求しない。変換、前処理、探索、同定、枝の確認を含めた全体時間を測る。

保証を付けた比較

返した値について、何を数学的に保証できたか。実解の存在、式との一致、他の値がないことを区別する。

厳密エンジンを使っていても、最後の枝の確認が高精度の数値照合だけなら、処理全体の保証が厳密になっているとは限りません。双方の実際の保証水準を記録する必要があります。

### 3.2 厳密側には、少なくとも二種類の比較相手が必要です

すべての数式処理系を試す必要はありません。しかし、現在の自動変換＋msolveだけでは不足です。


| 比較相手 | 必要な内容 |
| --- | --- |
| 強化した多項式処理 | 線形な消去、入力由来の非零条件による飽和、目標量への消去、候補の実数条件・枝の確認 |
| 作図の構造を保つ処理 | 探索変数0なら直接評価。順に決まる部分は式や三角系として保持。共通する代数定数を共有 |


重要なのは、同じ数学的情報を与えつつ、それぞれに適した表現を許すことです。数値側だけが作図や枝の意味を利用できる比較では、計算法の差と入力情報の差が混ざります。

例えば、以下は一般規則にできます。

正の長さや、作図の分母が非零であることを取り出す。
目標変数 $T$ とその定義を加える。
探索変数が0なら一般の多項式求解を起動せず評価する。
共通の $\sqrt3$ や既知の角の定数を、独立な未知量として何度も導入しない。
$\pi$ を含む面積なら、可能な場合は係数部分を扱う。
min などは、対応可能な範囲で場合分けする。

未対応を含めた全体成績は実用評価として報告してよいです。ただし、それを代数計算の原理的な限界と呼んではいけません。

### 3.3 「族」は、実問題から構造だけで選びます

実行時間や勝敗を見る前に、入力の構造に基づく選択規則を固定します。


| 実問題のまとまり | 主に調べること | 既存資料での手がかり |
| --- | --- | --- |
| 作図だけで決まる問題 | 展開による費用か、厳密な直接評価でも難しいのか | HMMT 2024 Guts 4 |
| 図は動くが値は有限の問題 | 配置求解と目標求解の差 | AIME 2012 I-14など |
| 非退化条件が重要な問題 | 飽和・実数条件の利用で差が消えるか | AIME 2005 I-01、HMMT 2019 Guts 17 |
| 接する条件を含む問題 | 残差の重複や微分の悪さが収束を妨げるか | 既存の精密化12問 |
| 非線形な作図を多く含む問題 | 作図を直接評価する効果と、その原因 | 作図を展開した既存の比較 |
| 値が複数ある問題 | 回収漏れ、枝探索、完全性 | 開発群8問 |
| 答えの係数が大きい問題 | 図の探索と式の同定の難しさの分離 | AIME 2014 II-10など |


「深い作図で数値法が勝った問題」から選ぶのではなく、該当する問題を全部集めます。対象が少なければ、それも結果です。

そして、全357問を調べても十分な幅の深さ・次数がなければ、このコーパスでは指数対線形の傾向を検証する材料がないと判断すべきです。補助点を水増しして深くしたり、数値を変更して難しくしたりしても、今回の要求への主証拠にはなりません。

### 3.4 測るべき量

主結果には、次を入れたいです。


| 分類 | 測定量 |
| --- | --- |
| 正解性 | 集合完全一致、誤った値、一部のみ、無回答 |
| 実用性能 | 制限時間ごとの正解率、全体時間、最大メモリ |
| 時間の内訳 | 入力変換、前処理、探索、精密化、式同定、枝の確認 |
| 作図の構造 | 演算数 $L$、深さ $k$、二次演算数 $q$、残る探索変数数 $d$ |
| 多項式化の負担 | 変数数、式数、項数、係数の大きさ、共有できる定数 |
| 代数的な構造 | 非退化成分の次元、計算できた範囲での配置次数と目標次数 |
| 数値計算の状態 | 評価回数、再出発数、必要精度、ヤコビアンの状態、枝条件からの余裕 |
| 保証 | 存在、目標値との一致、集合の完全性のどこまで確認したか |


次数が計算できなかった問題を、次数と時間の分析から黙って落とさないことも重要です。難しい問題だけ欠測になるためです。$2^q$ という上界を実際の次数の代わりに使うのも避けるべきです。

時間比較は、同一機・同一コア数・同一メモリ制限で行います。例えば1、3、10、30、180、600秒で、何問が解けたかを主図にすれば、成功した問題だけの中央値より全体像が分かります。

seed の反復は必要ですが、170実行は170の独立した問題ではありません。差や不確実性は、問題を単位として扱います。

また、34問は凍結した旧 solver に対しては開発外であり続けます。しかし、その結果を見て作った新しい説明や改良に対して、再び「未見の検証」とは呼べません。357問の範囲で続けるなら、追加研究を既知の実問題上での再現性・機構の検証として位置づければよいです。

### 3.5 原問を変えない介入実験は、今回の条件に合っています

同じ実問題について、

作図を直接評価する。
作図点を自由変数と等式に戻す。
$y=h(u)+z$ という、作図からのずれを変数にする。

という比較は有効です。人工の問題を増やしているのではなく、同じ問題の表現だけを変えて原因を調べているからです。

ここでは「変数の数」以上に、次の機構を調べる価値があります。作図の等式を一次近似で満たす方向を選んでも、有限の一歩を進むと、


$$y+\Delta y-h(u+\Delta u)
=
-\frac12D^2h(u)[\Delta u,\Delta u]
+
O(\|\Delta u\|^3)$$


というずれが生じます。直接作図する表現では、そのずれは毎回0です。

この説明には、実問題に結びつく予測があります。

中点の作図はアフィンなので、この二次のずれは生じません。

したがって、開発外34問で中点4問しか展開できず、差が出なかった結果は、この曲率による機構を十分に試したことにはなりません。逆に、非線形な交点や正規化を含む作図なら、調べる意味が大きい。もちろん、中点でも尺度やLMの減衰による差はあり得るので、「中点では一切差が出ない」とまでは言いません。
report-draft-v11(3)

成功率だけでなく、受理された歩幅、作図からのずれ、やり直し回数を測れば、既存の説明を検証可能な予測にできます。

## 4．より強い研究の核心は何か
### 4.1 第一候補：作図の意味を使って、数値的に悪い残差を直す

現在の結果の中では、私は「接する条件の書き換え」を重く見ます。

ただし、「符号付きにしたから効いた」だけでは説明が不足しています。

最小二乗なら、


$$|g(u)|^2=g(u)^2$$


です。絶対値を外しただけでは、目的関数は変わりません。解以外で微分を適切に計算すれば、ガウス・ニュートンの方向も同じになり得ます。

本質が「重複した零点を、単純な零点に変えたこと」なら、説明はずっと強くなります。

単位円の中心を $O=(0,0)$、円周上の点を $T=(1,0)$ とし、$T$ を通る直線の方向を $v=(s,1)$ とします。接する条件は $s=0$ です。

中心から直線までの距離で残差を書くと、


$$r_{\mathrm{dist}}(s)
=
\frac1{\sqrt{1+s^2}}-1
=
-\frac12s^2+O(s^4).$$


解で一次の変化が消えています。一方、半径と直線方向の垂直条件なら、


$$r_{\perp}(s)=(T-O)\cdot v=s$$


です。

前者の零点に対するニュートン反復は、近くでは誤差をおよそ半分ずつにする一次収束になります。後者はこの例なら一回で解けます。絶対値の有無以上に、零点の重複が変わっています。

この一般的な数値解析自体は既知です。特異な根を扱いやすくする deflation も既存研究があります。新規性を置くなら、次の部分です。
arxiv.org

作図から、接点が円と直線の上にあることを自動で確認する。
解集合を変えない条件を明示して、残差を自動変換する。
追加の大きな求解をせずに、数値的な特異性を取り除く。
その適用範囲と効果を、実際の出題問題で示す。

ここで必要な追加実験は明確です。

同じ初期候補から、同じ目標値の誤差を比較してください。

現状の119〜502桁という結果は有望ですが、書き換え前後で残差の意味が変わっています。残差の桁数だけでは、答えの精度がどれだけ改善したかが分かりません。また、接触・距離0・半径補助式の変更を一括して外しているので、規則別に切り分ける必要があります。
report-draft-v11(3)

対象も「精密化が実行された12問」だけにせず、全357問で自動規則が適用できる問題数を数えます。候補を発見できなかった問や、書き換えても改善しなかった問も残します。

これは、今回の思想に合う一般性です。適用条件を満たす入力には同じ規則が通り、その条件を満たす実問題が実際にあるという形で示せます。

### 4.2 第二候補：配置の難しさと、求める量の難しさを分離する

もう一つ有力なのは、

座標が決まりにくいことと、求める量が決まりにくいことは違う。

という点です。

例えば、許容配置 $F(u)=0$ が滑らかな集合をなし、自由に動ける方向を $v\in\ker DF(u)$ とすると、


$$d\tau(u)v=0$$


なら、その点では自由方向に動いても、目標値は一次では変化しません。

ただし、一点でこれを観測しても、値が一定だとは証明できません。例えば


$$F(x,y)=x,\qquad \tau(x,y)=y^2$$


では、原点で自由方向の微分は0ですが、許容配置上で値は変わります。連結成分全体での条件と、別成分の値の確認が必要です。

また、「全変数は決まらなくても、その関数は決まる」という考え方には、識別可能性の研究などに先行例があります。したがって、これだけを新しい普遍原理と呼ぶのは難しいです。
PLOS One

それでも、実問題について、

配置の次数や条件数は大きい。
求める量の次数・係数・感度は小さい。
その差が、求値処理の成功や必要精度を説明する。

という結果が出れば、単なる「深さ」よりよい説明になります。

反対側の例も重要です。AIME 2014 II-10 は答えの次数が2でも、係数の上限で同定に失敗しています。これは、次数だけでは性能を説明できないという、既にある反証材料です。失敗を説明できる指標の方が、成功例だけに合う指標より研究として強いです。
report-draft-v11(3)

### 4.3 最も強い追加案：数値で候補を得て、目標値だけを厳密に証明する

上位賞に向けて成果の質を上げるなら、私はここを重視します。

配置全体を厳密に決める必要はなくても、答えについての短い厳密な証拠は作れるのではないか。

手順は次の形です。

今の solver で値を推定する。
PSLQなどで候補の式、または候補多項式 $p(T)$ を得る。
元条件から $p(\tau)=0$ が従う証拠を探す。
実数の枝を絞り、許容配置の存在を確認する。

例えば、作図・制約・目標の定義を多項式 $H_j(z,T)=0$ として表し、入力から非零だと分かる因子の積を $s$ とします。場合によっては、


$$s^r p(T)^m
=
\sum_j A_j(z,T)H_j(z,T)$$


という恒等式が証拠になります。右辺は許容配置で0、$s\neq0$ なので、そこで $p(T)=0$ が従います。恒等式の検証は、厳密な多項式計算でできます。

例えば、

$p(T)=T-375$ なら、許容配置が一つ存在することと合わせて、値が375に確定する。
$p(T)=T^2-21$ なら、目標が正の距離であることから $\sqrt{21}$ に絞れる。

当然、どの正しい答えにも、この形の小さい証拠があるとは限りません。実数の不等式を本質的に使う証明には別の方法も必要です。まずは対象を限定してよいです。

この研究なら、測定するものも明確になります。

証拠を自動で作れた実問題数。
候補発見から証明までの全体時間。
証拠の大きさと、独立した検証器の実行時間。
候補を使わない目標消去との比較。
証明できなかった問題の構造。

数値から厳密な情報を復元・認証する方法自体は既存です。新規性は、幾何求値の目標に絞った自動処理と、その実問題上の有効性に置く必要があります。
arxiv.org

また、近似座標の近くに厳密解があると認証しても、PSLQの式との等号や、他の答えがないことまで自動的に証明されるわけではありません。区間法や $\alpha$-theory の通常の認証は、孤立した正則根などの条件を持ちます。正次元や全解の完全性に、そのまま流用できません。
arxiv.org

## 5．上位賞としての位置づけと、何を加えるべきか
### 5.1 現状をAと強く評価しにくい理由

賞固有の審査基準は示されていないので、実際の受賞予測はできません。研究内容だけについて厳しく評価すると、現状はB寄りで、Aを推す核心がまだ弱いと思います。

理由は次の五つです。

厳密法との主要な差が、事後の一般的な手当てでかなり縮んだ。
開発外34問での6部品のアブレーションは、正解数では大きな差がない。
作図消去の開発外検証は中点4問で、主張したい機構を十分に試せていない。
高精度照合と式候補の出力に比べ、正しさ・完全性の保証が弱い。
既存手法をうまく統合した実装、という評価を超える新しい説明がまだ定まりきっていない。 
report-draft-v11(3)

最後の点では、GMBとの差をもう一段詰める必要があります。GMBには既に、作図の直接計算、再パラメータ化、交点の枝の選択、退化を避けるための仕組みがあります。
arxiv.org

「GMBは値の集合を出さないので比較しない」だけでは、厳しい審査には弱いです。完成システムとして直接比較できなくても、図を作る部分に共通の精密化・式同定を接続した比較は考えられます。そこで何が新たに効いているかを示せると、貢献が明確になります。

### 5.2 上位賞に必要なのは、実験の数より一つのまとまった成果です

追加するとよいのは、次の組み合わせです。


| 必要なもの | 到達したい状態 |
| --- | --- |
| 強い比較 | 飽和・目標消去・作図保持を許しても、どこに差が残るかが分かる |
| 一つの核心的な仕組み | 成立条件、改善する理由、改善しない場合を説明できる |
| 自動化 | 問題IDごとの手当てではなく、入力の構造から同じ規則が適用される |
| 実問題での効果 | 該当問題を全件報告し、同じ条件からの比較で効果を確認する |
| 正しさの強化 | 少なくとも一部の実問題で、答えについて独立に確認できる証拠を出す |


ただし、上の短い接線の計算や、既知のニュートン法の性質を定理として足すだけでは足りません。それを入力から自動的に利用し、実問題の成否や計算量を説明・改善できるところまで必要です。

証明機能も、一問だけ手で証明して終わりでは弱いです。適用範囲が限られていても、同じ仕組みで複数の実問題を処理し、証明できる場合とできない場合が分かることに意味があります。

### 5.4 この方向をやめる基準も、先に決めるべきです

次の状態なら、「次数増大に対する普遍的優位」は主張の中心から外してください。

実際に高い次数を持つ問題が、357問中ほとんどない。
作図を保持した厳密評価で差が消える。
残る差が、$\pi$、min、変数0などの未対応だけで説明できる。
全解を要求した側と、一候補だけでよい側の課題差で説明できる。
有力な成功例が一、二問にとどまる。
性能を支配するのが、深さより条件数や係数の大きさだった。

その結果も、研究として使えます。「当初は代数次数が原因だと思ったが、実際には表現、退化、目標値の同定が主要因だった」と説明し、それに対応する改善を示せればよいからです。

私が上位賞向けに中心へ置くのは、「数値法は厳密法より普遍的に速い」という主張ではありません。実際の幾何求値問題について、作図の意味を利用して計算を安定させ、配置全体を決めずに必要な値を求め、その値を確認できる仕組みです。

この形なら、強い厳密法が多くの問題を解けても研究の核心は残ります。必要なのは、相手が失敗する例を探し続けることではなく、自分の方法が実問題で何を省き、なぜ効き、どこまで正しいと言えるのかを、一つの完成した結果として示すことです。
