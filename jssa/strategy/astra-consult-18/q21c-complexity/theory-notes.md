# Q21c：容易性を推論するときの反例と前提

これらは論文の新規な核ではなく、候補を棄却・限定するための議論である。幾何DSLへの困難性の帰着は作っていない。小さい計算は [theory_check.py](theory_check.py)、出力は [theory-check.json](theory-check.json)。

## 1. 「0次元・二次式・全解有理数」は十分でない

3-CNF式FのBoolean変数を `x₁,…,xₙ` とし、各変数に

```text
xᵢ(1−xᵢ) = 0
```

を課す。正リテラルの値をxᵢ、負リテラルの値を1−xᵢと書く。節jの3リテラルを `ℓⱼ₁,ℓⱼ₂,ℓⱼ₃` とし、補助変数yⱼで

```text
yⱼ − (1−ℓⱼ₁)(1−ℓⱼ₂) = 0
yⱼ(1−ℓⱼ₃) = 0
```

を課す。全式が総次数2以下であり、yⱼはxから一意に決まる。第2式は節が真であることと同値。従って実解が存在することとFの充足可能性は同値で、存在する解の全座標は0か1、解は有限個である。入力サイズはFのサイズの多項式で、係数も小さい。

したがって、有限な解集合・低い個別次数・全座標が作図可能という約束を置いても、変数数が増える族での存在判定は一般に容易にならない（P=NPの場合を除く）。「解集合が0次元」は「探索変数が0個」ではない。

## 2. 非空と少数答まで約束しても、全目標値の取得は難しくできる

Boolean変数zを追加し、各節についてtⱼも入れ、式を次に替える。

```text
xᵢ(1−xᵢ) = 0                     (全てのi)
z(1−z) = 0
yⱼ − (1−ℓⱼ₁)(1−ℓⱼ₂) = 0         (全てのj)
tⱼ − z yⱼ = 0
tⱼ(1−ℓⱼ₃) = 0
目標値 τ = z
```

z=0なら全てのBoolean割当てが解になり、y,tも一意に決まる。従って常に非空である。z=1を許す割当てはFを満たすものに限られる。解集合はちょうど `2ⁿ + #SAT(F)` 個の点からなり、全座標が0か1。目標値の集合は

```text
Fが充足不能： {0}
Fが充足可能： {0,1}
```

となる。正の目標値が必要ならτ=1+zに替えてよい。

よって、全式二次・全解有理数・非空・0次元・目標値は高々2個という約束の下でも、全目標値集合を多項式時間で返せればSATを解ける。目標値集合の出力は定数サイズであり、この反例の難しさは出力の長さではない。

**限界：** 一つの解ならz=0を選べばよい。この構成は非空集合からの一解探索を難しくしていない。また充足可能なときに目標値は二つなので、常に一意な目標値を求める課題の困難性も示していない。実際の幾何への帰着・非退化な配置の実現も未構成である。

小計算では、3変数上の全216種類の順序付き3リテラル節（繰返しを含む）と8割当て、計1,728件で最初の符号化を照合した。次に、各変数を一回ずつ含む8種類の節の全256部分集合について、常に非空で、上の目標値集合と解数になることを照合した。全216節について記号的に各式の最大総次数2も確認した。この有限チェックを一般nに関する証明の代わりにはしていない。

## 3. 作図後1変数でも全根数は指数的に増える

`f₀(x)=x`、`fᵢ₊₁(x)=2fᵢ(x)²−1` と置く。恒等式 `2cos²θ−1=cos2θ` から

```text
fₖ(x) = T_(2ᵏ)(x)
fₖ(cos θ) = cos(2ᵏ θ)
```

である。次数は2ᵏであり、根は

```text
xⱼ = cos((2j−1)π / 2^(k+1)),    j=1,…,2ᵏ
```

となる。全て(−1,1)内の異なる実根。角の二等分を繰り返すことで各根は作図可能である。

作図回路の長さはkで、自由入力はxの1個。補助変数を残せば、`u₀=x, uᵢ₊₁=2uᵢ²−1, uₖ=0` というk+1変数の二次系になる。全部代入すれば1変数・次数2ᵏになる。変数を減らすことと、明示入力を小さくすることは同じでない。

| k | 展開次数 | (−1,1)の実根数 | 平方因子 |
|---:|---:|---:|---|
| 1 | 2 | 2 | なし |
| 2 | 4 | 4 | なし |
| 4 | 16 | 16 | なし |
| 6 | 64 | 64 | なし |
| 8 | 256 | 256 | なし |

SymPyの厳密な多項式演算でk=1〜8を全て検査した。次数、Chebyshev多項式との一致、導関数とのgcdが定数、実根数を確認した。k=8では非零項129、最大絶対係数のビット長321。完全な表は [chebyshev-check.csv](chebyshev-check.csv)。

**限界：** 全根を一つずつ出力するなら指数個の出力が必要、という例である。根の対称性と上の公式から、一根は容易に指定できる。数値最適化が指数時間かかるという下界ではない。本solverでこの人工族を実行しておらず、幾何問題への埋め込みもしていない。

さらにd=0でも、`a₀=2, aᵢ₊₁=aᵢ²` は長さkの回路から `aₖ=2^(2ᵏ)` を作る。これを通常の二進整数で完全に書き出すと2ᵏ+1ビット必要だが、回路や指数式のままなら短い。「作図が指定済みなら容易」という主張には、出力形式の指定も欠かせない。

## 4. 固定変数数の定理を適用するために残る作業

半代数存在判定で全変数数を固定する既知の上界は、明示入力の多項式数・次数・係数長を用いる。今回のdだけを代入できない。少なくとも以下が必要である。

1. 平方根、分母、枝、不等式を含め、元問題と同値な明示半代数式を作る。
2. その全変数数N、総次数D、係数ビット長B、式数を数える。
3. それらが入力長に対してどう増えるかを定める。例えばNを定数とし、Dも入力長の多項式で抑える。
4. 存在判定、一解、近似精度付き探索、全目標値集合のどれを解くかを合わせる。

有限323問はどれも有限長なので、それだけで漸近的な問題族にならない。d≤9やN≤39という最大値に定数の名を付けても、説明したい能力の定理にはならない。N≤4,D≤4も、今回の表を読むための代理ラベルにすぎない。

算術回路による圧縮入力に関するPerrucci–Sabiaの困難性、数値評価とPosSLPに関するAllenderほかの位置づけ、平滑化定理の適用範囲は [literature.md](literature.md) に記録した。これらの一般論から、本DSLの最悪困難性や、この323問の易しさを証明したことにはならない。
