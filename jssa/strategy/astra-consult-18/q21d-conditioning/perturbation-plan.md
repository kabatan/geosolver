# 入力摂動の追加実行前記録

主測定でq<=.01は0問だった。元protocolの選定規則による対照3問はAIME-2006-I-01、AIME-2006-I-07、AIME-2006-II-01。強分離群の代わりに閾値を緩めた問題を補充しない。以下は測定実装の検算であり、主仮説を救う追加実験ではない。

## 対応付けを固定

- AIME-2006-I-01：AB=a=18、BC=b=21、CD=c=14。B=(a,0)、C=(a,b)、対応する三つのDistance条件、Dx<a・Dy>bを一緒に変える。直角は維持。各a,b,cを単独で相対摂動する。これらは入力に明示された長さ。
- AIME-2006-I-07：Creg/Breg=r=11/5を相対摂動する。また作図の上側直線の角度α=10度を相対摂動する（C0内のcos/sinの両方）。αはこのDSLでの任意の図示形状を含む可能性があり、原問の与件とは確認していない。この角度方向は、入力の自由な図示パラメータの対照と明記し、元問題の自然な角度感度とは数えない。面積比rは入力の等式の与件。
- AIME-2006-II-01：与えられた面積A=2116(sqrt(2)+1)を相対摂動する。正方形・45度方向などの作図と等辺条件は維持する。長さsの自然な感度はds/s=(1/2)dA/Aという解析解で独立検算できる。

## 手順

1. 各入力パラメータη=相対変化について、固定x*で±1e-6評価からB=dF/dη、tη=dτ/dηを測る。元のW、D、gを固定し、v=−(WJ)^+WB、dτ/dη=tη+gᵀvを予測する。
2. linear compatibility ||(I-AA^+)WB||/||WB||を記録。これが大きい場合、擬似逆の答えを「実現可能な入力摂動の感度」と解釈しない。
3. 各η=±1e-4,±1e-5、起点は保存hit、trf最大100評価、xtol/ftol/gtol=1e-12、1実行5秒、1worker・1thread。固定した尺度で等式を補正。元式max残差<=1e-8、guard・hardを通るものだけ成功とする。新しい大域出発点・乱数探索なし。
4. 実測の座標変化と目標変化を予測と比較。微小な予測（正規化微分<=1e-8）はrelative誤差でなくabsolute誤差を報告する。正規化誤差1%以内を検算合格とする。合格は主候補の続行条件とは別。
5. 出力は全24実行、6パラメータ（3+2+1）の計画。コンパイル・打切り・不実現も全件残す。

## 追加の理論対照（局所探索なし）

きれいな整数辺からなる二等辺三角形a=b=m²+1、c=2(m²−1)（m=2,10,100）は高さ2m、面積2m(m²−1)と整数になる。等辺長aを共通に変えると高さの相対感度a²/(4m²)はm²/4のオーダーで増大する。これは初等的反例で、新規発見やsolver固有の成果に数えない。式と高精度差分を照合して「整数の答え⇒良条件」の推論を排除する。
