**保証の範囲。** 以下は元DSLと保存多項式系を人が照合した意味の監査と、その後の機械的な有理係数検算である。DSL変換器全体の形式証明ではない。係数が非零有理数の式a·x+b=0による代入は、目標を残して複素解集合を同型に保つ。これと、元の実数条件から正当化した成分除去を区別する。

元の多項式系は各Q11 resultと同じフォルダのsystem.json。Q35の[components/](components/)には原式、加えた式、全代入履歴、許容配置と不許容族を保存し、[certificates/](certificates/)には簡約後の式に対するQ=ΣCᵢFᵢの全係数を保存した。[verify.py](verify.py)は保存Q・Fと入力を結び直し、恒等式をFraction演算で検算する。非零条件の補助変数も通常の変数として検算し、暗黙の因子除去はしない。

**AIME-2009-I-12。** 元DSLはA=(12,0)、B=(0,35)、I=(ix,iy)、ix<0、iy<0。求値はT=(AI+BI)/37+1である。直線ABの式は

```
L = 35ix + 12iy - 420 = 0.
```

L<0は明示された二つの不等式から従う。原代数系には、任意のwについて次の族がある（s₁,s₂は点と直線の距離、s₃=AI、s₄=BIの平方化補助変数）。

```
iy=w, ix=(420-12w)/35,
s1=s2=210/37,
s3=-37w/35, s4=37(35-w)/35,
T=2-2w/35.
```

全原多項式への代入残差は厳密に0。w<0なら距離補助変数も正だがix>12になり、ix<0に反する。Tは連続に動くので、原系だけから非零Q(T)は出ない。

L·z−1=0を加えると、次の式の非零定数倍について恒等式が得られる。

```
(3T-8)(3T+2)(1369T-2450)(1369T-288)=0.
```

IはAB上にないため厳密な三角不等式AI+BI>AB=37、従ってT>2。上の4根で2を超えるのは8/3だけ。存在の厳密配置は

```
ix=-576/1369, iy=-42875/4107,
s3=1801/111, s4=5044/111, T=8/3.
```

全原式と追加式、ix<0、iy<0、距離の正の枝を満たす。なお、この飽和による修正自体は[旧調査](../../astra-consult-17/H/sources/prior-README.md)にもある。今回はQ11の保存系に対し再構成した。

**HMMT-2006-FEB-GEO-01。** 元条件はDistance(A,Aclose)=0。保存系の該当部分は、s=√2の補助変数、p₂,p₃を座標差として

```
F0 = s²-2
F1 = p2*s + 2s² + s - h
F2 = p3*s - 2s² + s*g - 3s + h
F3 = p2²+p3²-s4²
F4 = s4
F5 = T-g-h-14
F6 = s*zz-1.
```

実数ならF3=F4=0からp₂=p₃=0。しかし複素数ではp₂=w、p₃=i·wが許され、

```
s=√2, zz=1/√2, s4=0,
h=4+√2+√2*w,
g=2-(1+i)*w,
T=20+√2+(√2-1-i)*w
```

が全原式を満たす。Tは非定数なので、元の複素代数系の目標消去イデアルは0である。

実数で同値なp₂=p₃=0を加えると(T−20)²−2の恒等式が出る。符号の選別も必要で、T>0だけでは二根を分けられない。そこで

```
F1+F2 = s(p2+p3+g-2),
F1-2F0 = s*p2+s-h+4
```

から、s≠0、p₂=p₃=0によりg=2、h=4+s、T=20+sを得る。元DSLのsqrt(2)は正の枝なのでT=20+√2。g=2、h=4+√2は正で、作図を閉じる厳密配置にもなる。今回の障害には「複素化した平方和」と「実数の距離0」の区別だけで足りる。

**JMO-2013-PRE-08。** 中心(ox,oy)、半径rの円が、中心A=(-5,0)、B=(0,6)、C=(20,0)、D=(0,−d)の円を内接させる式を使う。元DSLにr>0、d>0がある。保存系は

```
s1²=(ox+5)²+oy²,        s1=r-5,
s2²=ox²+(oy-6)²,        s2=r-6,
s3²=(ox-20)²+oy²,       s3=r-20,
s4²=ox²+(oy+d)²,        s4=r-d,
s5²=d²,                 T=s5.
```

この複素代数系ではr=ox=oy=0、d=w、(s₁,s₂,s₃,s₄,s₅)=(-5,-6,-20,-w,w)、T=wが自由になる。元の正の半径・距離の意味では不許容。r·z−1=0を追加するとT²−144の恒等式が得られ、T=|d|>0よりT=12。

厳密配置はr=3600/119、ox=2160/119、oy=−1200/119、d=12。全距離補助変数が正で、元の平方していない距離条件も満たす。この半径の飽和も旧調査に先行例がある。

**なぜ時間を延ばすだけではこの3問を救えないか。** 原系の全式を満たす族上でT(w)が非定数なら、恒等式Q(T)=ΣCᵢFᵢはQ(T(w))=0を全wについて要求する。多項式Qが非零ならこれは不可能である。保存系に既存の非零条件の補助式があれば、その式も上の族が満たすことを検算した。この結論は基底計算の速さに依存しない。

修正後の恒等式は、元DSLの許容実配置すべてに必要条件を与える。上の符号・不等式によって値を一つに絞り、厳密配置により存在も確認した。ただしQ11の一般的な値域推論がこの手製の根選別を自動的に行えるとは主張しない。

**動く図でも証明が短い自然例。** HMMT-2013-FEB-GEO-02の保存系を順に

```
F1=s1²-h²-25/4
F2=s2²-x²+11x-y²+2yh-h²-121/4
F3=s1-s2
F4=x²-(11/2)x+y²-yh
F5=s3²-x²-y²
F6=s3-T
```

とすれば

```
T²-24 = -F1+F2+(s1+s2)F3+2F4+F5-(s3+T)F6.
```

高さhを決める必要がない。これは台形の二つの長さの二乗差でh²が消える初等幾何と同じ内容である。G成功6問の恒等式は次のとおり。

| 問題 | 認証に使ったQ(T) | 非零因子の指数N | 係数の合計項数 |
|---|---|---:|---:|
| AIME-2015-II-07 | T−36/125 | 0 | 1 |
| HMMT-2008-FEB-GEO-06 | T²−17 | 2 | 10 |
| HMMT-2013-FEB-GEO-02 | T²−24 | 0 | 8 |
| HMMT-2013-FEB-GEO-08 | T²−1764/169 | 0 | 4 |
| HMMT-2022-FEB-GEO-01 | T²−441 | 0 | 31 |
| aime-2001-1-9 | T²−256/2025 | 1 | 46 |

Q11原票の再集計であり、新規に発見した規則ではない。AIME-2015-II-07は既に入力の目標式が定数。ほかの5例も、その自由度を消すより目標の関係だけを証明する方が少ない仕事で済むという既知の区別に当てはまる。

既存の恒等式sᴺQ(T)=ΣCᵢFᵢがあるとき、等式Gⱼ=0を追加して配置を孤立させても、右辺へ0·Gⱼを追加すれば同じ証明になる。したがって「孤立すること自体がその証明書を難しくする」という一般則は成り立たない。反対に、孤立した正しい実配置の周囲に不許容の複素成分を混ぜれば、目標恒等式そのものを消してしまえる。この区別が今回の小検証で確定した機構である。

**既知の手段との関係。** 非零条件を多項式系へ取り込むsaturationは標準的な代数計算で、msolveの公式文書にも定義がある。現在の実装の全機能や、本件を同予算で解けることを文献から推測してはいない。[msolve公式tutorial §7](https://msolve.proj.lip6.fr/downloads/msolve-tutorial.pdf)。零次元性の検査と多項式のイデアル所属の検査も通常のCAS機能である。[SymPy公式reference](https://docs.sympy.org/latest/modules/polys/reference.html#sympy.polys.polytools.GroebnerBasis.is_zero_dimensional)。

これらは現象を記述する便利な言語だが、この3例に深い理論が不可欠だったという証拠ではない。ここから54問全体の認証率や時間を定量予言する定理は得ていない。
