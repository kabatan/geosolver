# 文献確認後の第二監査（探索的、2026-10-23）

Hamami, van der Kuil, Mumma, van der Ham (2020), DOI 10.1016/j.actpsy.2020.103019 の著者版 p.5, Table 1 を確認した。exact/co-exact と metric/topological は別の軸である。最初の `diagram` タグを co-exact と読み替えてはいけない。特に接触・入射は exact でありうる。共円は同論文では metric/exact。

この発見後に行う再注釈であり、外部事前登録ではない。最初の計画・集計は変更しない。新規局所探索は0回のまま。対象・残差ノルム閾値1e-8は同じ。因果ではなく条件の未達を数える。

- 値の等式・角・平行・垂直・共円を exact/metric、点の直線・円への入射、共線、点の一致、接触を exact/topological と注釈する。これらは独立した対象の関係としての分類で、構成により恒真となる場合の計算負荷は別である。
- `OnSegment` は直線への入射と区間内の順序を含み、構成に相対的な分類が必要なので未分類にする。一般の代数式、ゼロ面積の軸帰属なども推測で補わない。
- 正則で非退化な配置の厳密な大小・不等は co-exact とする。距離・面積の非零と凸性・自己交差なしは topological、それ以外の明示的な長さ・角等の大小は metric。閉じた不等式、座標だけの式、混合式は未分類とする。
- 数値の余裕閾値による拒否・selector trace・例外を co-exact 陽性とは数えない。guard の False は実装上の判定であり数学的反例の証明ではない。
- 元の evaluator で失敗終点の残差行だけを再評価し、第一監査と同じ総ノルムか検算する。guard/hard は第一監査の保存値を利用する。
- exact/metric と exact/topological の未達、型の確定した co-exact guard の不合格、未分類を別に保存する。「どちらに由来したか」という単一原因の列は作らない。

この第二監査の結果がどうであっても、公式解答の定理数を人間の実測時間に置き換えない。人間との逆転の採否基準を集計値に合わせて変更しない。
