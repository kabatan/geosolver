2026-10-23。担当レンズ：他の機械との比較。これはこの方向全体の不可能性を示す判定ではなく、今回得た根拠に対する判定である。

今回の成果は、失敗した予測を含む再解析一式と、4者比較で取り違えてはいけない課題・データの整理である。相関予測、手法の使い分け、高速化、正答率改善をAの代案として提出するものではない。

## 2. 理論的な整理：比較単位は「問題名」だけでは足りない

幾何の仮定を P、許される配置を指定する条件を B、問いを Q とする。比較対象は少なくとも **(P, B, Q, 入力表現, 計算・回答プロトコル)** で固定する必要がある。

- 図の生成は、PとBを満たす配置 x を一つ返す課題。
- 定理の証明は、PとBを満たすすべての配置についてQが成り立つと示す課題。
- 求値は、指定された量の値を返す課題。複数の値がありうる場合には、その扱いも揃える必要がある。

図を生成してその上でQを検算しても、後者二つを一般に解いたことにはならない。この論理的な違い自体は紙と鉛筆で分かり、新しい研究の核ではない。

| 系・段階 | 難しさを説明するために見るべき対象 | 今回確認できたこと／未確認なこと |
|---|---|---|
| DD+AR単体 | 規則閉包で得られる関係、角度・比などの算術推論、必要な補助点 | 固定した規則・点集合の6実行を測定。AlphaGeometry全体の能力とは別 |
| AlphaGeometry系の全体 | 上記に加えて、補助構成を提案・探索する過程 | AG1の公開結果を転記。AG2は文献確認のみ |
| Wuの方法 | 仮定と結論の多項式化、消去順序、中間式、非退化条件 | 公開の問題別成績を再集計。今回JGEXを実行していない |
| 面積法 | 有向面積・比等の表現と、構成点を消去する順序・式の成長 | 手法の文献を確認。IMO-AG-30での同一条件の成績は未確認 |
| 数値 solver | 実際に探索する変数と残差、初期値からの更新過程、精密化・値同定の各段階 | 既存GMBの6記録を抽出。今回GeoSolverの新規探索はしていない |
| 単独LLM | 問題の表現、候補解法の生成、推論予算、出力の検査 | 当該15結論の回答ログなし。AG内の構成提案器と単独LLMを同一視しない |
| 人間 | 定理・表現・補助線の選択、既有知識、試験時間と採点 | 手元の人間成績はAIME/HMMTのみ。今回の結論別時間・正答率は欠測 |

これは難しさを一意に計算する理論ではなく、**競合する機構仮説を区別する整理**である。変数数や多項式次数だけから各欄の大小が決まる、といった定理は得ていない。

さらに「記号」と「数値」は実装の中では独立でない。保存したDD+ARのコードでも、図の数値座標を用いる向きの判定がある。AG2の自動図生成には数値最適化も使われる。したがって、システム全体の失敗をすべて「記号推論の難しさ」と呼ぶこともできない。[DD+ARの該当実装](upstream/dd.py)、[AG2論文 Appendix G](https://arxiv.org/html/2502.03544v3)

### ここから直ちに導けることと、実験が必要なこと

Qを目的関数・停止条件に入れない図生成器なら、P・B・初期値を固定してQだけ替えても生成計算は同じである。この不変性は実験で発見するものではない。一方、同じ述語・同じ点数のQでも、特定の規則集合でどれが導出されるかは別の問題である。候補1は後者について、方向を指定した予測を試した。

各方式の得意不得意が違うという一般論も自明に近い。候補2が研究になるには、同一課題の対で「なぜこちらが逆転するか」を内部の処理に結び付け、結果を見る前に指定する必要がある。

## 3. 候補1：同一の仮定から、問いだけで分かれる難しさ

### (a) 一文の主張

**同じ仮定・同じ共円述語・同じ4点という結論でも、問いが参照する構成上の関係によってDD+ARの到達可能性が分かれ、数値図生成にはその区別が現れない。**

今回の具体化は、IMO 2008 P1の六つの交点から選ぶ全15四点組である。

### (b) なぜ「そりゃそうだ」で終わらない可能性があるか

「証明と図生成は違う」だけなら終わる。狙ったのは、仮定も述語も点数も等しい15結論を、**2辺から2点ずつの3組／3辺から2+1+1点の12組**に分け、前者だけ導出されると予告することだった。表面的な問題サイズでは区別できない差を、規則系の構造に結び付けられる可能性があった。

しかし、その具体的な差は観測されなかった。非自明になりえた部分が失敗し、残った不変性だけを主張へ縮めて成功扱いにはしない。

### (c) 土台にした既存研究

[AlphaGeometryの公式入力](https://github.com/google-deepmind/alphageometry/blob/main/imo_ag_30.txt)では2008 P1が二つの結論へ分割されている。[Sinhaらの再評価、Figure 1](https://arxiv.org/html/2404.06405v2)では、AG1全体はP1aを解きP1bを解かず、DD+AR単体は両方を解かず、Wuは両方を解く。この公開成績を知った上での探索的検証であり、未知問題への盲検予測ではない。

とくに**AG1全体のa/bの差を、DD+AR単体の差へ移す根拠は弱かった**。今回その飛躍を反証する結果になった。現在の比較という点でも、AG2の報告ではIMO-AG-30の全30題が解かれており、AG1の穴を一般的な記号推論の限界にはできない。[AG2論文 Table 4](https://arxiv.org/html/2502.03544v3)

### (d) 1.5日で確かめる設計

最初の2時間を中止判定に使う。全30入力から同一仮定の群を列挙し、P1の全15結論を、固定3seedと一つの再命名で検査する。事前予測・上限・全件報告は[元計画](analysis-plan.md)に固定済み。この段階を今回完了した。

もし予測が成立していた場合だけ、残る時間で別の定理族の同一仮定対へ進み、同じ構造的区別が移るか調べる。人間・LLMについては同一結論ごとの記録が必要で、元のIMO一問の得点を小問へ複製しない。新たな人間実験なしに1.5日で四者の因果的説明を完成できるとは約束しない。

**今回は最初の中止条件に達したため、予測を取り替えて追加探索していない。**

### (e) 外れたときに残るもの

同一仮定群の一覧、15結論の全結果、実装と公開成績の対応、簡単な一般証明が残る。「同じ定理名を付けておけば比較可能」という誤りを避ける教材・比較手順にはなる。GeoSolverの新機構の発見にはならない。

### (f) 紙と鉛筆で先に導けないか

**残った主張は導けるので不合格。** 図生成のQ不変性は入力仕様から分かる。六点共円も、外心と九点円を用いる短い式で説明できる（5.4節）。DD+ARの具体的な3対12の区別は紙上で確立できておらず、実測でも成立しなかった。

### (g) 代替手段で得られないか

**得られるので不合格。** 解析的に交点を作るだけで全15結論を検算できる。通常の数値最適化によるGMBの既存6試行も、各試行で15結論すべてを自己検査で通していた。Wuの公開成績も両小問を証明している。GeoGebraでの同条件の再実行は未確認であり、実行したとは扱わない。

### (h) solverならではの能力が中心か

**中心になっていないので不合格。** 今回の一般的な説明は人手で導いた幾何・代数であり、数値計算はその検算である。多様な未知問題を同じ仕組みで解くGeoSolverの能力について、新しい説明を得ていない。

## 4. 候補2：機構から予告する難易度の逆転

### (a) 一文の主張

**同じ求値課題に対し、幾何関係の伝播・代数的消去・数値探索の内部処理が異なるため、単純な問題サイズでは説明できない難易度の逆転を、その処理構造から方向付きで予告できる。**

これは未検証の研究仮説である。単一の「人間難度」と機械の時間の相関を求める案ではない。

### (b) なぜ「そりゃそうだ」で終わらない可能性があるか

手法間の勝ち負けが違うことは既知である。非自明にする条件は、複数の問題対について「関係の伝播では短いが消去では中間式が増える」「その大小関係と数値探索の成否は逆になる」などを、実行前に同じ機構的説明から導くことにある。

そのうえで、数値 solver が単に一問の図を作る例示役ではなく、他方式と異なる答えへの到達過程を多様な入力で示す必要がある。**今回はそこまで具体的な予言を構成できていない。**

### (c) 土台にした既存研究

DD+ARとWuの相補性は[Sinhaら](https://arxiv.org/html/2404.06405v2)の主結果そのものである。転記表ではWuのみ7題、DD+ARのみ6題で、双方に包含関係がない。これを新発見にはできない。

面積法は、構成的幾何の証明を代数的な量の消去として扱う比較候補である。[Janičić・Narboux・Quaresma, The Area Method: A Recapitulation](https://doi.org/10.1007/s10817-010-9209-7)の書誌・要旨と公開実装を確認したが、本問題群での実行成績は未確認。Full-Angle methodの成績を面積法の値として流用しない。

数値的な図生成の比較対象は[GMB](https://arxiv.org/abs/2012.02590v2)。求値の共通課題についてはAG2に角度・比の計算用の表現があるが、それだけで任意のAIME/HMMT問題が翻訳できるわけではない。[AG2 §2](https://arxiv.org/html/2502.03544v3)

### (d) 1.5日で確かめる設計

以下は未実行の設計であり、今回の結果に追加した実験ではない。

1. **最初の3時間：共通課題と予測を固定する。** 人間成績のある既存問題から、角度・比の求値を最大12問選ぶ。同じ仮定・枝・問いを全方式に渡し、既知の答えを一部の方式だけに入力しない。AG2なら求値述語、Wu系なら未知の求値変数を含む消去、数値法なら同じ量の値を出力する。表現できなかった問題も記録し、成績を見て補充しない。
2. **次の3時間：少なくとも3対の方向を固定する。** 規則列・消去の依存関係・数値探索の更新式から、どの方式間で逆転を予想するかと、その理由を文章化する。変数数・次数だけの後付け説明は認めない。この段階で説明と予測を作れなければ、大きな計算へ進まず候補を棄却する。
3. **次の4時間：小さな再生実験。** 数値法は固定3seed、1実行60秒、同時実行最大2。記号器は同一課題ごとの同じ上限を別に定める。解の出力だけでなく、推論の到達関係、消去中の式の増加、数値の主要段階を保存する。LLMはモデル・プロンプト・推論予算を先に固定できる場合だけ別列で測る。取得できなければ欠測。
4. **最後の2時間：主張の判定。** 事前に挙げた逆転の向きと内部処理が対応するかを全対で報告する。既存の人間成績は同一大会内で参照し、新たな解答過程の測定と呼ばない。時間差・正答数だけが出た場合、機構仮説は支持されない。

この12時間程度の設計は、必要な実装・翻訳が利用可能な場合の小検証である。現時点では全方式の共通12問も、3対の予言も用意できていない。その準備不足を、大規模計算で埋める案にはしない。

### (e) 外れたときに残るもの

同じ求値課題に対する入力対応と、各方式がどの段階で止まったかの表が残る。限定的な比較資料にはなるが、逆転がなくても成功率表だけでAとして続行する理由にはしない。

### (f) 紙と鉛筆で先に導けないか

**未充足。** アルゴリズムの違いから「どこかで逆転する」こと自体は予想でき、既報でもある。紙上で分かる一般論を超えて、多様な具体例の方向と処理過程まで予告できるかが未確認。今回その追加部分の根拠を得ていない。

### (g) 代替手段で得られないか

**未充足。** Wu・面積法・通常の最適化を同じ対象で動かすことが、そもそも必要な対照である。GMBや一般的な最小二乗法でも同じ説明が完結するなら、本 solver を中心に据える理由は弱い。代替手段を避けて都合のよい対照だけを選ぶことはできない。

### (h) solverならではの能力が中心か

**条件付きで可能だが、今回は未達。** 一つのsolverが問題別の解法を与えられずに多様な入力を処理し、その共通機構が他方式との逆転を説明するところまで必要である。現在あるのは記号器どうしの公開の相補性で、GeoSolverはまだ研究上の主役になっていない。よって「保留」は採用推薦を意味しない。

### 5.4 共円性が紙と鉛筆で得られる理由

三角形ABCの外心をO、垂心をH、外接円半径をRとする。辺の中点をMとし、中心M・点Hを通る円とその辺の直線との交点をPとする。定義から |P−M|²=|H−M|²。O−Mは辺に垂直なので、

**|P−O|² = |H−M|² + |O−M|²。**

九点円の中心N=(O+H)/2を使えば、

**|H−M|² + |O−M|² = 2|M−N|² + |O−H|²/2 = (R²+|O−H|²)/2。**

右辺はどの辺を選んでも同じである。したがって六つの交点はOを共通中心とする同じ円に乗る。15個の四点結論として読むときは、六点が互いに異なる配置を対象とする。

この議論をA=(0,0)、B=(1,0)、C=(x,y)、y≠0で有理式へ展開し、三辺の式の差が厳密に0になることをSymPyで確認した。人手で作った証明の代数検算であって、未知の解法をsolverが発見したものではない。[厳密計算結果](exact-common-circle.json)

補助検算は、実行前に固定した六つの有理数座標で交点を解析的に計算した。60桁、全15四点組、共円行列式を最大点間距離の4乗で正規化、閾値1e-40。全配置が鋭角・六点相異で、最大値は約1.664e-61だった。閾値や配置の事後変更はない。[全90検算](analytic-coordinate-checks.csv)

## 6. データの接続で分かった限界

[coverage.json](coverage.json)に機械可読な集計を保存した。

- IMO-AG-30は30課題／元の28問題。GMB比較の36入力には、そのうち26元問題／28課題がある。欠けるのはIMO 2021 P3、2022 P4。
- 手元のhuman_feat.csvは323行、そのうち人間成績ありは131行（AIME 52、HMMT 79）。IMOは0行である。この表からIMO-AG-30の四者比較は作れない。
- IMO公式の元問題別得点を別途得ても、2008 P1a/bの難しさや15結論の解答時間にはならない。元問題の一つの値を小問へ重複配賦しない。
- GMBのper-trial.csvの136行は、図が存在して独立検査された部分集合である。既定・厳格の全216試行の完了表ではない。今回使った2008 P1の6行は[抽出表](gmb-2008p1-existing.csv)に残した。
- 草稿にあるGeoSolverの100/108は、図の独立数値検査の通過数である。AG/Wuの定理証明数と並べて勝率の順位を作ることはできない。また、この集計だけから2008 P1のGeoSolver個別成績も復元しない。
- AG2は既に旧IMO-AG-30を全問解くという報告がある。旧AG1の失敗例だけを数値solverの独自性の証拠にしない。
- 面積法、当該結論ごとの単独LLM、人間の同一課題への回答は欠測。三者・四者の実測比較が完了したとは主張しない。

必要な追加の公開データ、確認した文献、未確認箇所は[sources.md](sources.md)に具体的に記載した。追加データの不在を理由に停止せず、利用可能だった入力・保存ログ・公開表・厳密計算の範囲を完了した。

## 7. 何が残り、何を推薦しないか

今回の2候補をAの本線へ進めることは推薦しない。候補1は固定予測と(f)〜(h)で落ちる。候補2は既知の相補性を超える具体的予測と、solverを中心にした説明をまだ持たない。

残すのは、再実行可能な小検証、一般式、全件の成功・失敗表、比較対象の対応と欠測の一覧である。これらは比較の部品として利用できるが、「solverだから初めて見えた新しい幾何の難しさ」とは呼べない。

実行・成果物の案内は[README.md](README.md)、指定背景資料の確認範囲は[background.md](background.md)を参照。
