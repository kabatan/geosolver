高校2年生の研究レポート（日本学生科学賞・情報技術部門、最高賞を狙う）の理論部分について、数値解析・最適化・実代数幾何に詳しい研究者として相談に乗ってください。本人から「実験結果から自明に言えることを並べただけで、理論的な考察が浅い。もっと本質的な考察を」と言われています。下の実測を踏まえ、レポートの核になる理論を一緒に作りたいです。数学的に正確であることを最優先し、高校生が書けて審査員に伝わる形にしてください。

## 対象（前回の相談の続き）

幾何の求値問題を解く数値solverです。
- 問題は、探索変数 u∈R^d、作図 h（中点・交点・垂線の足・外心など。u から点を計算する関数）、等式 F(u)=0（m本）、不等式 G(u)>0（枝の指定）、求める量 τ(u) で書きます。答えは集合 {τ(u) | F=0, G>0} です（有限と仮定）。
- 残差ベクトル r(u)（等式のずれと、不等式違反のペナルティ）を、多数のランダム開始点から Levenberg–Marquardt（LM）で0にします。主探索は NOMAD です。
- 見つけた解は多倍長LMとニュートン法で数百桁に精密化し、PSLQで代数的数に同定して、120〜500桁で検証します。

## 新しい実測

**A. 二種類の難しさ（323問中、msolveが解けた201問）**
座標を多項式にして msolve で厳密に解く方法と比べました。
- 「ベズー数（方程式の次数の積）」と「探索変数の数 d」の順位相関は 0.12 で、ほぼ無関係でした。
- msolve の時間は、ベズー数と 0.69、d とは 0.28 の順位相関でした。
- solver の時間は、d と 0.57、ベズー数とも 0.50 の順位相関でした。
- msolve が解けなかった122問は、内訳が次のとおりです。いずれも solver はほぼ解いています。
  - 正次元（図は無数にあるが値は決まる）：68問
  - 時間切れ・メモリ：24問
  - 角度などが多項式化できない：15問
  - その他：15問
- 多項式の未知数は中央値9個で、探索変数の3個より多くなりました。

**B. 当たる確率 p（1回の局所LMで正しい解に収束する確率、292問、各200開始点）**
- p の中央値は、d=1 で1.00、d=3 で0.72、d=5 で0.15、d≥6 で0.11 でした。別seedでも再現しました（順位相関0.99）。
- 外れた開始点の行き先：
  - 残差が0でない点での停止が、d=1 で11%、d=5 で51%
  - 範囲外への逸脱が、d≥6 で42%
  - 等式は満たすが枝が違う点：ほぼ0
- t/p（t は1回の時間）と solver の実時間の順位相関は 0.69 でした。
- 正解での残差ヤコビアンの条件数 κ を使った回帰：log p を d だけで説明すると R²=0.16、d と log κ を使うと R²=0.24 になりました（234問）。

**C. 作図を自由点＋等式に書き換える介入（15問、k か所、k=0〜3）**
- 作図 y=h(u) を自由点 y と等式 y−h(u)=0（2本）に置き換えました。解の集合は変わりません。
- p の中央値は 0.96、0.77、0.40、0.38 と下がりました。1回のLMの時間は 1.0、2.4、4.1、7.9 倍、solverの時間は 1.00、1.55、1.80、3.43 倍でした。正解数はほぼ不変です。
- 正解でのヤコビアンの条件数 κ の中央値は 1.8、82、92、159 と悪化しました。同じ問題の中で見ると、Δlog κ と Δp の順位相関は −0.67（p=5e-5、30組）でした。
- 対照実験：書き換えた点を正しい位置 h(u) から出発させると、k=2 で p は0.40→0.76 に戻りましたが、k=3 では 0.39→0.42 でほぼ戻りませんでした。逆に下がった問題もあります（0.29→0.06）。
- 書き換えで p がほぼ変わらない問題や、上がる問題もありました。

**D. 重根**
条件 f=0 を f²=0 に書き換えると、精密化が進まず 5/5→0/5 になりました。

**E. 枝**
等式を満たす点には99%で到達するのに、正しい枝は0.3%という問題がありました。

**F. 人間の難しさ**
人間の難度（実正答率からのIRT）は、入力の構造を知った後では solver の時間の予測にほとんど寄与しませんでした。年度をまたぐ予測で、順位相関 0.80→0.80（AIME）、0.70→0.71（HMMT）です。

## 相談したいこと

1. **作図による変数消去の理論。**
   - 拡大系のヤコビアン J_aug=[[r_u, r_y],[−Dh, I]] と、縮約系 J_R=r_u+r_y·Dh（シューア補行列）の関係から、κ(J_aug) が κ(J_R) よりどれだけ悪くなりうるかを、‖Dh‖・‖r_y‖ などで評価できますか。下界や上界、典型的な振る舞いを知りたいです。
   - 実測の κ の悪化（1.8→82〜159）とつじつまは合いますか。
   - 拡大系で、y について内側を最小化した関数 ψ(u)=min_y ‖r(u,y)‖²+‖y−h(u)‖² は、元の φ(u)=‖r(u,h(u))‖² を「なめらかにしたもの」と見られますか。
   - だとすると、書き換えが局所解を増やす場合と減らす場合の条件（r が y について線形か、など）を整理できますか。p が上がる問題がある事実とも整合しますか。
2. **p の理論。**
   - ニュートン–カントロビッチの定理などから、「解のまわりに、収束が保証される半径 ρ ≈ c·σ_min/L の球がある」と言えます。ここで σ_min は最小特異値、L はヤコビアンのリプシッツ定数です。
   - すると p ≥ vol(B_ρ)/vol(box) ∝ (ρ/幅)^d となり、d について指数的、σ_min について冪的、という予測が立ちます。
   - これは下界にすぎませんが、log p ≈ a − b·d − c·log κ という形の実測（B、C）を説明する理論として、どこまで正当化できますか。弱点はどこですか。
3. **二種類の難しさの理論。**
   - 厳密法の計算量（グレブナー基底・msolve の F4/FGLM、次数 D の零次元イデアルで D の多項式時間、など）と、solver の計算量 t/p を対比したいです。
   - 「厳密法は代数的な大きさ（複素解の個数）に、solver は実の正しい解の引き込み領域の幾何に支配される。両者は独立な量で、だから得意な問題が違う」という主張を、どこまで厳密に言えますか。
   - 座標化で未知数が増えること（作図の消去が多項式側では使えない、または使うと次数が上がる）も含めて、整理してください。
4. **重根と枝。**
   - 重根の精度限界（有限精度 ε で到達できる精度が ε^{1/m} 程度、反復の収束率が 1−1/m）を、高校生向けに正確に書く方法を教えてください。
   - 枝については、p=Pr(E)·Pr(C|E) の分解が使えるかを知りたいです。Pr(C|E) を、等式の実解のうち正しい枝の割合と、各解の引き込み領域の体積で表すモデルはありますか。実測では、「正しい解の数/実解の数」と p の順位相関は 0.26 で、等分配とは言えませんでした。
5. **核となる主張。** 以上から、レポートの「本質的な考察」の核にすべき主張を1〜2個、数式1〜3本で提案してください。たとえば「solver の難しさ = 次元 × 条件数で決まる引き込み領域の小ささ」のような形です。
