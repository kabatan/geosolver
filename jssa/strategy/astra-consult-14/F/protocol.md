# astra-F：反証を試みる解析計画（実行前の固定）

2026-10-23。既存の相談A/B/C、v7、相談13とseed 0の集計は読んだ。以下は公開事前登録でも未見問題の確認実験でもない。既存集計の行数・単純相関は既に点検し、55,097開始であること、大会別の人間難度相関が混合相関と違うことを把握した段階で固定した。

## 統計監査

- 対象は start-feasibility-1023/per-problem.csv の292問。raw-323の記録との件数・成功数の照合、既存分解の再計算を行う。
- 別の一様乱数256点/問（seed `[1402301, SHA256(id)の先頭8桁を整数化]`）でhard feasibilityだけを測る。探索・公式解・終点を使用しない。失敗タグとguardの種類・個数も保存する。既存CSVのφをφ0、新しいものをφ256と区別する。
- φと成功率の順位相関を、変数数、DSLの不等式数、IRのhard検査数、等式数、DSL文字数で調整する。変数数カテゴリと順位化した連続共変量への回帰残差の相関も報告する。これで非線形交絡を完全に除去したとは扱わない。
- 主な予測比較は問題単位5分割×10回。学習問題のseed 0成功率から、未学習問題の既存seed 1成功率を予測する。固定のL2正則化ロジスティック回帰（切片以外の二乗和/2を、問題ごとの交差エントロピーの総和に加算）を使い、変数数カテゴリ＋不等式数＋hard検査数＋等式数＋log(DSL文字数)のモデルにφ256を追加する。全て学習側で標準化。各問題の重みは等しい。比較用に変数数だけ／変数数＋φも報告。log lossと成功率RMSE、問題単位の損失差の記述的bootstrap区間を出す。これは開発データ内の交差検証であり未知問題での事前登録済み検証ではない。
- 人間難度は同じ109問で、混合、大会別、大会内順位で比較する。相関のbootstrap区間を出し、「有意でない」を「無関係」と書かない。solverと人間への相関差も同じ集合上で確認する。
- φ=1でも低成功率、φ=0でも成功する反例、可行/不可行の両方が10点以上ある問題内の差を報告する。

## 罰則の対照実験

対象は既知の主例2問（AIME-2023-I-12、HMMT-2024-FEB-GEO-04）、Bの追加100開始と同じ座標。既知の効果が大きい2問の機構診断であり、問題集への汎化を主張しない。

全て元の等式・guard・hard検査・探索箱・参照答えで採点する。探索の残差はFにguard行g、hard行hを加えたRとする。gには元から係数10が、不可行時のhには10,000が入っている。

| 条件 | 変更 |
|---|---|
| base | R、LM上限320、許容値1e-14 |
| nohard | (F,g,0) |
| nohard_guard10 | (F,10g,0) |
| nohard_guard100 | (F,100g,0) |
| hard100 | (F,g,0.01h) |
| eqonly | (F,0,0)、最終の不等式検査は残す |
| tight | R、許容値1e-15（上限320は同じ） |
| sharpen | Bと同じ固定aで (1+||R||²/a²)R |
| sharpen_nohard | hard行を0にしてから同じaで増幅 |

各開始・各条件に30秒の上限を置き、時間切れ・エラーも分母に残す。2問×100×9=1,800探索。探索回数・真の残差呼出回数・停止理由・共通採点での成否を保存する。改善/悪化した条件を全て報告する。guardの重みを変えた条件は目的関数と局所極小も変えるので、Bの単調変換の不変性とは混同しない。

元のguard行について、出発時にhard不可行な点で0か、局所差分で傾きがあるかを調べる。「違反の情報を全く読めない」という表現を直接検査する。

本番全体の再実行、高精度化、厳密同定、図を描く人間の実験は実施しない。必要なら結果を見てからの追加分析を明示して分離する。
