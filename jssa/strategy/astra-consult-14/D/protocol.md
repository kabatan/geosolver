# astra-D：局所計算と求値の精度を分ける探索的調査

2026-10-23。背景の A/B/C・v7 の結果を読んだ後、以下の新規測定前に記す。公開事前登録ではなく、この作業内での計画固定である。既存323問は開発用問題であり、未見問題とは呼ばない。

## 第一候補

図を決める座標の悪条件と、求める値の悪条件は違う。等式ヤコビアンの弱い方向に目標量が変化しないとき、座標の精密化が難しくても値は早く決まる。この分離を、人間が難しく感じる幾何の関係を数値で読む経路として検討する。

1. seed 0 で当たりのある全問題の最初の当たりを取り、等式ヤコビアン J と目標量の勾配 g を測る。座標の単位は max(1, |x_j|)、残差の単位は各行のヤコビアンノルム（定数行は1）、目標量は max(1, |tau|) とする。差分幅 1e-5 と 1e-6 で感度を確認する。
2. 数値ランクは最大特異値の1e-8倍。フルランクでは、最悪の座標感度 1/s_min と、目標量の感度 ||g J^+|| を比べる。g による規格化を加えた比 q = ||g J^+|| s_min / ||g|| は、全体の単位によらない「弱い方向を目標が見る割合」の代理量。ランク落ちでは、g の nullspace 成分を別に記録し、擬似逆行列をそのまま誤差保証とは呼ばない。
3. rank deficient かつ nullspace への g の比が1e-5以下、またはフルランクで q<0.01 の例を候補とする。全ての例・欠測を保存し、成功例だけ選び直さない。既存の精密化時間・収束率・人間難度との関係も測る。正しい終点での診断なので「solverを動かす前の難度予測」とは言わない。
4. 候補の実際の高精度数値評価・近傍の摂動・必要に応じた診断用反復を行う。最初に作った予測と、測定後の追加仮説は分ける。自作のNewton/Gauss–Newton追跡を凍結版LMの軌道とは呼ばない。
5. 複数の正しい配置で座標が大きく違っても目標の高精度値が一致する例が得られても、完全性や恒等式の証明とは呼ばない。元の等式、guard、hard feasibility を必ず別に確認する。

## データ監査で既に分かった制約

raw-323 は323ファイル・55,097レコード、raw-323-seed1 は55,142レコード。seed 0 の全レコードに x/start があるが、seed 1 の records には両方とも保存されていない（first_hit には別途 x がある）。したがって「2 seed の全軌道を追った」とは書けない。292問×200=58,400 は最大数で、時間上限により実件数が少ない。

## 範囲

Python は指定された既存環境を -B で使用する。src は読み取りのみ。全出力は D 内。BLAS は1スレッド、初期測定は1プロセスで行う。インストール・commit・pushはしない。探索的な追加実験を行う場合も、その内容・失敗・件数・時間を保存する。

## 測定の修正と追加実験（survey の後、correction 実行前）

binary64 の差分で、作図により恒等的にゼロの行を行ノルムで割ると、丸め誤差を単位ノルムの行に増幅する例を認めた。このため等式の差分を60桁で計算し、差を取ってから float に変換した。binary64 の結果は binary64-* に残す。最初のHP呼び出しは、HP保護範囲内でfloatに変換したというAPIの使い方の誤りで全件失敗した（hp-api-error.json）。これを修正して再実行した。

修正後261問を測定でき、数値ランク落ちは30問。そのうち目標勾配のnull成分が1e-5以下は21問、フルランクでq<.01は1問。人間難度を含む全体の説明力は弱かった。これを踏まえ、次を**追加の探索的予測**として固定する。

- 保存済みの「当たり」の座標を一切動かさず、100桁で J と g を求め、J^T lambda = g の最小ノルム解によって tau_c = tau - lambda^T F と補正する。これは既存の随伴補正であり、新アルゴリズムとは言わない。座標は max(1,|x|)、残差はJ行ノルムで尺度をそろえる。SVDは相対1e-12で切る。
- 予測P1：seed 0 の評価可能な当たりの70%以上で、補正した目標値の参照値との一致が8桁以上増える。これは正答を既に近似的に得た候補に条件づけた予測である。
- 予測P2：seed 0/1 の最初の当たりについて、数値的に自由な方向が目標に見えない21問中10問以上で、正規化した座標差が1e-2以上ある一方、補正値が同じ参照枝と25桁以上一致する。枝の違う対は失敗として数え、都合のよい枝へ取り替えない。
- 同じJから実際に1回Gauss–Newton更新した後の目標値を対照にする。補正がこれを上回らなければ、高精度化の高速化を主張しない。
- raw / corrected / one-GN それぞれの値に、次数1〜4・最大係数10^6・許容1e-25・最大2000ステップのPSLQを適用する。公式答えを使うのは、値の誤差・得られた関係の真偽の採点だけ。元の図の等式・guard・hard feasibilityと、更新した図の同じ検査を記録する。補正値の同定だけで図の存在や答え集合の完全性を保証したとはしない。
- まず全ての当たりで計測する。仮説を満たさない例も残す。条件が悪い・非滑らか・特異な点でこの補正が常に安全だとは仮定しない。

## 第二候補：残差から値を直接取り出す（correction の後、fresh_dual 実行前）

correction の結果、raw が30桁未満なのに補正が60桁以上になった問題が10問あった。選択後の追加仮説である。特定の枝の開領域で `tau(u) = a + lambda^T F(u)` が恒等的に成り立つなら、正解から遠くても、微分から得た lambda による補正はaを直接返せる。F=0まで探索する必要がない。これを単なる近解での二次精度とは分けて検査する。

新規計測は次のようにする。

1. 探索変数がある全292問のDSLと探索箱のみを使う。rawの座標・p・答えは候補の選択にも、係数の計算にも使わない。ただし、この着想が既存結果を見て得られたことは隠さない。
2. 問題IDから決定する新seedで最大256個の一様点を生成し、guard・hard feasibilityを満たす最初の8点を校正用とする。満たす点が8個無ければ候補にしない。各点は一切最適化しない。100桁、中心差分1e-25、SVD相対1e-12で、局所の `tau - lambda^T F` を計算する。
3. 8点の補正値の相対幅が1e-30以下なら候補とする。元のtauも同じ基準で一定なら「最初からtarget一定」と別に数え、新しい発見数に混ぜない。係数自体の定数性は必須にしない（冗長な残差では同じ恒等式に非一意な係数がある）。校正表を保存してから正解と照合する。
4. 候補ごとに別seedで最大1024点から最初の32個のfeasible点を取り、同じ計算を行う。評価可能点だけ分母を減らして成功扱いにはしない。失敗・欠測も数える。
5. 追加予測P3：targetが校正点で一定ではない候補が5問以上見つかり、その80%以上は、独立な32個全てで同じ参照値と30桁以上一致する。新しい問題への一般化ではなく、新しい出発図への再現を試す。複数解の問題では1つの値を出しただけで完全解とは数えない。
6. 候補のうち解析できるものについて厳密な恒等式を確認する。8点・32点の数値的一致自体は証明ではない。数値の関係が既存v7の恒等式証明や標準の随伴法に対してどこまで追加なのかを明記する。

## 集計後の補足

複数枝が保存されている場合、survey/correction のアンカー選択は `first_hit` の枝キーを整数順に並べた最小キーの点である。「最初の当たり」はその枝内の保存点を指し、全枝で最小の出発番号を選んだという意味ではない。第二候補の乱数図による校正・検証はこのアンカーを使っていない。最終的な相関区間は、問題ごとに再標本化して順位化・調整を毎回やり直した audit.json を用いる。
