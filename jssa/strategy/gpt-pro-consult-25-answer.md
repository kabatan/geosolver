### ② 自動書き換えの中身を、本文だけで分かるようにする

これは、応用数学に出す場合に特に効く変更です。

現在の本文は、単位円の説明と実験結果は分かりますが、独自の仕組みである**「入力から何を確かめ、どの条件で自動的に書き換えるか」**の具体像を、S1.4にかなり預けています。
report-draft-v14(3)

3章か5.3に、既存の接線問題を一つ使って、次の対応を小さく示すとよいです。


| 入力から確認すること | その情報を使った処理 |
| --- | --- |
| 点 $T$ が、作図によって円上にある | 円の半径と $OT$ の関係を利用できる |
| 直線が、その点 $T$ を通る | 接するときの接点を特定できる |
| 円と直線が退化していない | 距離の条件を垂直の条件に書き換える |
| 必要な事実を入力から確認できない | この書き換えを適用しない |


実際の入力を数行抜き出し、この表と対応させてください。数値的に「接点らしく見えた」から変更する処理ではないことが伝わります。

さらに、現在の単位円の例を一般化した、次の短い式が有効です。円の中心を $O$、半径を $r>0$、円上の点を $T$、$T$ を通る直線の方向を $v\ne0$ とすると、


$$d(O,\ell)^2-r^2
=
-\frac{\bigl((T-O)\cdot v\bigr)^2}{\|v\|^2}.$$


これは、点と直線の距離の式から得られます。作図によって $T$ が円と直線の両方にあるなら、距離による残差は、垂直からのずれを二乗した形になることが見えます。接する解では、その残差の一次の変化が消えます。

この式自体を新発見として扱う必要はありません。入力からこの関係を利用できると判断する仕組みと、その効果の検証が、本研究の主張です。また、書き換え後に系全体の問題が必ず解消するわけではない、という限定も残します。

## 1．応用数学の上位作品と比べて、どう組み立てるか

### 数理的な内容は、次の三層まで本文に出したい

応用数学にするなら、現在より数理的説明を前に出すべきです。ただし、専門語や式の量を増やすことが目的ではありません。書き換えが正しく、その効果を説明できることを、本文だけで追えるようにするためです。

第一層：単位円の例は残す

現在の例は有効です。


$$r_{\mathrm{距離}}(s)
=\frac{1}{\sqrt{1+s^2}}-1
=-\frac{s^2}{2}+O(s^4),
\qquad
r_{\mathrm{接点}}(s)=s.$$


この式の直前に、平易な説明を置きます。

円周上の点を通る直線を、接線から少し傾ける。すると、中心から直線までの距離は、傾きに比べてわずかしか変わらない。一方、半径との垂直からのずれは、傾きに応じて変わる。

その後に、前者のニュートン更新では、小さい $s$ が毎回およそ半分になること、後者ではこの一変数の例では一回でゼロになることを示します。

ここまであれば、「数百桁になった」という結果が、計算法の仕組みと結び付きます。本文にも既にこの材料はあります。
report-draft-v14(3)

第二層：書き換えても条件の意味が変わらない理由を、短い補題として示す

例えば、円の中心を $O$、半径を $r>0$、円上の点を $T$、$T$ を通る直線の方向を $v\ne0$ とすると、


$$d(O,\ell)^2-r^2
=
-\frac{\bigl((T-O)\cdot v\bigr)^2}{\|v\|^2}.$$


したがって、作図によって $T$ が円と直線の両方にあることが保証されるなら、


$$d(O,\ell)^2-r^2=0
\quad\Longleftrightarrow\quad
(T-O)\cdot v=0.$$


同じ接線を表していても、一方の残差は垂直からのずれを二乗した形になる。 これが単位円の例を、もう少し広い場合に結び付けます。

この式と、入力から適用条件を確認する小さな例を、本文に出す価値があります。現在は自動化の詳しい部分をS1.4に預けていますが、そこは研究の独自の部分なので、本文で見える必要があります。
report-draft-v14(3)

ただし、ここから言えるのは、書き換えた条件で一次の変化が回復し得ることまでです。他の条件との組み合わせによっては、系全体の階数や精密化の進み方は変わりません。

第三層：ヤコビ行列を「全条件が、変数のずれをどう捉えるか」と説明する

微分可能な残差ベクトルを $F(u)$、条件を満たす点を $u_*$ とすると、近くでは、


$$F(u_*+e)=J(u_*)e+O(\|e\|^2),
\qquad
J=\frac{\partial F}{\partial u}.$$


この式には、次の説明を付けます。

一つの残差がよく変化しても、他の条件との組み合わせによっては、ある方向のずれを十分に捉えられない。そこで、すべての残差の一次の変化をまとめたヤコビ行列を調べる。最小特異値は、変数と残差の尺度を定めたうえで、変数のずれが残差に現れにくい方向を調べるために用いる。

本文では、この意味が伝われば十分です。特異値分解の計算法そのものを長く解説する必要はありません。差分幅、計算精度、数値的な階数の判定方法は、方法の節で要点を述べ、詳細を補足へ置きます。

本文に出す数学は、「具体例」「適用条件つきの同値性」「系全体を見る理由」の三層が中心です。

### 4-2．数理的にも、ある程度一般化して説明できる

例えば、ある残差が、許容な入力範囲で、

ただし、書き換え後の勾配が、他の残差が既に持っている情報と重なっていれば、系全体の階数は増えません。また、条件を満たす図が連続的に動ける場合など、同じ解集合を保つ限り残る自由度もあります。

なお、特異な解を持つ方程式系を変形して、ニュートン法の収束を改善するという一般的な発想には、既にdeflationなどの研究があります。一般化する場合も、本研究の独自の部分は、幾何の作図情報から適用条件を確認する仕組みと、その求値への効果を調べることとして説明するのが適切です。

### 4-4．測定を始める前に、特に確認したい五点
① 微分不能な残差を「特異」と判定しない

これは最優先です。

例えば $f(x)=|x|$ は原点で微分できません。しかし中央差分を取ると、


$$\frac{|h|-|-h|}{2h}=0$$


になります。これを「ヤコビ行列がゼロだから、一次の変化が失われた」と解釈すると誤りです。

旧残差に絶対値、距離0でのノルム、作図の枝の切り替えなどがある場合は、通常のヤコビ行列を論じられるか確認してください。微分不能なものは別扱いにします。滑らかな比較残差を使うなら、その比較が何を切り分けるのかも明示します。

例えば距離0の書き換えでも、元が二乗距離なら一次の変化の消失が問題になり、元が距離そのものなら解での微分不能が問題になり得ます。すべての書き換えを、最初から「同じ特異性回避」とまとめないことが重要です。

② 生の最小特異値を、異なる問題でそのまま比較しない

残差全体を1000倍すれば、最小特異値も1000倍になります。一方、純粋なニュートン法の更新は変わりません。変数の単位を変えても特異値は変わります。

したがって、変数と残差の尺度の決め方を固定します。最小値／最大値の比を使っても、変数ごと・残差ごとの尺度の問題がすべて消えるわけではありません。数値線形代数の研究でも、単位や尺度による悪条件と、本来の階数不足を区別する必要が指摘されています。
netlib.org

既存の計測に尺度の規則があるなら、それをまず確認し、結果を見て都合よく変更しない方がよいです。

③ 行列の形と、残っている自由度を確認する

ヤコビ行列が $m\times n$ のとき、$m$ は残差数、$n$ は探索変数数です。

特に $m<n$ では、一般的なSVDが返す特異値がすべて正でも、変数の方向には零方向が残ります。「返された特異値の最小値が正だから、全方向のずれを捉えられる」とは言えません。

また、図全体の平行移動・回転などが残っていれば、それに対応する零方向が生じます。座標の冗長性による階数不足を分ける必要は、数値ソルバーの公式文書でも扱われています。
Ceres Solver

少なくとも、行数・列数、座標の固定方法、補助変数の有無を記録します。探索変数が0個の問題も別扱いです。

④ 「座標の精度」と「求める値の精度」を同じにしない

例えば、


$$F(x,y)=(x,y^2),\qquad \tau(x,y)=x$$


を考えます。解 $(0,0)$ でヤコビ行列は特異ですが、ニュートン法で $x$ は一回で0になります。$y$ の収束が遅くても、求める値 $\tau=x$ は正確になれます。

つまり、残差が捉えにくい方向が、求める長さや角度を変えない場合があるということです。

本文でも、最小特異値が小さいまま高精度に達した例があります。この種の例は、単なる例外として片付けず、「何の精度を説明しようとしているか」を考える材料にしてください。

⑤ 参照図の精度と選び方で、関係を作ってしまわない

比較対象の最終出力をそのまま「正しい図」として使い、その点で特異値を測ると、到達誤差と特異値の測定誤差が結び付く場合があります。

ここは、前の回答で述べた単位円の例、適用条件、同値性、全系を見る理由を残します。

第二は、候補の選び方です。

値の集合を求める場合、残差が小さい候補だけを残すと、同じ答えの近くに偏り、別の値を取りこぼすことがある。

複数値8問で、集合の完全一致が19/24から13/24へ減り、一部の値だけを返す回数が増えた比較は、この説明によく対応しています。ただし、候補を散らせば全解を保証できる、とはしません。
report-draft-v14(3)

第三は、値の同定です。

図を高精度に求める難しさと、その図から得た値を式にする難しさは別であり、桁数を増やすだけでは解決しない失敗がある。

ここでは「同じ図で求める量だけを替える」実験が効きます。ただし、PSLQに係数上限があること自体を新発見にはせず、今回の失敗で何が制約になっていたかを切り分けた結果として扱います。

節名の「値の確定」は、**「値の同定と検証」**に変えることを勧めます。式の候補の同定、高精度での照合、一部の多項式関係の認証は、それぞれ保証する範囲が違うためです。
report-draft-v14(3)

### 章全体を大きく増やさずに実現できる

現行の構成を生かすなら、次の整理で十分です。


| 章 | 内容 |
| --- | --- |
| はじめに | 支援目的と、「主要な設計判断がどこで効くか」という中心の問い |
| 設計の章 | 入力から出力までの全体像と、7つの設計論点の表 |
| 実験設計の章 | 完成系での比較と、段階への入力をそろえた比較の違い |
| 結果の章 | 候補の選択、残差と精密化、値の同定の三つ。残差を最も詳しくする |
| 完成系の評価 | 開発外での性能、厳密法との比較、認証で分かる範囲 |


探索の重ね方は、候補を得る部分の補助結果として残せます。7つを説明するために、結果の章まで7つの同じ長さの節に分ける必要はありません。

## 3．「設計の理由」を成果として見せるために必要なこと
### ① 開発の時系列と、論文の説明順序を分ける

最も重要なのはここです。

完成した solver を後から整理し、その設計理由を追加実験で調べることは、正当な研究です。 論文を開発順に書く必要もありません。

ただし、後から整理した7項目を、最初からその通りに計画して設計したようには書かないことです。

方法の節には、例えば次のように書けます。

文章作成

本稿では、開発した solver の設計上の選択を、求めるものの定義から答えの同定までの論理的な順序で整理する。主要な選択について、開発中の観測をもとに効果を予測し、比較実験に先立って使用する版、対象問題、変更する処理、評価方法と予測を公開した。開発群での比較、比較に未使用の問題による検証、結果を見た後の追加分析は区別して示す。

この書き方なら、7項目への整理が現在行われていても問題ありません。

事前登録の意味も、既に見た結果から説明を考えることと、まだ見ていない結果を予測して確かめることを区別する点にあります。「登録した」という事実だけで、開発前から予測していたことになるわけではありません。
PNAS

### ② 各比較で「何が分かれば、説明を変えるのか」を示す

「別の方法では難しい問題が解けない」という予測だけでは弱いです。「難しい」を、その比較で失敗したことによって定義してしまうと、説明が循環します。

各比較で、少なくとも次の組が必要です。


| 書くもの | 内容 |
| --- | --- |
| 対象の性質 | どのような問題で差が出ると考えたか。その分類をどう決めたか |
| 代替案 | 採用した選択と、何を比較するか |
| 予測 | どの段階の、どの指標に差が出ると考えたか |
| 比較条件 | 何を替え、何を固定したか |
| 結果 | 改善、差なし、悪化、未実施をどう数えたか |
| 修正した結論 | 結果を受けて、当初の説明をどう狭めたか、変えたか |


既存の実験については、実際に公開した予測を使ってください。 今の構成に合うように予測の文章を作り直し、それを当初の予測として示してはいけません。整理し直した説明は、考察として書けます。

また、すでに挙動を見ていた開発群では、どこまで知っていたかを示すことが重要です。既存データの事前登録についても、事前の知識やデータへの接触を明示することが求められています。
cos.io

### ③ 同じ課題を、妥当な代案と比べる

「何を解くか」の分岐は、特に注意が必要です。

一つの値を求める方式と、すべての値を回収する方式では、そもそもの課題が違います。前者が一つしか返さないことを、後者の基準で「壊れた」とは言えません。

問題表現の比較も同様です。一方だけに解法から得た関係式を追加すれば、表現方法に加えて、与える情報も変わっています。

また、完成した solver から一つの機能を外す比較で分かるのは、他の部分を固定した、この構成での寄与です。別方式に合わせて全体を調整した実装との、一般的な優劣までは分かりません。

すべての組み合わせを試す必要はありません。主張する範囲を、実際の比較に合わせればよいです。

### ④ 段階での効果と、完成系での必要性を区別する

これは現在の研究の強みなので、新しい構成でも残してください。

同じ候補から残差だけを替えた比較と、完成した solver から工夫を外す比較は、違う問いに答えています。

前者は、その段階で何が変わるか。
後者は、他の段が補うことも含めて、全体に何が残るか。

後段が補って差が消えたなら、「採用した工夫がなければ解けない」とは言えません。一方、精密化の費用を減らす役割が残る場合はあります。

この区別を保つと、設計研究の結論が、

各工夫はすべて不可欠だった。

という説明から、

必要な役割を担う選択と、他の処理で補える選択があり、局所的な改善がそのまま全体性能になるとは限らなかった。

という、より具体的な知見になります。

### ⑤ 「失敗を説明する条件」と「実行前に枝を選べる規則」を分ける

7分岐の構成では、ここも重要です。

例えば、次の情報は失敗の原因を調べるために使えます。

正しい参照図で計算したヤコビ行列。
正しい答えの最小多項式の係数。
正解として知られている値の個数。

ただし、それらを得るために先に問題を解く必要があるなら、未知問題で、最初に選ぶべき枝を決める規則としては使えません。

「この性質が失敗に関係していた」と示したことと、「入力だけから最適な設計を選べる」と示したことは別です。

今回の研究は、前者だけでも成立します。後者までできたように書く必要はありません。これは、接点の書き換えを適用できるかの判定と、書き換えると性能が改善するかの予測を分けることにもつながります。

## この骨格に合わせた、はじめにの文案

現在のはじめにの第1段落は残せます。第2段落をこの構想に合わせるなら、例えば次の形です。

文章作成

幾何の求値を数値計算で行うには、問題の表し方から答えの同定まで、複数の設計判断が必要になる。本稿では、開発した solver の設計を7つの論点に整理し、主要な判断を別の選択に置き換えたとき、どの性質の問題で、どの段階の精度・時間・答えの回収が変わるかを調べる。特に、候補の選び方、作図情報を用いた残差の書き換え、数値から式への同定を取り上げる。各段階での効果と、他の段が補う分も含めた完成した solver での効果を比較し、それぞれの判断の役割と限界を明らかにする。

この問いに対応する結論は、7項目の選択をもう一度列挙する形にはしません。候補の多様性が関わる失敗、残差の表現が関わる失敗、同定の上限が関わる失敗を分け、その改善が全体に残る範囲まで示した、とまとめるのがよいです。

私なら、この方向で組み直します。7項目は設計全体を理解するために示し、研究結果の説明は3項目に集中させます。接する条件は、その中で仕組みと適用範囲を最も詳しく調べた成果として、十分な紙幅を確保します。
