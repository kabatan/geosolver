# astra-G 予備検証の固定基準

2026-10-23。新しい局所探索を一度も走らせる前に作成。既存 seed 0 の集計、依頼文の3例、seed 1/2 の既存要約は既読である。これは開発データでの機構検証であり、新しい問題に対する事前登録検証ではない。commit は依頼により行わない。

## 1. 既存終点の調査（新しい最適化なし）

- minima/raw-323 の探索変数のある292問、保存された start と x を使う。全 start の hard feasibility F と当たりを再集計する。
- F からの全失敗について終点の F を再評価し、F のままの有限終点を微小摂動する。対照は各問の F からの hit の最初の10個。非許容の終点は「許容側の壁」と数えない。
- 座標を探索箱の幅で無次元化する。半径 1e-6 の ±座標軸と8本の正規乱数単位方向（seed=[17001, 問題のソート番号, k]）で一度でも F が破れれば「境界近接」。座標軸の半径 1e-8 と 1e-4 も感度分析として測る。
- 保存された最も近い hit へ向かう方向も半径 1e-6, 1e-4, 1e-2 で測る。hit のない問題は欠測とする。これらは局所的な近接指標で、連結成分数・到達不能の証明ではない。
- 壁指標 W = (F から出て stuck となり、終点も F で、1e-6 の摂動で F が破れる数) / (F 出発点数)。両群10点以上の97問を主な比較対象とする。
- 入力構造として変数数、等式数、不等式の比較演算子、Angle/Area/積/枝選択、hard check の種類を記録する。成功図の min_margin と摂動距離は解を知った診断であり「入力だけの特徴」に混ぜない。
- 入力だけの追加指標：seed 17002 の箱内64点で F を測り、許容点で等式のガウス・ニュートン方向を1回だけ計算（箱幅で尺度化、中心差分 1e-6、最小二乗）。長さを無次元ノルム0.25に切り詰め、倍率 1, 1/2, 1/4, 1/8 のどれかで、等式二乗和が減るのに F を破る割合を Q とする。これは単発の診断であり反復探索ではない。尺度・停止法は本来のLMと同じではない。
- W、Q、構造の分離力を既存データで探索的に調べる。事後の相関や分類成績を未使用問題への予測成功と呼ばない。

## 2. 罰則だけの介入（新しい局所探索、固定された14問）

負例7問は seed 0 で n_F,n_I >=10 かつ p_I-p_F >0.20 の全問：
AIME-2010-II-14、HMMT-2007-FEB-GEO-06、HMMT-2007-FEB-GEO-04、HMMT-2024-FEB-GEO-01、JMO-2017-PRE-01、AIME-2007-I-15、HMMT-2022-FEB-GEO-03。

対照7問は両群10点以上、LM、変数4以下で p_F-p_I が大きい順（同点は id の降順）：
JMO-2006-PRE-02、HMMT-2024-FEB-GEO-04、HMMT-2008-FEB-GEO-02、HMMT-2006-FEB-GEO-06、AIME-2022-I-08、aime-2003-2-11、JMO-2024-PRE-03。

- seed 17007 の一様乱数列から F 40点、I 40点を順に採る（最大50000提案、足りなければ欠測を明示）。同一問題内の両条件は全く同じ点から開始する。
- baseline は凍結コードの `_collect_local_start_record`。no_hard は `_evaluate_hard_feasibility_penalty` だけを実行時に0へ差し替える。元の等式と滑らかな guard 罰則、非有限値の処理、停止条件、最終検査は変えない。hard 罰則の許容側の小さい余裕項も除くので「1e4 の段差だけ」の完全な分離ではない。
- 1開始・1条件10秒、元の評価上限を維持。タイムアウトも分母に含め失敗。順序は開始番号ごとに交互。最大4プロセス、BLAS等は各1スレッド。
- 当たりは既存 probe_basins と同じ判定（箱、等式ノルム<=1e-8、元のguard/hard、答えの相対誤差<=1e-6）。局所探索の有効な一図であり、完成solverの答え集合ではない。
- 予測P1：AIME-2010-II-14 の F で成功率が0.50以上上昇する。
- 予測P2：負例7問のうち W>=0.20 の群を「壁群」と固定し、Fでの改善の問題平均>=0.20、かつその群の3分の2以上で改善>=0.10。
- 予測P3（特異性、厳しい検証）：その他の14問内の非壁群では、Fでの変化の絶対値<=0.10 が80%以上。群が空なら判定不能。
- 予測P4：壁群の F の改善の平均が非壁群を0.15以上上回る。少数問題のため有意差の主張はしない。
- 各条件のF/I別 hit、stuck、wrong_answer、wrong_branch、left_box、timeout、評価数・実時間を全部残す。閾値を結果に合わせて変更しない。

## 3. 軌道の補助確認

AIME-2010-II-14 の seed 0, k=2,3,5 を baseline/no_hard で再実行し、全残差評価点の F と残差内訳、および SciPy の終了 status を記録する。LMの内部の採択フラグは公開されないので、評価点をそのまま「採択された反復」「拒否回数」と数えない。評価点の跳ね上がりと終点は状況証拠、同一開始の介入が因果比較となる。

## 4. 判断

P1/P2 が成立してもP3/P4が外れれば、「壁型だけを救う」を撤回する。構造からのQ等が弱ければ事前診断は未達成とする。局所探索の実装上の不連続を直したことだけでは、新しい幾何原理または人間の難しさとの相違を発見したとはしない。
