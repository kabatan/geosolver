# 引き継ぎ後の補足検証：停止判定・試行拒否・差分の分離

2026-10-23。この追記の実験を走らせる前に固定する。既存の
`preregistration-pilot.md`、292問の集計、14問×80点の介入結果、AIME の
104失敗終点の差分調査を読んだ後である。新問題への予測ではなく、既知の
開発データでの機構検証である。旧 P1–P4 の閾値・対象は変えない。

## 既読の事実と仮説

- AIME-2010-II-14 の既存3軌道は baseline がすべて xtol 停止。
  104失敗終点はすべて通常の前進差分幅で hard feasibility を破る。
- したがって「定数行による ftol/gtol 停止」だけでなく、
  「実際の試行の拒否」と「差分ヤコビアンに段差が入ること」を区別する。
- 旧14問中の160件（2条件合計）の error は、2対照問題の非許容開始で
  等式評価が非有限となったもの。最終候補・停止 status は存在する。
  全残差を 1e10 に置換する別の処理であり、1e4 の定数行と混同しない。

## 固定対象・条件

旧 `intervention.json` の全14問×80点（F40・I40、seed 17007）の開始座標を
そのまま使う。新たな抽選・問題選別をしない。AIME の seed 0、k=2,3,5
も6条件で再実行し、完全な native 呼び出しログを残す。

| 略号 | 変更（他は凍結版どおり） | 切り分け |
|---|---|---|
| B | baseline | 再現対照 |
| S | MINPACK 呼び出し時だけ ftol=gtol=0、xtol=1e-14 | 残差・差分・試行規則を保つ停止のみの変更 |
| J | MINPACK に渡す差分ヤコビアンの hard 最終行だけ0 | 実際の残差の段差を残し、差分への混入を除く |
| N | hard 罰則の関数だけ0（旧 no_hard と同じ） | 段差・許容側余裕項の両方を除く |
| C | hard 罰則の関数を常に1000（最終行は常に1e4） | 境界を除き、定数成分を全領域に残す |
| CS | C に S を併用 | 定数成分下の停止の寄与 |

S/CS は SciPy の公開 API の許容誤差チェックを変えず、その先の
`_minpack._lmder` の引数を monkeypatch する。MINPACK 自身の機械精度の
安全停止（info=6,7,8）と、gtol=0 での厳密な直交停止は残る。
これを「全停止を無効にした」とは書かない。raw info を保存する。
SciPy が info=6–8 をマップできない場合だけ、6→ftol、7→xtol、8→gtol
相当として戻し、raw info と変換を明示する。

J は厳密ヤコビアンではない。段差以外の差分行・有限精度は元のままで、
境界上の微分不存在も解決しない。C と N の差も、停止のほかにノルム計算・
減少比の丸め・信頼領域更新が入りうるので、単独で停止効果と呼ばない。
等式評価の非有限時の全行 1e10 は全条件で変更しない。

最大評価数80（差分評価を除く）、1条件10秒、元の最終採点・箱・guardを
維持。6条件の実行順は開始番号による巡回。最大4プロセス、BLAS各1スレッド。
時間切れ・error も分母に含める。計測用の追加評価は探索の評価数と別計数。
プロセス間で結果を共有せず、書き込みは G/ 内だけ。

## 記録と妥当性

MINPACK に渡す fun と jac の入口で記録する。差分のための内部 fun 評価を
native の試行点と混ぜない。次の jac の基点、または返された最終 x と
同じ試行点が受理されたと判定する。途中の jac なしの複数試行は最後以外
拒否である。同一座標・曖昧なケースは unknown とし推測で埋めない。
最後の8試行について基点・試行点、等式二乗和、guard行、hard行、F/I、
受理/拒否を保存する。全体の回数、最後の jac の hard 行の大きさ、
status・raw info・nfev も保存する。AIME3例は全呼び出し列も保存する。

記録が探索を変えていないことを、旧 B/N の全1120組の cls・終点・status
と比較する。不一致は隠さず列挙する。native nfev と呼び出し数、基点更新の
照合も行い、復元不能なものは因果判定から除外する（成功率の分母には残す）。
受理フラグは内部変数を直接読んだ値ではなく、native API のイベント列と
返却点からの復元であることを明記する。

## 結果を見る前の判定基準

1. **R1（停止のみ説への予測）**：AIME の F40点で S−B の成功率差は
   絶対値0.10以下、N−B は0.50以上。満たせば、この例の大差は ftol/gtol
   のみでは説明できない。満たさなければ停止が主要因という可能性を残す。
2. **R2（境界試行拒否）**：AIME の B の F 失敗の80%以上で、
   F基点→I試行かつ等式二乗和が減る native 試行が少なくとも1回拒否される。
   それ未満なら「試行拒否が広く観測された」と主張しない。
3. **R3（差分寄与）**：AIME の F40点で J−B の成功率差が0.20以上なら、
   段差を残しても差分行の変更が大きく効くため、「壁で道が塞がるだけ」
   という説明を退ける。0.20未満なら差分寄与はこの介入では大きく確認されない。
4. **R4（停止による救済の割合）**：旧壁群5問の F における B失敗→N成功の
   組のうち S も成功した割合が50%以上なら「救済の過半を停止変更でも得る」
   とし、幾何の説明をさらに縮小する。それ未満でも停止が無関係とはしない。
5. **R5（定数行の停止感度）**：全14問の F/I 計1120組で、N成功→C失敗の
   組を分母に、CSで成功へ戻る割合を報告する。50%以上なら、この独立対照で
   定数行による失敗の過半は停止変更で救われたとする。分母0なら判定不能。
   定数行の効果の一般的な不存在・存在をこの数だけから断定しない。

R1–R5を結果に合わせて変更しない。R2とR3が両方成立しうるし、停止と境界
効果が併存してもよい。結論は無理に二者択一にしない。入力だけの予測モデルの
旧 LOO 成績（AUC約0.57）は既読であり、ここでモデルを調整しない。
