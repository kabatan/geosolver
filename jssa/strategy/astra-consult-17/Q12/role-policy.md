# 入力からの役割選択案 v1

2026-10-23。結果を見て更新する学習器ではなく、有限個の証拠を要求する保守的な規則。**本稿は仕様であり、汎用の変換器を実装・検証した成果ではない。** 主張と限界は [answer.md](answer.md)、未使用問題での判定は [preregistration.md](preregistration.md)。

## 入力と出力

入力はDSL、変数箱、元の評価器の版、公開された命令の定義だけ。正答、既知解、保存start、成功率、問題名からの既知成績、人間難度は使わない。原文対応カードは意味の監査に使えるが、解法・答えは規則へ渡さない。

各条件に、`id / source_AST / dependencies / domain_obligations / role_search / role_refine / role_verify / witness / abstention_reason` を出力する。一つの条件が複数の役割を持ってよい。`role_verify`には常に元条件を残す。DSLの同一条件がhardとguardの両方へ出る場合は同一IDを共有する。

役割は次の順で決める。後の規則は前の定義域保護を上書きしない。判定できないことを陰性と数えない。

## R0：意味と実装上の経路を先に監査する

1. DSL依存グラフと、各命令の定義域を作る。除算の分母≠0、実平方根の被開平数≥0、正半径、非零直線、交点の存在、選択する枝などを区別する。
2. 等式、guard penalty、hard feasibility、作図の例外、最終検査のどこがその条件を使うかを記録する。集約行に埋まって条件別の寄与を復元できなければ `unseparable_penalty` とする。
3. 最終の合格条件・閾値は全比較で同じにする。箱外を最初に返す実装でも、監査用には各成分を独立に記録する。

原文の意味が未監査の問題を、変換によって正しくなった例として扱わない。入力修正は探索実験とは別版にし、成功を見て採否を変えない。

## R1：評価に不可欠な条件は定義域に残す

**判定**：その条件を前提にしないと、使用中の作図・残差が有限な実数値として定義できない、または指定された枝が定まらない。

**割当**：作図の定義域／評価前のチェック＋事後判定。通常のLMに巨大な定数行として見せることが理想という意味ではない。別の座標表示、定義域内の部分問題、または適切な制約付き法が必要になり得る。v1はその新しい解法を実装せず、既定処理を維持する。

**証拠の形式**：ASTの分母、平方根・逆関数の引数、明示された枝選択への依存経路。未対応の関数呼び出しやraw述語が評価器を保護するか判断できなければ `domain_unknown`。

「外しても実際にはたいてい評価できた」を証拠にしない。有限個の乱数点だけでは定義域全体の保証にならない。

## R2：正当化できる明示作図は維持する

**判定**：DSLに明示された非循環の構成 y=h(u) があり、枝が指定され、必要な定義域条件がR1で保持される。

**割当**：既存の作図＋事後判定。作図をいったん自由点へ戻すことを既定の改善としない。

新しく等式を作図へ変換する場合は、明示式、対象枝での同値性、定義域の証拠が必要。v1の完成solver比較では**既存作図をそのまま保つ**。未実装の自動消去を達成済みに数えない。

「安全な作図」の機構比較にはさらに、正規化した入力箱上で分母と枝判別量が0から離れることを、有理数演算・定数の符号・区間包含で証明できたものだけを使う。使用できる証拠生成は、四則演算・整数冪・有理数の端点による自然区間評価。区間を細分して数値探索したり、未知関数をサンプリングしたりしない。定数π等は採用版で固定した有理区間を使う。失敗なら `chart_not_certified`。

これは数値的に最も良い座標系だという認定ではない。大きなDh、差分誤差、尺度、Cのy依存が残る。列の膨らみ3倍等を性能予告の閾値に再使用しない。

## R3：接触の一次情報を残差に残す

Q4の `contact_tangency_source`、`distance_contact_sources` と同じ構文上の入射証明を使う。証明できる共有点と接触式を保存する。

- 直線と円：P∈L、P∈circle(O,R)から、tを線方向として `(O−P)·t=0`。単位化をしない場合は対応する非零の線長因子も保存する。
- 二円：共通点Pから `(O1−P)×(O2−P)=0`。同一円・同心等の除外、元の内外の枝は元検査へ残す。
- 他の等式から入射を証明した場合、二次消失はその等式を満たす集合上の性質と注記する。恒等的に入射を満たす作図と混ぜない。

接触式が定義の展開を通じて変数に依存するとき `Qactive=true`、定数だけならfalse。Q4と同じ構文依存であり、完全な恒等式簡約や全系のランク検査ではない。

**割当**：精密化では一次接触式を残差として使い、元の接条件・入射・枝を事後検査する。一般の接条件で入射を証明できない場合は `U` とし、既存の符号付き化は保持するが、二重根除去と呼ばない。単なる `d²−R²` への変更でQactiveを解決した扱いにしない。

v1の完成solver比較は、この既存の精密化を全条件で同じに保持する。Q2の機構実験でのみO/S/D/R/Aを切り替える。粗い探索へ同じ変換を入れる利益は別仮説であり、今回の仕様に混ぜない。

## R4：距離ゼロはベクトルの残差へ

`Distance(P,Q)=0` を座標差2行へ分解する。実数での零点集合の一致を根拠とする。2行は元の距離と整合する共通尺度を使う。

通常は一次消失の非平滑性／Gauss–Newton行列の違いを扱うもので、重複度を減らすと分類しない。適用対象がなければDはno-op。精密化にすでにある処理を新しい機能と数えない。

## R5：非零因子と退化の危険を区別する

元条件でd≠0が必要で、入力式から恒等式 f=dq を証明できれば、有効解上でf=0とq=0は同値。例はQ4の正半径r、Q6のuvである。ただし有効解の近傍でd≠0なら、割っても通常その根の重複度は変わらない。

証拠は、明示的な積の因子分解、または有限の多項式展開による係数一致に限る。Q2の数値解で割れるかどうかを判断しない。一次式を自動発見する探索や汎用の代数的分解はv1の範囲外。

**割当**：既存の正半径補助式は精密化の残差として維持する。新たな一般因子の補助式は提案として記録し、v1の完成solverへ黙って追加しない。因子dが0へ近づくと元残差が見かけ上小さくなる可能性を `factor_risk` とする。

性能選択のための保守的な `risk` は、以下のいずれかならtrueと固定する。

1. 定義域以外の非退化条件（非零面積、点の相異、正半径、非零距離など）のIDに対応する因子が、等式残差の明示的な乗数として現れ、既存実装にその因子を除いた補助式がない。
2. 上記の非退化条件はあるが、残差の乗数の監査が未対応で、危険を判定できない。

これ以外は `risk=false` とするが、未知の退化因子が存在しないという証明ではない。完全なCAD・実代数判定は行わない。この不完全性自体をQ2で評価する。

## R6：選別条件の段差を、条件単位で移す

候補 `eligible_late` は、R1に使われず、元の幾何の枝・向き・順序・単純性等を選別し、外しても**残る定義域条件の下で**同じ式を実数評価できると証明できたもの。対象条件の評価結果を除外しても、他条件・式を再評価できる独立した経路が必要である。

例えば自己交差の検査を使わずに点座標・角・線分を評価できるなら、その検査は候補になる。一方、交点を決める根の選択やゼロ分母の保護は候補にしない。guardの見た目が不等式かどうかだけでは決めない。

- `eligible_late=true`、`risk=false`、寄与が分離可能：探索中にその条件のguard/hard両方の寄与を外し、事後検査へ移す。
- `eligible_late=true`でも`risk=true`：v1では既定の探索処理を維持。検証用の一律介入Uだけがここも外す。
- `eligible_late=false/unknown`または集約行が分離不能：既定処理を維持し、保留理由を残す。

元のhardの集約を単に0にするNと違い、Pでは対象外のhardチェック・marginを保持して再集約する。guard側も対象外の違反量を保つ。論理ORを一部分だけ削る等の意味が不明な操作は行わず、その論理式全体を一つの条件として判定する。

この規則は「条件を外せば平均で改善する」という保証ではない。F/I逆転も予告しない。最終的に不適切な別枝へ落ちる割合が増え、有限予算では悪化する可能性を対照実験で測る。

## R7：最終検査と尺度の自由度

元の等式、全guard、hard、探索箱、有限な目標値、答え集合の採点を保持する。残差とguard/hard/箱/答えの各成分を別々に保存し、排他的な失敗ラベルを因果分類にしない。

相似不変性を入力の次元・命令の共変性から証明でき、かつ元の意味に長さの単位がない場合だけ、正の相似正規化を別の補足採点として認める。主採点を後から修正しない。固定長がある問題や非有界な近似列にはこの処理を適用しない。精密化の80桁合格だけで公式正答・座標精度・全解性を認定しない。

## v1の決定手順

```text
read DSL + frozen evaluator definitions
build dependency graph and condition-to-channel map
mark domain obligations or UNKNOWN                      # R0/R1
keep existing constructions; emit chart certificates     # R2
emit Qactive/U, distance-zero and factor-risk flags      # R3/R4/R5
for each condition in source order:
    if domain, UNKNOWN, or penalty inseparable: retain; record reason
    elif eligible_late and not risk: move both penalty paths to verify-only
    else: retain
keep existing refinement rewrites in every full-solver arm
verify against all original conditions, with common thresholds
```

作図・接触・距離ゼロの規則は、主として既存設計の維持と機構予告である。完成solverのv1で新しく変わるのはR6の選択的な局所探索罰則だけであり、NOMADの扱いは変えない。汎用の全段階最適化器を完成したと誇張しない。

必要な証拠を自動出力できなければ、問題ごとの手作業による「うまくいく役割」を後から付けず、保留として分母へ残す。十分な適用数が得られない場合、それもこの規則の限界である。
