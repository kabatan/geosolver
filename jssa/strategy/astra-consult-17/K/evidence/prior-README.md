# 正次元問題の求値恒等式（GPT-Pro相談6 §5・§8 実験3）

作成: 2026-10-22（クラウド、Singular 4.3.2 / sympy）。solver（60db4b6）は変更していない。

## 何を示したか

msolve で「解が有限でない（正次元）」とされた問題について、数値ではなく**多項式の恒等式**として

> 条件を満たすどの図形でも P(τ) = 0（P は GeoSolver が PSLQ で出した最小多項式、τ は求める量）

を証明した。恒等式の形は

  s^N · Q(t) = Σ C_i · F_i

で、F_i は問題の多項式化（厳密比較と同じ `algebraize.py` の fresh 方式）、t は求値を表す未知数（t − τ を分母を払った式が F_i に入っている）、s は非退化条件の積（分母 ≠ 0）。Q は P そのもの、または P を因数にもつ消去多項式 E。右辺は F_i = 0 のとき 0 なので、s ≠ 0 の図形では Q(τ) = 0 が成り立つ。各恒等式は Singular の `lift` で作り、Singular 内と sympy の展開の両方で検算した（どちらも 0 になった）。

| HMMT-2008-FEB-GEO-06 | 8 | **本当に動く**: A が 45°の円弧上を動く | t²−17 | P の恒等式（N=2） | 0.02秒 |
| HMMT-2013-FEB-GEO-08 | 5 | **本当に動く**: 角 g が決まらない | 13t−42 | E=(13t−42)(13t+42) | 0.02秒 |
| HMMT-2022-FEB-GEO-01 | 11 | **本当に動く**: U が AB 上を動く | t−21 | E=(t−21)(t+21) | 0.02秒 |
| AIME-2015-II-07 | 4 | **本当に動く**（ただし求値が固定点だけで決まる自明な例） | 125t−36 | P の恒等式 | 0.02秒 |

| AIME-2009-I-05 | 17 | 回転の固定漏れ（C 中心。ax=0 を足すと0次元） | t−72 | E=(t−72)(t+72)（係数 計4,827項） | 10.7秒 |
| AIME-2009-I-12 | 7 | **退化成分**: I が直線 AB 上に乗る成分だけが1次元 | 3t−8 | 非退化条件「I は AB 上にない」を足すと E=(3t−8)(3t+2)(1369t−2450)(1369t−288) | 0.02秒 |

「動ける向き」の判定は機械的に行った（`gauge.py`, `out/gauge.json`）。固定漏れの4問は、固定の式を1本足すと次元が 1→0 に落ち、さらに図形の形を表す量（AB² など）が有限個の値しかとらないことを消去で確かめた。「本当に動く」5問は、DSL がすでに点を座標で固定しており、形を表す量（AB², 高さ h, AU など）を消去すると 0 になる（その量が一定でない＝図形の形そのものが連続に変わる）ことを確かめた。

**E の場合の残り一歩（実数条件）。** Q = E のときは、P 以外の因数の根を実数条件で除く。上の表の ± 型（t+72 など）は、t が距離（√ の非負の枝）なので t ≥ 0 から P(τ)=0 が出る。AIME-2009-I-12 は飽和後の解が有限個（4点）でどれも座標が有理数なので、DSL の不等式（ix<0, iy<0, 距離 ≥ 0）を厳密に代入すると 8/3 だけが残る。

**存在について。** 恒等式は「条件を満たす図形があれば、答えは P の根」を示す。少なくとも一つ図形が存在することは別の話で、AIME-2009-I-12（有理数の座標で存在が厳密に分かる）以外は GeoSolver の高精度検証（数値）に頼っている。

## 人が読める例（レポートに使える）

**HMMT-2013-FEB-GEO-02**（台形の高さが決まらないのに AE が決まる）。恒等式は

  t² − 24 = −F1/4 + F2/4 + (x0+x1)·F3 + F4 + F5 − (x2+x3)·F6

で、意味は「AE ⟂ EC なので AE² = AC² − EC²、EC = BC なので AE² = AC² − BC² = (5.5² + h²) − (2.5² + h²) = 24」。h が打ち消し合うことが、正次元なのに求値が一定である理由そのもの。

**HMMT-2008-FEB-GEO-06**（A が円弧上を動いても外心 O が動かない）。s = Ay（A が BC 上にない）として s²·(t² − 17) = Σ C_i F_i。円周角 45° なので中心角 90°、O = (1, ±4)、OP² = 17。

**AIME-2013-I-03**（尺度が決まらない）。s·(t − 18) = −F6 + F7（F6 は 20 倍した e²−es+s²/20、s = e(e−s)）。e(s−e) = s²/20 から τ = (e² + (s−e)²)/(e(s−e)) = 18。

## 正次元63問への一括適用（1問300秒上限、4並列）

P が得られた63問（正次元65問のうち2問は HEAD 評価で不一致のため除外）に同じ手順を当てた（`out/batch-summary.csv`）。

| 結果 | 問題数 |
|---|---|
| 恒等式を作り Singular と sympy の両方で検算（P そのもの 5、E 経由 19） | 24 |
| 恒等式はできたが係数が 70〜250 MB で sympy の検算は省略（Singular 内の検算は通過） | 4 |
| 消去しても t だけの多項式が出ない（下記） | 15 |
| 300秒で終わらず | 17 |
| 求値が角度で多項式化の対象外 | 3 |

**t だけの多項式が出ない15問**は、τ が一定でない成分が複素数の解集合に混ざっているためで、P(τ) が誤りという意味ではない。分解できた11問のうち少なくとも7問（AIME-2009-I-12, AIME-2013-II-04, HMMT-2006-FEB-GEO-01, HMMT-2008-FEB-GEO-09, HMMT-2025-FEB-GEO-02, JMO-2013-PRE-08, aime-2000-2-6）では、τ が動く成分が「長さ0」「半径0」「高さ0」「点が直線上に落ちる」といった退化した図形だった。残り4問は成分の意味をまだ読んでいない（`out/components.json`）。試しに非退化条件を1つ足すと3問で恒等式ができた（`out_nd/`）：JMO-2013-PRE-08（半径 r ≠ 0）→ (t−12)(t+12)、aime-2000-2-6（高さ ≠ 0）→ t² の8因数の積、HMMT-2008-FEB-GEO-09（ay ≠ 0）→ 6根。JMO-2013-PRE-08 と HMMT-2008-FEB-GEO-09 はこの条件で0次元になり、正次元は退化成分だけが原因だった。

**時間切れ17問**には JMO-2013-PRE-05（接条件）など大きい問題が並ぶ。剰余が0にならなかったわけではなく、計算が終わらなかっただけ。

## レポートへの示唆

1. msolve の「正次元」は一種類ではない。10問を調べると、(a) 回転・尺度の固定漏れ（3問）、(b) 補助点の表し方の冗長さ（1問）、(c) 退化成分（1問、一括では少なくとも2問追加）、(d) 本当に図形が動くのに答えが一定（5問）に分かれた。比較では (a)(b)(c) を「厳密法が解けなかった」と書かないほうがよい。
2. (d) は §5.1 の「図形が動いても求値は動かない」の具体例で、恒等式という形で証明できた。HMMT-2013-FEB-GEO-02 の h の打ち消しは、人間の解き方（補助線の発見）と同じ構造を持つ。
3. 小さい問題では P(τ)=0 の証明が1秒未満で出る。一方、変数の多い問題では恒等式の係数が数百 MB になったり 300 秒で終わらなかったりし、厳密な証明のコストは問題の大きさで急に増える（厳密法比較の傾向と同じ）。

## ファイル

- `certify.py`: 1問の恒等式を作って検算（`python certify.py ID P係数 出力先 [秒] [追加の非退化条件]`）。`algebraize.py`・`run_exact.py` は branch claude/project-thread-fos2rk の `benchmarks/exact_comparison/`（src は 60db4b6 と同一）。
- `gauge.py`, `components.py`, `tabulate.py`: 動ける向きの判定、成分分解、集計。
- `out/<ID>/`: 10問の `system.txt`（多項式と変数の対応）、`certificate.txt`（係数 C_i）、`result.json`、Singular の入出力。
- `out_nd/<ID>/`: 非退化条件を足した4問。
- `all/<ID>/`: 一括の結果（5 MB を超える Singular 出力は除いた）。
