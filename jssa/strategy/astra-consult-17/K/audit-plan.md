# astra-K：既存結果の批判的再集計の手順

2026-10-23。以下は既存の草案・要約を読んだ後の**事後監査**であり、未知問題についての事前登録ではない。新しい局所探索は行わない。`src/` は読み取りのみ、出力はこの K ディレクトリだけ。

1. seed 0/1 の問題別 CSV と seed 2 の比較 CSV を照合し、分母、全150問の平均、両条件200試行の95問、seed 0 の両群10試行以上の層を報告する。
2. seed 2 で、常に plain、常に feasible、seed 0 の予測差が負なら plain（未定義なら feasible）、結果を見て良い方を選ぶ oracle を計算する。oracle は観測済み二方策の成功率上限の参考であり、未知問題で実行できる方策でも、費用や完成solverの上限でもない。
3. seed 0 の負予測29問について、seed 2 での符号の再現、分母不足、成功率差の大きさを確認する。ゼロ差を負と数えない。
4. seed 2 plain の既存の最初の20試行で p_F−p_I を推定する模擬選択を、21試行以上ある全問に適用する。両群に1試行以上あり、p_F<p_I なら plain、それ以外は feasible。評価には plain の21試行目以降、または別の feasible 実行を使う。公式正解を使う楽観的な事後診断であり、合法な未知問題方策とは呼ばない。費用は含めないので実用性の証拠にしない。
5. 予備20試行で片方の群が一度も出ない確率を、seed 0 の φ を代入した独立抽選モデルでも計算する。φ の推定誤差は残る。
6. 候補2の論理的な主張を小さい厳密な多項式例で点検する。既存63問の証明書は元データがあれば確認し、なければ未確認と明記する。

新しい局所探索や結果に合わせたモデル探索は行わない。追加で必要になった集計は追加分析と明記する。ブートストラップを使う場合は問題単位、乱数 17023、10,000反復とする。いずれも探索的な区間であり、事前仮説の検定ではない。

追加の事後監査：初回の再集計後、強い負予測8問の既存seed 2終点分類を集計する。候補2について H/sources/ に保存されていた既存実験の README・CSV・生成コードを読む（Hの新規実験の結論は用いない）。`identity_P` と `identity_E` を区別し、引用する小さい入力資料を K/evidence/ に複写する。候補4の根拠として既存 tangency-signed の12問も再集計する。これらも仮説検証の新規事前登録ではない。
