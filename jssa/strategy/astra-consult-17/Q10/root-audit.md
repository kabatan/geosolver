# 16問の実数枝監査

## 結論

**与えられたDSLについて、15問は原条件を使った数学的簡約と厳密恒等式で唯一値へ閉じる。残るJMO-2014-PRE-09は、原DSLが許す実配置で目標値が連続に動くため、余分な値を排除できない。**

これは15問の自動証明成功ではない。DSLから小さい式への含意は下記の人手の幾何・符号の議論であり、その先の恒等式と根の分離を機械検算した。[audit/charts/](audit/charts/) に全係数を保存した。H由来4件は出典とSHA256を明記し、Q10の新発見と数えない。図の存在は原問の前提。15問すべての厳密な存在証明を実施したという主張でもない。

ここでの「原条件」は提供された `benchmarks/cases.jsonl` のDSLの全条件と作図の定義域を指す。原問題文自体はローカル資料に見つからず、ネットワーク禁止に従い再取得していない。とくにJMOの原文が内点・相異なる点を要求するかは未確認である。**原問題文の監査が全問完了した、と読み替えない。**

## aime-2000-2-6：8個の正根から1個へ

下底a>0、上底b=top_right_x−top_left_x>0、高さh>0、切断比0<f<1とする。元DSLの符号に従って、長さと面積を平方根を介さず書ける。

- a−b=100。
- 上下半分の面積はそれぞれ h(a+3b)/8、h(3a+b)/8。
- 3倍の上半分=2倍の下半分より3a−7b=0。従ってa=175,b=75。
- 切断幅T=(1−f)a+fb>0。
- 半面積条件は2f(a+T)=a+b。

よってT²=18125。4本の式からT²−18125を生成元の線形結合として厳密検算した。[証明書](audit/charts/aime-2000-2-6.json)。

旧out_ndのEは `∏(T²−k)`、k∈{352500,252500,43125,18125,6900,3525,2900,2525}。負の8根はT>0で除き、正の8根のうち7根はT²=18125と両立しない。25√29だけが残る。h≠0は後付け仮定ではなくh>0から従う。上底・下底・面積の符号を使わずに、正根だけを数えても求値は完結しない。

## HMMT-2013-FEB-GEO-03：面積平方根の符号

p>0,v>0なので、向きを保つアフィン変換でA1=(0,0),A3=(1,0),A5=(0,1)に正規化できる。これは図を任意の一個に切断する操作ではない。面積倍率K=pvを保持する。A4=(a,b),A6=(a−1,b),A2=(a,b−1)と置くと、6交点は

`B1=(a,0), B2=(a,1−a), B3=(1−b,b), B4=(0,b), B5=(0,a+b−1), B6=(a+b−1,0)`。

元のOnSegmentからa,b∈[0,1],a+b≥1。正の3角面積により境界での等号も除かれる。U=√(K/2)>0、X=U(1−a)>0、Y=U(1−b)>0、Z=U(a+b−1)>0と置けば

`X²=9, Y²=4, Z²=1, U=X+Y+Z, T=U²−14`。

従ってX=3,Y=2,Z=1,U=6,T=22。符号を無視した小さい系ではT∈{−14,−10,2,22}となり、非負性だけでは2が残る。これはfreshの未計算Eを推定したものではなく、上記簡約系の全8符号組合せを列挙した結果。[符号表](audit/hexagon-sign-branches.json)。U=0になる枝はK>0にも反する。


## AIME-2016-I-06：内心・交点の順序

非退化三角形の内心Iは内部にあり、角二等分線CLとABの交点LはABの内部にある。外接円のもう一つの交点DはABの反対側なので、順序はC,I,L,D。したがってDI=IL+LD=5。

DはCを含まない弧ABの中点なのでDA=DB=DI。最後の等式は、∠IAD=A/2+C/2=(π−B)/2、∠AID=π−∠AIC=(π−B)/2から従う。

D中心・半径5の円はA,B,Iを通る。Lの方べきからLA·LB=25−LD²=16。元の外接円に対する方べきはLA·LB=LD·LC=3(T+2)。よってT=10/3。

`d=LD,e=LI,g=DI,w=LA·LB`として、`d−3,e−2,g−d−e,w−g²+d²,w−d(T+e)`から3T−10を表す係数を検算した。[証明書](audit/charts/AIME-2016-I-06.json)。この証明は符号を落としたfresh系の全成分に成立するのではなく、原問の内心と点の順序に成立する。

## AIME-2021-I-13：外接条件と弦

R1=961,R2=625、d=O1O2>0、外接する円の半径r>0。共通弦ABの直線はx=aで、`2da=d²+R1²−R2²`。二つの外接条件の二乗を引くと

`d(ox−a)=r(R1−R2)=336r`。

h=ox−aとする。角POQ=120°の弦の中心距離はr/2なので4h²−r²=0。次の恒等式を検算した。

`r²(d²−672²)=4(dh+336r)(dh−336r)−d²(4h²−r²)`。

r>0で割れ、d>0で負根−672を除ける。[証明書](audit/charts/AIME-2021-I-13.json)。r=0という退化成分を残したままE=0を見て「消去不能」と一般化しない。

## JMO-2014-PRE-09：排除できない実成分

元の図を−45°回転し、a=s/√2と置く。O=(0,0), A=(0,a), B=(a,0), C=(0,−a), D=(−a,0)、P=(0,3),Q=(5,0),R=(0,−4),S=(−t,0)。元の線分条件はa≥5、0<t≤aを含み、a>5とは要求しない。

交点は

```
X=((5a−15)/2,(15−3a)/2)
Y=(5a−20,4a−20)
Z=(t(a−4)/(4−t),4(t−a)/(4−t)).
```

t=4はCDとRSが平行になり、a≥5の下では交点が存在しない。共線式は厳密に

`det(Y−X,Z−X)=(a−5)(a−4)(23t−60)/(t−4)`。

a>5ならt=60/23。ところがa=5ならX=Y=Qなので、0<t≤5,t≠4の**すべて**が許される。従って与えられたDSLの目標集合は `(0,5] \ {4}`。60/23もこの集合の一要素にすぎない。

t=1,2の2配置について全距離・共線・線分・交点式を有理数と√2で厳密検査し、各交点の分母非零も確認した。100桁の元evaluatorでもhard_feasible=true、最大残差3.64×10^-100以下、目標値1,2となった。[反例と検算記録](audit/JMO-2014-PRE-09-counterexample.json)。

原問題文が「QはOBの内点」または「X≠Y」等を要求するなら、その条件でa=5を除ける。しかし手元のDSLにはなく、原文も再確認できていない。そこでa−5を勝手に飽和してPを証明することはしない。Hは局所分類と明記しているので、Hの局所計算への反証ではなく、大域的な求値への拡張を阻む別成分の具体化である。この問題の参照値とDSLの差そのものは [既存履歴](../../../history/candidates-v1-v8.md) にも記載があり、それ自体をQ10の新発見とは数えない。今回の追加は成分の式、目標集合、厳密反例の提示である。
