# 数値ランクの例外と追加の配置

初回の固定基準は `preregistration.md`、事後診断の基準は `diagnostic-protocol.md`。
この文書の実数上の議論で、元の数値結果を書き換えない。

## AIME-2008-I-10：複素正次元と孤立実点は両立する

DSL は A=(0,0),D=(d,0),B=(u,√3u),C=(v,√3u),F=(v,0)、
d>v>u>0、AB=CD、AC=BD=10√21、EA=10√7、ED=30√7。
AB²=CD² より (d-v)²=u²。d>v なので d=u+v。
AC²=2100 より v²+3u²=2100。

```
2800-d² = (v-3u)²/3 >= 0.
```

一方 ED-EA<=AD=d より d>=20√7。両側の限界が一致するため、
d=20√7,v=3u,u=5√7。三角不等式の等号から E=(-10√7,0) も固定される。
従って実数の許容配置はこの一点（鏡像も DSL の符号で除外）。EF=25√7。
ヤコビアンの零空間2次元は、実際の2次元変形を意味しない。
この例を単なる「ゲージ固定漏れ」「分母0」とまとめるのも不正確。
二乗和と実不等式を利用しており、複素イデアルの通常の飽和だけで同じ結論が出るとは限らない。

## AIME-2018-II-14：接線条件による一意性

A=(0,0),B=(7,0),C=(c,h),AC=8,h>0、a=BC、u=(15-a)/2 とする。
非退化三角形なので 0<u<7。余弦定理、内心、接点から

```
a=15-2u,  c=(113-a²)/14,  h²=64-c²
I=(u,r), r/h=u/(8+c)
X=(7+(7-u)(c-7)/a, (7-u)h/a).
```

AX 上の内接円との第二交点 Y は `Y=tY X`、`tY=u²/|AX|²`。
これは円の式 `(x-u)²+(y-r)²=r²` に直線 AX を代入した二次式で、
一つの根が X に対応することから得られる。
P=(3,0) と Y を結ぶ直線が内接円に接するとき、Y はその接点だから
`(Y-I)·(P-I)=r²`。代入整理すると

```
4u(u-8)(u-7)(5u-21) / (7(2u²-45u+224)) = 0.
```

分母は |AX|² に対応し、非退化三角形の辺 BC 上にある X は A ではないので非零。
0<u<7 の根は u=21/5 だけ。したがって
C=(124/25,36√19/25)、Q=(21/59)C、AQ=168/59。
上記因数分解と Q の比は `analytic_audit.py` が有理式として検算する。
数値ランクは閾値に敏感だったが、この実数の議論では配置は孤立する。

## AIME-2015-II-11：全ラベル付き点の変化だけでは誤分類する

V は O を通り OB に垂直な直線を表すための点で、P,Q はその直線と他の直線との交点。
V が同じ直線上を動いても原図は変わらない。
診断の合格4点で、全点の正規化距離二乗の最大変化は9.44e-4。
V を除いて同じ量を再計算すると最大4.64e-15だった。
これを真の変形17問から除き、16問と数えた。初回基準にも補助点の意味を読む規則を明記してある。

## aime-2000-2-6 の2次元という解釈

下底 b、上底 a、高さ h>0、上底の横ずれ z とする。
中点で切った上部・下部の面積は h(b+3a)/8 と h(3b+a)/8。
`3上部=2下部` と `b-a=100` より a=75,b=175。
半分の面積で切ると断面長 ℓ は `ℓ²=(a²+b²)/2=18125`。
これらの式は h,z を制限しない。h>0,z∈R を変えた台形は元の条件を満たす。
したがって局所2次元というヤコビアン診断に、独立した幾何的根拠がある。
ただし、固定した小歩幅による第二零空間方向の最大形変化は6.91e-6で、
検出閾値1e-5未満だった。第一方向は4.13e-4で合格。閾値を後から下げてはいない。
