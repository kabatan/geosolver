# 追加した小さい証明書の意味

`new_certificates.py` は、ここで導いた**実数の枝に対応する簡約多項式系**について、
`s^N P(T) - Σ C_i F_i` を有理係数で展開し、厳密に0になることを検査する。
F、s、N、P、全係数 C_i は `certificates/*.json` に保存した。
これは元の fresh 変換の全生成元に対する `lift` の再実行ではない。
幾何から簡約式への含意は以下の議論による。機械検算している範囲は、その先の恒等式である。
公式解と既存の P は調査時に既に見ている。解答を隠した自動発見実験ではない。

## AIME-2011-II-04：二等分線の向きは変わっても比は一定

DSL と同じ A=(0,0), C=(11,0), B=(x,y), D=(1-t)B+tC とする。
条件は AB=20, y>0, 0<x<11, ∠BAD=∠DAC。
両角の余弦を比較して共通の非零因子 |AD| を払うと B·D=20 D_x。
したがって

```
F1 = x²+y²-400
F2 = (1-t)(x²+y²)+11tx-20((1-t)x+11t)
   = (1-t)F1+(20-x)(20-31t)
```

20-x>0 なので t=20/31>0。M=D/2 として P=BM∩AC を計算すると
P_x=11t/(1+t)。よって T=CP/PA=1/|t|=1/t、F3=tT-1=0。

恒等式は

```
(20-x)(20T-31) = -T(1-t)F1 + T F2 + 31(20-x)F3.
```

s=20-x, N=1、P(T)=20T-31。s≠0 は DSL の x<11 から従う。
y>0 の円弧上で B は連続に動ける。例えば B=(5,5√15), t=20/31 は厳密な許容配置であり、
存在もこの構成から分かる。恒等式の検算だけの時間は約0.003秒。

## aime-2003-1-12：AD≠BC が必要な理由も見える

a=AB=CD=180, b=BC, d=DA, k=BD², T=cos∠DAB=cos∠BCD。
凸性により両方は通常の内角で、余弦定理と周長条件から

```
F1 = 180²+d²-k-360dT
F2 = 180²+b²-k-360bT
F3 = b+d-280
```

が0になる。恒等式は

```
(d-b)(9T-7) = -F1/40 + F2/40 + (d-b)F3/40.
```

s=d-b, N=1。s≠0 は追加した仮定ではなく、DSL の AD≠BC そのもの。
この条件を落とすと平行四辺形の枝が混ざり、そこで T は自由になる。
したがって「元の複素系から一変数多項式が出ない」理由と、非等号の役割が同じ式で分かる。
厳密な存在例は A=(0,0), B=(180,0), D=(98,56√2),
C=(98398/361,31416√2/361)。このとき d=126,b=154,CD=180,周長640、
各頂点の外積は正で、両内角の余弦は7/9。`analytic_audit.py` でも検算する。
この配置には厳密な凸性と非退化の余裕がある。dを近傍で変え、
D=(7d/9,4√2d/9)、b=280-d、Cを二円 BC=b,DC=180 の同じ側の交点とすれば連続族になる。
検算だけの時間は約0.002秒。この連続族の全範囲を機械的に求めたものではない。

## JMO-2013-PRE-05：接する二円の半径比

DSL と同じ X=(0,0), R=(9,0), S=(2cosθ,2sinθ),
P=(p,0), Q=(qcosθ,qsinθ) とし、0<θ<π, p,q>0。
O1 は P,Q,S の外接円、O2 は P,Q,R の外接円。
PR が O1 に接する点は P、QS が O2 に接する点は Q なので、X の方べきから

```
F1 = p²-2q
F2 = q²-9p
```

が0になる。c=cosθ, A=p²+4-4pc=PS², B=q²+81-18qc=QR² と置く。
外接円半径の公式（辺の積を面積の4倍で割る）から

```
T = R1/R2 = q*PS/(p*QR) > 0
F3 = T² p² B-q² A = 0.
```

ここで

```
h1 = (p²+2q)(q²-18qc)+324pc
h2 = -(q²+9p)(p²-4pc)-72qc
K  = p² B(qT+p)
V  = q²T²+pqT+p²
```

とすると、求める証明書は

```
q³K (9T³-2)
  = (9pK-9Vh1) F1 + (-2qK-9Vh2) F2 + 9Vq² F3.
```

s=q³K, N=1。p,q,T>0、B=QR²>0 なので s>0。
この式は P(T)=9T³-2 **自体**の恒等式であり、符号の異なる根を含む六次式だけではない。
生成コードは全33項の係数を厳密展開し、残差0を確認した（検算約0.014秒）。
導出の補助式 `p^4 B-q^4 A=h1 F1+h2 F2` も直接展開で検算できる。

θ を自由に変え、p=∛36, q=p²/2 とすれば上記方べき条件を満たす。
p≠9,q≠2 と sinθ>0 により両外接円が存在し、方べきと円上点から接線条件も従う。
T>0 の範囲で P は単調増加し、根は一つ。したがってこの実数族の全体で半径比が一定と分かる。
これが旧300秒打切りの問題を小さい式で証明できた例。ただし、幾何的な簡約を考える時間を
上記の0.014秒に含めていないため、旧手順との速度比較には使えない。

## HMMT-2023-FEB-GEO-01：旧63問の外の追加例

k=√3、六角形の辺長を a、P の y 座標を y とする。
DSL の枝は 0<y<ka/2 なので面積の符号は固定されている。

```
F1 = ka²-2ay-80       (=4 Area(P,B,C)-80)
F2 = ay-23           (=Area(P,A,D)-23)
F3 = 2T-3ka²         (六角形面積の定義)
F4 = k²-3
T-189 = 3F1/2 + 3F2 + F3/2 + 0F4.
```

s=1,N=0。P の x 座標は動くが、この証明書には現れない。
比較CSVでは `free_parameter` で、旧63問に含まれない。旧24問への新規追加数3には数えない。
