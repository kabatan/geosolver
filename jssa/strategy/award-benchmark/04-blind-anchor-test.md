# 4. 目隠し較正テスト：GPT-Pro の判定を人間の審査に合わせる手順

作成 2026-10-24。目的は、GPT-Pro の判定が「GPT-Pro の好み」なのか「人間の審査員の判定」に近いのかを、**答えの分かっている実物**で測ってから、geosolver を判定させること。

## 考え方

1. 実際の受賞作（第64〜69回、情報・技術／応用数学、高校）から、段階ごとに4件ずつ、計16件の概要を選んだ（A 総理・文科大臣賞、B その他の名前付きの賞、C 入選1等、D 入選2・3等）。
2. geosolver も**同じ定型・同じ長さ**の概要（約600字、【動機】【方法】【結果】【まとめ】【展望】）にした。本文 v14 から、数字を変えずに縮めたもの。受賞作は概要しか公開されていないので、同じ形式でないと公平に比べられない。
3. 学校名・氏名・賞を伏せ、17件を3通りの並び順に混ぜた（[anchors-order1.md](anchors-order1.md)〜[3](anchors-order3.md)）。答えは [anchors-key.md](anchors-key.md)（GPT-Pro には渡さない）。
4. 新しいセッションの GPT-Pro に、人間の審査の観点（[01](01-official-criteria.md) 1-6）で17件を順位づけさせる。
5. 受賞作16件で「GPT-Pro の順位」と「実際の段階」がどれだけ合うか、どちらにずれるか（例：技術的に高度な D を高く置きすぎる、社会貢献型の A を低く置く）を測る。**そのずれを知ったうえで**、geosolver が何番目に置かれたかを読む。

選び方：アルゴリズム・計算・機械学習の作品を各段階に入れ（geosolver と比べやすくするため）、同時に各段階の典型（A の社会貢献型、C の「作れた」型）も入れた。

## 手順

1. ChatGPT で**新しいチャット**を開く（過去の相談の記憶を持ち込まない。メモリ機能が有効なら、この判定では一時チャットを使う）。
2. 下の「判定プロンプト」を貼り、続けて anchors-order1.md の全文を貼る。添付ファイルとして [01-official-criteria.md](01-official-criteria.md) を付けてもよい（観点の根拠）。**02・03・anchors-key は付けない**（答えが分かってしまう）。
3. 別の新しいチャットで order2、さらに別のチャットで order3 を行う。可能なら各順序で2回ずつ、計6回。
4. 回答を `jssa/strategy/award-benchmark/runs/run-<順序>-<回>.md` に保存する。
5. 採点（下の「採点のしかた」）。

## 判定プロンプト（そのまま貼る）

```
この判定ではWeb検索・ブラウジングを一切使わないでください。題名で検索して受賞歴を調べることは禁止です。

あなたは日本学生科学賞（読売新聞社主催）の中央審査委員会です。委員は物理・化学・生物・地学・電子工学・ロボット学・数理工学・応用数学・情報科学の研究者と、中学・高校の教員で構成され、情報・技術や応用数学を専門とする委員は一部です。

これから、高校の部「情報・技術」「応用数学」に応募された研究作品の概要（各約1,000字の定型）を17件示します。学校名・氏名は伏せてあります。評価の段階はまちまちで、賞を取っていない作品も含まれます。

日本学生科学賞には点数表の形の公式審査基準はありません。主催者が公表している審査委員の助言と最終審査での質問から、次の6つの観点で評価してください。学会論文の査読の基準（先行研究との厳密な線引き、統計的厳密さ）ではなく、この賞の審査委員がどう判断するかを推定してください。
1. 動機と問いが明確で、何が分かっていて何が未解明かを示しているか
2. 新しさ・独自の工夫が具体的に言えるか
3. 方法とデータが正しい手順で十分にあり、再現性や誤差を考えているか
4. 論理の流れがシンプルで、専門外の委員にも伝わるか
5. 社会的な意義・発展性・着眼点の面白さがあるか
6. 事実と意見を分け、都合の悪い結果も書いているか

出力：
(a) 17件それぞれについて、6観点を各1〜5点で採点し、一行の講評を書く。
(b) 17件全体の順位（1位＝最も高く評価される）を付ける。同順位は使わない。
(c) 各作品を次の段階に分類する。各段階の件数に決まりはない。
  A＝内閣総理大臣賞・文部科学大臣賞の有力候補
  B＝その他の名前付きの賞（大臣賞・読売新聞社賞・科学技術振興機構賞など）の水準
  C＝最終審査に進む水準（入選1等）
  D＝入選2等・3等の水準
  E＝入選に届かない
(d) 題名や内容から、実際に見覚えのある作品があれば番号を挙げる（無ければ「なし」）。
(e) 判断が難しかった作品と、その理由。
```

注：実際は16件が受賞作（入選2・3等を含む）で、geosolver だけが未審査。プロンプトでは、全件が受賞作だと分かって段階を上にずらすことがないよう、こう書いた。

## 採点のしかた

答え（anchors-key.md）と照らし、受賞作16件について次を計算する。

| 指標 | 計算 | 意味 |
|---|---|---|
| 段階一致率 | GPT-Pro の段階＝実際の段階 の割合 | 25%（4択の偶然）より十分高いか |
| ずれの向き | (GPT-Pro の段階 − 実際の段階) の平均（A=1…E=5） | 正なら GPT-Pro は**辛い**、負なら**甘い** |
| 順位相関 | 順位と実際の段階のスピアマン相関 | 0.5以上なら人間の判定をある程度再現 |
| 型ごとのずれ | A の社会貢献型（盲導杖・点字）と D の技術型（SQA・AmoebaSAT）をどこに置いたか | 「技術の高度さを高く見て、意義を低く見る」癖の有無 |

そのうえで geosolver について：
- 6回の段階の分布（例：B 3回・C 3回）と、順位の中央値。
- 受賞作でのずれの向きで読み替える。例：GPT-Pro が受賞作を平均で半段階辛く付けるなら、geosolver の判定も半段階上に読む。技術型の D を一貫して B に上げるなら、技術型の geosolver の判定も割り引く。
- (d) で見覚えありと答えた作品は、採点から外した値も出す（知識で当てている可能性）。

## 実行上の注意（10/24の実施で判明）

- GPT-Pro は判定中にWeb検索で受賞歴を見つけることがある。プロンプト冒頭で検索を禁止し、検索ツールもオフにする。検索が走った回は採点から外す。
- WinPC のクリップボードと Chrome のタブは他のセッションと共有される。判定用は別ウィンドウで行い、送信前に入力欄の中身を確認する。

## このテストで分からないこと（限界）

- 受賞作は約1,000字の概要で、審査員が実際に読んだのは全文レポート（と最終審査では対面の質疑）。概要での順位は、全文での順位の近似でしかない。
- 賞は他分野の作品との相対比較で決まる。情報・技術だけを並べても、その年の全体の中の位置は再現できない。
- geosolver の概要は私（Claude）が本文 v14 から作った。概要の書き方そのものが判定を動かす。本人が書き直した版でもう一度測るのが望ましい。
- 16件はアルゴリズム・計算寄りに選んだ。社会貢献型の作品を増やすと、geosolver の相対位置は下がる可能性がある。
