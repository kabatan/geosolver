# GPT-Pro が過大・過小評価した受賞作の特徴（応用数学版目隠しテスト6回から）

作成 2026-10-24。データは [runs/am-score.md](runs/am-score.md)（応用数学の受賞作15件＋情報・技術の A 2件、Web検索なし・一時チャットで6回）。作品の中身は各作品の概要（`raw/works/`）。**事実**＝表の数字と概要に書いてあること、**推測**＝そこから読み取ったこと。

## 結論（先に）

- GPT-Pro は、**証明・統計・比較・妥当性確認・限界の明記がそろった「論文として整った」概要**を上に置く。題材の重要さや問いの面白さは、ほとんど順位に効いていない（推測）。
- 人間の審査は逆に、**問いそのものの魅力（音楽・自然現象・認知症・駅のエスカレーター）、他分野にまたがる着眼、はっきりした意外な答え、大きな着想**を上に置き、方法の整い方の弱さをかなり許している（推測）。
- GPT-Pro の回どうしの順位相関は0.89で、このずれは偶然ではなく一貫した好み（事実）。

## 2. 上に置きすぎた作品にあって、下に置きすぎた作品にないもの（推測）

| 特徴 | 過大評価の側 | 過小評価の側 |
|---|---|---|
| 主張を支える形式的な証拠（証明・有意差・相関・ベースライン比較） | ほぼ全件にある | 少ない（音律の相関、エスカレーターの実測くらい） |
| 方法の完結性（定式化→手法→検証→限界がそろう） | そろっている | 欠けている（正多角形は証明なし、量子は未検証、空間認知は実データなし） |
| 問いの広がり・題材の魅力 | 狭いか、問題の内側で閉じている（魔方陣の拡張、配分方式、GKの指標） | 大きいか、他分野にまたがる（音楽、生態系、認知症、駅の混雑、量子計算） |
| 答えの分かりやすさ | 数値や証明として正確だが、専門外には意味が伝わりにくい | 一文で言える（「両側に立つ方が速い」「既存の指標で見えない時期から異常が出る」「一要素で一斉開花が再現できる」） |
| 着想の大きさ | 既存の枠の中の改良・拡張 | 枠を新しく作る（新しい音律、量子画像処理、空間認知のモデル化） |

一言でまとめると（推測）：**GPT-Pro は「方法がどれだけ整っているか」で並べ、人間の審査は「問いと答えがどれだけ面白く、新しいか」で並べている。** 人間の審査も方法の整い方を無視してはいない（割当問題は B、Boid は B）が、上位の決め手にはなっていない。

## 3. この結果の限界

- GPT-Pro も私も読んだのは約1,000字の概要だけ。審査員は全文レポートと対面の質疑を見ている。音律や空間認知は、全文や質疑で方法の弱さが補われていた可能性がある。
- 応用数学の A は1件だけで、その概要は文字化けしていた。音律の低評価には文字化けも効いた可能性がある。
- 受賞は他分野を含む全体の中で決まる。15件の並びだけでは再現できない部分がある。
- 「問いの魅力」は私の読み取りで、測った量ではない。

## 4. v15 を人間の審査に合わせるための示唆（推測。研究方針スレッド向け）

- geosolver の概要は6回とも A・1位（6観点で 5・5・5・4・4・5）。これは GPT-Pro が好む「整った方法」（工夫を外した比較、開発に使っていない問題での検証、不利な結果の開示）を最も満たしているためで、審査の予測ではない。
- 人間の上位作品の側から見て、geosolver に足りない可能性があるのは次の3点。
  1. **専門外の人が面白いと思う問い**：「人間は補助線や定理で解くが、計算機は図を作るだけで解ける。では計算機にとって何が難しいのか」のように、一文で興味を引く形。
  2. **一文で言える意外な答え**：「『接する』の書き方を変えるだけで、答えの精度が8桁以下から数百桁（340〜484桁）に変わる」のように、数字が専門外にも驚きとして伝わる形。工夫の一覧や比較の網羅は、その答えを支える役に回す。
  3. **着想の広がり**：幾何の問題を解くことが何につながるか（本人の目的「LLMや人間が幾何問題を解くのを支援」）を、問いと答えに結びつける。
- 逆に、方法の網羅（事前登録、除去実験の全件、外れた予測の一覧）を本文の前面に出しても、人間の審査では上がりにくい可能性がある。補足資料に回して、本文は「問い→意外な答え→なぜそうなるか」の一本の流れにするのがよいと考える。
- 採点基準の交差検証（`../rubric-cv/`）で、GPT-Pro に受賞作から基準を作らせたときに、この「問いの魅力」の側をうまく取り込めるかを確かめる。取り込めなければ、GPT-Pro の判定は弱点探しにだけ使う。
