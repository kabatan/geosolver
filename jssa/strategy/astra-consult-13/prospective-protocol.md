# 未使用問題での検証案

これは今後の実行用の設計案である。未使用問題のID・DSL・乱数・実行コードをまだ凍結していないので、完成した事前登録でも、実施済みの実験でもない。今回の探索的測定は `analysis-plan.md` と `answer.md` に記載した。

**対象と順序**

1. 開発292問、その書き換え、既に結果を見た外部テストから離れた40問を用意する。母集団は、指定DSLで記述でき、探索変数があり、元の分岐でLMを使う問題（変数数が元の等式数以下）に限定する。Powellと変数0の問題への一般化は別課題にする。
2. 問題一覧・採用順・重複する問題族・除外理由を、局所探索の結果を見る前に固定する。既存の全292問から後で一部を抜いて「未使用」とは呼ばない。2026年問題も、既に評価結果を利用したものは自動的に未使用扱いにしない。同じ生成テンプレートの数値違いも別の独立問題族と数えない。
3. DSLは問題文から作り、正解から逆算した座標や補助条件を入れない。DSLと元の問題の対応の監査、参照解による最終採点器の準備は、探索結果を見る前に済ませる。新問題を確保できない場合は、既知問題・新seedの再現試験に名称と結論を限定する。
4. solver、ライブラリ、DSL、初期箱、hard判定、採点条件、モデル係数、seed生成法、失敗の扱いをファイルとSHA256で固定する。登録はテストの局所探索を始める前に日付つきで保存する。途中で設定を修正した場合、その結果は開発用へ移す。

**予測する量**

対象は単一開始の成功確率 `p_B`。予算Bは、既存と同じLMの `max_nfev=80, ftol=xtol=gtol=1e-14`、`x_scale='jac'`、1開始の探索時間上限10秒。開始ごとに独立したsolver状態を使う。成功は元の等式残差ノルム≤1e-8、guardとhard判定を満たす、元の終点判定箱内、公式答えのいずれかと相対許容1e-6で一致、の全て。複数解の全回収や本番パイプライン全体の成功ではない。

各問題で、結果用の乱数と独立な4,096点を元の箱から一様に採り、`H(x)=hard_feasible` の平均をφとする。判定器内部の評価不能もH=0に含まれることを明記し、幾何的な違反と評価不能の件数を別記する。0/4,096を真のφ=0としない。別の32点で元の拡張残差ノルムの中央値aを計算し、`a=max(a,1e-6)` とする。aは問題内で固定し、成功率で調整しない。

主モデルは既存のLM問題で学習する。

```
M0: logit(p_i) = β0 + 変数数のカテゴリ項（1, 2, 3, 4, 5以上）
M1: logit(p_i) = β0 + 同じカテゴリ項 + γ φ_i
```

学習は `audit.py` と同じ、問題を等重みにした平均二項対数損失＋L2罰則0.01/2。切片は罰しない。標準化の平均・標準偏差は学習集合だけから作る。ハイパーパラメータを新問題で選ばない。学習対象の範囲、全係数、標準化量とテスト40問の予測値を、テストの成否を開く前に保存する。既存LMの保存済み52,757試行は全て10秒未満だったが、旧データの問題単位120秒打ち切りによる試行数の違いは学習データの限界として残す。

**四つの条件**

| 条件 | 初期化 | 探索残差 |
|---|---|---|
| U0 | 元の箱の一様分布 | 元のR |
| F0 | hard判定を満たす最初の提案点 | 元のR |
| U1 | U0と同じ点 | `(1+||R||²/a²)R` |
| F1 | F0と同じ点 | 同じ単調変換 |

40問×64開始番号×4条件＝10,240試行枠。各問題・各開始番号に別の乱数列を割り当て、Uは第1提案、Fは最大4,096提案のうち最初にH=1となる点を使う。Uの第1提案がfeasibleならUとFの点は同じ。初期点群は両残差条件で共通とし、条件の実行順を無作為化する。単調変換により非有限になった場合も失敗に数える。

4,096提案でfeasible点が得られない枠は、F条件の「初期化失敗」として失敗に数える。最後の不適切な点から走らせてfeasible条件に混ぜない。提案数・初期化時間・探索時間・差分評価を含む総評価数・終了理由を記録する。時間切れ、例外、初期化失敗を分母から除かない。全条件64枠で固定し、問題単位の時間上限に達したところで完成済み試行だけを分母にする設計を避ける。

**主評価と反証条件**

- 予測の主評価：U0の結果について、問題を等重みにした `log loss(M1)−log loss(M0)`。問題族を単位とした対応ブートストラップ95%区間の上端が0未満なら、登録した母集団・予算で追加予測力を支持する。0をまたげば未確立、下端が0超なら悪化。順位相関だけを主評価へ差し替えない。
- 初期化介入の主評価：40問の `p(F0)−p(U0)` の等重み平均。問題族を単位に再標本化し、その内側で開始番号の4条件を組として再標本化する。95%区間が正の側なら、登録した初期化方策の平均効果を支持する。負の問題と初期化失敗も全て示す。40問の平均が正でも、個々の問題での改善や普遍的な機構は保証しない。
- 両方を同時に研究の主成功と定義するなら、上の両基準を満たすことを要求する。「どちらかだけ有意」で包括的な成功とはしない。個別問題の有意差検定を並べる場合は別途多重比較補正する。
- bの副評価：同じ出発点でU1−U0、F1−F0を比較し、さらにUの出発時H=0/1で救済・損失を分ける。H=0に改善が集中し、Fでは小さくなることを方向予測とする。ただしFの天井効果だけでも差が縮むので、これだけで媒介機構の証明とはしない。
- 人間難度はあれば大会別に副解析する。「無関係」は非有意差から言わない。等価性を主張するなら許す相関幅と必要問題数を別途登録する。この40問は人間の認知仮説の検証用に設計していない。

**恒等式と予測を区別する**

同一問題の真の確率について、元の初期分布なら厳密に

`p_U = φ p_F + (1−φ) p_I`

である。無制限の棄却抽出なら `p_F−p_U=(1−φ)(p_F−p_I)`。新問題の結果を見てp_Fとp_Iを代入するのは説明的分解であり、予測検証には数えない。

最大K=4,096提案、全不適切なら失敗とする本方策では、`q=1−(1−φ)^K` として `p_F_policy=q p_F`、したがって介入差は `q p_F−p_U`。無制限の式をそのまま量の予測に使わない。

この最小設計の新問題への主予測はM0/M1に限定する。新問題の介入量まで予測するなら、既存の開始別データで `logit P(hit|d,H)=β0+β_d+β_H H` などのモデルを別に固定し、予測したp_F、p_Iとφを組み合わせる。そのモデルは各問題固有のp_F、p_Iを当てたことにはならない。新問題の条件付き成功数をモデルへ戻してはいけない。

既知問題で新seedを使う追加実験なら、旧seedのp_F、p_Iからの量の予測が可能。ただし一方の観測数が0なら欠測、少数なら二項不確かさが大きい。点推定だけの±0.10一致率を使わず、例えば両群20点以上という量予測の対象規則を結果前に固定し、対象外の件数も報告する。

**費用と2日での運用**

局所探索の上限は10,240×10秒＝約28.4コア時間、4コアで約7.1時間、16コアで約1.8時間。これは探索部分の上限で、DSL作成、コンパイル、提案点の判定、集計を含まない。1試行1コア、BLASも1スレッド。今回の測定では292問×1,024点の静的判定は1プロセス約161秒だったが、新入力で同じ速度とは保証しない。未使用テスト以外の入力で起動時間と1判定の費用を点検し、計算が収まることを確認してから本登録する。

第1日は未使用入力の監査、学習、ハッシュと予測値の保存、静的測定と実験の開始。第2日は残りの実行、全40問の固定した集計、費用比較、失敗の確認に使う。入力40問の正しいDSLを作れない場合、計算コアを増やしても未使用問題の条件は満たせない。問題数を後から減らして成功宣言するのでなく、探索的な再現試験として報告する。

成功率の改善だけで速度改善としない。無制限棄却抽出で、判定1回の平均費用をc_H、feasible開始の探索費用をt_Fとすると、独立再開始での成功までの期待費用は `(c_H/φ+t_F)/p_F`。実験では有限Kと全ての失敗を含めた実測の費用／成功数も併記する。成功0回を無限の真の期待時間と断定しない。
