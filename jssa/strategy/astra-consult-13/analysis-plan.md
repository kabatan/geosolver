# 相談13の追加点検計画（探索的解析）

相談文、astra-12 A/B/C、v7、既存の出発点別集計を読んだ後の計画であり、独立な事前登録ではない。既存の seed 0 と人間難度の概算も既に確認した。新しい問題への一般化を検証したとは扱わない。

1. `start-feasibility-1023/per-problem.csv` の分母を `minima/raw-323` と照合する。問題別の試行数、欠落、成功率を確認する。
2. φ と p、変数数を調整した関係、大会別の人間難度との関係を再集計する。問題を単位としたブートストラップ区間を出す。全て満たす／全て違反するという観測を真の確率1／0とは解釈しない。
3. 同じ問題内での feasible / infeasible の差と、棄却抽出という初期分布変更の効果 `(1−φ)(p_F−p_I)` を分ける。未観測の条件付き確率は推定不能とする。全問題を混ぜた成功率の差を平均介入効果と呼ばない。
4. 新しい乱数で各問題1,024点の hard-feasibility だけを評価し、φを測る。局所探索は実行しない。元の箱・DSL・判定器を使い、問題IDのSHA256と固定のsalt `consult13-phi-20261023` で乱数を固定する。作図の評価不能もこの判定の失敗に含め、タグを別記する。
5. 既存pへの予測を、問題・大会年をまとめた5分割交差検証10回で調べる。基準は変数数1/2/3/4/5以上のカテゴリ、追加量は生のφ。各問題同じ重みのロジスティック回帰、平均二項対数損失＋係数のL2罰則0.01/2、切片は罰しない。特徴の標準化は学習側のみ。モデル選択・ハイパーパラメータ調整はしない。副比較は変数数＋log(1+hardチェック数)へのφ追加。
6. 独立φと既存seed 1のpとの比較も行う。ただしseed 1の成績は以前から使用済みなので未見検証とは呼ばない。既存seed 1のfeasible別集計、seed 2の介入は実行しない。

コード・集計・測定の全出力を本ディレクトリだけに保存する。既存ファイルは変更しない。Pythonは指定のvenv、bytecodeの書き出しは止める。結果の都合で指標や対象を変更しない。
