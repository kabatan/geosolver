## S1 理論

### S1.1 当たるまでの時間（本文3.4、5.2）

1回の局所探索が正しい値に当たる確率を p、1回の時間を t とする。出発点を独立に選び直すと、当たるまでの回数 K は幾何分布に従い、E[K] = 1/p である。よって E[T] = t·E[K] = t/p となる。t をさらに「評価1回の費用 c × 1回の評価回数 n」に分けると、E[T] = c·n/p である。実際のsolverは出発点を適応的に選ぶので、この式はsolver全体の予測ではない。局所探索の難しさを測る物差しとして使う。

### S1.2 必ず収束する球と、p の下界（本文5.2）

正しい解 u* でのヤコビアンの最小特異値を s、ヤコビアンのリプシッツ定数を L とする。減衰のないLM法（ガウス・ニュートン法）の誤差 e は e_次 ≤ L e² / (2(s − L e)) を満たす。半径 ρ = s/(2L) の球の中から出発すれば、誤差は毎回半分以下になる。出発点を一辺 W の箱から一様に選ぶと、p ≥ v_d (ρ/W)^d（v_d は半径1の d 次元球の体積）となる。これは下界であって法則ではない。

### S1.3 自由点の座標と、ずれの座標（本文5.3）

元の系 E の残差を R(u) = C(u, h(u)) とする。自由点の系 Y は (u, y) を変数にし、残差は (C(u, y), y − h(u)) である。ずれの系 Z は (u, z) を変数にし、残差は (C(u, h(u)+z), z) である。LM法（MINPACK の方式。SciPy 1.18 の既定）の1歩は、次の最小化で決まる。

  min |J δ + r|² + λ|D δ|²（D はヤコビアンの各列の大きさから作る対角行列）

**命題1。** 書き換えた点が等式に現れない（C が y によらない）とき、z = 0 から出発した Z の反復は、E の反復と完全に一致し、z はずっと 0 のままである。

証明：Z のヤコビアンは [[J_R, 0], [0, I]] である。u の列は E と同じなので、D の u の部分も同じになる。z の部分は残差が 0 で、列は単位ベクトルである。よって最小化は u と z に分かれる。z の部分は min (1+λ)|δz|² なので δz = 0 になる。u の部分は E の式と同じになる。∎

**自由点の系との違い。** Y のヤコビアンは [[J_R, 0], [−H, I]] で、u の列に作図の微分 H が加わる。列の大きさは膨らみ、D の u の部分が大きくなって、u の歩幅が縮む。D = I の場合でも、δy を先に消すと、u にかかる減衰は λ(I + HᵀH/(1+λ)) になる。作図が敏感な方向ほど動きにくい。

**命題2（書き換えた点が等式に現れる場合）。** Z の z の動きは、列 [C_y; I] についての正則化された補正になり、|C_y| に応じて小さく保たれる。このとき E との一致は近似にとどまる。実測では、6問中5問で終点の92%以上が一致した。AIME 2025 II-5 では43%だった（S2.5）。

**以前の見方との関係。** 以前は J_aug = [[I, B], [0, I]]·diag(J_R, I)·[[I, 0], [−H, I]] から、階数が保たれること（rank J_aug = q + rank J_R）と、条件数が a² 程度まで悪くなりうることを示した。同じ H が、LM法の歩幅の調整にも入り込む。これが命題1との違いである。

### S1.4 値が一定であること（本文5.1）

M = {u : F(u) = 0, G(u) > 0} の上で τ が連続で、値が有限個なら、τ は M の各連結成分の上で一定である。連結な集合の連続な像は連結で、有限集合の連結な部分は1点だからである。

注意：解の1点で「DF(u)v = 0 ならば Dτ(u)v = 0」を確かめただけでは、一定とは言えない。例えば F = y、τ = x² では、原点でこの条件が成り立つが、y = 0 の上で τ は一定ではない。そこで本文では、恒等式 s^N·P(τ) = Σ C_i F_i（s は図が退化しない条件）を作り、M 全体で P(τ) = 0 を示した。63問中24問で作り、2通りに検算した（例：HMMT 2013年2月 幾何2番、τ² − 24）。

### S1.5 重根と精度（本文3.5）

f(x) = (x − α)^ν g(x)（g(α) ≠ 0）とする。このときニュートン法の誤差は e_次 ≈ (1 − 1/ν)e である。残差が δ のとき、座標の誤差は (δ/|g(α)|)^(1/ν) 程度までしか言えない。円の上かつ直線の上に作った点の、接点からの符号付きの位置を h とすると、R − d = h²/(R + d) で、接する条件は h について二重根になる。

### S1.6 同定に要る桁数（本文3.5）

次数 n の最小多項式を PSLQ で探すとき、入力は (1, τ, …, τⁿ) の n+1 個である。必要な精度の目安は、(n+1)×（係数の桁数）程度とされる。ただし、入力の正しい桁数、許容値（mpmath の既定では作業精度の約4分の3）、次数や係数の上限にも左右されるので、鋭い境目ではない。本文では、公式の答えから求めた最小多項式で、この目安と作業精度（120桁以上）の差を示しただけである。正解を知った上での診断で、未知の問題への予測ではない。

参考：次数 n、係数の絶対値 H 以下の整数多項式は (2H+1)^(n+1) 個ある。精度 D 桁で偶然どれかの根に一致する確率は、粗い見積もりで (2H+1)^(n+1)·n·10^(−D)/H 程度になる。n = 4、H = 10⁹、D = 90 でも 10⁻⁵⁰ 程度である。
