## S1 理論

### S1.1 当たるまでの時間（本文3.4、5.2）

1回の局所探索が当たる確率を p、1回の時間を t とする。出発点を独立に選び直すと、当たるまでの回数は幾何分布に従い、期待値は 1/p である。よって当たるまでの時間の期待値は t/p となる。t を「評価1回の費用 c × 1回の評価回数 n」に分けると c·n/p である。n には、微分を差分で求めるための評価も含む。実際のsolverは出発点を適応的に選ぶので、この式はsolver全体の予測ではない。局所探索の難しさを測る物差しとして使う。二段構え（安い1段目と、補いの2段目）が有利かどうかも、この式だけでは決まらない。1段目の費用と、2段目に回す確率の両方によるからである。

### S1.2 必ず収束する球（本文5.2、5.3）

正しい解 u* でのヤコビアンの最小特異値を s、ヤコビアンのリプシッツ定数を L とする。減衰のないガウス・ニュートン法の誤差 e は e_次 ≤ L e² / (2(s − L e)) を満たすので、半径 ρ = s/(2L) の球の中から出発すれば、誤差は毎回半分以下になる。出発点を一辺 W の箱から一様に選べば、p ≥ v_d (ρ/W)^d（v_d は d 次元の単位球の体積）。これは下界であり、d が大きいと p が小さいことの説明にはならない。本文では、5.3節の「解の近くでは自由点の系の不利が消える」という予測の根拠（ρ の中では、どの系も収束する）としてだけ使う。

### S1.3 3つの系と、命題1（本文5.3）

**3つの系。** 元の系 E は変数 u で、残差は R(u) = C(u, h(u))。ここで y = h(u) は書き換える点の作図、C は元の等式である。
- 自由点の系 Y：変数 (u, y)。残差は (C(u, y), G(u, y))。G = 0 は作図を表す等式（例：「D は直線 AI 上にある」「D は直線 BC 上にある」）で、G(u, h(u)) = 0 を満たす。
- ずれの系 Z：変数 (u, z)。点を y = h(u) + z と作図で作り直し、残差は (C(u, h(u)+z), z)。

**LM法の一歩。** MINPACK の方式（SciPy 1.18 の method="lm" の既定）では、一歩 δ は min |Jδ + r|² + λ|Dδ|² で決まる。D はヤコビアンの列の大きさから作る対角行列で、λ は信頼領域の大きさと、予測した減少と実際の減少の比から毎回更新される。

**命題1。** 書き換えた点が元の等式に現れない（C が y によらない）とする。厳密な算術で、2つの系に同じ尺度の初期化と更新規則、同じ初期信頼領域と更新規則、同じ停止条件と同じ評価の上限を使い、一歩の解が一意であるとする。このとき、z = 0 から出発した Z の反復の u は E の反復と完全に一致し、z はずっと 0 のままである。

証明（帰納法）。ある反復で z = 0 で、u と λ と D_u が E と同じだとする。Z のヤコビアンは [[J_R, 0], [0, I]] で、u の列は E と同じである（z の行は u によらない）。一歩の最小化は u と z に分かれ、z の部分は min (1+λD_z²)|δz|² なので δz = 0 となる。u の部分は E の式と同じで、同じ一歩を与える。z = 0 なので、残差のノルム、尺度を付けた変数と一歩の大きさ、予測した減少と実際の減少は、どれも E と同じになる。したがって、λ と D の更新も、一歩を受け入れるかどうかの判定も、停止の判定も同じになり、次の反復でも仮定が成り立つ。最初の反復では、z = 0 と、E と同じ u から始めるので仮定が成り立つ。∎

実際の計算は浮動小数点なので、収束しない軌道（局所解の境目の近くなど）では、丸め誤差の違いが増幅されて終点がずれることがある（S2.5）。

**自由点の系で、ニュートン法の向きは変わらない。** C が y によらないとき、Y のヤコビアンは [[J_R, 0], [G_u, G_y]] である。G_y が正則なら、ガウス・ニュートン法の一歩 min |J_R δu + R|² + |G_u δu + G_y δy + G|² では、第2項を δy の選び方で0にできるので、δu は E のガウス・ニュートン法の一歩と同じになる。δy = −G_y⁻¹(G + G_u δu) で、G = 0 なら δy = H δu（H は作図の微分）である。つまり、u をどちらへ動かすかは、点を作図で計算しても、式で持っても変わらない。

**違うのは、一歩をどこまで受け入れるか。** 一歩の大きさは、残差全体が減るかどうかで決まる（ガウス・ニュートン法では線探索、LM法では信頼領域）。E では、点は u から毎回正確に作り直されるので、一歩を制限するのは元の等式 R の非線形性だけである。Y では、y は直線的に y + H δu へ動くが、本当の作図の点は h(u + δu) にある。その差 h(u + δu) − h(u) − H δu は一歩の長さの2乗に比例して大きくなり、作図の式の残差 G として現れる。遠い出発点からの大きな一歩ほど、この残差が増えて一歩が受け入れられず、切り詰められる。

**予測。** 自由点の系の不利は、出発点と解の距離とともに増え、解の近くでは消える（解の近くでは一歩が小さく、作図の式の線形近似が正確だから）。出発点での量（列の大きさの膨らみ、作図の曲がり具合）だけでは、この不利は予測できない。道のりの長さに依存するからである。この予測は S2.5 で確かめた。

**書き換えた点が元の等式に現れる場合。** C が y による場合、Z の z は元の等式に引かれて0から離れる。δz = −(BᵀB + I + λD_z²)⁻¹Bᵀ(R + A δu)（A = C_u + C_y H、B = C_y）であり、Z も E と一致しない。どれだけ離れるかは問題による（S2.5）。v6 の「命題2」（z は小さく保たれる）は一般には成り立たないので削除した。反例：h = 0、C = M + u + y では、Z の一歩の u は −3M/7、E では −M/2 になる。

### S1.4 値が一定であること（本文5.1）

M = {u : F(u) = 0, G(u) > 0} の上で τ が連続で、値が有限個なら、τ は M の各連結成分の上で一定である。連結な集合の連続な像は連結で、有限集合の連結な部分は1点だからである。

注意：解の1点で「DF(u)v = 0 ならば Dτ(u)v = 0」を確かめただけでは、一定とは言えない。例えば F = y、τ = x² では、原点でこの条件が成り立つが、y = 0 の上で τ は一定ではない。そこで本文では、恒等式 s^N·P(τ) = Σ C_i F_i（s は図が退化しない条件）を作り、M 全体で P(τ) = 0 を示した。63問中24問で作り、2通りに検算した。例：HMMT 2013年2月 幾何2番（台形の高さ h が消えて AE² = 24）、HMMT 2008年2月 幾何6番（OP² = 17）。

msolve の「正次元」は複素数の範囲での判定で、実際に図が動くとは限らない。小さい10問を調べると、回転の固定漏れ2問、大きさの固定漏れ1問、補助点1問、退化した成分1問、本当に図が動くもの5問だった。厳密な方法が本質的に解けなかったとは言えない。

### S1.5 重根と精度（本文3.5）

f(x) = (x − α)^ν g(x)（g(α) ≠ 0）とする。ニュートン法の誤差は e_次 ≈ (1 − 1/ν)e で、残差が δ のとき座標の誤差は (δ/|g(α)|)^(1/ν) 程度までしか言えない。円の上かつ直線の上に作った点の、接点からの符号付きの位置を h とすると R − d = h²/(R + d) で、接する条件は h について二重根になる。

### S1.6 同定に要る桁数（本文3.5）

次数 n の最小多項式を PSLQ で探すとき、入力は (1, τ, …, τⁿ) の n+1 個である。必要な精度の目安は（n+1）×（係数の桁数）程度とされる。ただし、入力の正しい桁数、許容値（mpmath の既定では作業精度の約4分の3）、次数や係数の上限にも左右されるので、鋭い境目ではない。本文では、公式の答えから求めた最小多項式で、この目安と作業精度（120桁以上）の差を示しただけである。正解を知った上での診断で、未知の問題への予測ではない。

### S2.8 GMB と msolve（本文4）

**GMB。** GMB の論文 [6] の36問を、各3回、180秒で解いた。GMB は論文の既定設定（eps = 10⁻³）と厳格な設定（eps = 10⁻⁸、点の正則化なし、10万反復）の2通り。両方の出力した図を、同じ独立の検査器（80桁、条件のずれの許容 10⁻³ / 10⁻⁶ / 10⁻⁹）にかけた。データ：ブランチ nycxfb の jssa/results/gmb-comparison-20261022/、jssa/results/gmb-success-definition/。

| 定義 | GMB 既定 | GMB 厳格 | solver |
|---|---|---|---|
| モデルを返した | 95（88.0%） | 47 | — |
| GMB 自身の検査（評価値が eps×10 以下）を通った | 74（68.5%） | 41 | — |
| 独立の検査 10⁻³ | 38 | 42 | 98 |
| 独立の検査 10⁻⁶ | 30（27.8%） | 29 | 100（既定の比較）／101（厳格の比較） |
| 独立の検査 10⁻⁹ | 28 | 23 | 100 |

（いずれも108回中。GMB の入力を原文に合わせて差し替えた IMO 2015 P3 の3回は、独立の検査の数に含めていない。）

論文の93.52%は「36問×3回の平均で、モデル（図）を1つ作れた割合」で、上の「モデルを返した」（88.0%）に当たる。論文では、図ができたときに結論の式が ε×10 以内で成り立った割合が85.84%で、こちらは「GMB 自身の検査」（74/95 = 78%）に近い。独立の検査 10⁻⁶ で通らなかった GMB の図は、既定では62回すべてが等式のずれによるもので、うち35回はずれが 10⁻³〜10⁻² だった（GMB 自身の許容 0.01 の内側）。厳格な設定では15回中14回が等式のずれ、1回が鋭角の条件の違反だった。枝の違いだけで落ちた図は0回。したがって、論文の値と本研究の値の差は、主に「何を成功と呼ぶか」と「等式のずれの許容」から来ている。論文の時間制限とハードウェアは論文に書かれていないので、それ以上の比較はしない。

**msolve。** 323問を座標の多項式の系に自動で変換し（平方根は補助変数、不等式と枝は扱わず、実数解を solver と同じ最終検査器で絞り込む）、msolve 0.9.4 で解いた（同じPC、1問1800秒、4並列、メモリ5GB）。データ：ブランチ nycxfb の jssa/results/exact-comparison-pc-20261022/。

| msolve の結果 | 問題数 | solver が1回以上正解 | solver の時間の中央値 |
|---|---|---|---|
| 答えの集合が一致 | 201 | 201 | 2.0秒（msolve 0.03秒） |
| 正次元（複素数の範囲で解が無数） | 65 | 65 | 15.8秒 |
| 自由な変数が残る | 3 | 3 | 7.9秒 |

| 多項式にできない | 15 | 14 | 13.2秒 |
| 未知数がない・未実行 | 15 | 15 | — |

本文の「正次元68問」は、上の65問と3問の合計である。多項式にすると未知数が増える（中央値で、探索変数3個が未知数9個に）。小さい問題では厳密な方法の方がはるかに速く、solverの利点は、多項式にすると大きくなる問題と、値だけを決めればよい問題にある。
