# 作図で解く求値幾何solverと、その難しさ（題名は仮）

（v8・10/23夕。v7 の問2を作り直した。5.3節以降が新しい。新しい結果はすべて実行前に予測と判定基準を commit した。証明・手順・全ての表は補足資料 S1〜S5。【 】は本人確認か未完。）

## 要旨

幾何の求値問題を、作図と条件で書いた入力から、定理を探さずに数値計算で解くsolverを作った。作図で決まる点は変数にせず、見つけた図を数百桁まで精密化し、答えを √ などを含む式として同定する。開発に使った323問では969回中953回正解し、開発外の2026年の20問では60回中55回正解した。問いは2つである。(1) solverをどう実現したか。(2) そのsolverにとっての難しさは、人間の難しさとどう違うか。solverの費用の大部分は、正しい図に当たるまでの探索にある。その当たりやすさは、人間に示す問題文が同じでも、条件を探索のどこで扱うかで大きく変わった。作図を等式に戻すと、作図の線形近似のずれが一歩を切り詰め、当たる確率は1.00から0.03まで下がった。また、出発点の図が問題の不等式（凸、点の並び、どちら側か）を満たすかで当たりやすさが分かれ、満たす出発点を選び直す方策は、150問で当たる確率を0.39から0.55に上げた。問題ごとの上がり幅は事前に予測でき、実測との順位相関は0.90だった。一方、もともと当たりにくい問題の半数はほとんど変わらず、この方策で減らせる難しさと減らせない難しさを分けられた。これらの量と人間の難度との対応は弱かった。

## 1 はじめに

LLMの数学の力を競う大会（AIMO）で、私はLLMが長さや角度を求める幾何の問題（求値問題）を苦手とすることを知った。数学オリンピックで幾何を学んできた経験から言えば（IMO 2025 金メダル）、人間が苦労するのは補助線や定理を見つける部分である。しかし、図を正確に作れれば、答えは計算で求まるはずである。そこで、問題を作図と条件で書いた入力から、計算だけで答えを求めるsolverを作った。【本人確認：AIMOを見た時期と、目的の書き方。】

問いは2つである。(1) solverをどう実現したか。(2) そのsolverにとっての難しさは、人間が感じる難しさとどう違うか。

## 2 先行研究と、この研究の新しさ

AlphaGeometry [1, 2] は命題を証明する方法で、値を求める本研究とは課題が違う。図を座標の多項式で表して厳密に解く方法 [3, 13] は、答えの正しさを保証できる。数値的な方法では GMB [6] が最も近く、座標の取り方を工夫して変数を減らし、点を離す損失なども使って図を1つ作る。したがって「作図で変数を減らす」「退化した図を避ける」こと自体は新しくない。本研究の新しさは2つある。1つは、答えの値の集合を求め、値を式として同定して高精度で確かめる solver を作り、323問で既存の方法と比べたこと。もう1つは、条件を数値探索のどこで扱うか（作図で計算するか、等式で探すか、出発点の選び方に使うか）を変える対照実験と介入を行い、難しさがどこまで減り、どこで減らないかを、予測を先に固定して調べたことである。

## 3 solverをどう実現したか

### 3.1 問題の表し方

問題は、探索変数 u（d 個の実数）、作図 h、等式 F(u) = 0、不等式 G(u) > 0、求める量 τ で書く。中点や交点などは、作図で u から計算する。不等式は、条件を満たす図が複数あるときにどれを指すか（枝）を決める。求めるのは集合 { τ(u) ｜ F(u) = 0, G(u) > 0 } である。

### 3.2 4つの困難と、それを受け持つ仕組み

表1　困難と仕組み

| 困難 | 仕組み |
|---|---|
| 探す変数が多い | 作図で点を消す。式で直接解ける小さな系は、枝を列挙して探索を省く（代数的前処理） |
| 正しい図に当たらない | 微分を使わない安い探索（NOMAD [9]）を1段目に置き、答えが出なければLM法 [10] の多点出発（第2探索）と、範囲を分けた再探索で補う |
| 精度が上がらない | 多倍長のLM法とニュートン法。「接する」などの条件は符号付きの残差に直す |
| 値が式にならない | PSLQ [11] で最小多項式を同定し、120〜500桁で条件と枝を確かめる |

### 3.4 仕組みの役割

本計測（323問×3回）の記録から、各仕組みが答えを出した問題を調べて影響を予想し、1つずつ外した計測と比べた（S2.2）。代数的前処理は、答えを出した97問のうち74問で、外すと1.5倍以上遅くなった（他の問題では0問）。第2探索は、答えを出した10問のうち9問を、外すと失った。時間の51%は候補の精密化に使われる（S2.9）。接する条件を符号付きの残差に直すと、同じ候補の残差が8〜48桁で止まっていた7問が、119〜502桁に届いた（S2.7）。

## 4 達成したこと

各問題に180秒と1コアを与え、seedを変えて3回ずつ解いた（表2）。開発用の323問は、AIME・HMMT・日本数学オリンピック予選（2000〜2025年）から私が選んだ。入力はAIが書いたので、解き方が入り込んでいないかを正解を見ずに全問調べ、問題文をそのまま書き移したと確認できた246問を「直接入力」と呼ぶ。答えが複数ある問題は、値の集合が一致したときだけ正解とした。

表2　問題の種類ごとの成績（各3回）

| 問題 | 問題数 | 正解した回数 | 時間の中央値 |
|---|---|---|---|
| 開発用 | 323 | 953/969 | 5.2秒 |
| うち直接入力 | 246 | 724/738 | 6.6秒 |
| 2026年の新しい問題 | 20 | 55/60 | 9.9秒 |
| 自動生成（答えが複数の32問を含む） | 88 | 264/264 | 1.3秒 |

GMB の論文の36問で、両方の出力を同じ独立の検査（条件のずれ 10⁻⁶ 以内）にかけると、図を作れた回数は solver 100/108、GMB 30/108 だった（S2.8）。多項式にして msolve [13] で解く方法は、答えを得た201問では solver よりはるかに速かった（中央値0.03秒）。残る122問（解が有限個でない問題、多項式にできない問題、時間切れなど）は、solver が121問を解いた。

## 5 solverにとっての難しさ

### 5.1 費用の大部分は、正しい図に当たるまでの探索

1回の局所探索（LM法）が当たる確率を p、1回の時間を t とすると、当たるまでの時間の期待値は t/p である。探索変数のある292問で、問題ごとの t/p の違いの87%は、当たるまでの評価回数の違いだった（S2.3）。以下では p を、箱から一様に選んだ出発点からの LM法1回の当たる確率として調べる。

### 5.2 作図を等式に戻すと、一歩が切り詰められる

作図 y = h(u) で計算していた点を自由な点 y に戻し、作図を表す等式 G(u, y) = 0 を加えても、正しい図も問題文も変わらない。15問で作図を k か所書き換えると、当たる確率の中央値は 0.96、0.77、0.40、0.38 と下がった（k = 0〜3）。変数の数が同じで、作図の上から始まる系（y = h(u) + z の z を変数にする）では、命題1（S1.3）のとおり元の系とほぼ同じになった（図2）。変数の数の増加だけでは説明できない。

AIME 2014 II-14（1.00→0.03）の反復を、減衰のないガウス・ニュートン法で追跡すると、u を動かす向きは元の系と同じだった。違ったのは受け入れられる一歩の長さで、長さ 1/128 の一歩で元の等式の残差は両方の系で同じだけ減ったが、自由点の系では線形近似では0のはずの作図の等式の残差（2乗和）が約550に跳ね、一歩は 1/8192 まで切り詰められた。この機構から「出発点が解に近いほど不利は小さい」と予測し、10問で確かめた（図3）。作図で点を計算する設計が効く理由の一つは、点がいつも作図の上にあり、このずれが生じないことである。

### 5.3 不等式は、出発点の段階で当たりやすさを分ける

作図は反復の中で条件を守らせる方法だった。では、作図で守らせていない条件はどう効くか。不等式・枝・「三角形がつぶれない」などの条件（以下、許容条件）は、solver の探索では、破ると一定の罰則が加わる形で扱われる。人間は図を描いた時点でこれらを満たしているが、solver は箱から一様に出発点を選ぶので、許容条件を破った図から始まることがある。

292問の55,097出発点を調べると、34%が許容条件を破っていた。当たる割合は、満たす出発点で0.71、破る出発点で0.33だった。問題ごとの「出発点が許容条件を満たす割合」φ は、反復探索をせずに測れる量で、当たる確率 p との順位相関は0.49（変数の数をそろえて0.38）だった。別の seed でも同じ値が出た（S5.1）。

そこで介入として、出発点が許容条件を満たすまで選び直す方策を試した（上限2000回。検証用の改変で、凍結した solver の成績とは分ける）。同じ問題で、p は φ と、満たす出発点からの確率 p_F、破る出発点からの確率 p_I を使って p = φ p_F + (1 − φ) p_I と書けるので、選び直しによる変化は (1 − φ)(p_F − p_I) と予測できる。この予測を seed 0 から問題ごとに計算して固定し、新しい seed で150問を実行した。予測した4項目はすべて成立した（S5.2）。

- 当たる確率の平均は 0.390 から 0.545 に上がった（93問で上昇、27問で低下。符号検定 p < 10⁻⁹）。
- 問題ごとの変化は予測と順位相関0.90で一致し、平均絶対誤差は0.05だった（図4、122問）。
- 予測が負の問題では、実際に下がった。AIME 2010 II-14 は満たす出発点からの方が当たりにくく（12/116 対 76/84）、選び直すと 0.50 から 0.12 に下がった。「許容条件を満たす出発点なら良い」とは限らない。
- もとの p が0.3未満の75問では、変化の中央値は0.02だった。18問は0.3以上上がったが、36問はほとんど変わらなかった。

![図4](figures/fig4_feasible_start.png)
図4　選び直しによる当たる確率の変化。横軸は seed 0 から予測した変化、縦軸は新しい seed での実測。破線は予測と実測が等しい線。

つまり、当たりにくさの一部は「許容条件を破った図から始まること」で生じ、その部分は事前に測って減らせた。一方、最も当たりにくい問題の半数は、許容条件を満たす図から始めても当たりにくいままだった。【完成した solver での費用込みの比較（150問×3 seed×2条件）を実行中。結果で一文を加える。】

### 5.4 残る難しさについて分かったこと、分からなかったこと

残る難しさの手がかりとして、外れた探索の終点を調べると、約35%は2点がほぼ重なった図だった（当たりではほぼ0%）。そこで、2点を重ねても等式がすべて満たされる図を数値探索で検出できる問題（65/292問）を調べると、変数の数をそろえた5つの層すべてで当たりにくかった（並べ替え検定 p = 0.0016）。変数の数・φ・この検出の有無で当たる確率を予測する式を292問で固定し、未使用の2026年の20問に当てると、実測との順位相関は0.79だった（変数の数だけでは0.71）。ただし事後に比べると、検出の有無を除いて変数の数と φ だけにした式の方が良く（0.82）、未使用問題で効いていたのは φ だった。また、検出された2点に反発する項を加えても当たる確率は上がらなかった。重なった図の検出は、開発用の問題では当たりにくさと結びついたが、原因とも、未使用問題での予測の助けとも言えなかった（S5.3）。

## 6 人間の難しさとどう違うか

人間の難しさは、補助線や定理という見通しが立つかで決まる。solver の難しさは、条件を探索のどこで扱うかで変わり、その一部（許容条件を破った出発点）は事前に測って減らせ、別の一部（作図を等式で探すことによる一歩の切り詰め）は作図の設計で避けられた。

人間の難度（実際の正答率から推定された Easy2Hard [12]）との対応は弱く、大会によって違った。大会ごとの順位相関は、AIME（43問）では人間の難度と p が −0.24、φ が −0.34 で、人間に難しい問題ほど solver にも当たりにくい弱い傾向があった。HMMT（66問）では −0.14 と −0.08 で、ほぼ対応しなかった。逆向きの例もある。HMMT 2019年2月 幾何10番は、正方形を3段重ねた複雑な図で人間には難しい（HMMT の79問中、上位約1割）が、作図だけで図が決まる（d = 0）ので、探索なしに1.5秒で解けた。人間にとっての難しさの中心である「関係の発見」は、solver では入力の作図として与えられ、solver の難しさは、作図で消せなかった条件をどう探すかに移る。

## 7 限界

solver は、すべての答えを見つけたことも、答えの式の正しさも、数学的には保証しない。323問は開発に使った問題である。5章の p は LM法1回の当たる確率で、完成した solver の時間ではない。φ は実装した許容判定で測った量で、枝や作図の評価可能性も含む。重なった図の検出は数値探索によるもので、検出されない問題に重なった図がないことは示していない。外れた予測（重なった図への反発、単調な誤差の変換の一般化、条件の種類からの予測）は S5.4 に記した。

## 8 結論

作図で決まる点を計算し、候補の探索、高精度化、値の同定を組み合わせた solver を作り、開発用323問で969回中953回、開発外の20問で60回中55回正解した。solver の費用の大部分は正しい図に当たるまでの探索にあり、その当たりやすさは問題文ではなく、条件を探索のどこで扱うかで変わった。作図を等式で探すと、線形近似のずれが一歩を切り詰めた。許容条件を出発点の選び方に使うと、当たる確率は平均0.39から0.55に上がり、問題ごとの効果は事前に予測できた。一方、最も当たりにくい問題の半数はこの方法では変わらず、減らせる難しさと減らせない難しさを分けられた。【本人確認：次の一手。】
