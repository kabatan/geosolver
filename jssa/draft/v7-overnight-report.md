## 一番大きな変化：5.3節の「なぜ」を、実験で一段ずつ詰めた

問2の核心は「人間には同じ問題でも、solverの難しさは表し方で変わる。それは何で決まり、なぜか」です。夜の間に、予測を先に固定しては確かめる、を4回繰り返しました（予測はすべて実行前に commit）。

1. **v6 の説明は外れた。** v6 では「作図の微分で u の列が膨らみ、歩幅が縮む」と説明していました。新しい43問で予測を固定して確かめると、列が3倍以上膨らむ6問で低下を当てたのは3問だけでした。膨らみが10⁹倍でも低下しない問題もありました。
2. **原因を追った。** 減衰のないガウス・ニュートン法で AIME 2014 II-14 を1歩ずつ追跡しました。u を動かす向きは、元の系と自由点の系で同じでした（条件付きで式からも言えます）。違ったのは、受け入れられる一歩の長さです。同じ一歩で元の等式の残差は両方で同じだけ減ります。しかし自由点の系では、線形近似では0のはずの作図の等式の残差が約550に跳ね、一歩が 1/8192 まで切り詰められました。
3. **この機構から出る予測も確かめた。** 「出発点が解に近いほど不利は小さい」という予測を10問で確かめました。結果は予測どおりで、解の近くでは10問中8問で差がなく、遠ざけると不利の中央値が 0 → 0.07 → 0.30 → 0.50 と増えました（図2）。
4. **座標だけを変えた対照（GPT-Pro の提案）。** 作図の行の式は自由点の系と同じまま、点の座標の取り方だけを変えた系を作りました。当たる確率の中央値は、自由点の系の0.15から0.77に戻りました（元の系は0.93）。10問中5問では元の系とほぼ同じになりました。ただし、事前に一致を予測した2問のうち JMO 2013 予選3 は0.45にとどまり、この予測は外れました。

結論として、不利の多くは座標の取り方で生じます。ただし作図の行の式も効く場合があり、原因を一つに絞り切ったわけではありません。本文もこの範囲で書きました。
