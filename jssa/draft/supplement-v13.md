# S1 solver の数理と実装

本文3章の仕組みを、式と擬似コードで説明する。すべて凍結版（kabatan/geosolver の 60db4b6）のコードで確かめた。各節の末尾にファイル名を書いた（`src/geosolver/` は省略）。数値の定数はコードの既定値で、323問の本計測もこの値で動いている。実験の数値は補足 S2 の再掲である。 理論（旧 S1.1〜S1.6）は S1.8〜S1.13 に置いた。

記号は本文3.1と同じにする。探索変数 u ∈ ℝ^d、作図 h、等式の残差 F(u) = (F_1(u), …, F_m(u))、不等式などの許容判定 G、求める量 τ。求めるのは集合 { τ(u) ｜ F(u) = 0, G(u) を満たす } である。

## S1.1 作図による変数消去

### S1.1.1 入力と評価

入力は、探索変数の名前、作図の列 y_1 = h_1(u), y_2 = h_2(u, y_1), …、条件、求める量からなる（例は本文図1の AIME 2021 I-11）。1点の評価は次のとおりである。

```
evaluate(u):
    ctx ← {u}
    for (名前 y_k, 式 h_k) in 作図の列:          # 書いた順に1回ずつ計算
        ctx[y_k] ← h_k(ctx)                     # 交点がない・直線が決まらない等なら失敗
    r_i ← 左辺_i(ctx) − 右辺_i(ctx)   (i = 1..m)   # 等式の残差
    return r, 許容判定 G(ctx)
```

作図は中点・交点・垂線の足・外心などの関数で、点は常に作図の上にある。等式は「左辺 − 右辺」を残差にする（high_precision_expressions.py）。不等式、点の並び（ConvexPolygon など）、交点の枝の選び方は許容判定 G に入り、残差には入らない。

### S1.1.2 何が消えるか

作図で決まる点 y を自由な変数に戻すと、変数は (u, y) になり、作図を表す等式 Q(u, y) = 0 が加わる。作図で計算すると、y = h(u) を代入した

  F(u) = C(u, h(u))

だけが残る。例題 AIME 2021 I-11 のDSLでは、等式は AB = 4、BC = 5、CD = 6、DA = 7、4点の共円の5本である。AB = 4 は A = (0,0)、B = (4,0) の作図で自動的に満たされる冗長な1本なので、5本は独立な等式の数ではない。4つの垂線の足をすべて自由点にすると変数は 4 + 8 = 12、DSLに書かれる等式は 5 + 8 = 13 になる（足1つにつき「直線上にある」「垂直」の2本）。作図で計算すれば変数は4、等式は5のままである。

開発用323問の探索変数の数 d は、0が31問、1が43問、2が73問、3が65問、4が55問、5が26問、6が20問、7が9問、9が1問だった（benchmarks/dsl から数えた）。d = 0 の31問は作図だけで図が決まり、探索をしない。8月の書き直しの前は、8変数以上の問題が44問あった（S3）。

作図で計算するときのヤコビアンは連鎖律で J_E = C_u + C_y H（H = ∂h/∂u）になる。自由点の系との違いは補足 S1.10 の命題1で扱った。

### S1.1.3 評価できない点

作図は定義域を持つ。円と直線が交わらない、2点が一致して直線が決まらない、三角形がつぶれる、といった点では評価が失敗する。この失敗は「隠れた制約」で、探索器には明示的な制約式として渡していない。1段目の探索（S1.2）はこれを NOMAD の DiscoMADS に任せ、局所探索では大きな罰則に置き換える。

交点が2つある作図は、Intersect の引数（n 番目、ある点を除く、ある点に近い・遠い）で枝を選ぶ。どの枝を選んだかは記録され、最終検証（S1.5.2）で同じ枝のままかを確かめる（intersections_selection.py、final_verifier.py の same_branches）。

### S1.1.4 探索の箱

各変数の探索範囲は [−s, s] で、s は「その変数に関係する等式に現れる数の最大値の2倍」と10の大きい方（上限20000）である。不等式から下限や上限が決まる変数（例：cy > 0）は、その側を固定する（problem/domain_bounds.py の search_bounds）。

## S1.2 探索の流れ：NOMAD → 局所探索の多点出発 → 範囲を分けた再探索

### S1.2.1 全体

1問の流れは次のとおりである（engine/standard/orchestration/run_external_pipeline.py）。

```
solve(問題, seed):
    結果1 ← 試行(1段目: NOMAD, seed 1個, 代数的前処理あり)
    if 結果1 で答えが1つ以上採用された:
        return 結果1
    結果2 ← 試行(第2探索: hybrid_legacy_nomad, seed 5個, 代数的前処理なし)
    return 採用数が多い方（同数なら精密化の最良残差が小さい方、さらに同じなら評価回数が多い方）

試行(探索法, seeds):
    if 代数的前処理が使える: 候補 ← 代数的前処理（S1.6）
    else:
        出発点 ← 一様乱数 50点 × seed数 ＋ 構造を使った標本
        候補 ← 探索法(出発点)                       # 最大20個
    精密化（S1.3） → 最終検証と同定（S1.5）
    if 採用がない（または全てが精密化の途中で止まった候補） and 残り時間 ≥ 8秒:
        候補 += 範囲を分けた再探索（S1.2.4） → 精密化 → 最終検証と同定
    return 採用された答え
```

本文の「第2探索」は、2回目の試行（`hybrid_legacy_nomad`）を指す。1回目で答えが出たときは走らない。代数的前処理の候補が一部しか検証を通らなかったときは、1回目の試行で通常の数値探索も走らせ、両方の採用を合わせる。

### S1.2.2 1段目：NOMAD（DiscoMADS）

目的関数は、残差の尺度をそろえた2乗和に、許容判定の罰則を足したものである（engine/standard/search/nomad_blackbox_adapter.py）。

  f(u) = Σ_i (r_i(u) / σ_i)² + 10⁶ · [u が許容判定を満たさない]

作図が評価できない点では、NOMAD に「評価失敗」を返す。DiscoMADS の隠れた制約の設定（DISCO_MADS_HID_CONST、そのときの出力値 10²⁰）で扱われる。

**残差の尺度 σ_i。** 最初の乱数の点（1回目の試行では50点）で各等式の |r_i| の中央値を求める。中央値の最大と最小の比が10未満なら尺度はかけない（σ_i = 1）。10以上なら、σ_i = max(中央値_i, 中央値の幾何平均) とする（run_initial_probe.py）。長さの2乗の式と角度の式のように、単位の違う等式が混ざったときに、片方だけが目的関数を支配しないようにするためである。幾何平均で下を押さえるので、もともと小さい等式を拡大しすぎない。

**設定。** seed 1個、評価の上限200回、出発点は乱数50点（と構造を使った標本）のうち、不等式を満たす点を優先し、その中で f が最小の点。箱は両側に幅の25%ずつ広げる（不等式で決まる側は広げない）。

### S1.2.3 候補の選び方

探索で評価したすべての点から、精密化に回す候補を選ぶ（build_guard_feasible_ledger.py）。

```
F ← 評価した点のうち、評価でき、許容判定を満たす点（f の小さい順）
台帳 ← [F の先頭]
while |台帳| < 160:                       # max(20×8, 64)
    台帳 に、すでに選んだ点から最も遠い点を加える（距離は箱の幅で割った座標で測る）
候補 ← 台帳から同じ「最も遠い点」の規則で20個選び、f の小さい順に並べる
```

残差だけで上位20個を取ると、同じ谷に落ちた点ばかりになる。最良の点を1つ残したうえで、離れた点を優先して選ぶので、答えが複数ある問題でも別の解の近くの点が残りやすい。

### S1.2.4 第2探索（hybrid_legacy_nomad）

1回目の試行で答えが採用されなかったときだけ走る（engine/standard/orchestration/run_search.py）。

```
第2探索(seeds = s, s+1, …, s+4):
    A ← NOMAD(DiscoMADS)を seed ごとに1回ずつ（出発点は乱数250点から5個）
    T ← 残り時間
    B ← 局所探索の多点出発(出発点 = A の上位5点 ＋ 5個の出発点, seeds, 時間 T/2)
    C ← 局所探索の多点出発(出発点 = 5個の出発点, seeds + 5, 残りの時間)
    return A ∪ B ∪ C から S1.2.3 の規則で20個
```

局所探索の多点出発は、seed ごとに次を行う（engine/standard/search/scipy_multistart_backend.py）。

- 出発点：与えられた点、スクランブルした Halton 列の320点、箱の内側の格子状の点。各 seed の最初の数点を先に回し、深い点は後に回す。
- 各出発点から、等式が変数以上なら LM 法（SciPy の `least_squares(method="lm")`、評価の上限80回、許容誤差10⁻¹⁴）、変数の方が多ければ Powell 法（反復400回）。
- LM 法に渡すベクトルは、残差に2成分を足したものである。

  ( r_1/σ_1, …, r_m/σ_m, 10·g(u), 10·p(u) )

  g(u) は不等式の違反量の和、p(u) は許容判定を破れば10³、満たせば 10⁻⁶ / (許容判定の最小の余裕) である。作図が評価できない点では全成分を10¹⁰にする。
- 時間の半分を使い切ったら、上下限付きの TRF 法（Halton 24点、許容判定を満たす点から順に）に切り替える。

### S1.2.5 範囲を分けた再探索

どの候補も最終検証を通らなかったとき、残り時間が8秒以上あれば走る（run_rescue_search.py、select_rescue_boxes.py）。

```
代表 ← 台帳の先頭 ＋ 「最も遠い点」で最大6個
for 各代表 c:
    半径_j ← 箱の幅_j × clamp(0.5 × (c から最も近い他の代表までの距離), 0.02, 0.35)
    c を中心とする小さな箱で NOMAD（MADS）、評価80回まで、上位6点を残す
合計8秒まで
```

広い箱では見落とした谷を、候補の近くの小さな箱で探し直す。代表どうしが近いほど箱は小さくなる。

### S1.2.6 その他の経路

d = 1 の問題では、まず1変数の根の挟み込み（格子と Brent 法）と、平方数の差を使う整数の枝の列挙を試す。不等式に有理数の境界があるときは、その境界上の点を候補に加える（finite_guard_search.py）。整数であることが条件の問題では、整数値に固定して閉じ直す経路がある（integer_targets.py）。どれも候補を出すだけで、精密化と最終検証は同じである。

### S1.2.7 各部分の役割（S2.2 の再掲）

外す実験（seed 0、323問）では、第2探索を外すと、第2探索が答えを出していた10問のうち9問を失った。1段目の NOMAD を局所探索の多点出発に替えると、正解の数はほぼ同じ（両方正解313問）で、両方正解の問題の時間比の中央値は1.7倍だった。再探索が答えを出していた9問では、外すと1問を失い、逆に3問が新しく解けた。開発外34問での同じ実験（事前登録6の実験2）では、全部入り93/102に対し、第2探索なし91、1段目の NOMAD を替えた版96で、差は小さかった（S4.4）。

## S1.3 多倍長での精密化

### S1.3.1 流れ

候補1つの精密化は次のとおりである（engine/standard/refinement/mpmath_refiner.py、refiner_config.py）。

```
精密化(x):
    if 120桁での残差 < 10⁻¹⁵ かつ 許容判定を満たす:          # すでに良い点
        仕上げ(x) を試す。目標に届けば終わり、届かなければ下へ
    if 等式の数 ≥ d > 1 かつ 許容判定を満たす:
        x ← 減衰なしのニュートン法（120桁、12回まで）。失敗したら元の x のまま
    for (桁数, 目標) in [(50, 10⁻²⁰), (100, 10⁻⁵⁰), (120, 10⁻⁸⁰)]:
        x ← LM法(x, 桁数, 目標)
        if 残差 > √目標 かつ 目標に届かずに止まった: break
    仕上げ(x)

仕上げ(x):
    if 120桁での残差 ≤ 10⁻¹⁰ かつ 許容判定を満たす:
        for (桁数, 目標) in [(120, 10⁻⁸⁰), (250, 10⁻¹⁵⁰), (350, 10⁻²²⁰), (500, 10⁻³²⁰)]:
            x' ← ニュートン法(x, 桁数, 目標, 最大 max(80, 2×桁数) 回)
            if x' が全ての元の等式で目標を満たし、許容判定も満たす: x ← x'
    return x
```

### S1.3.2 多倍長の LM 法

1回の更新は

  (JᵀJ + λI) δ = −Jᵀr

を mpmath の LU 分解で解く（levenberg_marquardt_step.py）。SciPy の LM 法と違い、λ にかける対角行列は単位行列である。λ の初期値は10⁻⁶で、改善すれば λ/4（下限10⁻¹²）、しなければ 4λ にする。δ に対しては、刻み幅を1, 1/2, 1/4, … と20回まで半分にし、箱の中にあり、許容判定を満たし、残差のノルムが減る最初の点を受け入れる（line_search.py）。止まるのは、80回反復、相対的な改善が10⁻¹⁰未満の更新が5回続いたとき、受け入れに12回続けて失敗したときである。

J は中心差分で求める（finite_difference_jacobian.py）。刻みは

  h_j = max(1, |x_j|) · 10^(−min(桁数/2, 30))

である。中心差分の打ち切り誤差は h² 程度、丸め誤差は 10^(−桁数)/h 程度なので、120桁では、関数が滑らかで適切に尺度化されている場合の目安として、J の相対誤差は 10⁻⁶⁰ 程度になる（高階微分が大きい場合や悪条件の作図では悪くなりうる）。変数に依存しない行がわかっている問題では、互いに影響しない列をまとめて1回の差分で求める。角度を含む問題では、折れ目で中心差分が0になるときだけ片側の差分を使う。

### S1.3.3 なぜ段階的に桁を上げるか

正則な解の近くでは、ニュートン法の誤差は e_次 ≈ (L/2s) e² で減り（s は最小特異値、L はヤコビアンのリプシッツ定数、S1.9）、正しい桁数は1回ごとにおよそ2倍になる。そのため、浮動小数点の候補（15桁程度）を最初から500桁で計算する必要はない。安い50桁で谷の底に近づき、100桁、120桁と上げてから、仕上げで250〜500桁に伸ばす。ただし J に相対誤差 η があると、ニュートン法の誤差は1回で κη 倍程度（κ は条件数）までしか減らない。120桁の中心差分では η は10⁻⁶⁰程度なので、この制限は目標の10⁻⁸⁰に対して強くない。仕上げでは、解析的な微分が使える問題ではそれを使う。

### S1.3.4 特異なヤコビアンと、変数が等式より多い系

回転のような自由度や重複した等式があると、J は正方でなかったり特異だったりする。仕上げでは、全体のニュートン法が使えないとき、または結果が確認を通らなかったとき、次の方法に切り替える（`_run_rank_aware_findroot`）。

```
J の各行・各列を最大成分で割って大きさをそろえる
完全ピボット選択のガウス消去で、独立な行の組 R と列の組 C を選ぶ
   （ピボットが 最大成分 × 10^(−min(25, max(12, 桁数/3))) 以下になったら止める）
C 以外の変数を固定し、R の等式だけでニュートン法を解く
最後に、元の全ての等式で残差が目標以下かを確かめる
```

選び方は局所的な座標の取り方にすぎず、条件を加えたり外したりはしない。採否は元の全ての等式で決める。

## S1.4 接する条件の符号付き残差

### S1.4.1 問題

入力の IsTangent(直線, 円) の値は |d − r|（d は中心から直線までの距離、r は半径）、IsTangent(円, 円) の値は min(|d − (r₁+r₂)|, |d − |r₁−r₂||) である（geometry/mp/mp_api.py）。値が0になる集合は正しいが、絶対値のため0の点で微分できない。中心差分は折れ目の両側の傾きを打ち消して0に近い値を返すので、LM 法やニュートン法は解の近くで正しい向きを失い、「近いが精度が上がらない点」で止まる。

もう1つの問題は二重根である。接点 P を「直線と円の交点」として作図すると、接する図では2つの交点が重なる。補足 S1.12 のとおり、P の位置のずれを h とすると R − d = h²/(R + d) で、残差は h の2乗でしか変わらない。残差 δ まで下げても、座標は √δ の精度にしかならない。

### S1.4.2 置き換え

精密化（S1.3）の間だけ、残差を、0になる集合が同じで、解で単純な0を持つ式に置き換える（mpmath_refiner.py の `_smooth_zero_constraint_residuals`、engine/standard/problem/tangency_contacts.py、geometry/mp/signed_tangency.py）。優先順は次のとおりである。

| 元の条件 | 置き換え後の残差 | 使う条件 |
|---|---|---|
| IsTangent(Line(A,B), 円)、または Distance(中心, Line(A,B)) = 半径 | ((O − P)·(B − A)) / \|AB\| | 接点 P が円の上と直線の上にあることを、作図か別の等式から示せるとき |
| IsTangent(円₁, 円₂) | ((O₁ − P) × (O₂ − P)) / r₁ | 2つの円に共通の点 P があると示せるとき |
| IsTangent(円₁, 円₂) | d − (r₁+r₂) と d − \|r₁−r₂\| のうち絶対値が小さい方（符号付き） | 上の条件が示せないとき |
| IsTangent(直線, 円) | δ² − r²（δ は正規化した直線の式に中心を代入した符号付きの値） | 接点が示せないとき |
| Distance(P, Q) = 0 | (P.x − Q.x, P.y − Q.y) の2行 | 両方が点のとき |

1行目は「接線は接点で半径に垂直」を使う。P が円の上かつ直線の上にあれば、この内積が0であることと接することは同値で、接触の方向にとった局所的な変数については0は単純な根になる（探索変数に合成した後も単純とは限らない）。2行目は「2円が共通点で接するなら、2つの半径は一直線上にある」を使う。δ² − r² = (δ − r)(δ + r) は、r > 0 なら δ = ±r で単純な0を持つ。

接点の証明は、入力の構文だけで行う。たとえば P が Intersect(直線, 円) として作図されている、P が直線を作る2点のどちらかである、OnCircle(P, 円) = 0 という等式がある、といった場合である。示せないときは置き換えない。

このほか、Circle(B + r·v, r) の形の円が別の円に内接する条件では、半径 r > 0 が作図の定義域から言えるので、r を割った後の等式 2((B − O)·v + R) + r(v·v − 1) = 0 を補助の行として加える（positive_radius_contacts.py）。元の行はすべて残す。

### S1.4.3 何が保証されるか

置き換えは精密化の一歩を決める残差だけを変える。最終検証（S1.5.2）は元の条件で行い、0になる集合が同じ符号付きの形（IsTangent を符号付きの値に、絶対値をその中身に書き換えたもの）で残差の小ささを判定する。採否は元の条件に対する数値検証で決める。

### S1.4.4 効果（S2.7 の再掲）

接する条件を含む24問のうち、探索で候補が作られる12問で、同じ候補の集合を置き換えありとなしで精密化した。置き換えなしでは7問で最良残差が8〜48桁にとどまり、ありでは119〜502桁に達した。残りの5問は両方で同程度だった。

## S1.5 最終検証と PSLQ による同定

### S1.5.1 流れ

精密化した候補は、残差の小さい順に次を通る（assemble_exact_results.py）。

```
for 候補 x（残差の小さい順）:
    検証(x, 桁数の段 = 80, 120, 180, 250, 350, 500)     # S1.5.2
    if 不合格: 捨てる
    if 求める量が数だけの式でない:
        確認(x, 桁数の段 = x の桁数より上の 250, 350, 500)   # もう一度、独立に
    同定(τ(x), τ の誤差の上限)                          # S1.5.3
    同定できたら採用
```

### S1.5.2 検証

各段の桁数で、次を行う（engine/standard/evaluation/final_verifier.py）。

1. 元の等式を「左辺 − 右辺」に正規化し、IsTangent を符号付きの値に、絶対値をその中身に置き換える（0になる集合は変わらない）。
2. 各等式の大きさと微分を測り、大きさをそろえた J で、独立な行と列を S1.3.4 と同じ方法で選び、ニュートン法の修正を最大8回行う。修正は、全ての等式のずれが減り、交点の枝が変わらないときだけ受け入れる。
3. 正規化した残差 max_i |r_i| / max(|r_i|, 項の大きさ, Σ_j |∂r_i/∂x_j| s_j) が10⁻³⁰以下であること（s_j は箱の幅、|x_j|、1 の最大）。
4. 不等式、点の並び、直線が定まる、三角形がつぶれない、交点の枝、作図の定義域について、余裕が誤差の100倍より大きいこと。余裕が誤差より小さく判定できないときは「未確定」で、合格にしない。
5. 求める量 τ とその誤差の上限を計算する。

連続する2つの段で合格し、桁数が180以上になった時点で合格とする。最短では120桁と180桁で合格する。

### S1.5.3 同定

τ の値と誤差の上限 ε から、正しい桁数 D = −log₁₀(ε / max(1, |τ|)) を求め、同定に使う桁数を min(検証の桁数, D + 10) にする。30桁未満なら同定しない（runtime/symbolic_operations.py）。

整数係数の多項式 a₀ + a₁τ + … + a_nτⁿ = 0 を、PSLQ でベクトル (1, τ, …, τⁿ) の整数関係として探す（exact/polynomial_search.py）。

```
for n = 1, 2, …, 最大次数:
    a ← PSLQ((1, τ, …, τⁿ), 許容誤差 10^(−桁数/2)（100桁以下では 10^(−3×桁数/10)）, 係数の上限)
    a を因数分解し、τ に最も近い実根を持つ既約因子を選ぶ（近さが同じなら棄却）
    相対残差 |Σ a_k τ^k| / Σ |a_k τ^k| < 10^(−3×桁数/5)（100桁以下では 10^(−2×桁数/5)）なら採用
    （τ を 10^k 倍した値でも同じことを試し、係数を戻す）
```

最大次数と係数の上限は、精密化の残差で3段階に分ける（identify_answer.py）。残差 ≤ 10⁻⁷⁰ なら次数8・係数10⁸、≤ 10⁻⁵⁵ なら次数6・係数10⁷、それ以外は次数4・係数10⁶。323問の公式の答えの次数は最大4だった（S2.7）。

候補の式が得られたら、SymPy で多項式の実根を厳密に表し、τ に最も近い根を選ぶ。その根と τ の差が ε 以内でなければ棄却する。多項式の残差でなく根までの距離で判定するのは、(x − 72)² のような重複した関係では残差が誤差の2乗になり、精度を実際より高く見せるからである。0と同定される場合は、τ が誤差の範囲で0であるときだけ採用する。

多項式で同定できないときは、A·π + B（A, B は有理数）の形を探す。求める量が角度や π を含むときは、多項式の前に有理数かどうかを先に試す。求める量が数だけの式（√2 など）なら、その式をそのまま答えにする。ほかの候補ですでに同定した式があれば、まずそれと誤差の範囲で一致するかを確かめる。

### S1.5.4 何を保証しないか

PSLQ が返すのは、指定した次数と係数の範囲で見つかった関係で、真の答えである証明ではない。確かめているのは「検証済みの τ と、選んだ代数的数の差が、数値的に推定した誤差の範囲内にある」ことまでで、区間演算などによる厳密な包含の証明ではない（本文7章）。必要な桁数の目安は補足 S1.13 にある。

## S1.6 代数的な前処理

### S1.6.1 対象

次を満たす問題では、数値探索の前に、作図と条件を多項式にして、有限個の解を厳密に列挙する（engine/standard/search/algebraic_branches.py）。

- 探索変数が1〜12個。
- 作図と等式で使う関数が、点・直線・円・交点・中点・垂線の足・外心・距離・面積・接する、などの定められた範囲にある。等式が比較や条件分岐を含まない（不等式は別に扱うのでよい）。

### S1.6.2 手順

```
代数的前処理(問題):
    各等式を、座標の多項式 P_i(u) = 0 にする:
        分母を払う
        √c を含む式 a + b√c = 0 は、a² − b²c = 0 に置き換える（絶対値も同様）
        元の √ や絶対値が非負であることは別に記録する
    （次数8、項60個を超えたらやめる）
    定数係数の行の組み合わせで、1次式の行を作って加える        # 距離の2乗の差など
    1次式の行で変数を消す（行の簡約）
    残りを、変数を共有しない組に分ける
    各組で:
        変数7個以下、次数4以下なら、辞書式順序のグレブナー基底を求める
        0次元（解が有限個）でなければやめる
        最後の変数だけの多項式 f を取り、平方因子を除く（次数16まで）
        他の変数が f の変数の1次式で書ければ、f の実根から全解を作る
        書けなければ、T = Σ kⁱ x_i（k = 1, 2, 3）を加えて同じことを試す
    各実根を数値の点にし、候補として渡す
CPU 時間0.5秒、全体1.5秒を超えたら、この経路をやめて通常の探索に戻る
```

### S1.6.3 何が保証されるか

多項式にするとき、分母を払い、√を2乗するので、元の問題にない根が加わることはあるが、元の実数解が失われることはない（各操作は元の等式から導かれる必要条件である）。したがって、列挙した根の中に元の問題の全ての解が含まれる。余分な根は、通常の精密化（S1.3）と最終検証（S1.5）で落ちる。前処理は候補を出すだけで、採否は数値探索で見つけた候補と同じ基準で決まる。

一部の枝が検証を通らなかったときは、浮動小数点での不合格は「解がない」ことの証明ではないとして、同じ seed の通常の数値探索も走らせ、両方の採用を合わせる（S1.2.1）。

### S1.6.4 効果（S2.2 の再掲）

代数的前処理が答えを出していた97問のうち74問は、外すと1.5倍以上遅くなった（中央値2.3倍）。ほかの226問では変化がなかった。

## S1.7 尺度座標

### S1.7.1 考え方

長さを決める条件が比だけの問題では、図全体を t > 0 倍しても条件は保たれ、求める量（比や角度）は変わらない。このとき、探索変数の1つを1に固定してよい。凍結版は、これを入力の構文から証明できたときだけ使う（engine/standard/problem/positive_scale_chart.py、engine/standard/search/scale_chart.py）。

### S1.7.2 証明の規則

全ての式に「長さの次数」を付けて確かめる。探索変数は次数1、数は次数0（0は任意の次数）。和・差は両辺の次数が等しいこと、積・商は次数の和・差、√ は次数の半分、sin・cos・tan は引数が次数0であることを要求する。点の座標は次数1、直線の式 ax + by + c は c だけが次数1、円の半径は次数1である。

次の全てが成り立てば、尺度座標を使う。

1. 全ての作図が、t 倍に対して t 倍の図を返す（定義域も t 倍で保たれる）。
2. 全ての等式の左辺と右辺が同じ次数を持つ（同次式）。
3. 全ての不等式が同次で、t > 0 倍で真偽が変わらない。
4. 求める量の次数が0。
5. ある探索変数 x について「x > 0」が条件にある。

このとき、許容な図 u に対して u/x も許容で、x 成分は1、求める量は同じである。逆に x = 1 の許容な図は元の問題の許容な図である。したがって、x = 1 に固定した問題の答えの集合は、元の問題の答えの集合と一致する。

### S1.7.3 使い方

x = 1 に固定して変数を1つ減らした系を、代数的前処理（S1.6）に渡す。得られた根は、x = 1 を加えた点として、通常の探索の候補に加える。通常の探索は置き換えず、そのまま走る（run_search.py）。

### S1.7.4 効果（S2.2 の再掲）

凍結版で尺度座標だけを外しても、時間比は1.15〜1.17倍で、計測の負荷の差と区別できなかった。10月の改良で v5（この固定を加えた版）の正解が319から322に増え、時間の中央値が4.4秒から3.1秒に下がったが、その理由はこの表からは分からない（S3）。開発外34問で尺度座標を外した版は94/102（全部入り93）、両方正解の時間比の中央値1.00だった（S4.4）。

### S1 後半：理論（S1.8〜S1.13）

## S1.8 当たるまでの時間

1回の局所探索が当たる確率を p、1回の時間を t とする。出発点を独立に選び直すと、当たるまでの回数は幾何分布に従い、期待値は 1/p である。よって当たるまでの時間の期待値は t/p となる。t を「評価1回の費用 c × 1回の評価回数 n」に分けると c·n/p である。n には、微分を差分で求めるための評価も含む。実際のsolverは出発点を適応的に選ぶので、この式はsolver全体の予測ではない。局所探索の難しさを測る物差しとして使う。二段構え（安い1段目と、補いの2段目）が有利かどうかも、この式だけでは決まらない。1段目の費用と、2段目に回す確率の両方によるからである。

## S1.9 必ず収束する球

正しい解 u* でのヤコビアンの最小特異値を s、ヤコビアンのリプシッツ定数を L とする。減衰のないガウス・ニュートン法の誤差 e は e_次 ≤ L e² / (2(s − L e)) を満たすので、半径 ρ = s/(2L) の球の中から出発すれば、誤差は毎回半分以下になる。出発点を一辺 W の箱から一様に選べば、p ≥ v_d (ρ/W)^d（v_d は d 次元の単位球の体積）。この評価は、残差が0の解でヤコビアンの列が独立であること、近くで滑らかであること、減衰のないガウス・ニュートン法を正確に計算することを仮定し、さらに確率の式は収束する球が箱に含まれることを仮定する。正次元の解や重根では仮定が成り立たないことがあり、評価の上限を持つLM法の成功を直接保証するものでもない。これは下界であり、d が大きいと p が小さいことの説明にはならない。

## S1.10 3つの系と、命題1

**3つの系。** 元の系 E は変数 u で、残差は R(u) = C(u, h(u))。ここで y = h(u) は書き換える点の作図、C は元の等式である。
- 自由点の系 Y：変数 (u, y)。残差は (C(u, y), G(u, y))。G = 0 は作図を表す等式（例：「D は直線 AI 上にある」「D は直線 BC 上にある」）で、G(u, h(u)) = 0 を満たす。
- ずれの系 Z：変数 (u, z)。点を y = h(u) + z と作図で作り直し、残差は (C(u, h(u)+z), z)。

**LM法の一歩。** MINPACK の方式（SciPy 1.18 の method="lm" の既定）では、一歩 δ は min |Jδ + r|² + λ|Dδ|² で決まる。D はヤコビアンの列の大きさから作る対角行列で、λ は信頼領域の大きさと、予測した減少と実際の減少の比から毎回更新される。

**命題1。** 書き換えた点が元の等式に現れない（C が y によらない）とする。厳密な算術で、2つの系に同じ尺度の初期化と更新規則、同じ初期信頼領域と更新規則、同じ停止条件と同じ評価の上限を使い、一歩の解が一意であるとする。このとき、z = 0 から出発した Z の反復の u は E の反復と完全に一致し、z はずっと 0 のままである。

証明（帰納法）。ある反復で z = 0 で、u と λ と D_u が E と同じだとする。Z のヤコビアンは [[J_R, 0], [0, I]] で、u の列は E と同じである（z の行は u によらない）。一歩の最小化は u と z に分かれ、z の部分は min (1+λD_z²)|δz|² なので δz = 0 となる。u の部分は E の式と同じで、同じ一歩を与える。z = 0 なので、残差のノルム、尺度を付けた変数と一歩の大きさ、予測した減少と実際の減少は、どれも E と同じになる。したがって、λ と D の更新も、一歩を受け入れるかどうかの判定も、停止の判定も同じになり、次の反復でも仮定が成り立つ。最初の反復では、z = 0 と、E と同じ u から始めるので仮定が成り立つ。∎

実装の残差は、元の等式の行に、guard の破れに比例する行と、許容判定の行（S5.1）の2行を加えたものである（scipy_multistart_backend._evaluate_augmented_residual_vector）。命題の C はこの全残差を指すので、この2行も書き換えた点によらないか、軌道上で一定である必要がある。本文の6問では、元の系とずれの系の終点が93〜100%一致し、JMO 2013 予選3 の不一致は丸め誤差と追跡した（S2.5）が、2行の依存は問題ごとには確かめていない。

命題1が言うのは u の反復が同じことで、計算の費用は同じではない（変数が増えると差分の評価や線形代数の費用が増える）。停止条件と評価の上限は、両方の系で共通の量にもとづく必要がある（変数の数に比例する上限をそのまま使えば、止まる時点が変わりうる）。本研究の LM法の上限（SciPy の max_nfev）は、差分のための評価を数えない。実際の計算は浮動小数点なので、収束しない軌道（局所解の境目の近くなど）では、丸め誤差の違いが増幅されて終点がずれることがある（S2.5）。

**自由点の系で、減衰のないガウス・ニュートン法の向きは変わらない。** C が y によらないとき、Y のヤコビアンは [[J_R, 0], [G_u, G_y]] である。G_y が正則なら、ガウス・ニュートン法の一歩 min |J_R δu + R|² + |G_u δu + G_y δy + G|² では、第2項を δy の選び方で0にできる。よって最適な δu の集合は E と同じで、E の一歩が一意（J_R の列が独立）なら一歩そのものが同じになる。G = 0（作図の上）なら δy = H δu（H は作図の微分）。J_R の列が独立でないと、最小ノルムの選び方で δu は変わりうる（例：R = u₁ + u₂ − 1、G = y − u₁ を原点から解くと、E は (1/2, 1/2)、Y は (δu₁, δu₂, δy) = (1/3, 2/3, 1/3)）。

**LM法では向きも変わる。** 減衰項 λ(|D_u δu|² + |D_y δy|²) があると、δy を動かすこと自体に費用がかかり、δy を消去すると u の問題に (G + G_u δu)ᵀ W_λ (G + G_u δu)、W_λ = I − G_y(G_yᵀG_y + λD_yᵀD_y)⁻¹G_yᵀ が加わる。また列の大きさから作る D_u も E と Y で変わる。例：C(u) = (u₁ − 1, u₂ − 1)、G = y − u₁ を u = y = 0 から、λ = 1、D = I で解くと、δu は E で (1/2, 1/2)、Y で (2/5, 1/2) になる。作図が線形でも向きが違う。したがって本文の追跡結果（向きが同じで、長さが違う）は、減衰のないガウス・ニュートン法についてのものである。

**一歩が受け入れられるかどうか。** 目的関数 f = |r|²/2、線形モデル m(s) = |r + Js|²/2 とし、実際の減少と予測した減少の比 ρ = (f(x) − f(x+s)) / (m(0) − m(s)) で一歩を判定する（信頼領域法と MINPACK の考え方）。C が y によらず、作図の上 y = h(u) から、ガウス・ニュートン法の向きに (αv, αHv) だけ進むとする。作図の等式の線形予測は0だが、実際には q_G(α) = G(u + αv, h(u) + αHv) = O(α²|v|²) が残る。元の等式の部分は E と同じなので

  ρ_Y = ρ_E − |q_G(α)|² / (2·pred)

となる（pred は予測した減少）。作図が曲がっているほど、また一歩が長いほど、ρ_Y は小さく、一歩は切り詰められる。作図の残差は一歩の2乗、目的関数への追加は4乗の大きさである。ただし一般のLM法の一歩では作図の等式の線形予測も0とは限らず、実際と予測の差には符号のある交差項が入るので、ずれが常に同じ向きに働くとは言えない。

**座標だけを変える系 Z_G。** Y を純粋に y = h(u) + z と座標変換した系は、残差 (C(u, h(u)+z), G(u, h(u)+z)) を持つ。本文のずれの系 Z は、さらに作図の行を G から z に取り替えている。C が y によらず z = 0 なら G = 0、G_u + G_y H = 0 なので、Z_G のヤコビアンは [[J_R, 0], [0, G_y]] となり、命題1の帰納法がそのまま使える（G_y が正則で一歩が一意などの条件の下で）。したがって Y と Z_G の違いは、残差の式を変えない座標の取り替えだけによる（S2.5(e)）。

**予測。** 上の機構なら、自由点の系の不利は出発点と解の距離とともに増え、解の近くでは小さくなる。ただし、近い出発点から収束しやすいこと自体は、正則性などの条件の下で既存の局所収束理論が予想することであり、この予測が当たっても、悪化の原因がこの機構だけだとは言えない（S2.5(d)）。

**書き換えた点が元の等式に現れる場合。** C が y による場合、u と z の更新が結びつくので、一般には z = 0 が保たれず、E との一致は保証されない。δz = −(BᵀB + I + λD_z²)⁻¹Bᵀ(R + A δu)（A = C_u + C_y H、B = C_y）であり、Z も E と一致しない。どれだけ離れるかは問題による（S2.5）。v6 の「命題2」（z は小さく保たれる）は一般には成り立たないので削除した。反例：h = 0、C = M + u + y を u = z = 0 から、λ = 1、列の大きさによる尺度（D² = diag(1, 2)）で解くと、Z の一歩の u は −3M/7、E では −M/2 になる。

## S1.11 値が一定であること

M = {u : F(u) = 0, G(u) > 0} の上で τ が連続で、値が有限個なら、τ は M の各連結成分の上で一定である。連結な集合の連続な像は連結で、有限集合の連結な部分は1点だからである。

注意：解の1点で「DF(u)v = 0 ならば Dτ(u)v = 0」を確かめただけでは、一定とは言えない。例えば F = y、τ = x² では、原点でこの条件が成り立つが、y = 0 の上で τ は一定ではない。そこで本文では、恒等式 s^N·P(τ) = Σ C_i F_i（s は図が退化しない条件）を作った（本補足のみの結果）。63問中24問で作り、2通りに検算した。内訳は、P そのものの恒等式が5問、P を因数にもつ消去多項式 E の恒等式が19問である。E の恒等式から言えるのは「許容図形の値は E の根に含まれる」までで、P(τ) = 0 を導くには E の余分な根を原問の実数条件で除く必要がある（± 型のように t ≥ 0 で除ける問題もあるが、例えば AIME 2007 II-15 では E = (t − 260)(t − 4)(129t − 260) の根が全て正で、符号だけでは除けない）。19問全部でこの排除を示したわけではない。また、恒等式は図の存在を示さない。例：HMMT 2013年2月 幾何2番（台形の高さ h が消えて AE² = 24）、HMMT 2008年2月 幾何6番（OP² = 17）。

msolve の「正次元」は複素数の範囲での判定で、実際に図が動くとは限らない。小さい10問を調べると、回転の固定漏れ2問、大きさの固定漏れ1問、補助点1問、退化した成分1問、本当に図が動くもの5問だった。厳密な方法が本質的に解けなかったとは言えない。

## S1.12 重根と精度

f(x) = (x − α)^ν g(x)（g(α) ≠ 0）とする。ニュートン法の誤差は e_次 ≈ (1 − 1/ν)e で、残差が δ のとき座標の誤差は (δ/|g(α)|)^(1/ν) 程度までしか言えない。円の上かつ直線の上に作った点の、接点からの符号付きの位置を h とすると R − d = h²/(R + d) で、接する条件は h について二重根になる。

## S1.13 同定に要る桁数

次数 n の最小多項式を PSLQ で探すとき、入力は (1, τ, …, τⁿ) の n+1 個である。必要な精度の目安は（n+1）×（係数の桁数）程度とされる。ただし、入力の正しい桁数、許容値（mpmath の既定では作業精度の約4分の3）、次数や係数の上限にも左右されるので、鋭い境目ではない。本補足では、公式の答えから求めた最小多項式で、この目安と作業精度（120桁以上）の差を示しただけである。正解を知った上での診断で、未知の問題への予測ではない。

**GMB。** GMB の論文 [6] の36問を、各3回、180秒で解いた。GMB は論文の既定設定（eps = 10⁻³）と厳格な設定（eps = 10⁻⁸、点の正則化なし、10万反復）の2通り。両方の出力した図を、同じ独立の検査器（80桁、条件のずれの許容 10⁻³ / 10⁻⁶ / 10⁻⁹）にかけた。データ：ブランチ nycxfb の jssa/results/gmb-comparison-20261022/、jssa/results/gmb-success-definition/。

# S3 開発外の問題での評価（本文6章）

### S3.1 開発群の入力が開発中に変わったこと

開発用323問の入力（DSL）は、solver を作る途中で直されたものがある。修正台帳（commit c30f97d9）と旧・新の DSL、移行元の Git 差分を照合すると、作図・変数・条件・求める量の変更または新規作成を確認できたのは、重複を除いて84問以上だった。残り239問について「修正なし」を保証するものではない。

修正の多くは、原文の書き移しの誤り・符号・求める量の訂正である。一方、solver への適応と言える例もある。

- JMO 2009 予選2：自由点の形式で退化した偽の解4を受け入れたのを見て、交点の指定を変えた（変数4→1）。台帳自身が「solver 側の問題を入力の表現で避けた」と記している。
- 旧302問の自由度の圧縮：性能の低下を見て、自由な座標を作図やパラメータの式に置き換えた。HMMT 2019年2月 幾何10番は38→0変数、AIME 2025 II-12 は20→1変数。圧縮前の DSL が残っていないので、効果の大きさは再検証できない。
- HMMT 2020年2月 幾何5番などは、公式解説の図の分け方を入力に使っている。これは solver が見つけた解法ではない。

修正の有無と局所探索の当たりやすさ p の関係は単純ではない（修正を確認した84問の平均 p 0.471、それ以外 0.594。難しい問題ほど修正の対象になりやすいので、修正の効果の推定にはならない）。以上から、本文では開発群の成績を「開発に使った集合での成績」とし、主な根拠を開発外の問題に置いた。

出典：jssa/difficulty/unseen-1983/failure-audit/c/answer.md、history-evidence.md。

### S3.2 開発外34問の作り方と予測

- 問題の選び方：開発用323問・2026年20問・S3.3 の54候補のどれにも含まれない、平面幾何の求値問題。AIME は2001〜2019年、HMMT は2010〜2025年の2月大会（Guts と Team を含む）。問題文と答えは公式の資料（AIME は公式の解答冊子か AoPS Wiki、HMMT は公式 PDF）で確かめ、確かめられない問題は使わなかった。
- 書き方の規則：2026年20問と同じ規則（benchmarks/new-2026/authoring-rules.md）。求める量は幾何の量そのもので、「m + n」「切り捨て」などの答えの形式は採点の側で変換する。解法から来る定数は入力に入れない。
- 入力を作る間は solver を一度も動かさず、正しい図の代入による数値の検算だけを行った。

### S3.3 最初に作った未使用26問と、その失敗の原因

開発外34問の前に、AIME 1983〜1999年と HMMT から54候補を集め、問題文と答えを公式の資料で確かめられた26問を対象に、予測を固定してから凍結版で解いた（seed 201〜205）。結果は130回中85回正解（65%）で、予測（85%以上）を下回った。誤った値を返した実行は0回だった。

失敗した10問のうち9問は、この時の入力の規則が「m + n」「a + b」「100a + b」「切り捨て」などの答えの形式を、整数の変数（既約であることを示す整数 h, k による ha + kb = 1 を含む）や床関数として入力に書き込んでいた。成功した16問には、整数の変数も床関数もなかった。開発群・2026年20問・開発外34問の規則（幾何の量そのものを求める）とは食い違っていた。

原因の確認（失敗5問を個別に調査）：
- 正しい図を100桁で入力に代入すると、5問とも全ての条件を満たした。既知の正解の図と矛盾する条件は見つからなかった（余分な図を許す誤りや、別の枝の欠落までは排除できない）。

- AIME 1996-15 は、床関数が高精度の評価で実装されておらず、評価の段階で落ちた（実装の不具合）。

書き直し（失敗を見た後の事後の作業）：整数が問題の本質である AIME 1983-12 を除く8問を、答えの形式だけを外す機械的な規則で書き直し、予測を公開してから新しい seed で解き直した（各5回、計40回）。最初の実行で保存処理の上限により記録が欠けた実行があり、保存側の上限だけを直してその実行を再実行した。再実行後の集計で40回中38回正解し、残る2回は再実行後も出力ファイルの大きさの上限で異常終了した。凍結版・元の入力での65%は変えず、書き直した結果は別に扱う。

### S4.3 厳密法との比較（開発外34問）

感度：有限でない5問のうち3問は、Singular の消去で得た候補に参照の値が含まれた（候補が参照集合と一致したのは1問）。これを正解に数えると E1 は24問、E2 は9問（変換不能も除くと5問）。主判定の定義は変えていない。

限界：時間は共有機・4並列での参考値で、solver の170回とは実行時期・負荷が異なる。msolve は各問1回。変換器の未対応や、未知数0の入力の扱いは、厳密法の数学的な限界ではない。「有限でない」の原因は、主実験の時点では調べておらず、次の段落は実行後の調査である。

有限でない5問の原因（事後）：複素数上の多項式系の次元を Singular で確かめた。AIME 2005 I-1（次元1）は中心が重なる退化した環、HMMT 2019 Guts 17（次元2）は辺の長さ0の退化した成分で、これらを除くと次元0になる。AIME 2012 I-14（次元1）、HMMT 2011 Guts 1（次元2）、HMMT 2023 Guts 3（次元1）は、正しい図そのものに形の自由度が残り、求める値だけが一定になる。座標の固定し忘れ（剛体運動）が原因だった例はない。これは複素数上の等式系の次元で、不等式付きの実の図の次元とは区別する。HMMT 2024 Guts 4 の時間切れは、入力が正五角形を直接作図する（探索変数0）のに対し、変換器が三角関数の定数を多項式の変数にしたためで、厳密法一般の不得手とは言えない。AIME 2014 II-10 で solver が同定に失敗したのは、PSLQ の係数の上限（10⁸）が答えの最小多項式の係数（14桁）より小さかったためで、保存した高精度の値から上限10¹⁴で同定し直すと正しい式が得られた（120桁でも350桁でも同じ）。出典：jssa/difficulty/capability-1024/examples/（examples-3.md、infinite-5.md）。

事後の追加比較（結果を見た後。凍結版の主結果とは別）：
- Singular の候補が参照集合と一致した AIME 2012 I-14（{375}）は、図を復元すると元の入力の最終検証（180桁）を通った。等式から BC² = 9(x² + y²) = 375 がどの許容な図でも成り立つ。事前登録の成功条件を満たすので、加えれば厳密法側は24/34。主集計の23/34は変えない。
- 退化した2問に原文から保証される非零条件を加えて飽和し、図が動く3問に求める量 T を加えて T へ消去した（Singular、各1回、20秒上限）。AIME 2005 I-1：(T − 300)(T + 4500) = 0 から 300π（7.0秒。π を扱うため T = K/π を手で加えた）。AIME 2012 I-14：T = 375（0.02秒）。HMMT 2011 Guts 1：(9T² − 1)(9T² − 25) = 0 から元の条件で1/3（0.02秒）。HMMT 2023 Guts 3：T² = 21 から √21（0.02秒）。HMMT 2019 Guts 17：20秒で打ち切り（候補の62次式までは得たが絞り込みは未確認）。4問とも復元した図が元の入力の最終検証を通った。時間は高負荷の共有機での参考値で、変換と手での導出の時間を含まない。
- したがって、厳密法との差の多くは、今回の自動手順が配置そのものを列挙する形だったことによる。問題ごとに非零条件や求める量を選べば、厳密法でも多くは短時間で解ける。

出典：jssa/difficulty/capability-1024/exp1-msolve/（summary.md、answer.md、per-problem.csv）。

### S4.10 目標値が満たす多項式の認証（事前登録9・9b）

方法（certify-1024/README.md）：入力を多項式に変換し、求める量 T を変数に加え、入力から含意される非零条件で飽和した系 J をつくる。solver の答えの最小多項式 p(T) について、J が単位イデアルでないこと、p が J の根基に属すること（Rabinowitsch の方法）、べき乗の正規形と矛盾しないことを Singular で確かめ、少なくとも一方の証拠（恒等式）を SymPy の別プログラムで検算した。所属すれば、入力の等式と非零条件を満たす任意の図で p(T) = 0 である。図の実在・一意性、答えの集合の完全性は示さない。

# S5 許容条件と出発点、当たりにくさの別の指標、外れた予測（本文5.1・7章）

検証した仮説と判定基準は、実行前に commit した（commit の番号は各項）。事後分析はそのつど「事後」と書く。局所探索は凍結版（60db4b6）の単一出発の局所探索で、探索変数のある292問のうち272問は LM法、条件より変数が多い20問は Powell 法。探索箱から一様に選んだ出発点、評価の上限は本番と同じ、1問120秒の予算。出発点の数は問題により200未満のことがある（292問で計55,097個。予算で打ち切られた38実行）。「当たり」は、終点が元の等式・不等式・箱を満たし、答えの値が公式の答えのどれかと一致すること。これは「1つの有効な配置に到達した」ことで、完成solverが答えの集合を正しく返すこととは別の評価である。

### S5.1 φ と当たる確率（seed 0、seed 1）

許容判定は凍結版の hard feasibility（問題の不等式・枝の guard、直線が定まる、三角形がつぶれない、交点の選び方、作図が評価できること）。破ると局所探索の残差ベクトルの最後の1成分が一定値（10³×10）になる。その成分は局所的に一定で勾配を持たないが、元の等式の行の勾配は残る。傾きのある罰則（guard の破れの大きさに比例する項）もあるが、本節の判定には含めない。

| φ の測り方 | p の測り方 | φ と p の順位相関 | 変数の数をそろえた偏順位相関 |
|---|---|---:|---:|
| seed 0 の出発点 | seed 0 | 0.48 | 0.38 |
| seed 1 の出発点 | seed 1 | 0.49 | 0.38 |
| 独立な乱数（1問1,024点） | seed 0 | 0.49 | 0.38 |

| | seed 0 | seed 1 |
|---|---:|---:|

### S5.2 選び直しの介入（seed 2、150問）

対象は seed 0 で φ < 1 の150問。条件 plain は通常の出発点、条件 feasible は許容判定を満たすまで同じ箱から選び直す（乱数 [2, 99, k]、初回を含め最大2001回。満たす点がなければ最後の点から探索する）。予測値は seed 0 から問題ごとに計算して固定した（predictions.csv、cd39dac）。平均は問題ごとの成功率を同じ重みで平均した値。

同じ問題・同じ出発点の分布では、全確率の式から p = φ p_F + (1 − φ) p_I。全ての出発点を許容点にできれば、変化は (1 − φ)(p_F − p_I) になる。式自体は既知の分解で、検証したのは、seed 0 で測った問題ごとの p_F・p_I が、新しい seed で実施した上限付きの方策の効果に移るかである。初回を含む提案回数を K とし、提案が独立で同じ分布に従うと仮定すると、許容点を得る確率は a_K = 1 − (1 − φ)^K、変化は Δ_K = (a_K − φ)(p_F − p_I) となる。事前登録の採点は元の式 (1 − φ)(p_F − p_I) のまま行った。

### S5.6 境界での「壁」

開発群の機構検証（事後に選んだ14問、開発用データ）。予測は実行前に固定した（jssa/strategy/astra-consult-17/G/preregistration-pilot.md、preregistration-resume.md）。

AIME 2010 II-14 では、条件を満たす出発点40個からの当たりが5/40だった。条件を破った点に一定の罰則を足す項（hard 罰則）を外すと36/40になった。一方、停止の判定（ftol・gtol）だけを変えても5/40のままだった。当たらなかった35件はすべて、「条件を破る側へ進むと等式の残差は減るが、罰則のために一歩が拒否される」形だった。この意味で、罰則は境界で一歩を拒む「壁」として働いた。罰則で一歩が拒まれることは、解へ至る許容な経路がないことを意味しない。

予測の判定：P1〜P4（この問題と、似た5問での改善、その他9問での不変）は成立。停止の変更や差分の変更だけで救えるかを見た R3〜R5 は不成立で、効いていたのは罰則の不連続さそのものだった。ただし、どの問題で逆転するかを入力の構造だけから予告する規則は得られなかった。完成 solver の1段目は NOMAD であり、この結果は完成 solver の費用や答えの集合については何も示さない。

出典：jssa/strategy/astra-consult-17/G/answer.md。

### S5.7 問う量を替えると、同定で詰まる（予測を立てない探索）

事前の予測なしの探索（Q43c）。20問（開発10問、開発外 a・b 各5問。事前のハッシュ順で選択）について、同じ入力で問う量だけを原問・長さ・面積・角・比の5種類に替え、seed 43101・43102、各180秒・1コアで解いた。交換後には独立な正解の集合がないので、表は正答率ではなく「答えを返した率」。

| 問う量 | 答えを返した問題/20（seed 43101・43102） | 数値検証を通った候補あり/40試行 |
|---|---|---:|
| 原問 | 19・19 | 40 |
| 長さ | 17・17 | 39 |
| 面積 | 14・14 | 39 |
| 角 | 7・8 | 38 |
| 比 | 17・17 | 40 |

問う量だけで答えを返すかどうかが変わった問題は、両 seed とも14/20問。ただし2問（AIME 2012 I-14、HMMT 2011 Guts 1）は替えた量が図とともに連続的に動くので、答えを返さないのが正しい。2問を除いても12/18問で差があった。「原問は答える、替えると答えない」47試行のうち44試行では、数値検証を通った候補があった。

- AIME 2019 I-12：図は一意（x = 9 + √221）。原問と比は1.3〜2.9秒で答えたが、長さ・面積・角は各0/2で、124〜179秒で答えなし。長さ・面積の最小多項式の最大係数は約1.3×10²⁰、3.1×10¹⁴で、PSLQ の係数の上限10⁸を大きく超える（比は約10⁵）。
- AIME 2014 II-10：面積 3042147√3（最大係数 約2.8×10¹³）は2回とも答えなし。角 π/3、長さ 2014√3（最大係数 約1.2×10⁷）、比1は各2/2で約3秒。次数はどちらも2で、次数だけでは差を説明できない。
- 別の同定の経路もあるため、係数の大きさだけで失敗を証明したとは言わない。

関連：答えに定数を足す・2問を合成するだけで最小多項式の定数項が跳ね、同定で落ちる例（Q43e、jssa/difficulty/sweep/e-compose/）。保存した高精度の値から上限10¹⁴で同定し直すと AIME 2014 II-10 は正しい式が得られた（S4.3）。

## S6.1 制作の記録

最初の版（2025年12月）から、PSLQ による同定と「接する」条件の命令はあった。2026年3月、それまでの探索と精密化を部分的に直し続けた結果、仕組みが複雑になりすぎたため、外部の探索器を使う構成を試した。計画書では、値が定義されない点や不連続が多い問題では単純な差分進化法は不利だとして NOMAD を第一候補にし、高精度化は mpmath に一本化した。試験では、2つの答え（312と468）を持つ問題で両方を残差 10⁻⁷⁹ まで回収でき、これを新しい構成の基本にした。【本人確認：この時期の判断と、1〜7月の没になった検討の範囲。】
