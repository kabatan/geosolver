# DSL修正版（r1）

`benchmarks/cases.jsonl` と `dsl/` の323問（研究用の凍結版）は変更していない。
このディレクトリは、323問DSL監査（AI一次確認、2026-10-21）で見つかった問題を直した別の版を置く。旧版の結果もそのまま使えるように、ファイルを分けてある。

```bash
uv run python benchmarks/research_runner.py validate --cases benchmarks/dsl-revisions/cases.jsonl
uv run python benchmarks/research_runner.py run benchmarks/local-evaluation/<name> --cases benchmarks/dsl-revisions/cases.jsonl --seeds 0,1,2
```

## 修正した問題

| id | 旧版の問題点 | r1 での書き方 |
|---|---|---|
| HMMT-2015-FEB-GEO-04 | B′,C′,A′,D′ を垂線の足にしていて、原文の定義と違っていた | 原文どおり「Bを通りBCに垂直な直線とADの交点」などにした |
| HMMT-2016-FEB-GEO-03 | target が答えの式 (三角形−円)/3 そのものだった | 図が手元にないため、X=頂点A近くの「三角形の内側で円の外側」の部分、Y=辺BCの外にはみ出した円の部分と解釈した。扇形の面積公式で直接書き、対称性による3等分は使っていない |
| AIME-2015-II-07 | target が「高さ/底辺」で、βを手で導いた結果だった | P を AB の1/3と2/3の位置に置いた2つの長方形で「面積=αw−βw²」が成り立つ、という条件を書いた。α と β は未知数として解かせる |
| AIME-2013-II-15 | 「角Bが鈍角」という場合を手で選んでいた | 原文の「鋭角三角形」では解がない（原文の不備）。そこで鋭角の条件だけを外し、三角形であることだけを条件にした。解は2つ出る（Bが鈍角の場合とAが鈍角の場合）。参照答は両方の値の集合で、公式の答えは前者 |

## 修正しなかったもの

- JMO-2010-PRE-11, JMO-2016-PRE-08: 監査では「原文の条件を解いて置き換えている」と判定した。しかし手元の書き起こしのとおりに書くと、答えが一意に決まらなかった（数値で確認）。正しいのは旧DSLの条件（それぞれ「AM:CN=MP:NP かつ AP=CP」と「AX:XD:BC=1:3:10」）で、書き起こしの方が誤っている可能性が高い。そのため旧版のままにしてある。公式の問題画像で確認が必要。
- aime-2001-1-13: DSLの内容は AIME 2001 II 第13問。id の「1」と出典表記の付け間違いで、DSL自体は正しい。id は結果ファイルとの対応を保つために変えていない。
