# 入力の同値性を確認するための補足証明

これはsolverによる探索や、出力結果を見た後の入力調整ではない。
原文と公開GMBLの条件を読み、明示されていない条件が他の仮定から従うかを
独立に確認した記録である。以下の議論は非退化・実数・厳密な条件について述べる。
数値的に小さい残差からその条件が自動的に保証される、という意味ではない。

## IMO 2000 P1: 短縮版で失われた共通接線の枝指定

現行IMO公式サイトの短縮版にはP,Qを作る対象がchordsと書かれているが、
当時のUK Team Leaderによる[一次報告の問題1（PDF 4頁）](https://www.imo-register.org.uk/2000-report.pdf)
では支持直線の交点と明記されている。この点では公開GMBLと新DSLの解釈を支持する。
一方、この一次資料には共通接線をNよりMに近い方に選ぶ指定があり、短縮版にはない。

次は、公開GMBLの全仮定を満たしても、この枝指定が従わない厳密な有理反例である。

```
C=(0,0), D=(1,0), M=(2/5,0), A=(1/5,1), B=(7/10,1),
N=(896/2005,376/401), E=(2/5,2),
P=(104/25,0), Q=(-84/25,0).
```

二つの円の方程式は

```
ω1: x²+y²-(2/5)x-(24/25)y=0,
ω2: x²+y²-(7/5)x-(91/100)y+2/5=0.
```

各円の所定四点の所属、共通接線y=1、P,Q,Eの直線交点、Eの二つの正の半直線所属は
すべて厳密分数演算で確認できる。しかし距離(M,AB)=1、距離(N,AB)=25/401なので、
選ばれているのはNに近い方の接線である。MをCDの内部に置く条件やEの半直線条件でも
この枝は除かれない。

検算の詳細をreviews/counterexample_2000_p1_tangent_branch.jsonへ保存した。
これは探索出力や性能評価ではなく、短縮された問題文の仮定の欠落を示す証拠である。
両者の原文検査に同じ枝条件を追加する等の比較契約が決まるまでは、元のIMO問題に
忠実な比較として実行しない。

## IMO 2005 P1: 開線分と閉線分の違い

六角形A1,A2,B1,B2,C1,C2はこの頂点順に狭義凸である。
A1=BならC1,C2,A1が同一直線AB上にあり、連続する三頂点が共線になる。
A2=CならA2,B1,B2が同一直線CA上にある。その他の辺端点も巡回的に同様。
同じ辺上の二点が一致する境界も狭義凸性から除外される。

したがって全条件を同時に満たす配置については、author入力の閉区間パラメータと
公開GMBLの開区間パラメータは同じ領域を与える。

## IMO 2005 P5: P,Q,Rの非退化性

狭義凸四角形の対角線の交点Pを原点とし、独立な方向ベクトルu,vについて

```
A=a u, C=-c u, B=b v, D=-d v   (a,b,c,d>0)
```

と置く。BC=DAかつBE=DFより、ある0<t<1で

```
E=(1-t)b v-tc u,
F=-(1-t)d v+ta u
```

となる。EFのu成分はt(a+c)、v成分は-(1-t)(b+d)なので、EFはACにもBDにも
平行でなく、Q,Rは一意に存在する。

P,E,Fが共線なら外積からab=cd。u,vを単位ベクトルとしてBC=DAの両辺を二乗し、
a=cd/bを代入すると

```
|BC|^2 = (d^2/b^2)|BC|^2
```

となる。辺は非零なのでb=d、従ってa=cとなり、BCとDAは平行である。
これは原文の非平行条件と矛盾する。

よってP,Q,Rは相異なり非共線である。DSLのArea(P,Q,R)>0は新たな仮定ではなく、
他の仮定に含意される非退化性の明示化である。端点E=B,F=DまたはE=C,F=Aは
交点の一意性を壊すので、原文の三角形の定義域にも入らない。

## IMO 2007 P2: BCEDの円周順序

B=(0,0), C=(1,0), D=(1+a,h), h≠0とし、s²=a²+h²と置く。
F=(1-t)D+tC (0<t<1) なら、平行四辺形のAから引いたAFとBCの交点は
G=(g,0), g=1/t>1である。EC=EF=EGより

```
E.x=(1+g)/2,
E.y=(g-1)(s²-ag)/(2hg)
```

となる。BCDの外接円はx²+y²-x-(s²+a)y/h=0である。この式にEを代入し、
4h²g²/(g-1)を掛けるとs²(g+1)(g²-s²)=0となるため、g=s>1。
従ってhE.y=(s-1)(s-a)/2>0であり、直線CDに対するBとEの符号付き外積の積は
-s(s-1)(s-a)/2<0。EはBCと同じ半平面側の、Bを含まない弧CD上にある。
よって円周上の順序はB,C,E,Dとなり、追加した狭義凸性は他の仮定の帰結である。

この代数展開と符号判定はauthorの導出とは独立に再確認した。

## IMO 2008 P6: BC上の接点がCより先になること

Bを原点、A=(1,0)、C=c(cosθ,sinθ), c>0, 0<θ<πとする。
鏡映しても接線・凸性の条件は変わらない。両接点がBAとBCの正の半直線上にあるので、
Bからの接線長はともにs>1である。円の中心はO=(s,s tan(θ/2))、
半径はr=s tan(θ/2)となる。

凸四角形ABCDについてD=αA+βCと書くと、α>0, β>0, α+β>1である。
k=(1+cosθ)/2∈(0,1)と置く。Oと直線ADの距離がrになる条件を二乗して展開し、
非零の因子を除くと

```
s(s-1)(1-α)=βc(s-k)
```

を得る。右辺は正なのでα<1。凸性からβ/(1-α)>1であるため

```
c < s(s-1)/(s-k) < s.
```

BC上の接点のBからの距離はsなので、接点はCより先にある。GMBLのBC側に
not(on-seg ...)が書かれていなくても、他の仮定がこれを含意する。
この結論にCDへの接線条件は使っていない。接線式の展開も独立に照合した。

## IMO 2015 P3: 円周順序の仮定は省略できない

これは含意証明ではなく、名義上のGMBL条件と原文との差を示す厳密な反例である。
次の点は、有理数の分数演算だけで照合できる。

```
B=(0,0), C=(1,0), A=(3/5,2), H=(3/5,3/25),
Q=(93/61,75/61),
K=(136782/147365,-1026/29473).
```

ABCは鋭角三角形でAB²=109/25>104/25=AC²。Hはその垂心である。
外接円Γの方程式x²+y²-x-47y/25=0へQ,Kを代入するといずれも厳密に0となり、
(H-Q)·(A-Q)=0および(H-K)·(Q-K)=0も厳密に成立する。
ところがK.y<0であり、A,B,C,K,Qという原文の円周順序にはならない。

これはGMBの探索・出力の失敗を測定したものではない。原文と公開GMBLの数学的な
仮定が同値でないことを示す、手で導出した座標の検算である。実装のacute-triが
この形をサンプルできるかどうかとも独立である。原文順序をGeoSolverだけに課して
既存のGMB受理成績と直接比較することはできず、比較契約の追加決定が必要となる。

## IMO 2015 P4: F,Gの円周順序と安定した構成

B=(0,0), C=(1,0), A=(a,h), h>0とし、D=(d,0), E=(e,0), 0<d<e<1とする。
円Γの中心がAであるためa=(d+e)/2。その半径rは

```
AB²-r²=de>0,  AC²-r²=(1-d)(1-e)>0
```

を満たす。Γの内部にA、外部にB,Cがある。ΩのうちAを含む円周部分はB,Cへ
至る前にそれぞれΓを横切るので、二交点は一つずつ弧ABと弧ACにあり、いずれもy>0。

Ωをx²+y²-x+w y=0, w=(a-|A|²)/hと書く。F=(fx,fy)としたとき、
BDFの外接円はx²+y²-dx+v y=0, v=w-(1-d)fx/fyである。
AB上のBと異なる交点K=λAについて

```
λ=1-(1-d)(a-h fx/fy)/|A|².
```

Kが線分AB上にあり、F≠A,Bであるためλ<1。従ってa fy-h fx>0となり、
Fは直線ABについてCと反対側、すなわち弧AB上にある。もう一方のGは弧AC上であり、
A,F,B,C,Gの円周順序が得られる。GMBLのclosedなon-segが許す端点K=AはF=A/Bを、
E=CはF又はG=Cと補助三点円の退化をもたらすので、非退化な全条件では残らない。

なお、Fを未知のΩ上の点としてΓ所属を等式で課す表現では、探索途中のFはまだ
Γ上にない。そこでG=Intersect(Γ,Ω,exclude=F)とすると、Fがどちらの交点にも
一致しない途中配置で二候補が残り、構成が未定義になる。この変換上の欠陥は
本評価前にG=Reflect(F,Line(A,O))へ修正された。ΓとΩはいずれも中心線AOの鏡映に
不変なので、最終条件下では厳密にもう一つの交点を与え、途中でも構成が定義される。
これは結論X∈AOを仮定した構成ではない。

## IMO 2016 P1: 内角二等分線の枝

平行移動・回転・一様拡大縮小によりC=(0,0), F=(1,0)とする。
直角三角形BCFでは0<B.x<1、A=(a,0)についてa=1+FB>1である。

DA=DCを二乗して引くとD.x=a/2。従ってADとABは、どちらもAC方向への射影が
正である。この半平面内の二本の半直線に対し、ACがmodπの角二等分線となるなら、
ACは外角二等分線でも反対向きの半直線でもなく、正向きの内角二等分線である。

またEA=EDから

```
(E-A) dot (D-A) = |D-A|^2/2 > 0
```

を得る。一方、(C-A) dot (D-A)=a^2/2>0なのでAEとACの双方がAD方向へ正射影を
持つ。二つ目のmodπ二等分条件でも同じ理由により正向き内角枝が選ばれる。

一般にはGMBのi-bisector残差だけでは内外角を区別できないが、この問題では
他の仮定がその区別を補っている。DSLの正向きの内角guardは意味を変えない。

## IMO 2019 P2: QがBB1の内部にあること

鏡映を必要なら使い、A=(0,0),B=(1,0),C.y>0とする。B1=bC (0<b<1)、
v=P-B1、alpha=angle(B,A,C)と置く。Pは三角形内部なので、vからCへ反時計回りに
測った角phiは(0,pi)にある。

P1=B1-rv (r>0)より、P1C=(1-b)C+rvである。二つの非平行ベクトルの正の和の
方向はその間に厳密に入るため、

```
0 < angle(P,P1,C) < phi
```

である。原文のangle(P,P1,C)=alphaからphi>alphaが従う。
vの偏角はalpha-phiであり(-pi,0)にあるためv.y<0、すなわち0<P.y<B1.y。
PQがABに平行でQが直線BB1上であることから、QはBB1の内部にある。

したがって公開GMBLにQの線分所属assertがなくても、既存のP1条件と他の
非退化条件からそれが従う。新DSLで直接dot<0を記すことは追加仮定ではない。
