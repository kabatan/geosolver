# 36問の独立入力監査

担当: `independent_review`。authorとは別に、全36問の原資料・GMBL・構成式・条件式・
auditを読んだ。点を固定することによる形の自由度の消失、結論の混入、内外角、
交点枝、線分・半直線、円周順序、退化条件を確認した。

## 現在の状態：原問題を基準とする比較

2026-08-31のユーザー承認後、2000P1・2015P3だけに不足条件を補った別のGMB入力を作成した。
`alignment/` に両方向の同値性証明・構文確認・補足レビューを保存し、現在は36/36問が入力準備合格。
公式GMB入力34問＋補正版2問を用いる「原文準拠版」であり、公式入力をそのまま再現した実験と区別する。
下記の旧監査は未変更の公式入力についての記録として保持し、過去の成績は置き換えない。

- 現在の公開GMBLだけで原文の仮定を共通検査できるもの: 34件。
- 元のGMBLに実際の仮定欠落があるため比較契約を保留するもの: 2000P1、2015P3。
- case/audit/GMBL/原文PDFのhash不一致: 0。2000P1の追加一次資料もhash照合済み。

各 `IMO_YYYY_PN.json` が、監査した入力のhashと個別所見を持つ。

`original_conditions_covered_by_gmbl=false`や実行ロックを上書きしない。

## 実際に見つけた問題

1. **2000P1の接線の選択条件。** 現行公式サイトの短縮版にない条件が、当時の英国団長の
   一次報告に記されている。共通接線を「NよりMに近い方」に選ぶ指定はGMBLからも欠ける。
   他の仮定ではその枝が定まらないことを厳密有理反例で確認した。新DSLには条件を追加済み。
2. **2015P3の円周順序。** 原文のA,B,C,K,Qという巡回順がGMBLから欠ける。
   これも他の全仮定を満たす厳密有理反例で確認した。新DSLは原文の順序を保持する。
3. **2015P4の変換時の構成。** 未知点Fがまだ両円の交点でない途中に`exclude=F`で他方の
   交点を選ぶ構成は未定義になる。両円の中心線による鏡映へ置き換え、最終条件下の
   同値性を独立に確認した。これは元solverの性能runに基づく修正ではない。

2件の原文欠落は、既存のGMB成績の失敗や誤受理を実測したという意味ではない。
片側の入力だけを直して「同じ仮定を与えた比較」と報告しないための保留だった。
現在は別のGMB入力へ不足分を加え、すでに原文に忠実だったGeoSolver入力と仮定をそろえている。

## 本当は欠落でなかった条件

2007P2の円周順序、2008P6のBC接点の位置、2015P4のF/G順序、2016P1の内角枝、
2019P2のQの線分所属などは、GMBLに個別のassertがなくても他の仮定から従う。
端点・非退化性を含む独立の証明は `EQUIVALENCE_ARGUMENTS.md` に保存した。
単に表記が見つからないことを理由に非同値と判定しなかった。

2010P2はユーザー承認済みのBC内部の共通範囲に両入力を統一した。
2014P4も両者とも内部点を用いる。これらは原文をclosedと解釈した全境界配置を
網羅する変換ではないことを、caseレビューで明示している。

## 証跡

- `counterexample_2000_p1_tangent_branch.json`: 接線枝欠落の有理反例と全条件の厳密残差。
