## 1. Component-local target exactification

The shortest disposable route is not a new algebraic backend.  Reuse
`MSOLVE_EXACT_WITNESS_BIGINT_TRANSPORT_REOPEN_V1`, which already has lossless
BigInt transport and a static upper surface of 20 reversible QQ covers, 18
endpoint-compatible covers, and 9 capped sources in 9 anonymous signatures.
NewRUR/PACE is the same RUR proof state with higher observed startup cost;
alphaCertified proves convergence/realness of a regular numerical root but not
an exact algebraic target descriptor; the existing bounded regular-chain lane
improved 0/61 sources.

Minimum repair, per endpoint:

1. bind immutable source bytes/SHA, full ordinary proposal SHA, endpoint bits,
   compiler/replay ledger SHA, and the exact QQ cover;
2. require one exact RUR factor and one rational isolating box to select a
   unique real parameter root; proximity only orders boxes and is never proof;
3. independently verify the RUR identities and evaluate every coordinate in
   the selected real embedding;
4. run the unchanged QQBar replay of every construction, source equation,
   definedness condition, guard, bound, branch/selector, and raw target;
5. factor the exact raw target polynomial, choose a unique irreducible factor
   by an exact isolator, and recompute the factor-local real-root ordinal;
6. release only that replayed descriptor.  Preserve the numerical baseline,
   set target-image completeness false, and never early-stop from a local root.

This safely handles a target identity valid on one component even when
`T-q` has nonzero remainder modulo the global source ideal.  It is a connector
repair of the existing msolve exact-witness lineage, not a new RUR candidate.

D0 must contain reducible two-target systems, guard-filtered components,
close disjoint boxes, selector branches, and a component-collapsed target;
positive-dimensional, non-radical/repeated, overlapping-box, wrong-factor,
source-mutation, guard, raw-target, and RUR-identity negatives fail closed.
Variable/equation permutation, rational row scaling, and reversible affine
target transforms must preserve the exact descriptor set.  Advance only with
gains on three unrelated generated structures, no false/extra descriptor, and

the already-qualified static panel.

Primary basis: Rouillier-style RURs and exact isolating boxes; the repository's

isolation.  alphaCertified remains only a regular-root existence comparison.

## 2. Universal-rigidity stress certificate

For a bar framework in affine dimension `d`, Connelly's super-stability
sufficient condition requires:

- the candidate coordinates affinely span `R^d`;
- an exact equilibrium stress matrix `Omega` with `Omega*1=0`, `Omega*P=0`,
  zero nonedge entries, `Omega >= 0`, and rank `n-d-1`;
- no nonzero symmetric `d x d` matrix `S` satisfying
  `(p_i-p_j)^T S (p_i-p_j)=0` on every edge.

For bar-only graphs stress-sign conditions are vacuous.  Genericity is not an
assumption of this sufficient theorem and must not be inferred numerically.
The Gortler--Healy--Thurston generic global-rigidity theorem is not a substitute
for universal rigidity of a special algebraic realization.

Every edge length must be an exact consequence with the same value for every
source-valid configuration.  Safe source-only closure admits exact constant
`Distance` equalities; constant-radius `OnCircle`/`PointOnCircle`/circle
intersection edges; equality propagation to an already fixed distance; and
midpoint/reflection consequences only after their parent distance is fixed.
Line incidence, intersection, parallelism, perpendicularity, midpoint, or
circle membership without a fixed radius is not a bar edge.  Fixed anchors may
form their complete exact-distance clique.

The anonymous upper census signature is `(n,m,degree multiset,fixed-anchor
count,edge-provenance histogram,target operator)`.  It first requires a
connected target-bearing graph, a congruence-invariant target, and `m>=2n-3`;
then exact stress/conic checks are later filters.  The explicit-edge quick
ceiling was only 4/56 missing sources, in four singleton shapes, with none
meeting `m>=2n-3`.  Construction-derived fixed-edge closure has not yet proved
the required four sources/two signatures, so the route is `HOLD_CENSUS`.

## 3. Target-cell Positivstellensatz cover

The proposed cell/gap proof is implementable as an exact certificate checker,
but not as a current certificate producer.  It overlaps the archived exact
Positivstellensatz extraneous-root filter directly, and composes that filter
with the existing target-constrained NRA/Hermite existence lanes.  The current
real-radical SOS candidate verifies supplied bounded rational Gram identities
only; its four-source/two-signature producer gate is still unmet.

For finite zero-dimensional sets, existing RUR plus exact Hermite/Tarski sign
queries decides the same cell emptiness more directly.  For genuinely
positive-dimensional inequality sets, no Archimedean hypothesis, practical
degree bound, or exact rational Gram recovery is available.  SDP failure would
not be evidence of feasibility.  Therefore this route is
`STOP_BEFORE_CODE_NO_EXACT_PRODUCER`; reopen only after bounded rational
Positivstellensatz proposals occur on four sources in two signatures and all
descriptor-existence witnesses join independently.
