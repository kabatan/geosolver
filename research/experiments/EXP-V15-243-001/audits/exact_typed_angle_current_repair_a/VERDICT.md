## Disposition

**STOP before any formal or real-data execution.** The typed-angle exact
identity is mathematically sound on the bounded DSL subset, but the current

campaign harness.

## Blocking findings

1. The arm contract is invalid. `arm.json` records mechanism hash
   `0f2868ee2ee1f3281b0865b14d2e7728fe19c82853759b17900f92386960d0fe`,
   while frozen `worker.py` is
   `3efbe3e0735f801a1512c50072ae226dad8ebb58b9ba3bed0464f19b9fd62a57`.
   Its uppercase ID `EXACT_TYPED_ANGLE_EQUALITY_REPAIR_A` also violates the
   common launcher's lowercase arm-ID contract. The official launcher must
   reject this arm before a worker starts.
2. `_run_repair_a` passes `0.75 * timeout_seconds` into the complete current
   exact outer. That outer calls the ordinary/current HP attempt with the
   reduced value. Thus the stated “unchanged current route first” is false: an
   ordinary or exact authority needing the last quarter can be changed into a
   timeout/insufficient-allocation failure even when the side lane never
   activates. Returning that shortened baseline object by identity does not
   establish recall non-regression.
3. Side routing is based on a substring of a child `failure` string. The
   artifact is checked for schema, source SHA, endpoint SHA, rejected status,
   and false authority, but is not joined to the baseline mapping's recorded
   child-result SHA/process receipt; `completed`, wall-budget, truth/safety
   flags, exact `failure_type`, and an exact typed failure code are not required.
   This is not truth or case routing and a false activation still reaches the
   exact fail-closed verifier, but it is not an adequate provenance boundary
   for spending the side quota.
4. The copied repair closure is self-measured rather than fixed to reviewed
   expected bytes. Local boundary, fallback, candidate, DAG, and QQBar files are
   hashed into the dry plan, which usefully detects dry/execute drift, but no
   preregistered constants reject an unintended copy. The caller-selectable
   runtime root, resolved Julia executable, Julia project/manifest, and Nemo
   environment are not hash-bound; the plan explicitly reports the environment
   as non-hermetic. The common Python version probe does not close this exact
   runtime gap.

## What passed static review

The new relation is restricted to bare, keyword-free, same-arity
`Angle(...)=Angle(...)`. Two-argument evaluation succeeds only for two exact
lines and uses normalized `(|dot|,|cross|)` in `[0,pi/2]`; three-argument
evaluation succeeds only for exact points and uses `(dot,|cross|)` in
`[0,pi]`. Both reject zero vectors/lines, prove the unit identity, require the
expected principal-domain bounds, and compare both components. This matches
the public unsigned radian semantics, distinguishes supplementary point
angles, ignores line orientation, and fails closed on mixed arity/type,
keywords, arithmetic wrappers, degeneracy, and qreflect.

On a side success, source and endpoint bytes are strongly bound, numeric
multi-precision replay and exact QQBar source/guard/bounds/raw-answer replay are
conjoined, the minimal polynomial/root ordinal/isolator pass the copied
canonical boundary, and the unchanged outer service remains responsible for
exact identity deduplication. Side failure returns the shortened baseline
mapping by identity and adds no telemetry. Nested search/exact children are in
the existing guarded process group and use the per-core lease. The candidate
entrypoint itself has no campaign global lock; direct invocation is therefore
ineligible for evidence.

## Smallest causal repair

- Give the current exact outer the original full endpoint timeout. Attempt the
  side only from wall time actually left after it returns, capped at 25% of the
  original allocation. If less than the side minimum remains, return the exact
  current result object. Do not reserve time by shortening current/ordinary
  work.
- Pass the baseline mapping into the activation check. Require its recorded
  child-result SHA to equal the just-read atomic artifact, require all immutable
  safety fields and the accepted guarded-process receipt, and match the pinned
  baseline's exact failure type and complete message (or, preferably, a new
  versioned `ANGLE_EQUALITY_AMBIGUOUS_FULL_TURN` code). Substring matching is
  insufficient.
- Freeze expected SHA-256 values for every copied executable file and cascade
  them to a lowercase `arm.json` with the actual entrypoint hash. Force one
  frozen runtime root and bind the Julia executable/version plus project and
  manifest bytes used by Nemo. Add one-byte mutation tests for every local and
  runtime dependency.
