# EXACT_TYPED_ANGLE_EQUALITY_V1

- **Hypothesis:** QQBar's scalar angle subtraction creates spurious full-turn lifts. A direct same-typed `Angle = Angle` is injective in the DSL's declared principal domain and can be proved without constructing an angle scalar.
- **Authorized reopen evidence:** aggregate only: 44 ambiguous-lift attempts over 3 cases; four relevant constraints have direct `Angle(lhs) = Angle(rhs)` source shape. No case identity, value, truth, scorer, development item, or family label was inspected.
- **Mechanism:** for point angles in `[0,pi]`, compare exact normalized `(dot, |cross|)` using denominator-free squared identities plus the exact dot sign. For unoriented line angles in `[0,pi/2]`, compare exact normalized `(|dot|, |cross|)` by squared identities. This distinguishes supplementary point angles without a square root or `2*pi` lift.
- **Applicability:** direct equality only; both sides must have the same typed arity, radian unit, and domain. Every ray/line norm must be proved nonzero and every coordinate algebraic. Oriented/full-circle angles do not exist in the audited DSL and fail closed.
- **Authority preservation:** activation requires exact source equations, typed guards, definedness, branch/selector/phase, raw target, square-free minimal polynomial, real-root ordinal, and isolator replay. A failure at any obligation leaves the original result unchanged. The adapter activates only on the exact prior ambiguous-lift failure.
- **Fallback/safety:** mixed/unknown unit or domain, arithmetic around an angle, zero vectors, undecidable algebraic signs, incomplete replay, and non-direct relations fall back. `qreflect` is explicitly excluded for a separate ablation. No ID/value/family routing exists.
- **Nearest prior work / reopen gate:** the old QQBar and witness-semantics routes used `(left-right).is_zero()` and enumerated full turns. The reopen gate is the authorized ambiguous-lift aggregate plus a typed direct equality, removing that failure cause rather than tuning lift bounds.
- **D0:** generated exact structures `6/6`; supplementary/full-turn/orientation/zero/mixed-unit/replay near-misses rejected `11/11`; metamorphic scale/rotation/reflection/permutation `4/4`; static direct-shape accepts `4/4`, invalid shapes reject `5/5`; containment and timeout fail-closed pass. Fifteen unit tests pass on Python 3.12.11/SymPy 1.14.0 pinned to CPU15.
- **Disposition:** `D0_PASS_SOURCE_ONLY`. The authorized four source relations are shape-compatible, but runtime activation remains conditional on exact typed-domain and replay proofs. No formal/dev/98/scorer/truth run was performed.
