# Guard/equation swap prospective breadth v1

## Hypothesis and mechanism

At a finite, square, full-rank equality root rejected by a source-proven
differentiable strict guard, temporarily dropping one residual row creates a
one-dimensional level set.  Following that set toward increasing guard margin,
solving the swapped system `F_-j=0, g=tau`, and then restoring the complete
source system can enter a source-valid basin that an ordinary solve fixed at
the invalid equality root cannot reach.

The candidate is a direct copy of the frozen proposal kernel with its square
and swapped-system rank test replaced by column-pivoted QR.  SVD is retained
only to obtain the one-dimensional kept-system null tangent.  It receives no
case/family/name/target/truth/outcome input.  CPQR/SVD rank, row conditioning,
guard transversality, literal bounds and current numerical state are the only
selection signals.  Swapped equations never have authority; every exported
point requires a cache-bypassing complete source replay.

## New prospective D0

The old 60/60 graph/circle/coupled panel was not rerun.  This arm instead uses
three unseen infinite structures:

- a rotated transcendental helix with an already-interior decoy margin;
- two negative roots separated by a curved quadratic strict guard and a
  rational carrier;
- a rotated four-dimensional exponential/trigonometric triangular chain.

Each structure has positive, unsatisfiable-negative and near-miss strata.
Near misses rotate among a singular entry root, an unproven smooth-looking
margin, and an opaque source branch.  Constants, rigid frames, physical units
and residual order vary without entering candidate code.

Promotion requires gains in at least two structures, false promotions zero,
fresh replay, and representation invariance.  Aggregate evidence is recorded
in `BREADTH_AGGREGATE.json`.

## Result

`D0_PASS`: 108 prospective source-only cases completed.  The candidate gained
all 36 positive instances across all three structures, while the identity
root control gained 0.  The 72 negative/near-miss cases produced no source
root and false promotions were 0.  Positive median callback counts were
20--27.  Negative instances were deliberately expensive (median 143--181),
so any future connection remains capped at one of four lanes and must stop on
neutral exact recall plus work regression.

## Thin connection decision

`HOLD_NO_THIN_EXACT_CONTROL_SEAM`.

The common-control search binding exposes starts and final endpoint evidence,
but not a complete analytic source Jacobian plus source-proven differentiable
strict-margin gradients at invalid equality roots.  The archived real adapter
already attempted the available typed seam: its aggregate audit found only
one of 18 sources structurally capable and zero runtime entries on that source.
Reusing that fixed postlude would repeat a terminal zero-activation experiment.

Broadening analytic coverage requires compiler/AD/trajectory work rather than
a candidate-private wrapper and breaches the 30-minute/5% infrastructure cap.
No common harness, compiler, scorer, worker, HP path or exact authority was
changed.  This candidate therefore stops after D0 until a future solver exposes
the required anonymous analytic observation natively.  Any later connection
must keep at least 75% byte-identical baseline work, cap this lane at 25%, and
return every proposal to the canonical verifier.
