# Archive champion-v2 + POC + exact-outer reopen

## Hypothesis

The historical champion-v2/PointOnCircle arm is worth reopening only if every
positive-dimensional ordinary HP authority is demoted to a proposal until the
existing `exact_outer_decorator` independently confirms the same primitive
minimal polynomial/root ordinal by exact source, guard, and branch replay.
The existing zero-dimensional source-exact route remains its own authority and
must not be sent through numerical HP.

The historical `131` target-only record is motivation for the reopen, not a
proof or a result produced by this candidate.

## Mechanism

- Hash-pin and import `champion_v2_poc_preloaded.py`; do not copy or edit it.
- Preserve the PointOnCircle-repaired HP bridge, endpoint order, reservoir,
  budgets, and historical ordinary `_run_hp_candidate` callable.
- Expose only the reviewed per-core lease from `hp_lock_scheduler/policy.py` as
  the minimal resource-runtime shim required by `exact_outer_decorator`.
- Globally require `CONFIRM_ALL_AUTHORITIES`; conflicting environment settings
  fail before the historical worker is used.
- Exact descriptor mismatch, malformed success, insufficient confirmation
  budget, missing exact evidence, source/guard/branch mismatch, and child
  failure all fail closed. Resource-busy statuses remain requeue terminals.
- Keep the champion-v2 zero-dimensional source-exact authority objects and
  execution route unchanged; only add PLAN custody metadata.

No source content, case ID, family, truth value, expected target count, answer
value, or prior outcome participates in routing.

## Reopen and promotion gates

This is an archive-reopen candidate, not a promotion claim. Run only source
and unit smoke while the formal CPU set is occupied. A benchmark owner may
later compare it against the unmodified default exact-outer control under the
common harness. Formal score, safety, speed, and holdout gates remain those of
the campaign plan.

Reopen is invalid if the frozen historical/POC, exact-outer, authority-boundary,
or lease-policy hashes change, or if the PLAN no longer reports exactly one
ordinary HP capture and global `CONFIRM_ALL_AUTHORITIES`.

## Source-only evidence

The local tests use synthetic sources only. They check historical callable and
zero-authority identity, global mode, exact-match publication, insufficient
deadline rejection, malformed-success rejection, truth-blind PLAN fields, and
hash-closed dependency custody. They do not inspect scorer data or real cases.
