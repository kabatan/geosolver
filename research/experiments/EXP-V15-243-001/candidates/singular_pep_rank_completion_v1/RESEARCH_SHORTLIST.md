# Primary-source diversification after the 551-candidate audit

`rg` was run over all 551 `EXP-V15-243-001/candidates` directories and 1,278
card/decision/ledger files.  Search keys were mathematical state and failure
mechanism, not candidate names.  Truth, scorer, holdout and case-level outputs
were not opened.

## 1. Singular polynomial-eigenproblem rank completion — selected for D0

- **State:** polynomial matrix coefficients, normal rank/corank, randomized
  rank-completing perturbations, left/right eigenvectors, cross-trial labels.
- **Failure addressed:** a structurally singular elimination pencil has
  identically zero determinant, so ordinary companion/resultant enumeration
  cannot separate its true eigenvalues from arbitrary singular fibres.
- **Distinctness:** existing bounded polynomial/homotopy lanes require a
  full-rank square witness and explicitly reject rank-deficient counters;
  Macaulay/RUR lanes store a finite quotient algebra, not randomized
  normal-rank/eigenvector consensus on a singular polynomial matrix.
- **Primary:** Hochstenbach, Mehl, Plestenjak,
  [Numerical methods for eigenvalues of singular polynomial eigenvalue problems](https://arxiv.org/abs/2406.16832).
- **Real seam:** only a safely recognized small polynomial-matrix/elimination
  pencil; proposals still require canonical source replay.  This is the
  thinnest executable D0, but real compiler work is not authorized here.

## 2. Exceptional-stratum projection with fibre products

- **State:** source parameter ball, replicated solution fibres, projection to
  the nearest discriminant/exceptional parameter stratum.
- **Failure addressed:** solution count, dimension or multiplicity changes
  under tiny source-coefficient perturbations.
- **Distinctness:** coefficient monodromy tracks roots in a generic regular
  fibre and local monodromy tracks branches at one singular germ; neither
  searches parameter space for the nearby locus where solution structure
  changes.  Archive searches found descriptive `exceptional stratum` guards,
  but no fibre-product/projection implementation.
- **Primary:** Cobian, Hauenstein, Wampler,
  [Robust Numerical Algebraic Geometry](https://arxiv.org/abs/2403.18749).
- **Gate:** reproduce one parameter exceptional stratum stably from generic
  perturbations before any source connector.  Backend work exceeds a toy D0.

## 3. Nonsquare interval-Krawczyk surface patches

- **State:** an `m<n` interval patch, tangent/free coordinates and a generalized
  inclusion certificate for a positive-dimensional variety.
- **Failure addressed:** ordinary Krawczyk rejects rank-deficient/singular or
  positive-dimensional solution sets because it proves an isolated square root.
- **Distinctness:** all archived interval candidates use square isolated-root
  contraction/exclusion, Hansen--Sengupta, or subdivision ordering.  This is a
  different theorem and output object: a certified local manifold patch.
- **Primary:** Burr, Hauenstein, Lee,
  [Certified surface approximations using the interval Krawczyk test](https://arxiv.org/abs/2602.07718).
- **Gate:** an interval extension plus stable positive nullity.  Do not reopen
  ordinary box/radius/order tuning.

## 4. Flat-truncation Moment-SOS atom extraction

- **State:** moment/localizing matrices, relaxation bound, flat ranks and
  extracted atomic support.
- **Failure addressed:** bounded low-degree polynomial systems whose real roots
  are missed by local or complex-path search.
- **Distinctness:** archive `sum-of-squares` mentions concern residual merits
  and sign proofs; no moment matrix, localizing matrix, flat truncation or atom
  extraction candidate was found.  RUR/homotopy do not carry a positive-measure
  certificate.
- **Primary:** Huang and Nie,
  [Finite convergence of the Moment-SOS hierarchy for polynomial matrix optimization](https://arxiv.org/abs/2403.17241).
- **Gate:** zero relaxation bound and stable flat truncation, with every atom
  replayed.  Heavy SDP work stays below the 25% side quota.

Noise-aware rank-deficient SQP was retained as a fifth reserve, but not selected:
its residual/Jacobian seam is thin, while the archive already contains several
normal/tangential trust-funnel, rowspace and semismooth mechanisms.  A D0 would
first need to demonstrate that measured evaluator noise, rather than another
rank threshold or funnel parameter, is the causal new state.
