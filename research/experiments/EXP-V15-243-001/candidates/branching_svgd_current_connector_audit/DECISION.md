# Branching SVGD current-campaign connector decision

**STOP_BEFORE_CONNECTOR.  No connector was created.**

The hash-bound current progressive/adaptive binding has source replay, but its
parent-visible record is only an endpoint plus scalar semantic validity,
residual norm, guard, and hard-feasibility assessment.  The raw residual
vector, Jacobian/score, source bounds, and branch token required by the frozen
Branching-SVGD D0 are available only inside a disposable local-kernel child and
are not returned.  The deep adapter explicitly returns `checkpoint=None`,
`checkpoint_resumable=False`; both scheduler adapters declare original-start
reexecution rather than a current checkpoint.

The current adaptive full wrapper replaces the baseline search seam.  It does
not expose a hook that runs an immutable completed baseline first and then
charges a surplus-only side tail.  Consequently it cannot prove baseline
allocation >=75%, side wall/callback <=25%, or byte-identical baseline result
custody for this connector.

The runtime does contain exact-outer `CONFIRM_ALL_AUTHORITIES` and the existing
champion-v2 zero-dimensional source-exact authority.  Those downstream
authorities cannot manufacture the missing numeric side seam; without an
emission route, no positive-dimensional Branching-SVGD proposal is proven to
reach exact authority.

Because the callable seam is incomplete before considering any source,
truth-free static activation is zero anonymous strata rather than the required
two.  Development/formal source inputs were deliberately not opened: input
inspection cannot repair a missing API.  Count-matched immigration cannot be
run on the same callback/replay path for the same reason.

## Excluded non-current particle tail

The clean worktree `codex/exp-progressive-exact-particle-tail@742e7f4d` has an
after-baseline tail wrapper, but it is absent from `experiment@5f9dee88` and is
a fixed-particle consensus/equality-force framework, not role-coloured
Branching SVGD.  Importing it would change the frozen D0 mechanism and add a
non-current population framework, so it is not a valid thin connector seam.

## Frozen reopen gate

Reopen only when all of the following are independently present in the current,
hash-bound common BASE:

1. A post-completion surplus-tail hook that cannot mutate baseline RESULT bytes
   and enforces baseline >=75% and side wall/callback <=25%.
2. The same callback ledger exposes raw residual, Jacobian or score, semantic
   validity, source bounds, guard/hard state, and branch token without a second
   numerical kernel.
3. The unchanged D0 mechanism statically activates through that callable seam
   on at least two anonymous source strata; unsupported sources fail before
   offspring generation.
4. Count-matched immigration is callable on the identical population schedule,
   callback ledger, and replay path.
5. Every positive-dimensional proposal goes through fresh source replay and
   global exact-outer `CONFIRM_ALL_AUTHORITIES`, while the zero-dimensional
   authority route and objects remain identical.

The audit read source bytes only.  It did not import or execute a solver, open
case inputs/results, use scorer/truth/validation/sealed data, or use CPUs 0--6.
